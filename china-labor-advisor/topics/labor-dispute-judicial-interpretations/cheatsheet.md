## 高频条文速查（劳动者视角）

| 场景 | 条文 | 结论 |
|---|---|---|
| 有工资欠条只讨工资 | 解释一15 | **直诉**，免仲裁（普通民事） |
| 工资调解协议不履行 | 解释一51 | **直诉**（普通民事） |
| 仲裁超期不裁决 | 解释一12+仲裁法29/43 | **直接起诉**（六项正当事由除外） |
| 仲裁不立案/逾期不决定 | 解释一5/6+仲裁法29 | 法院**受理** |
| 部分不服起诉 | 解释一16 | **全裁决不生效**，法院重审 |
| 终局判断（数项） | 解释一19 | **每项**均≤12个月最低工资才算终局 |
| 终局+非终局混含 | 解释一20 | 按**非终局**（双方可诉） |
| 劳动者起诉 vs 单位撤销 | 解释一21 | 单位撤销**不受理**；驳回/撤诉后30日再申请 |
| 不予执行 | 解释一24 | **七事由**，举证在单位；裁定后30日可诉 |
| 撤销被驳后抗辩 | 解释一25 | **同理由不得**再提不予执行 |
| 公司合并/分立 | 解释一26 | 告**合并后/实际用工**（不明全列） |
| 无照经营 | 解释一29 | 告单位或**出资人** |
| 挂靠 | 解释一30+解释二2 | 告用工方+**执照出借方**（用工主体责任） |
| 转分包给无资质 | 解释二1 | **承包人**承担用工主体责任 |
| 关联公司混同用工 | 解释二3 | 报酬福利**共同担责**（同意内部约定除外） |
| 期满继续用工 | 解释一34+解释二11 | 默示原条件续延；**超1个月**可要求续订（含无固定）；单位解除担后果 |
| 离职协议翻盘 | 解释一35 | **显失公平/重大误解/欺诈胁迫**→撤销 |
| 竞业没约定补偿 | 解释一36 | 履行后可要**30%月均工资**（最低工资兜底） |
| 竞业没接触秘密 | 解释二13 | 条款**不生效**/超比例部分**无效** |
| 在职竞业（高管等） | 解释二14 | **有效**，无需补偿 |
| 单位3个月不付竞业补偿 | 解释一38 | 劳动者可**解除**约定 |
| 单位提前解竞业 | 解释一39 | 劳动者多拿**3个月**补偿 |
| 违反竞业 | 解释一40+解释二15 | **继续履行+返还补偿+违约金** |
| 加班费举证 | 解释一42 | 劳动者先举"存在"→单位掌握考勤不提供的**不利后果** |
| 口头变更（降薪调岗） | 解释一43 | 实际履行**超1个月**=有效——**及时书面异议** |
| 被开除/降薪/算年限 | 解释一44 | **单位负举证责任** |
| 迫使解除（欠薪等五情形） | 解释一45 | 报酬+**经济补偿**+可赔偿金 |
| 换壳工龄 | 解释一46 | 五情形"非因本人原因"→**合并计算** |
| 没通知工会就解除 | 解释一47 | **违法解除**（2N）；**起诉前**补正除外 |
| 营业期限届满解散 | 解释一48 | **经济补偿** |
| 欠薪保全 | 解释一49 | 困难/逃匿可能→**免担保**；生效后**3个月**内申请执行 |
| 规章制度 | 解释一50 | **民主程序+不违法+公示**；**合同约定优先** |
| 二倍工资精度 | 解释二6 | 按月；不满一月按**实际工作日** |
| 二倍工资免责 | 解释二7 | 不可抗力/劳动者**故意重大过失**（单位举证） |
| 三期/服务期/工会任期 | 解释二8 | 期满**法定续延**，不罚二倍 |
| 视为无固定后 | 解释二9 | 可要求**补签书面**；期间**不再二倍** |
| 两连签认定 | 解释二10 | 延长满1年/自动续延届满/**换主体**/其他规避 |
| 服务期特殊待遇 | 解释二12 | 损失赔偿=**实际损失+过错+已履行年限**（非38条解除才赔） |
| 违法解除后选路 | 解释二16 | 六情形=**不能继续履行**（转2N）；否则可恢复 |
| 职业病没做离检 | 解释二17 | 解除后请求**继续履行**支持（一审辩论终结前补检/拒检例外） |
| 空窗期工资 | 解释二18 | 违法解除→恢复前一日按**正常工资**；双方过错分担 |
| "自愿放弃社保" | 解释二19 | **无效**→38条解除+补偿；单位**补缴后索回补贴** |
| 时效抗辩 | 解释二20 | **仲裁阶段不提=失权**（诉讼/再审不得提，新证据除外） |

## 二倍工资"封顶图"

```
用工之日
  │  第1个月：补签窗口（不罚）
  ▼
满1个月 ──────────────────────── 满1年
  │  第2个月起：【每月二倍差额】    │
  │  （不满一月按实际工作日，解释二6）│
  │  免责：不可抗力/劳动者故意重大过失 │
  │  扣除：法定续延期（三期/服务期/   │
  │        工会任期，解释二8）        │
  ▼                                ▼
【最多11个月差额】          视为无固定期限合同
                               │
                               ├─ 可要求【补签书面】（解释二9）✓
                               └─ 期间【不再二倍】（解释二9）
```

## 违法解除"两条路"决策卡（解释二第16–18条）

```
被违法解除
  │
  ├─ 排雷：六情形命中吗？
  │    ① 仲裁/诉讼中合同期满且无续订续延情形
  │    ② 已享受养老保险待遇
  │    ③ 单位破产
  │    ④ 单位解散（合并/分立除外）
  │    ⑤ 已建新劳动关系且影响工作/拒解除
  │    ⑥ 其他客观不能
  │
  ├─ 命中 → 选【2N赔偿金】
  └─ 不命中 → 选【继续履行】
        ＋ 空窗期工资（解除决定日→恢复前一日，正常标准）
        ＋ 职业病岗位未做离检的 → 继续履行近乎必赢（解释二17）
```

## 竞业限制"三查"速查卡（解释一36–40+解释二13–15）

```
① 效力：接触了秘密吗？
   否 → 条款【不生效】（解释二13一）
   是 → 范围适配吗？超比例 →【超额无效】（解释二13二）
② 对价（离职后条款）：约定补偿了吗？
   没有 → 履行后可要【30%月均工资】（最低工资兜底）（解释一36）
   单位3个月没付 →【解除约定】（解释一38）
   单位提前解约 → 多拿【3个月】（解释一39）
③ 违约：违反有效约定 →
   【返还已付补偿 + 违约金 + 继续履行】（解释二15+解释一40）
   无"付钱买断"
在职条款（高管/高技/保密）：有效、无需补偿（解释二14）
```

## 时效速查（调解仲裁法27+解释二20）

| 争议 | 时效 |
|---|---|
| 一般 | **1年**（知道或应当知道权利被侵害起） |
| **欠薪** | **在职期间不受限**；**离职起1年** |
| 中断 | 主张/请求救济/对方同意→**重新计算**（留痕！） |
| 中止 | 不可抗力→原因消除后**继续计算** |
| 抗辩失权 | 单位**仲裁阶段不提**时效→诉讼/再审**无效**（新证据除外）（解释二20） |

## 当事人"找得出钱的人"速查

| 情形 | 告谁 |
|---|---|
| 公司合并 | **合并后单位** |
| 公司分立 | **实际用工单位**；分不清→**全部分立后单位** |
| 无照/吊销/届满仍经营 | 单位或**出资人** |
| 挂靠借用执照 | 用工方+**执照出借方** |
| 转分包给无资质个人 | **承包人**（用工主体责任） |
| 承包经营 | **发包方+承包方**双列 |
| 招用未离职劳动者 | 新单位：第三人/共同被告（依请求） |
| 关联公司混同用工 | **关联单位共同**（报酬福利） |
| 外企代表处 | 代表处+可**追加外国企业** |
| 派遣用工 | **派遣+用工共同**（仲裁法22条） |
