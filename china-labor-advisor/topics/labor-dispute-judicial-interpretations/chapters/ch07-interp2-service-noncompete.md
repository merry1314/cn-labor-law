# Chapter 7: 解释（二）服务期与竞业限制（第12–15条）

## Core Idea
本章是**服务期**与**竞业限制**争议的2025年审判口径：服务期+特殊待遇的**损失赔偿裁量规则**（第12条）、**未接触秘密的竞业限制条款不生效/部分无效**（第13条）、**在职期间竞业限制条款有效**（第14条）、**违约后返还补偿+违约金并行**（第15条）。总体方向：**竞业限制必须"对价+适配"**——没接触秘密的条款不生效，范围超比例的超额部分无效。

## Frameworks Introduced
- **服务期损失赔偿裁量（第12条）**：
  - 前提：单位**约定服务期**+**提供特殊待遇**（超出正常劳动报酬的对价）
  - 劳动者**违反约定提前解除**且**不符合劳动合同法第38条**单方解除情形
  - 单位请求**赔偿损失** → 法院**综合考虑**：① **实际损失** ② **当事人过错程度** ③ **已经履行的年限** → 确定赔偿数额
  - When to use: 注意与劳动合同法第22条**违约金**的区分——第22条是**专项培训费用**的按比例违约金；本条针对的是**"特殊待遇"**（住房补贴、安家费、股权/期权、特殊津贴等非培训对价）——单位没有约定违约金时，仍可主张**损失赔偿**（裁量确定）
  - 劳动者**依38条被迫解除**的 → 单位**不得**主张（单位过错在先）
- **未接触秘密→竞业条款不生效/部分无效（第13条）**——竞业限制的"适配原则"：
  - **情形一**：劳动者**未知悉、接触**单位的商业秘密和与知识产权相关的保密事项 → 请求确认竞业限制条款**不生效** → **支持**
    - When to use: 前台、保洁、无涉密内容的普通岗位被"全员签竞业"——条款对劳动者**不生效**（无需履行，也不欠单位"履行义务"）
  - **情形二**：条款约定的**范围、地域、期限**等与劳动者**实际知悉、接触**的保密事项**不相适应** → 请求确认**超过合理比例部分无效** → **支持**
    - 例：接触的是华东区A产品线客户名单，条款却约定"全球+全部产品+2年"→超出合理比例部分无效
    - When to use: 不是一刀切无效，而是**"超额无效"**——合理部分（与知悉范围适配的）仍有效
- **在职期间竞业限制条款有效（第14条）**：
  - 单位与**高管、高技、其他负有保密义务人员**约定**在职期间**竞业限制条款
  - 劳动者以"**不得约定在职期间竞业限制**"或"**未支付经济补偿**"为由请求确认**无效** → **不予支持**
  - When to use: 澄清两个常见抗辩：① 在职期间竞业限制（"在职不得自营/兼职竞争业务"）**可以约定**且有效——这是忠实义务的合同化，不以离职补偿为前提 ② 在职条款**不需要付补偿**（补偿制度针对的是**离职后**竞业限制）
  - 边界：主体仍限于**高管/高技/保密人员**（与劳动合同法第24条一致）——普通员工的"在职竞业"条款仍受第13条"未接触秘密不生效"约束
- **违约：返还补偿+违约金并行（第15条）**：
  - 劳动者**违反有效**的竞业限制约定
  - 单位请求：① **返还已支付的经济补偿** ② **支付违约金** → **依法支持**（两项并行）
  - When to use: 竞业限制"三件套"后果：**返还补偿+违约金+继续履行**（解释一第40条：付违约金后单位仍可要求继续履行）——违反成本=拿回的钱+违约金+2年内不能就业

## Key Concepts
- **服务期特殊待遇赔偿**：实际损失+过错+已履行年限三因素裁量（第12条）
- **适配原则**：未接触秘密→不生效；范围超比例→超额无效（第13条）
- **在职竞业有效**：高管/高技/保密人员；不以补偿为前提（第14条）
- **违约双付**：返还补偿+违约金（第15条，+解释一第40条继续履行）

## Mental Models
- "对价-适配"双检验（竞业条款审查）：① **接触了吗**？（没接触→不生效）② **范围适配吗**？（超合理比例→超额无效）——两个都过，条款才"全额有效"
- "在职/离职二分"（第14条）：**在职**竞业=忠实义务，有效且无需补偿；**离职后**竞业=需要**按月补偿**对价——审查条款先分"在职还是离职"
- "服务期两类型"（第12条 vs 劳动合同法22条）：**培训费**→法定违约金（按比例，22条）；**特殊待遇**（非培训）→**损失赔偿**裁量（第12条）——单位"给钱留人"的两条索赔路径
- "违约三件套"（第15条+解释一40条）：返还补偿+违约金+继续履行——违反竞业限制没有"付钱买断"选项

## Anti-patterns
- **"全员竞业"模板合同**: 第13条——普通员工未接触秘密→条款**不生效**；全员签竞业既无效力又增加单位补偿支出
- **竞业范围"全球全行业"**: 第13条二——与知悉范围**超比例**部分**无效**；签约时把范围写宽不如写实
- **用"在职竞业"卡劳动者兼职**: 第14条仅限**高管/高技/保密人员**——普通员工的在职竞业条款仍可能被第13条击穿
- **服务期"特殊待遇"当违约金依据**: 第12条是**损失赔偿**（裁量），不是**违约金**（约定）——没有约定违约金时，单位按实际损失+过错+已履行年限主张，数额通常**低于**约定的天价违约金
- **劳动者依38条被迫解除还赔服务期**: 第12条明确排除——单位欠薪/不缴社保迫使离职的，服务期赔偿责任**不成立**

## Worked Example
小孙（销售总监，掌握全国客户名单与定价体系）离职后入职竞争对手，单位已按月支付竞业补偿。处理（单位视角+劳动者视角）：
1. **条款有效性**：小孙**接触**了核心商业秘密→条款**生效**（第13条一不成立）；范围"全国+本行业"与其知悉范围**适配**→无超额无效
2. **违约后果**（第15条）：单位请求**返还**已付补偿（如已付6个月）+**违约金**（约定50万，法院可酌减※民法典585条）→**并行支持**
3. **继续履行**（解释一第40条）：单位可要求小孙**继续履行**竞业限制（2年期内不得在竞业单位工作）
4. **若小孙抗辩"没给够补偿"**: 单位已按月支付→抗辩不成立；若单位**3个月未付**→小孙可先依解释一第38条**解除**竞业限制→之后的入职**不构成违约**
5. **对照：若小孙是前台**（未接触秘密）：条款**不生效**（第13条一）——入职竞业单位**不违约**，已付补偿的返还争议也失去基础

## Key Takeaways
1. 服务期+**特殊待遇**+劳动者违约提前解除（非38条）→单位可索赔，按**实际损失+过错+已履行年限**裁量（第12条）
2. 竞业限制**未接触秘密→条款不生效**；范围**超合理比例→超额无效**（第13条）
3. **在职期间**竞业限制（高管/高技/保密人员）**有效**，不以补偿为前提（第14条）
4. 违反**有效**竞业限制→**返还已付补偿+违约金**并行（第15条）；加解释一第40条**继续履行**
5. 劳动者依**38条被迫解除**的，单位不得主张服务期赔偿（第12条排除）
