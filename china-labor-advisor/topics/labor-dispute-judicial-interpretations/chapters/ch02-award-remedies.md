# Chapter 2: 解释（一）裁决效力与救济（第16–25条）

## Core Idea
本章解决"仲裁裁决出来后在法院层面怎么算数"：**部分起诉=全裁决不生效**（第16条）、**多劳动者部分起诉的分效力**（第17条）、**终局/非终局以裁决书载明为准+未载明时的认定**（第18、19条）、**混含事项按非终局**（第20条）、**劳动者起诉与单位撤销申请的冲突处理**（第21、22条）、**撤销的审理方式**（第23条）、**不予执行七事由**（第24条）、**执行与撤销的竞合：中止/恢复/终结**（第25条）。核心逻辑：终局裁决对**单位**的救济是"撤销"（中院、有限事由），对**劳动者**是"起诉"（基层、全审）——且**劳动者一旦起诉，单位的撤销通道关闭**。

## Frameworks Introduced
- **部分起诉→全裁决不生效（第16条）**：
  - 当事人对裁决**部分事项**不服起诉 → **整个裁决不发生法律效力**
  - When to use: 单位赢了3项、劳动者不服其中2项起诉 → 全部6项回到法院重审——"部分不服"的代价是整体重启
- **多劳动者分效力（第17条）**：
  - 仲裁对**多个劳动者**裁决后，**部分**起诉 → 对**起诉者**不生效；对**未起诉者**生效（可申请执行）
  - When to use: 集体案件——"先下手者"把与自己相关的部分拉进诉讼，其他人不受拖带、可直接执行
- **裁决类型以裁决书为准（第18条）**：
  - 终局/非终局**以裁决书载明**为准
  - **未载明**时：单位向**基层法院起诉**→法院审查：认定**非终局**→受理；认定**终局**→基层法院**不受理**，告知单位**30日内向中院申请撤销**；已受理的→驳回起诉
- **"数项均不超"才终局（第19条）**：
  - 裁决涉及**数项**（报酬+补偿+赔偿金多项）→ **每项**确定的数额均不超过当地月最低工资标准12个月金额的，才按**终局裁决**处理
  - When to use: 单位常用"把单项金额做大"（如把补偿金算成13个月）试图把案件顶出终局——劳动者反查：**逐项**核对是否超线
- **混含按非终局（第20条）**：同一裁决**同时包含**终局事项与非终局事项 → 按**非终局裁决**处理（双方都可15日起诉）
- **劳动者起诉 vs 单位撤销（第21条）**——冲突规则：
  - 劳动者依第48条（调解仲裁法）向**基层法院起诉**，单位同时依第49条向**中院申请撤销** → 中院**不予受理**；已受理的→**驳回申请**
  - **被驳回起诉或劳动者撤诉的** → 单位可自收到裁定书起**30日内**再向中院申请撤销
  - **效果**：劳动者的起诉权**优先**——单位不能"一边撤一边看"；只有劳动者这条路走死了（被驳回/撤诉），单位的撤销通道才重开
- **撤销裁定终审（第22条）**：中院的驳回/撤销裁定为**终审裁定**——没有再审上诉（但可依第20条解释二的时效规则等走审判监督程序，极窄）
- **撤销审理方式（第23条）**：中院**组成合议庭开庭**审理；阅卷+调查+询问后无新事实证据理由的，可**不开庭**；可组织**调解**→调解书→不履行可执行
- **不予执行七事由（第24条）**——执行阶段的"第二次审查"：
  - 被申请人（通常是单位）举证证明生效裁决书/调解书有下列之一+审查核实 → 依**民事诉讼法第237条**裁定**不予执行**：
    1. 事项不属仲裁范围/仲裁机构无权仲裁
    2. 适用法律法规确有错误
    3. 违反法定程序
    4. 证据是伪造的
    5. 对方隐瞒足以影响公正裁决的证据
    6. 仲裁员索贿受贿、徇私舞弊、枉法裁决
    7. 执行该裁决**违背社会公共利益**
  - 不予执行裁定中应告知：收到裁定**次日起30日内**可就该事项向法院起诉
  - When to use: 劳动者申请执行时，单位的最后抗辩机会——但**举证责任在单位**，且只有七事由
- **执行与撤销竞合（第25条）**：
  - 终局裁决→劳动者申请**执行**，单位申请**撤销** → 法院裁定**中止执行**
  - 单位**撤回**撤销申请或申请被**驳回** → **恢复执行**
  - 裁决被**撤销** → **终结执行**
  - **关键堵漏**：单位撤销被驳回后，又想在**执行程序中用相同理由**提不予执行抗辩 → **不予支持**
  - When to use: 防止单位"撤销+不予执行"双通道重复拖延——同一事由只能用一次

## Key Concepts
- **部分起诉全不生效**（第16条）
- **数项均不超才终局**（第19条）
- **混含按非终局**（第20条）
- **起诉优先于撤销**（第21条）
- **撤销终审**（第22条）
- **不予执行七事由**（第24条）
- **中止/恢复/终结执行**（第25条）
- **事由用一次**：撤销被驳后不得以同理由再抗不予执行（第25条）

## Mental Models
- "终局三判断"模型：①裁决书写了吗？（没写→18条审查）②数项都≤12个月吗？（19条逐项）③混含了吗？（混含→非终局，20条）——三步走完才知道单位能不能诉
- "通道优先级"模型：劳动者起诉（基层全审）> 单位撤销（中院有限）> 单位不予执行抗辩（七事由，且与撤销事由不重复）——劳动者的程序位阶始终最高
- "中止-恢复"执行模型：单位申请撤销≠执行停摆的永久状态——撤申请被驳回=恢复执行，裁决被撤销=终结——劳动者申请执行时同步盯住撤销进展

## Anti-patterns
- **单位"化整为零"顶出终局**: 19条逐项判断——把一项金额做大不能救其他项，但**任何一项**超线就整体变非终局（单位角度是"争取"，劳动者角度是"核对"）
- **单位撤销+不予执行"双保险"**: 25条堵死同理由二次抗辩——单位第一次用掉的事由，执行阶段不能再用
- **劳动者"赢了不申请执行先等撤销结果"**: 撤销中止执行只是程序状态——主动申请、盯进展，驳回后立即恢复
- **对部分裁决"认了不诉"但整体被拖**: 16条——只要一方对任何一项起诉，全裁决不生效，没起诉的部分也进诉讼重审（既是风险也是机会：对劳动者有利的部分也在诉讼中重新确认）

## Worked Example
某终局裁决（每项均≤12个月最低工资）：单位付工资2万+补偿1.5万。劳动者不服（认为补偿算少了），向基层法院起诉；单位不服，向中院申请撤销。处理：
1. **冲突处理**（第21条）：中院对单位的撤销申请**不予受理**——劳动者的诉讼通道优先
2. **诉讼**：基层法院审理；若法院**驳回起诉**（如程序问题）→ 单位在收到裁定书**30日内**可向中院申请撤销（第21条后段）
3. **若劳动者胜诉/调解**：单位不履行→劳动者申请执行；单位不能再以"撤销被否"的相同理由提不予执行（第25条）
4. **集体版本**：3名劳动者同裁决，仅小周起诉→裁决对小周不生效、对另两人**生效**（第17条）——另两人可立即申请执行，不被小周的诉讼拖住

## Key Takeaways
1. 部分事项起诉→**全裁决不生效**（第16条）
2. 终局判断三步：裁决书载明→数项逐项≤12个月→混含按非终局（第18–20条）
3. 劳动者起诉**优先**于单位撤销；驳回/撤诉后单位30日再申请撤销（第21条）
4. 撤销裁定**终审**（第22条）；中院合议庭审理，可调解（第23条）
5. 不予执行**七事由**+举证在单位；裁定后30日内可起诉（第24条）
6. 撤销被驳后**不得**以同理由再提不予执行（第25条）
