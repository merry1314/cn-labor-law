# Chapter 4: 解释（一）实体规则（第34–54条）

## Core Idea
本章是解释（一）的"实体干货"，覆盖**合同期满未续签的默示续延**（第34条）、**离职协议效力**（第35条）、**竞业限制全套规则**（第36–40条：未约定补偿=30%月均工资+最低工资兜底、单位3个月不付钱劳动者可解约、单位可提前解约但补3个月、违约后仍须继续履行）、**无效合同后果**（第41条）、**加班费举证**（第42条）、**口头变更超1个月有效**（第43条）、**单位决定的举证倒置**（第44条）、**迫使解除的五情形**（第45条）、**非本人原因换单位的工龄合并**（第46条）、**未通知工会=违法解除（起诉前补正除外）**（第47条）、**经营期限届满解除的补偿**（第48条）、**欠薪保全免担保**（第49条）、**规章制度三要件+合同约定优先**（第50条）、**调解协议约束力+工资调解直诉**（第51条）、**撤销错误解除+变更给付数额**（第53条）。

## Frameworks Introduced
- **期满继续用工的默示续延（第34条）**：
  - 合同**期满**后劳动者**仍工作**、单位**未表示异议** → 视为双方同意**以原条件继续履行**
  - **一方提出终止**的 → 法院**应予支持**（注意：此时终止=单位/劳动者提出终止无固定期限状态——单位提出的，多数地区按终止固定期限合同处理，可能触发经济补偿※）
  - 应签**无固定期限**而未签 → 法院可视为双方存在**无固定期限合同关系**，以原合同确定权利义务
  - When to use: "到期没续签还在干"——不是没有合同，是**默示以原条件续延**；单位不能主张"没合同所以随便走"
- **离职协议（N+1私了协议）效力（第35条）**：
  - 就解除/终止手续、工资、加班费、补偿、赔偿金等达成的协议：**不违反强制性规定**+**无欺诈胁迫乘人之危** → **有效**
  - 存在**重大误解或显失公平** → 当事人请求**撤销**的 → 支持
  - When to use: "离职协议签了还能翻吗"——原则上不能（有效）；两条翻盘路：**显失公平/重大误解**（如按0.5个月补偿实际应7个月2N）或**欺诈胁迫**（诱导签"个人原因辞职"）
- **竞业限制五规则（第三十六至四十条）**——劳动者与单位双向：
  - **未约定补偿**（第36条）：有竞业限制约定但未约定经济补偿，劳动者**履行了**竞业限制义务 → 可要求按**离职前12个月平均工资的30%按月支付**；**低于履行地最低工资的，按最低工资**支付
    - When to use: "签了竞业但没说给钱"——不是白干：履行了就有30%的法定补偿请求权
  - **约定了补偿的正常履行**（第37条）：除另有约定外，单位要求履行/劳动者履行后要求付补偿 → **均支持**（解除时即启动，不以"是否还有秘密"为前提）
  - **单位3个月不付钱**（第38条）：因**单位原因**导致**3个月未支付**经济补偿 → 劳动者请求**解除竞业限制约定** → 支持
    - When to use: 单位"只约束不给钱"超过3个月 → 劳动者发函解除竞业限制，之后自由就业
  - **单位提前解约**（第39条）：竞业限制期限内，单位请求**解除协议** → 支持；此时劳动者可请求单位**额外支付3个月**竞业限制经济补偿
    - When to use: 单位"我不需要你竞了"=也要付钱——额外3个月是法定"解约对价"
  - **违约后继续履行**（第40条）：劳动者违反竞业限制**支付违约金后** → 单位仍可要求**继续履行**竞业限制义务（违约金≠"买断"竞业义务）
- **无效合同后果（第41条）**：
  - 合同无效但劳动者已付出劳动 → 单位按劳动合同法**第28条**（报酬，参照相同相近岗位）+**第46条**（经济补偿情形）+**第47条**（补偿计算）支付**劳动报酬和经济补偿**
  - 因**单位原因**订立无效合同致损害 → **赔偿**经济损失
- **加班费举证（第42条）**——劳动者与单位各担一段：
  - **加班事实存在** → **劳动者**负举证责任
  - 但劳动者有证据证明**单位掌握**加班事实存在的证据（考勤、审批、打卡系统）而单位**不提供** → **单位承担不利后果**
  - When to use: 加班费案件"两步举证"：先拿出加班存在的初步证据（打卡截图、加班群记录、排班表照片）→ 锁定单位掌握的完整考勤 → 单位拿不出=按劳动者主张的风险
- **口头变更超1个月有效（第43条）**：
  - 协商一致变更合同**虽未采用书面形式**，但**实际履行口头变更超过1个月**+不违反法律法规+不违背公序良俗 → 以"未采用书面形式"主张**变更无效**的 → **不支持**
  - When to use: 降薪调岗的"默认风险"——反对就要**及时书面异议**并**拒绝履行**；默认干满1个月，变更大概率锁死
- **单位决定的举证倒置（第44条）**：因单位作出的**开除、除名、辞退、解除劳动合同、减少劳动报酬、计算工作年限**等决定发生争议 → **用人单位负举证责任**
  - When to use: "被开除"案件的举证责任分配——单位必须证明解除合法（事由+程序），不是劳动者证明"我没错"
- **迫使解除五情形（第45条）**：单位有下列之一**迫使劳动者提出解除** → 单位支付**劳动报酬和经济补偿**，**并可支付赔偿金**：
  1. 暴力、威胁、非法限制人身自由**强迫劳动**
  2. **未按约定**支付报酬或提供劳动条件
  3. **克扣或无故拖欠**工资
  4. **拒不支付**延长工作时间的工资报酬
  5. **低于最低工资**支付工资
  - 定位：劳动合同法第38条的细化（1994年《劳动法》第32条口径的延续）——被迫解除+补偿（+可索赔）
- **工龄合并计算（第46条）**——"非因本人原因换单位"的年限接续：
  - 劳动者**非因本人原因**从原单位被安排到新单位工作，原单位未支付经济补偿，劳动者依**劳动合同法第38条**与新单位解除，或**新单位提出**解除/终止 → 请求**原单位工作年限合并计算**为新单位年限 → 支持
  - **五情形认定**（"非因本人原因"）：
    1. **原工作场所、原岗位**不变，合同主体由原单位变更为新单位
    2. 单位以**组织委派或任命**形式调动
    3. 因单位**合并、分立**等调动
    4. 单位及其**关联企业轮流订立**劳动合同
    5. 其他合理情形
  - When to use: "换壳辞退"（从A公司转到集团内B公司再被裁）——N按**合并年限**算，不能"清零重来"
- **未通知工会=违法解除（第47条）**：
  - 已建立工会的单位解除**符合第39、40条**，但**未按第43条事先通知工会** → 劳动者请求**赔偿金**（2N）→ **支持**
  - **但**：**起诉前**单位已**补正**程序的 → 除外
  - When to use: 单位"实体合法但程序漏了通知工会"=**违法解除**——程序不是走过场；单位的补救窗口=**起诉前**补通知工会
- **经营期限届满的补偿（第48条）**：劳动合同法施行后，因单位**经营期限届满不再继续经营**致合同不能继续履行 → 劳动者请求**经济补偿** → 支持
  - When to use: 有限责任公司"营业期限到期解散"——员工不是"合同自然结束"，是单位原因终止→N
- **欠薪保全免担保（第49条）**：
  - 诉讼中劳动者申请**财产保全**：经济确有困难，或**有证据证明单位欠薪逃匿可能** → **减轻或免除担保**义务，及时保全
  - 保全裁定应告知：裁决/裁判文书**生效后3个月内**申请执行，逾期**解除保全**
  - When to use: 单位有跑路/转移资产苗头→立即申请保全（免担保）；**3个月**申请执行期是硬节点
- **规章制度效力（第50条）**——"三要件+一个优先"：
  - 经**民主程序**制定+**不违反**国家法律法规政策+已向劳动者**公示** → 可作为确定双方权利义务的依据
  - 内部规章制度与**集体合同或劳动合同**约定不一致 → 劳动者请求**优先适用合同约定** → 支持
  - When to use: 规章制度是"地板"不是"天花板"——合同约定优于制度；制度缺三要件之一（尤其**公示**）不能作为管理/解除依据（联动劳动合同法第4、39条抗辩）
- **调解协议的约束力（第51条）**：
  - 在**调解仲裁法第10条**调解组织主持下达成**具有劳动权利义务内容**的调解协议 → 具有**劳动合同的约束力**，可作为法院裁判根据
  - **仅就劳动报酬**达成调解协议，单位不履行 → 劳动者**直接起诉** → 法院**按普通民事纠纷受理**（与第15条工资欠条直诉并列为"直诉"通道）
- **人民调解司法确认（第52条）**：在**人民调解委员会**主持下**仅就给付义务**达成的调解协议，双方认为有必要 → 可共同向调委会所在地**基层法院申请司法确认**（确认后直接强制执行）
- **撤销错误解除+变更给付（第53条）**：
  - 单位开除、除名、辞退等处理或解除**确有错误** → 法院可判决**撤销**（恢复劳动关系）
  - **追索劳动报酬、养老金、医疗费、工伤保险待遇、经济补偿金、培训费及其他相关费用**等案件，**给付数额不当**的 → 法院可予以**变更**
  - When to use: 法院不是"只确认有没有、不管给多少"——数额不当可直接改判（给付之诉的变更审理）

## Key Concepts
- **默示续延**：期满继续用工=原条件继续履行（第34条）
- **离职协议**：有效为原则；显失公平/重大误解/欺诈胁迫可撤销（第35条）
- **竞业限制**：未约定补偿=30%（最低工资兜底）；3个月不付→劳动者解约；单位提前解约→补3个月；违约后仍须履行（第36–40条）
- **加班费两步举证**：劳动者初步证据+单位掌握证据倒置（第42条）
- **口头变更1个月锁死**（第43条）
- **单位决定举证倒置**：开除辞退降薪算年限——单位负举证（第44条）
- **迫使解除五情形**（第45条）
- **工龄合并**：非本人原因换单位五情形（第46条）
- **未通知工会=违法解除**（起诉前补正除外）（第47条）
- **营业期限届满=应补偿**（第48条）
- **欠薪保全免担保+3个月执行期**（第49条）
- **规章制度三要件**：民主程序+不违法+公示；合同约定优先（第50条）
- **工资调解协议直诉**（第51条）
- **给付数额可变更**（第53条）

## Mental Models
- "离职协议审查表"（第35条）：①违反强制性规定吗？②有欺诈胁迫乘人之危吗？③**显失公平**吗（对比法定应得：2N/补偿/欠薪差额，差距悬殊=显失公平）④重大误解吗——四问任一成立→撤销请求
- "竞业限制时间轴"（第36–39条）：签了没写钱→履行后按30%要钱；单位3个月不给→劳动者解约；单位主动提前解约→劳动者多拿3个月——**任何时点劳动者都不吃亏**
- "加班费举证接力"（第42条）：你的初步证据（截图/记录）→ 接力棒交给单位的考勤系统 → 单位交不出 → 你赢
- "换壳工龄"（第46条）：岗位没变、公司变了=同一份工作——五情形抓住"非因本人原因"，N按合并年限
- "规章制度地板论"（第50条）：制度只能抬高不能压低个人合同——合同与制度冲突，**合同优先**

## Anti-patterns
- **默认接受口头降薪满1个月**: 第43条——超1个月+内容不违法=变更锁死，再主张无效不被支持；**当天**书面异议+拒绝履行才是正解
- **签完离职协议才发现"少了"**: 第35条翻盘靠**显失公平/重大误解**——金额差距越大越有利；"我觉得亏了"但金额接近法定标准→难撤销
- **竞业限制"白干"**: 没写补偿≠无效白干——**履行了**就有30%请求权（第36条）；不履行的自由，履行的要价
- **加班费"裸告"**: 第42条第一步是**你的**初步证据——什么都没拿就去告，败诉风险高；先固定打卡/群记录/排班
- **没通知工会就解除**: 第47条——实体再合法，漏工会=违法解除（2N）；单位补救窗口只有**起诉前**
- **规章制度"没公示"也拿来开除**: 第50条三要件——没公示=不能作为依据（联动劳动合同法第4条）

## Worked Example
小林2020年入职A公司，2024年A公司与集团B公司"人员划转"（原岗位原办公地点，合同改与B签），2025年B公司以"经营调整"为由解除。小林主张：工龄应自2020年算（合并4.5年）。处理：
1. **工龄合并**（第46条）：原场所原岗位+合同主体变更=第46条（一）"非因本人原因"→ 小林依第38条（或B提出解除）→ 请求**合并计算**→支持→N=4.5个月（4年6个月）
2. **解除合法性**（第44条举证倒置）："经营调整"若对应第40条（三）客观情况重大变化→B须证明：协商变更不成+30日通知或+1+通知工会（第47条）
3. **若未通知工会**：违法解除→小林选择2N=9个月（4.5×2）
4. **离职协议**：B提出"按3个月私了"→对比法定9个月（2N）→**显失公平**（第35条）→不签或签后撤销
5. **保全**：B有转移资产苗头→诉讼中申请财产保全，经济困难→**免除担保**（第49条）→判后3个月内申请执行

## Key Takeaways
1. 期满继续用工=默示原条件续延；应签无固定未签=视为无固定关系（第34条）
2. 离职协议有效为原则；**显失公平/重大误解/欺诈胁迫**可撤销（第35条）
3. 竞业限制：未约定补偿→**30%月均工资**（最低工资兜底）；单位**3个月不付**→劳动者可解约；单位**提前解约**→**额外3个月**；违约后**仍须履行**（第36–40条）
4. 加班费：劳动者先举"存在"初步证据→单位掌握考勤不提供的承担不利后果（第42条）
5. 口头变更**实际履行超1个月**=有效（第43条）——异议要及时书面
6. 开除辞退降薪算年限→**单位负举证**（第44条）
7. 迫使解除五情形→报酬+补偿+可赔偿金（第45条）
8. **非因本人原因换单位**五情形→工龄合并（第46条）
9. **未通知工会=违法解除**（起诉前补正除外）（第47条）
10. 营业期限届满不再经营→经济补偿（第48条）
11. 欠薪保全**免/减担保**+生效后**3个月**申请执行（第49条）
12. 规章制度=民主程序+不违法+**公示**；**合同约定优先**（第50条）
13. 工资类调解协议不履行→**直诉**（第51条）；给付数额不当→法院可**变更**（第53条）
