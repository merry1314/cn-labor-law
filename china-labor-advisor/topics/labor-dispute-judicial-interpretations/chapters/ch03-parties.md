# Chapter 3: 解释（一）当事人规则（第26–33条）

## Core Idea
本章回答"告谁/谁有资格当当事人"：**合并→合并后单位、分立→实际用工单位（不明则全列）**（第26条）、**招用未离职劳动者→新单位第三人/共同被告**（第27条）、**承包经营→发包+承包双方为当事人**（第28条）、**无照经营→单位或其出资人**（第29条）、**挂靠→单位+执照出借方**（第30条）、**遗漏必参加人→追加**（第31条）、**退休/内退等人员的用工争议定性：劳务 vs 劳动**（第32条）、**外国人用工：无证不认劳动关系，持双证可认**（第33条）。

## Frameworks Introduced
- **合并/分立的当事人（第二十六条）**：
  - 单位**合并** → 合并前争议由**合并后单位**为当事人
  - 单位**分立** → 分立前争议由**分立后实际用人单位**为当事人
  - 分立后**具体承受单位不明确** → **分立后的单位均为当事人**（全列，内部再分）
  - When to use: 公司重组、"新东家不认旧账"——权利义务随主体存续，告承继者；分不清就全告
- **招用未离职劳动者（第二十七条）**：
  - 原单位与劳动者争议 → 可列**新单位为第三人**
  - 原单位以**新单位侵权**起诉 → 列**劳动者为第三人**
  - 原单位以**新单位+劳动者共同侵权**起诉 → 新单位与劳动者为**共同被告**
  - When to use: 与劳动合同法第91条（招用未解除劳动者的连带赔偿）联动——"挖人挖出连带责任"的诉讼构造
- **承包经营（第二十八条）**：劳动者在承包经营期间与**发包方和承包方**双方或一方发生争议起诉 → **承包方和发包方作为当事人**（双列）
  - When to use: 与解释二第1、2条（转分包/挂靠的**用工主体责任**）衔接——包工头用工出事故，发包/被挂靠单位跑不掉
- **无照/吊销/届满仍经营（第二十九条）**：劳动者与**未办理营业执照、执照被吊销、营业期限届满仍继续经营**的单位争议 → 将**用人单位或其出资人**列为当事人
  - When to use: 公司注销前/吊销后仍在用工——**刺破到出资人**的当事人规则（与劳动合同法第93条出资人责任、社保法第93条逻辑一致）
- **挂靠借用执照（第三十条）**：上述无照单位**挂靠/借用他人营业执照**经营 → 将**用人单位和营业执照出借方**列为当事人
  - When to use: 建筑、运输行业挂靠经营——出借方不能"只是租个照"免责
- **遗漏当事人追加（第三十一条）**：诉讼中法院审查发现仲裁裁决**遗漏必须共同参加的当事人** → **追加**为诉讼当事人；被追加人应担责的→**一并处理**
  - When to use: 仲裁阶段漏列（如该告派遣+用工只告了一个）→法院阶段补救，不必重走仲裁
- **退休/内退等人员的用工定性（第三十二条）**——注意：第一款已被解释二第21条**废止**：
  - ~~（原第一款）已享受养老保险待遇或领取退休金的人员的用工争议→按**劳务关系**处理~~ → **废止**，改按解释二第3条思路（关联用工/综合判断）
  - **第二款（仍有效）**：**停薪留职、未达退休年龄内退、下岗待岗、经营性停产放长假**人员与**新用人单位**发生用工争议 → 按**劳动关系**处理
  - When to use: "双劳动关系"场景——老单位保留关系+新单位用工，新单位是标准劳动关系（工伤、社保责任全在）
- **外国人用工（第三十三条）**：
  - **未依法取得就业证件**即签合同 → 请求确认劳动关系 → **不予支持**
  - 持**《外国专家证》+《外国人来华工作许可证》** → **可以认定劳动关系**
  - When to use: 与解释二第4条（2025-09-01起更宽：永久居留/工作许可+合法停留/按规定手续）**衔接替换**——解释二施行后以解释二第4条为准（解释二第21条明确"不一致的以本解释为准"）

## Key Concepts
- **承继主体当事人**：合并/分立/承包/挂靠/无照经营的"告谁"规则（第26–30条）
- **追加遗漏当事人**：法院阶段补救（第31条）
- **劳务 vs 劳动关系**：退休返聘（已废止条款）vs 内退待岗双劳动关系（第32条）
- **外国人就业证件**：劳动关系认定的前提（第33条，被解释二第4条更新）

## Mental Models
- "主体穿透"模型：公司形态变化（合并/分立/注销/挂靠/承包）**不消灭**劳动者的请求权——当事人规则就是"把真正能担责的主体拉进诉讼"：承继者、出资人、发包方、出借方、新单位
- "双列"口诀：合并→告后家；分立→告实际用工（不明全告）；承包→发包+承包双列；挂靠→用工+出借双列
- 退休返聘条款的**版本切换**：解释一第32条一款（劳务关系）已被解释二废止——2025-09-01后引用"退休返聘=劳务关系"的旧口径要慎重（解释二第3条转向综合判断+连带责任路径）

## Anti-patterns
- **公司注销/吊销后"无人可告"**: 第29条——告**出资人**；挂靠的告**出借方**（第30条）——主体落空不是死胡同
- **分立后只告"名义承继"的一个**: 分不清谁承接→**全部分立后单位**列为当事人（第26条）
- **退休返聘按"劳务"一刀切**: 解释一第32条一款已废止（解释二第21条）——2025-09-01后应结合解释二第3条及个案综合判断，勿直接套旧结论
- **外国人"黑工"合同当劳动合同处理**: 无证→不认劳动关系（第33条）——报酬可能按劳务/不当得利主张，但**工伤、社保**待遇失去劳动法通道

## Worked Example
某建筑公司将项目**转包**给无资质的"李老板"（个人），李老板招用的木工小杨受伤。处理：
1. **当事人/责任主体**：解释一第30条（挂靠）思路+**解释二第1条**（2025-09-01起）：转分包给无资质个人→劳动者可请求确认**承包人（建筑公司）为承担用工主体责任单位**，承担支付报酬、认定工伤后的工伤保险待遇责任
2. **诉讼构造**：告建筑公司（用工主体责任）+李老板（实际用工，第28条承包双列逻辑）——法院追加/一并处理
3. **未缴工伤保险**：工伤保险待遇由责任主体支付（社保法第41条逻辑在主体责任框架内展开）
4. **时效与路径**：工伤认定（人社）→劳动能力鉴定→待遇争议仲裁→诉讼

## Key Takeaways
1. 合并→合并后单位；分立→实际用工单位（不明全列）（第26条）
2. 招用未离职者：新单位第三人/共同被告（第27条，联动劳动合同法91条）
3. 承包→发包+承包双列（第28条）；无照经营→单位或**出资人**（第29条）；挂靠→+**执照出借方**（第30条）
4. 遗漏必参加人→法院**追加**（第31条）
5. 内退/停薪留职/待岗/放长假人员与新单位=**劳动关系**（第32条二，仍有效）
6. 外国人：无证不认劳动关系（第33条，解释二第4条更新标准）
