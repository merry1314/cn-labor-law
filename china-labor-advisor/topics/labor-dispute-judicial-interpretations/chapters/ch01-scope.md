# Chapter 1: 解释（一）受案范围与程序衔接（第1–15条）

## Core Idea
解释（一）（法释〔2020〕26号，2021-01-01施行，54条）是劳动争议进入**法院**的第一道筛子：哪些纠纷法院收（第1条九类）、哪些不收（第2条六类）、去哪个法院（第3条）、仲裁不立案/超期/支付令/工资欠条等**程序衔接**怎么处理。最实务的两条：**第15条"工资欠条"可直接起诉**（仲裁前置的法定例外）、**第12条仲裁超期可直接起诉**（六项正当事由除外）。

## Frameworks Introduced
- **九类受理的劳动争议（第1条）**——不服仲裁裁决起诉，法院应予受理：
  1. 履行劳动合同过程中的纠纷
  2. **未签书面合同但已形成劳动关系**后的纠纷
  3. 劳动关系是否**解除/终止**+应否支付**经济补偿金**的纠纷
  4. 解除/终止后请求**返还劳动合同定金、保证金、抵押金、抵押物**，或办理**人事档案、社会保险关系移转**手续的纠纷
  5. **未办理社保手续且经办机构不能补办**→无法享受社保待遇→请求**赔偿损失**的纠纷
  6. 退休后与**尚未参加社保统筹**的原单位因追索**养老金、医疗费、工伤保险待遇**等发生的纠纷
  7. 因**工伤、职业病**请求**工伤保险待遇**的纠纷
  8. 依**劳动合同法第85条**请求**加付赔偿金**的纠纷
  9. 因**企业自主改制**发生的纠纷
  - When to use: 立案前核对纠纷类型——注意第5条把"未办社保+不能补办+损失"纳入了法院受案（与"单纯补缴走行政"形成边界）
- **六类不属于劳动争议（第2条）**：
  1. 请求**社保经办机构**发放社会保险金的纠纷（→对经办机构走行政/行政诉讼，见 social-insurance-law ch10）
  2. 住房制度改革产生的**公有住房转让**纠纷
  3. 对**劳动能力鉴定结论**或**职业病诊断鉴定结论**的异议纠纷（→走鉴定程序/行政复议/行政诉讼，不走劳动仲裁）
  4. **家庭/个人与家政服务人员**纠纷（→普通民事）
  5. **个体工匠与帮工、学徒**纠纷
  6. **农村承包经营户与受雇人**纠纷
  - When to use: 家政保姆、装修师傅帮工、农户雇工——不属劳动争议，直接民事起诉
- **法院管辖（第3条）**：**用人单位所在地**或**劳动合同履行地**的**基层人民法院**；履行地不明确的→单位所在地（与仲裁管辖规则一致，履行地优先的逻辑在诉讼中体现为"不明确才退单位所在地"）
- **双方互诉并案（第4条）**：劳动者与单位均不服**同一裁决**、向**同一法院**起诉→**并案**，互为原告被告，一并裁决；一方撤诉→按另一方请求继续审理；分别向两地起诉→**后受理移送先受理**
- **仲裁不受理的处理（第五至九条）**：
  - **无管辖权不受理**（第5条）：法院查明确无管辖→告知向有管辖权的仲裁机构申请；确认有管辖但仲裁委仍不受理→**法院受理**
  - **不属劳动争议不受理**（第6条）：属劳动争议→受理；不属劳动争议但属**法院主管的其他案件**→依法受理（转轨）
  - **主体不适格**（第7条）：确属不适格→不予受理；已受理→**裁定驳回起诉**
  - **重新裁决不服**（第8条）：仲裁委为纠正错误重新作出裁决→**受理**
  - **不属法院受理范围**（第9条）：不予受理；已受理→驳回起诉
- **先予执行裁决不可诉（第10条）**：不服**预先支付**劳动报酬、工伤医疗费、经济补偿或赔偿金的裁决起诉→**不予受理**；单位不履行给付义务→劳动者申请**强制执行**，法院应予受理（先予执行是"快钱"通道，单位只能用执行抗辩，不能用起诉拖延）
- **生效调解书不可反悔起诉（第11条）**：调解书已生效，一方反悔起诉→不予受理；已受理→驳回起诉（对比：仲裁庭**调解书签收前**可反悔——签收即锁死）
- **仲裁超期直接起诉（第12条）**——劳动者的"超期解锁"：
  - 仲裁委**逾期未作出受理决定或仲裁裁决**→当事人直接起诉，**法院应予受理**
  - **六项除外**（有正当事由的除外）：移送管辖中；正在送达/送达延误；等待另案诉讼结果/评残结论；等待开庭；启动鉴定/委托调查取证；其他正当事由
  - 起诉须提交**受理通知书或其他已接受仲裁申请的凭证**
  - When to use: 与调解仲裁法第29条（不受理/逾期→起诉）、第43条（超45+15日→起诉）联动；"超期起诉"的举证=受理通知
- **支付令衔接（第13条）**：
  - 依**劳动合同法30条2款**（欠薪支付令）申请→符合督促程序→受理；被裁定**终结督促程序**后直接起诉→**告知先仲裁**（欠薪支付令失效=回到仲裁前置）
  - 依**调解仲裁法16条**（调解协议支付令）申请→被终结后**依据调解协议直接起诉**→**受理**（调解协议类可直诉，区别于欠薪支付令类）
  - 两条支付令"失效后去向不同"——这是解释一最细的程序设计
- **增加诉讼请求（第14条）**：与讼争劳动争议**不可分**→**合并审理**；属**独立的劳动争议**→告知先申请仲裁（新增请求别"顺嘴"——独立的得另走仲裁）
- **工资欠条直诉（第15条）**——仲裁前置的最大例外：
  - 劳动者以**工资欠条**为证据直接起诉，请求**不涉及劳动关系其他争议**→**视为拖欠劳动报酬争议**，法院**按普通民事纠纷受理**
  - When to use: 有单位盖章欠条、只讨工资、不扯劳动关系/解除等其他问题→**跳过仲裁**直接起诉（实践中常用于单位欠薪跑路前固定债权）
  - 边界：只要请求"涉及劳动关系其他争议"（如同时主张经济补偿）→回到仲裁前置

## Key Concepts
- **九类受理/六类排除**：劳动争议法院受案的边界（第1、2条）
- **并案互诉**：双方不服同一裁决→互为原被告（第4条）
- **先予执行裁决不可诉**：只能执行抗辩（第10条）
- **仲裁超期直诉**：六项正当事由除外（第12条）
- **两条支付令的失效去向**：欠薪类→回仲裁；调解协议类→直诉（第13条）
- **工资欠条直诉**：仲裁前置的法定例外（第15条）

## Mental Models
- "法院筛子"模型：进法院先过四道筛——①属不属于劳动争议（1/2条）②主体适格吗（7条）③有没有走过仲裁程序（前置+15条例外+12条超期）④请求能不能合并（14条）
- "欠条是通行证"模型：工资欠条+单一工资请求=免仲裁直通法院——所以欠薪谈判中**逼单位出具盖章欠条**是有程序价值的动作
- "超期=解锁"模型：仲裁受理了但不立案决定/不裁决（且无六项正当事由）→起诉权自动解锁；手里要留**受理通知书**

## Anti-patterns
- **有欠条还去仲裁**: 第15条直诉更快——除非请求里混入了补偿金等其他争议
- **仲裁超期没证据**: 第12条要求提交受理通知书/接受申请凭证——立案时就要留好
- **对先予执行裁决"起诉拖延"**: 第10条不予受理——单位只能走第24条不予执行抗辩（七事由），不能用起诉挡执行
- **生效调解书反悔再诉**: 第11条驳回起诉——签收调解书前才是反悔窗口
- **新请求"顺便"加进去**: 独立的劳动争议请求不能合并（第14条）——会被要求另走仲裁

## Worked Example
小刘被公司欠工资6万元，公司出具了**盖章欠条**（"欠小刘2025年1–6月工资60000元"）。小刘同时想主张违法解除赔偿金2N。处理：
1. **拆请求**：工资6万（有欠条、单一请求）→ **第15条直诉**（基层法院，普通民事）；赔偿金2N（涉及解除争议）→ **先仲裁**（调解仲裁法第5条前置）
2. **直诉立案**：欠条原件+劳动关系基本证据（工牌/流水）→法院按普通民事受理，不走仲裁
3. **仲裁线**：2N申请仲裁→裁决→不服15日内起诉（与工资案可分别推进）
4. **若公司"欠薪逃匿"苗头**：诉讼中申请**财产保全**（解释一第49条：经济困难或欠薪逃匿可能→**减轻/免除担保**）

## Key Takeaways
1. 法院受理九类（第1条）/排除六类（第2条）——立案前对表
2. 管辖：单位所在地或履行地基层法院（第3条）
3. 先予执行裁决不可诉，只能执行抗辩（第10条）；生效调解书不可反悔（第11条）
4. 仲裁超期直诉（第12条，六项除外，须受理凭证）
5. 支付令失效：欠薪类回仲裁、调解协议类直诉（第13条）
6. **工资欠条+单一工资请求=直诉免仲裁**（第15条）
