# Chapter 6: 解释（二）书面合同与无固定期限（第6–11条）

## Core Idea
本章是"**未签书面合同二倍工资**"与"**无固定期限合同**"两大高频争议的2025年审判口径：**二倍工资按月计算、不满一月按实际工作日**（第6条）、**单位免责三事由**（不可抗力/劳动者故意或重大过失/其他法定，第7条）、**期满法定续延不罚二倍**（第42条情形/服务期/工会任期，第8条）、**视为无固定→可要求补签书面但不支持期间二倍**（第9条）、**"两连签"四种认定**（延长期满/约定自动续延届满/变换签约主体/其他规避行为，第10条）、**期满继续用工超1个月→可要求按原条件续订（含无固定）**（第11条）。

## Frameworks Introduced
- **二倍工资计算口径（第六条）**：
  - 未依法订立书面合同应支付二倍工资的，**按月计算**
  - **不满一个月的，按该月实际工作日计算**
  - When to use: 核算二倍工资差额的精度规则——首尾不完整月不再"按整月"或"按半月"粗算，按**实际工作日**折算
- **二倍工资免责三事由（第七条）**——单位的抗辩窗口：
  - 劳动者以未订立书面合同请求二倍工资 → **支持**，但**用人单位举证证明**下列之一除外：
    1. 因**不可抗力**导致未订立
    2. 因**劳动者本人故意或者重大过失**未订立（如劳动者拒签、伪造签名后声称没签、长期不配合签约）
    3. 法律、行政法规规定的其他情形
  - **举证责任在单位**（第7条"用人单位举证证明"）
  - When to use: 劳动者"故意不签合同"想套二倍工资的，单位可以本条抗辩——**故意/重大过失**的认定需要单位拿出证据（拒签记录、催告函）
- **期满自动续延不罚（第八条）**——合同期满但**法定续延**的，不算"未订立书面合同"：
  - 合同期满，有下列情形之一的 → 认定**合同期限依法自动续延**，**不属于**未订立书面劳动合同的情形：
    1. **劳动合同法第42条**规定的不得解除情形（三期/医疗期/工伤失能/满15年距退5年等）
    2. **劳动合同法实施条例第17条**规定的**服务期尚未到期**
    3. **工会法第19条**规定的**工会任期未届满**
  - When to use: 三期员工合同到期后单位"没续签"——不是单位赖账，是**法定续延**，劳动者不能反过来套二倍工资；续延期间按原条件履行
- **视为无固定的"补签不加倍"（第九条）**：
  - 有证据证明存在**劳动合同法第14条3款**"视为已订立无固定期限劳动合同"情形（满1年未签书面合同）：
    - 劳动者请求**与单位订立书面合同** → **支持**（把"视为"落实为纸面）
    - 劳动者以单位**未及时补订**书面合同为由，请求**视为已订立期间的二倍工资** → **不予支持**
  - When to use: 满1年未签后，二倍工资的"惩罚期"在**满1年当天止**——之后的"视为无固定期间"不再按月累加二倍（单位不再被无限惩罚，劳动者拿到的是"无固定期限合同地位"本身）
- **"两连签"四种认定（第十条）**——第14条2款3项的展开：
  - 下列情形认定符合"**连续订立二次固定期限劳动合同**"：
    1. **协商延长**劳动合同期限**累计达到一年以上**，延长期限届满的
    2. 约定合同期满后**自动续延**，续延期限届满的
    3. 劳动者**非因本人原因**仍在**原工作场所、原岗位**工作，单位**变换劳动合同订立主体**但继续劳动管理，合同期限届满的
    4. 以**其他违反诚信原则的规避行为**再次订立劳动合同，期限届满的
  - When to use: 单位常见规避手段逐一点名：**"延长1年"算一次签订**、**"自动续延条款"算一次签订**、**"换关联公司签合同"算一次签订**——绕不过"两连签"；第（四）项是**诚信兜底条款**，任何变相重签都可能被穿透
  - 联动：解释一第46条（换主体→工龄合并）+ 解释二第3条（关联单位共同责任）——"换壳"三件套全被覆盖
- **期满继续用工超1个月（第十一条）**：
  - 合同期满后劳动者**仍工作**、单位**未表示异议超过一个月**：
    - 劳动者请求**按原条件续订**劳动合同 → **支持**
    - 符合订立**无固定期限**合同情形的，劳动者请求**以原条件订立无固定期限**合同 → **支持**
    - 单位**解除劳动合同**的，劳动者请求单位**承担解除法律后果**（补偿/赔偿金）→ **支持**
  - When to use: 解释一第34条（默示以原条件继续履行+一方提出终止支持）的**补强**——"继续用工超1个月"后，单位想走人必须走**解除程序并承担后果**（N或2N），不能再主张"期满终止/协商终止"
  - 与解释一第34条的衔接：34条管"视为原条件继续履行"的状态认定，第11条给劳动者**主动选择权**（要续订/要无固定/要解除后果）

## Key Concepts
- **二倍工资按月+实际工作日**（第6条）
- **免责三事由**：不可抗力/劳动者故意重大过失/其他法定（第7条，举证在单位）
- **法定续延**：第42条情形/服务期/工会任期→期满自动续延不罚二倍（第8条）
- **视为无固定**：可要求补签书面；期间不再二倍（第9条）
- **两连签四认定**：延长累计满1年/自动续延届满/换主体继续管理/其他规避（第10条）
- **期满用工超1个月**：可要求原条件续订（含无固定）；单位解除须担后果（第11条）

## Mental Models
- "二倍工资三段时钟"（劳动合同法+解释二）：第1个月（补签窗口，不罚）→ 第2个月起**按月**罚（不满一月按**实际工作日**）→ **满1年**：视为无固定，惩罚**封顶**（第9条）——单位最多付**11个月**二倍差额
- "规避四连击"（第10条）：延长=签订、自动续延=签订、换壳=签订、其他规避=签订——**所有"不重新签"的花样都被计次**
- "1个月异议期"（第11条）：期满后单位想终止，**一个月内**必须明确异议；沉默超1个月=默认续订，走人就要走解除程序付钱
- 续延豁免（第8条）：**法定**续延（三期/服务期/工会任期）不是单位的"漏签"——别把保护期当单位的违约期

## Anti-patterns
- **劳动者"故意拖不签"**: 第7条（二）——单位有催告+拒签证据的，二倍工资抗辩成立；劳动者"不签等二倍"的策略可能落空
- **满1年后继续"按月算二倍"**: 第9条——视为无固定期间**不再**二倍；请求被补签书面合同才是正路
- **三期/服务期"没续签"反告二倍**: 第8条——法定续延期间不算未订立——二倍请求不成立（但续延期间工资等正常权利不受影响）
- **单位"自动续延"条款当护身符**: 第10条（二）——约定自动续延且续延期届满=计一次签订；**两次**之后该签无固定了
- **期满后"沉默拖过1个月"再辞退**: 第11条——超1个月未异议，解除须承担法律后果（N/2N），不能按"期满终止"处理

## Worked Example
小李2023-01签1年合同（至2023-12-31），到期后继续工作，2024-01-20单位与其签**补充协议"延长合同1年"**（至2025-01-19）；2025-01-19到期后又继续工作至2025-06-01，单位始终未签新合同。处理：
1. **第一次"延长"**（第10条一）：协商延长累计达1年且届满→认定为**一次**固定期限合同的订立（"两连签"计1）
2. **第二段到期后**：继续工作超1个月未异议（第11条）→小李可请求**按原条件续订**；若此前已有两次固定期限（前合同+延长）→符合**两连签**（第10条）→可请求**订立无固定期限合同**
3. **二倍工资**：2025-02-01起至2025-06-01（单位未签书面）→二倍工资差额：2月整月+3、4、5月整月+6月按**实际工作日**（第6条）
4. **若单位2025-03-01（未超1个月异议期前）书面终止**：按期满终止处理+经济补偿（第46条五：单位未维持/提高条件）；若**超1个月后**解除→按**解除**处理（第11条：N或2N视合法性）
5. **劳动者"故意不签"抗辩风险**：若单位有2025-02-10催告签约的邮件而小李拒签→单位可依第7条（二）抗辩二倍工资

## Key Takeaways
1. 二倍工资**按月**计算；不满一月按**实际工作日**（第6条）
2. 单位免责三事由：不可抗力/**劳动者故意或重大过失**/其他法定——**举证在单位**（第7条）
3. 期满遇**第42条情形/服务期/工会任期**→法定自动续延，**不罚二倍**（第8条）
4. 视为无固定→可要求**补签书面**；该期间**不支持二倍**（第9条）
5. **两连签四认定**：延长累计满1年/约定自动续延届满/换主体继续管理/其他规避行为（第10条）
6. 期满继续用工**超1个月**未异议→可要求**原条件续订（含无固定）**；单位解除须担法律后果（第11条）
