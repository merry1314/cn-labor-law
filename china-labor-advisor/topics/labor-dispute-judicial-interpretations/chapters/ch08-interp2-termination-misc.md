# Chapter 8: 解释（二）违法解除后果、职业健康与时效（第16–21条）

## Core Idea
解释（二）收尾五条解决**违法解除的"继续履行"判定**（第16条六情形"不能继续履行"）、**职业病离岗检查的履行保障**（第17条）、**违法解除后继续履行期间的工资**（第18条）、**约定不缴社保无效+补缴后可索回补贴**（第19条——"自愿放弃社保"的最终定论）、**仲裁时效抗辩失权**（第20条——仲裁阶段不提，诉讼阶段不提了）+ 施行与废止（第21条）。

## Frameworks Introduced
- **"不能继续履行"六情形（第十六条）**——劳动合同法第48条"二选一"的判定标准：
  - 单位**违法解除或终止**后，下列情形认定为"**劳动合同已经不能继续履行**"（→劳动者只能选**2N赔偿金**，不能要求恢复）：
    1. 合同在**仲裁或诉讼过程中期满**，且**不存在**依法应当**续订、续延**情形的
    2. 劳动者**开始依法享受基本养老保险待遇**的（退休）
    3. 单位被**宣告破产**的
    4. 单位**解散**的（**因合并或分立需要解散的除外**——承继单位可继续履行）
    5. 劳动者**已与其他单位建立劳动关系**，对本单位工作造成**严重影响**，或经单位提出**不与新单位解除**的
    6. 存在合同**客观不能履行**的其他情形
  - When to use: 劳动者主张"恢复劳动关系"前先自查六情形——命中其一，"继续履行"请求**不成立**，转主张2N；反过来，单位抗辩"不能履行"也要落进六情形
  - 注意第（一）项的"且不存在应当续订续延情形"——若存在第42条保护（三期等）应续延→合同**未到期**→仍可继续履行
- **职业病离岗检查与继续履行（第十七条）**：
  - 单位**未按**国务院安监、卫生部门规定组织**接触职业病危害作业**的劳动者进行**离岗前职业健康检查**
  - 劳动者在**解除劳动合同后**请求**继续履行**劳动合同 → **支持**
  - **两例外**（一审法庭辩论终结前）：① 单位**已组织检查**且劳动者**未患职业病** ② 单位组织检查，劳动者**无正当理由拒绝**
  - When to use: 与劳动合同法第42条（一）（职业病患离检期间不得解除）联动——**没做离检就解除=解除效力受阻**，劳动者可要求**恢复劳动关系**；单位的补救窗口=**一审法庭辩论终结前**补做检查
- **继续履行期间的工资（第十八条）**：
  - 单位**违法解除、终止**且合同**可以继续履行**
  - 劳动者请求支付**违法解除决定作出之日**至**继续履行前一日**的工资 → 单位按**提供正常劳动时的工资标准**支付
  - **双方都有过错**的 → **各自承担相应责任**
  - When to use: "空窗期工资"——仲裁+诉讼期间（可能数月到一年）被违法解除的空档工资，按**正常工资标准**全额补发；不是"生活费"或"最低工资"
  - 过错相抵：劳动者自身也有过错（如严重违纪部分成立）→责任分担
- **"自愿放弃社保"无效（第十九条）**——高频争议的定论条款：
  - 单位与劳动者**约定**或劳动者**承诺**"**无需缴纳社会保险费**" → **认定无效**
  - 单位未依法缴纳 → 劳动者依**劳动合同法第38条1款3项**请求**解除劳动合同+经济补偿** → **支持**
  - **单位补缴后**，请求劳动者**返还已支付的"社保费补偿"**（单位以现金形式多发的"社保补贴"）→ **支持**
  - When to use: "我签了放弃社保声明还能翻案吗"——**能**：约定无效→38条被迫解除+经济补偿成立；单位补缴后可以拿回**多给的补贴**（但**不能**以此对抗劳动者的解除权与补偿请求）
  - 配套动作：劳动者主张后单位往往**立即补缴**→补贴被索回——**经济补偿+工资差额**才是净收益，策略上要算账
- **仲裁时效抗辩失权（第二十条）**——程序硬规则：
  - 当事人在**仲裁期间因自身原因未提出**仲裁时效抗辩
  - 在**一审或二审诉讼期间**提出 → **不予支持**（失权）
  - **例外**：基于**新的证据**能够证明对方请求权**时效届满**的 → **支持**
  - 未依前款提出时效抗辩的，又以时效届满为由**申请再审**或提出**再审抗辩** → **不予支持**
  - When to use: 双向意义——**劳动者**：单位在仲裁阶段没提时效（比如默认实体审理），诉讼阶段**翻不出时效**；**单位**：时效抗辩**必须**在仲裁阶段提出（一审提=晚了），**新证据**（如劳动者长期不在岗、中断事由不成立的反证）是唯一的诉讼阶段翻盘通道
  - 注意："因自身原因"未提出——若因仲裁委原因（如未送达、程序瑕疵）未获提出机会，可能不受失权约束（个案判断）
- **施行与废止（第二十一条）**：
  - 自**2025年9月1日**起施行
  - **解释（一）第32条1款**（退休返聘按劳务关系）**同时废止**
  - 此前发布的司法解释与本解释**不一致的，以本解释为准**（包括"两高三部"旧解释中涉劳动争议的条款）

## Key Concepts
- **不能继续履行六情形**（第16条）
- **离岗职业健康检查**：未做→解除受阻，可继续履行；一审辩论终结前补做/劳动者拒检为例外（第17条）
- **空窗期工资**：违法解除决定作出→继续履行前一日，按正常工资标准（第18条）
- **放弃社保约定无效**+38条解除补偿+补缴后索回补贴（第19条）
- **时效抗辩失权**：仲裁不提，诉讼不提（新证据除外）；再审不得再提（第20条）
- **2025-09-01施行**；解释一第32条1款废止（第21条）

## Mental Models
- "恢复劳动关系可行性自查"（第16条）：想"回公司"先排雷——合同期内？没退休？单位没破产解散？没去对手公司干得影响工作？——六情形全不命中，"继续履行"请求才站得住；命中→转2N+**空窗工资**（第18条）
- "违法解除的完整账"（第48条+第18条）：2N 或 继续履行+**空窗期全额工资**——两条路都要把"仲裁到判决那大半年的工资"算进收益模型
- "社保声明作废"（第19条）：签了也没用（无效）→ 38条解除+补偿成立；单位唯一拿回的是**补缴后的现金补贴**——劳动者的净收益=补偿+工资差额−被索回补贴
- "时效抗辩=仲裁阶段的牌"（第20条）：牌**只能打一次**，在**仲裁**阶段；诉讼阶段亮=无效（新证据除外）——劳动者开庭时盯住单位有没有提，没提就默认它**失权**了

## Anti-patterns
- **恢复请求不排雷就主张**: 第16条——已入职新单位且"造成严重影响"（如竞业岗位、关键岗位）的，"继续履行"大概率不被支持——先评估再选路
- **职业病岗位"没体检就辞职走人"**: 第17条——单位没做离检→劳动者可要求**继续履行**（合同恢复）；反过来劳动者**无正当理由拒绝检查**→例外成立，单位解除风险降低
- **"放弃社保+拿补贴"两头占**: 第19条——约定**无效**，单位随时可主张补缴；补缴后**补贴被索回**；劳动者真正稳的收益是**经济补偿**——别把补贴当长期福利
- **单位"诉讼阶段才提时效"**: 第20条——**不予支持**（除非新证据）；单位律师在仲裁阶段不提=自废武功
- **时效"新证据"幻想**: 新证据必须能证明**请求权时效届满**（如重新发现劳动者从未主张的中断不成立证据）——"当时忘了提"不是新证据

## Worked Example
小何（化工企业车间员工，接触职业病危害因素）2025-05被公司以"违纪"解除，公司**未组织离岗前职业健康检查**。小何要求恢复劳动关系。处理：
1. **解除效力**（第17条）：单位未按规组织离岗职业健康检查→小何请求**继续履行**→**支持**（除非单位在**一审法庭辩论终结前**补做检查且证明未患职业病）
2. **空窗工资**（第18条）：自**解除决定作出之日**至**恢复履行前一日**（假设诉讼历时8个月）→按**正常劳动工资标准**全额支付
3. **若公司证明"违纪"部分成立**（双方都有过错）：第18条后段——**各自承担相应责任**（可能影响空窗工资比例，但"未做离检"的解除阻碍本身不消除）
4. **社保线**：若小何还主张"公司没缴社保"（有放弃声明）→第19条：声明**无效**→可另依38条解除+补偿（与恢复二选一，不能既恢复又要解除补偿）；公司补缴后可索回已发"社保补贴"
5. **时效线**：公司若**仲裁阶段未提**时效抗辩→诉讼阶段提**无效**（第20条）——小何的解除/恢复请求不受时效偷袭

## Key Takeaways
1. **不能继续履行六情形**：期满无续延/退休/破产/解散（合并分立除外）/已建新劳动关系影响工作或拒解除/其他客观不能（第16条）
2. **未做离岗职业健康检查**→解除后请求**继续履行**支持；一审辩论终结前补检未患病/劳动者拒检为例外（第17条）
3. **违法解除+可继续履行**→**空窗期工资**按正常标准（第18条）；双方过错→分担
4. **约定不缴社保=无效**→38条解除+经济补偿；单位**补缴后可索回**已付补贴（第19条）
5. **仲裁时效抗辩**：仲裁阶段不提→诉讼/再审不得提（**新证据**除外）（第20条）
6. 2025-09-01施行；**解释一第32条1款废止**；冲突以解释二为准（第21条）
