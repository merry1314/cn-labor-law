# Chapter 5: 解释（二）责任主体与外国人用工（第1–5条）

## Core Idea
解释（二）（法释〔2025〕12号，2025-09-01施行，21条）开篇解决"**谁为用工结果负责**"：**转分包给无资质主体→承包人承担用工主体责任**（第1条）、**挂靠→被挂靠单位担责**（第2条）、**关联单位交替/同时用工→书面合同优先确认，无合同按用工管理行为综合认定+关联单位共同担责**（第3条）、**外国人劳动关系三情形**（第4条）、**外企常驻代表机构可当当事人**（第5条）。核心立场：违法转包分包、挂靠经营不能成为"甩掉用工责任"的通道。

## Frameworks Introduced
- **转分包的用工主体责任（第1条）**：
  - **具备合法经营资格的承包人**将承包业务**转包或分包**给**不具备合法经营资格**的组织或个人
  - 该组织/个人招用的劳动者请求确认**承包人为承担用工主体责任单位**，承担**支付劳动报酬、认定工伤后的工伤保险待遇**等责任 → **依法支持**
  - When to use: 建筑、装修、物流等行业层层转包——"包工头没资质"不是免责理由，**有资质的承包人**是责任终点；工伤认定后待遇由承包人承担
  - 注意：是"用工主体责任"（报酬+工伤待遇兜底），不必然等于确认与承包人的**劳动关系**（双重区分：劳动关系认定 vs 主体责任承担）
- **挂靠的用工主体责任（第2条）**：
  - 无合法经营资格的组织/个人**挂靠**具备资格的单位**对外经营**
  - 其招用的劳动者请求确认**被挂靠单位**为承担用工主体责任单位（支付报酬、工伤后工伤保险待遇等）→ **依法支持**
  - When to use: 与解释一第30条（挂靠→用工方+出借方列为当事人）联动——挂靠出工伤/欠薪，**出借资质的一方**兜底
- **关联单位用工（第3条）**——"混同用工"的认定与责任：
  - 劳动者被**多个存在关联关系的单位交替或同时用工**，请求确认劳动关系：
    1. **已订立书面劳动合同** → 按**劳动合同**确认
    2. **未订立书面合同** → 根据**用工管理行为**，综合**工作时间、工作内容、劳动报酬支付、社会保险费缴纳**等因素确认
  - 请求**关联单位共同承担**支付劳动报酬、福利待遇等责任 → **支持**
    - **例外**：关联单位之间依法对劳动者的报酬、福利等作出约定**且经劳动者同意**的除外
  - When to use: "A公司签合同、B公司发工资、C公司缴社保、天天在D公司干活"——写劳动合同的那家=确认对象；没写合同的按**谁管理谁发钱谁缴社保**综合认定；责任上关联单位**共同承担**（除非劳动者同意过内部约定）
  - 与解释一第46条（非因本人原因换单位五情形→**工龄合并**）互补：第46条管**年限计算**，本条管**关系确认+共同责任**
- **外国人劳动关系（第4条）**——比解释一第33条更宽的三情形：
  1. 已取得**永久居留资格**的
  2. 已取得**工作许可**且在中国境内**合法停留居留**的
  3. 按照国家有关规定**办理相关手续**的
  - 有其一 → 请求确认劳动关系 → **依法支持**
  - When to use: 2025-09-01起**替代**解释一第33条（解释二第21条："不一致的以本解释为准"）——旧标准"外国专家证+工作许可证"双证要求放宽为"工作许可+合法停留"即可
- **外企常驻代表机构（第5条）**：
  - 依法设立的**外国企业常驻代表机构**（办事处/代表处）**可以作为劳动争议案件的当事人**
  - 当事人申请**追加外国企业**参加诉讼的 → 依法支持
  - When to use: 在代表处工作被欠薪/被辞退——直接告代表处；责任覆盖不够（代表处资产有限）→ **追加背后的外国企业**

## Key Concepts
- **用工主体责任**：转分包/挂靠场景下，有资质方对报酬+工伤待遇的兜底责任（第1、2条）
- **用工管理行为综合认定**：无书面合同时按管理、时间、内容、报酬支付、社保缴纳五因素（第3条）
- **关联单位共同责任**：混同用工下报酬福利的共同承担+劳动者同意例外（第3条）
- **外国人三情形**：永久居留/工作许可+合法停留/按规定手续（第4条）
- **代表机构当事人资格+追加外国企业**（第5条）

## Mental Models
- "资质兜底"模型：违法转分包/挂靠=把用工风险转移给了**最有资质、最有偿付能力**的主体——法律不让"层层甩锅"：劳动者→无资质包工头（没钱）→有资质承包人/被挂靠单位（兜底）
- "五因素"模型（第3条二）：没合同别慌——**谁在管理我（考勤指挥）、我干什么活、谁给我发钱、谁给我缴社保、工时归谁**——指向谁/谁为主就是劳动关系对象；责任则关联单位**一锅端**
- "确认与责任分离"模型：确认劳动关系（跟哪家有合同/管理关系）是一件事；**共同承担责任**（钱一起赔）是另一件事——没确认到劳动关系的关联单位也可能对报酬福利**共同担责**

## Anti-patterns
- **"只是分包给班组"的抗辩**: 第1条不看"形式名称"——转包分包给**无资质**组织/个人，承包人就背用工主体责任
- **关联公司"轮流签合同"**: 解释二第3条+解释一第46条+解释二第10条（四）"以违反诚信原则的规避行为再次订立"——轮流签合同既可能导致**共同责任**，也可能被计入**"连续两次固定期限"**
- **外国人"没工作证"就当劳务处理**: 第4条三情形——合法停留居留+工作许可即认劳动关系；只有**完全无证**才不认（衔接解释一第33条口径的剩余适用）
- **只告代表处**: 代表处资产有限→第5条**追加外国企业**，别在"执行不能"上吃亏

## Worked Example
某外资代表处雇员小赵被欠薪3个月并被辞退；该代表处由境外母公司派驻，境内资产很少。同时小赵发现工资有时从母公司的境内关联公司（同一高管团队）账户发放。处理：
1. **当事人**（第5条）：告**代表处**（适格当事人）+ 申请**追加外国企业**（母公司）参加诉讼
2. **关联用工**（第3条）：关联公司发过工资→属于"关联单位交替用工"——有书面合同按合同确认；就报酬请求主张**关联单位共同承担**（除非公司能证明"内部约定+小赵同意"）
3. **欠薪双轨**：投诉（调解仲裁法第9条）+ 仲裁（欠薪时效：在职不算，离职起1年）
4. **外国人身份**：若小赵持工作许可且合法停留→劳动关系确认无障碍（第4条二）
5. **执行**：代表处+母公司连带执行——避免"代表处是个空壳"的执行落空

## Key Takeaways
1. 转分包给无资质主体→**承包人**承担用工主体责任（报酬+工伤待遇）（第1条）
2. 挂靠→**被挂靠单位**承担用工主体责任（第2条）
3. 关联单位交替/同时用工：有合同按合同；无合同按**管理行为五因素**；关联单位对报酬福利**共同担责**（劳动者同意内部约定的除外）（第3条）
4. 外国人三情形认劳动关系：永久居留/工作许可+合法停留/按规定手续（第4条）
5. 外企代表处可当当事人；可**追加外国企业**（第5条）
