# Chapter 1: 职工带薪年休假条例（10条全文）

## Core Idea
《职工带薪年休假条例》（国务院令第514号，**2008-01-01**施行，10条）确立了年休假制度的三个支柱：**权利**（连续工作满1年即享有，休假期间工资不变）、**天数**（5/10/15天三档，按**累计**工作年限）、**补偿**（应休未休=**300%日工资**，含正常工资即额外补200%）。单位义务是"**安排休假**"——不安排+不付钱=**责令改正+加付赔偿金**（第7条）。

## Frameworks Introduced
- **权利主体（第2条）**：
  - 机关、团体、企业、事业单位、民办非企业单位、**有雇工的个体工商户**等单位的职工
  - 条件：**连续工作1年以上**（实施办法第3条明确=**连续工作满12个月**）
  - 双义务/权利：单位**应当保证**职工享受年休假；年休假期间享受**与正常工作期间相同的工资收入**
  - When to use: "连续工作"不限于**本单位**——实施办法第4条：**累计**工作时间（不同用人单位期间+法定视同工作期间都算）；第3条的"连续满12个月"是**资格门槛**（跨单位连续），第4条的"累计"是**天数**计算——两个口径分工
- **天数三档（第3条）**——按**累计**工作年限：
  | 累计工作 | 年休假天数 |
  |---|---|
  | 满**1年**不满**10年** | **5天** |
  | 满**10年**不满**20年** | **10天** |
  | 满**20年** | **15天** |
  - **国家法定休假日、休息日不计入**年休假假期（周六日+法定节假日休假"不耗"年休假天数）
  - When to use: 天数争议=**累计工龄**举证——社保缴费记录、原单位离职证明、档案是主要证据；"满10年"=**含10年整**（民法典1259条本数规则）
- **五情形不享受当年（第4条）**：
  1. 依法享受**寒暑假**且休假天数**多于**年休假天数的（教师典型）
  2. 请**事假**累计**20天以上**且单位按规定**不扣工资**的
  3. 满1年不满10年：请**病假**累计**2个月以上**
  4. 满10年不满20年：请**病假**累计**3个月以上**
  5. 满20年：请**病假**累计**4个月以上**
  - When to use: 五情形是**单位抗辩**的主要武器——但注意第（二）项的双要件（事假20天+**不扣工资**，扣了工资就不触发）；实施办法第8条：**已休**当年年休假后**年度内**又出现（二）–（五）情形的→**不享受下一年度**（当年已休的不追回）
- **安排规则（第5条）**：
  - 单位根据生产工作具体情况+**考虑职工本人意愿**，**统筹安排**
  - 年度内可**集中**也可**分段**；**一般不跨年度**
  - 因生产工作特点**确有必要**跨年度→可跨**1个年度**（实施办法第9条：跨年度安排须**征得职工本人同意**）
  - **不安排**：确因工作需要不能安排，**经职工本人同意**，可以不安排→对**应休未休**天数按**日工资300%**支付
  - When to use: "经职工同意"是**不安排**的**前置要件**——单位单方"今年不让休"=违法；同意须**书面**（实施办法第10条二款的"本人原因**书面**提出不休"是单位**免责**路径——职工口头说"不想休"的，单位仍有风险）
- **300%补偿（第5条后段）**：
  - 应休未休天数×**日工资收入×300%**
  - **口径**（实施办法第10条明确）：300%**包含**正常工作期间的工资→实际**额外补发200%**（已发工资100%+补200%）
  - When to use: 算账=**未休天数×日工资×200%**（额外部分）；日工资=月工资÷**21.75**（实施办法第11条）；月工资=**前12个月剔除加班工资**的月平均工资（不满12个月按实际月份）
- **监督与救济（第六、七、八条）**：
  - 县级以上**人事部门、劳动保障部门**依职权**监督检查**；**工会**依法维护年休假权利
  - **处罚**（第7条）：不安排又不给300%→责令**限期改正**；逾期不改正→责令支付**年休假工资报酬**+按数额**加付赔偿金**；拒不支付的→公务员单位**处分**责任人员；其他单位→**申请人民法院强制执行**
  - **争议**（第8条）：年休假争议→按**有关法律、行政法规**处理（实施办法第16条明确=**劳动争议**处理：仲裁→诉讼）
- **实施办法授权（第9条）**：国务院人事部门、劳动保障部门分别制定**实施办法**——企业侧即《企业职工带薪年休假实施办法》（人社部令第1号，2008-09-18发布施行，见ch02）

## Key Concepts
- **连续工作满12个月**=资格门槛（第2条+实施办法3条）
- **天数按累计工龄**：5/10/15天三档（第3条）
- **法定假日/休息日不计入**（第3条二）
- **五情形不享受当年**：寒暑假更多/事假20天不扣薪/病假2、3、4个月（第4条）
- **集中/分段，一般不跨年**；跨年须**职工同意**（第5条+实施办法9条）
- **不安排须职工同意**→**300%日工资**（含正常工资=额外200%）
- **责令改正+加付赔偿金+强制执行**（第7条）
- **争议=劳动争议**（第8条+实施办法16条）

## Mental Models
- "资格与天数分离"模型：第2条"连续满1年"=**能不能休**（资格，跨单位连续12个月）；第3条"累计工作"=**休几天**（5/10/15，全职业生涯累计）——跳槽不清零天数（但资格要连续满12个月）
- "安排义务"模型（第5条）：年休假是**单位应当保证**的权利——决定权在单位（统筹安排），但**必须安排**或**征得同意不安排+300%**——三选一：休/同意不休+300%/违法
- "300%=100%+200%"模型：未休补偿=正常工资（100%，通常已发）+**额外200%**——算账别把300%全额当索赔额（已发部分不重复主张）
- "书面同意"模型：单位免责的**唯一**干净路径=职工**本人原因+书面**提出不休（实施办法10条二）——"老板说今年太忙别休了"（单位原因）=**必须付300%**；"我自己不想休"但没书面=灰色地带（单位举证风险）

## Anti-patterns
- **"你去年没休完，今年清零"**: 条例无"清零"规则——未休的当年按300%结算；跨年度安排须**确有必要+职工同意**（且只可跨1个年度）——"作废"不成立
- **"新入职当年没有年休假"**: 连续工作满12个月即有资格（**跨单位**连续）；新进单位当年度按**剩余日历天数折算**（实施办法5条）——"本单位干满1年才给"是错误口径
- **用事假/病假"卡"年休假**: 第4条双/多要件——事假20天**且**不扣工资；病假按工龄档**2/3/4个月**——差一天不触发；**工伤停工留薪期、产假、婚丧假、探亲假**不计入年休假也不触发（实施办法6条）
- **口头"同意不休"**: 不安排须**职工本人同意**；职工**本人原因**不休须**书面**——单位的免责举证全靠书面——没书面=按**未休300%**赔
- **把年休假当福利可扣可罚**: 年休假=**法定权利**——以"没休完扣工资""年休假当事假"处理=违法；已休天数**多于**折算的（解除合同时）**不扣回**（实施办法12条二款）

## Worked Example
小唐累计工作12年（5年前公司+现公司），入职现公司第8个月（当年已过200天、剩余165天）。当年未休年假，年底被通知"明年再说"。处理：
1. **资格与天数**：连续工作>12个月✓；累计12年→**10天**（第3条）
2. **当年度折算**（实施办法5条）：（165÷365）×10=**4.5天**→不足1整天不享受→**4天**
3. **跨年安排**：单位要"跨到明年"→须**确有必要+征得小唐同意**（实施办法9条）——小唐不同意→单位应在**本年度内**安排
4. **应休未休补偿**（第5条+实施办法10条）：4天×日工资×300%（含已发工资→额外**200%**）；日工资=前12个月剔除加班工资的月平均工资÷**21.75**（假设月均10000→日工资459.77→4×459.77×200%=**3678元**）
5. **若年底被解除合同**（实施办法12条）：按当年**已过**日历天数折算：（265÷365）×10-已休0=**7天**（>1整天部分7.25→**7天**）×日工资×200%（额外）——**离职结算**是年休假补偿的高发时点
6. **救济**：单位不付→投诉（劳动行政部门责令+**加付赔偿金**，第7条/实施办法15条）+**劳动仲裁**（16条，1年时效）

## Key Takeaways
1. 资格：**连续工作满12个月**（跨单位连续）（第2条+实施办法3条）
2. 天数：**5/10/15**按**累计**工龄；法定假日/休息日**不计入**（第3条）
3. **五情形**不享受当年：寒暑假更多/事假20天+不扣薪/病假2、3、4个月（第4条）
4. 安排：**集中/分段**，一般不跨年；跨年须**职工同意**（第5条）
5. 不安排须**职工同意**→应休未休×**日工资300%**（含正常工资=额外200%）
6. 处罚：责令改正→支付+**加付赔偿金**→**强制执行**（第7条）
7. 争议=**劳动争议**（仲裁→诉讼）（第8条）
