# Cheatsheet — 职工带薪年休假（条例+实施办法）速查

## 版本信息

| 项 | 内容 |
|---|---|
| 条例 | 职工带薪年休假条例（国务院令第514号），**2008-01-01**施行，10条 |
| 实施办法 | 企业职工带薪年休假实施办法（人社部令第1号），**2008-09-18**施行，19条 |
| 母法 | 劳动法第45、46条 |
| 适用 | 企业/民办非企业/有雇工个体户+劳动关系职工；机关事业社团参照；船员按《船员条例》 |
| 年度 | **公历年度**（实施办法18条） |

## 天数速查

| 累计工作 | 年休假 |
|---|---|
| 满1年不满10年 | **5天** |
| 满10年不满20年 | **10天** |
| 满20年 | **15天** |

- 资格：**连续工作满12个月**（跨单位连续，实施办法3条）
- 档位按**累计工龄**（不同单位期间+视同工作期间，实施办法4条）
- **法定休假日、休息日不计入**（条例3条二）

## 不享受当年（条例4条）

| 情形 | 门槛 |
|---|---|
| 寒暑假 | 休假天数**多于**年休假天数 |
| 事假 | 累计**20天以上**且**不扣工资** |
| 病假（1–10年档） | 累计**2个月以上** |
| 病假（10–20年档） | 累计**3个月以上** |
| 病假（20年+档） | 累计**4个月以上** |

- 已休当年后出现上述情形→**不享受下一年度**（当年不追回，实施办法8条）
- **不冲抵**：探亲假/婚丧假/产假/**工伤停工留薪期**（实施办法6条）

## 折算公式

| 场景 | 公式 | 取整 |
|---|---|---|
| 新进当年度 | （剩余日历天数÷365）×全年天数 | 不足1整天**不享受** |
| 离职当年度 | （已过日历天数÷365）×全年天数**-已休** | 不足1整天**不支付**；多休**不扣回** |

## 300%补偿卡

```
应休未休天数 × 日工资 × 300%（含已发正常工资 → 额外实付 200%）
日工资 = 月工资 ÷ 21.75
月工资 = 前12个月【剔除加班工资】月平均工资（不满12个月按实际月份）
单位免责唯一路径：已安排 + 职工【本人原因】+【书面】提出不休 → 只付正常工资
```

## 安排规则

| 规则 | 要件 |
|---|---|
| 集中/分段安排 | 单位统筹+考虑本人意愿 |
| 跨1个年度 | **确有必要**+**职工同意** |
| 不安排 | **确因工作需要**+**经职工同意**→付300% |
| 约定从优 | 约定/制度**高于**法定→按约定（实施办法13条） |

## 劳务派遣（实施办法14条）

| 待岗发薪天数 vs 应休天数 | 结果 |
|---|---|
| **多于** | **不享受**当年年休假 |
| **少于** | 派遣单位+用工单位**协商安排补足** |

## 监督与救济

| 步骤 | 内容 | 条文 |
|---|---|---|
| 1 | 劳动行政部门**监督检查** | 条例6/办法15 |
| 2 | 不安排又不付→责令**限期改正** | 条例7/办法15 |
| 3 | 逾期→责令支付+**按数额加付赔偿金** | 条例7/办法15 |
| 4 | 拒不支付→**申请法院强制执行**（公务员单位→处分） | 条例7/办法15 |
| 5 | 争议→**劳动争议**（仲裁→诉讼，**1年时效**） | 条例8/办法16 |

## 关键数字卡

```
12个月     资格门槛（连续工作）
5/10/15    天数三档
20天       事假门槛（+不扣工资）
2/3/4个月  病假门槛（按工龄档）
365        折算分母（公历年度）
21.75      月计薪天数（日工资分母）
300%       未休补偿（含正常工资=额外200%）
1年        跨年上限 / 仲裁时效
前12个月   月工资口径（剔除加班工资）
```

## 高频误判卡

| 误判 | 正解 |
|---|---|
| "本单位干满1年才有年假" | 资格=**连续**满12个月（跨单位）；天数=**累计**工龄（跳槽不清零） |
| "没休完=清零" | 无清零规则：跨年须**同意**且仅跨1年；未休=**300%** |
| "签了自愿放弃就不给了" | 免责=已安排+本人原因+**书面**；格式条款放弃=**无效** |
| "离职没休=作废" | 第12条**必须折算结算** |
| "产假/工伤假冲抵年假" | **不冲抵**（实施办法6条） |
| "加班费高的月均直接算基数" | **剔除加班工资**（实施办法11条） |
| "仲裁能要加付赔偿金" | 加付赔偿金=**行政**罚则（多数地区司法不支持直接主张）；投诉才是杠杆 |
