# 术语表（按条文）

| 术语 | 条文 | 定义/说明 |
|---|---|---|
| 残疾人 | 第2条 | 心理、生理、人体结构上某种组织、功能丧失或不正常，全部或部分丧失以正常方式从事某种活动能力的人 |
| 残疾类型 | 第2条 | 视力、听力、言语、肢体、智力、精神、多重残疾等 |
| 禁止基于残疾的歧视 | 第3条 | 不得因残疾差别对待，残疾人公民权利和人格尊严受法律保护 |
| 特别扶助 | 第4条 | 国家采取辅助方法和扶持措施，减轻或消除残疾影响和外界障碍 |
| 按比例安排残疾人就业 | 第33条 | 用人单位按不低于1.5%比例安排残疾人就业，达不到则缴纳保障金 |
| 残疾人就业保障金 | 第33条 | 未按比例安排残疾人就业的用人单位缴纳的资金 |
| 福利企业 | 第32条 | 政府和社会举办的集中安排残疾人就业的福利性单位 |
| 集中就业 | 第32条 | 通过福利企业、盲人按摩机构等集中安排残疾人就业 |
| 行政事业性收费免除 | 第36条 | 从事个体经营的残疾人免除行政事业性收费 |
| 免费就业服务 | 第37条 | 公共就业服务机构和残联就业服务机构为残疾人免费提供服务 |
| 适当劳动条件 | 第38条 | 根据残疾职工特点提供劳动条件和劳动保护，改造劳动场所/设备/设施 |
| 强迫残疾人劳动 | 第40条 | 禁止以暴力、威胁或非法限制人身自由手段强迫残疾人劳动 |
| 社会保险补贴 | 第47条 | 对生活确有困难的残疾人给予社保补贴 |
| 护理补贴 | 第48条 | 对生活不能自理的残疾人给予护理补贴 |
| 盲人免费乘车 | 第50条 | 盲人持有效证件免费乘坐市内公共汽车、电车、地铁、渡船 |
| 无障碍设施 | 第52-53条 | 符合国家无障碍设施工程建设标准的建筑物、道路、交通设施等 |
| 考试合理便利 | 第54条 | 盲人参加考试提供盲文试卷、电子试卷或专人协助 |
| 专用停车位 | 第55条 | 有条件的公共停车场为残疾人设置专用停车位 |
| 导盲犬 | 第58条 | 盲人携带导盲犬出入公共场所受法律保护 |
| 法律援助 | 第60条 | 经济困难残疾人可获法律援助或司法救助 |
| 就业歧视起诉权 | 第64条 | 招用方面歧视残疾人的，残疾人劳动者可直接向法院起诉 |
