# 操作模式

## 模式1：按比例就业合规审查（用人单位视角）

**步骤**：
1. **计算应安排人数** = 在职职工总数 × 1.5%※（各省比例不同，向上取整）
2. **核实已安排人数**：持有效残疾证的在岗职工
3. **差额处理**：
   - 已安排 ≥ 应安排 → 合规，可享受税收优惠
   - 已安排 < 应安排 → 缴纳残疾人就业保障金，或补充招聘
4. **提供适当条件**：对残疾职工提供适当劳动条件和劳动保护（第38条）

**关键数字**：
- 比例底线：**1.5%**※
- 集中就业单位：残疾人职工占比 ≥ 25%（就业促进法第55条）

**违规后果**：未缴保障金 → 责令限期缴纳 + 滞纳金 + 罚款

## 模式2：残疾人就业歧视维权三步法

**第一步：固定证据**
- 招聘简章/录用通知中的歧视性表述（如"残疾人谢绝"）
- 投递简历被拒的记录（邮件、短信、录音）
- 残疾证、劳动能力证明

**第二步：选择维权途径（三选一，可并行）**
- **行政投诉**：向当地残联投诉（第59条），残联要求主管部门查处
- **直接起诉**：依第64条直接向法院起诉（**无需仲裁前置**）
- **劳动仲裁**：如涉及劳动关系建立后的歧视，可申请仲裁（第60条）

**第三步：主张权利**
- 请求权基础：第3条（平等权）+ 第38条（招用不得歧视）
- 附加请求：民法典第109条一般人格权 + 第1183条精神损害赔偿
- 法律援助：经济困难可申请（第60条）

## 模式3：残疾人就业扶持申请

| 扶持项目 | 申请主体 | 依据 | 办理部门 |
|---|---|---|---|
| 税收优惠 | 安排残疾人达标/超比例单位 | 第36条 | 税务部门 |
| 行政事业性收费免除 | 从事个体经营的残疾人 | 第36条 | 工商/审批部门 |
| 政府采购优先 | 残疾人福利性单位 | 第36条 | 财政/采购部门 |
| 公益性岗位安置 | 就业困难残疾人 | 第36条 | 人社部门 |
| 免费职业培训 | 残疾人 | 第37条 | 残联就业服务机构 |
| 社保补贴 | 生活困难残疾人 | 第47条 | 社保/残联部门 |
| 护理补贴 | 生活不能自理残疾人 | 第48条 | 民政/残联部门 |

## 模式4：无障碍设施维权

**场景**：公共场所/建筑物无障碍设施不符合标准或被占用

**步骤**：
1. 拍照/录像固定证据
2. 向设施管理方或主管部门投诉（第66条）
3. 涉及残疾人专用停车位被占用 → 向交管/城管部门举报
4. 涉及考试合理便利被拒 → 向考试组织部门或教育主管部门投诉（第54条）
5. 涉及导盲犬被拒 → 向残联投诉或向法院起诉（第58条）
