# 速查表

## 高频数字卡

| 数字 | 含义 | 条文 |
|---|---|---|
| **1.5%**※ | 用人单位安排残疾人就业比例底线 | 第33条 |
| **25%** | 集中使用残疾人的用人单位中残疾人职工占比 | 就业促进法第55条 |
| 免费 | 残疾人公共就业服务、职业培训 | 第37条 |
| 免费 | 盲人市内公共交通、盲人读物邮件寄递 | 第50条 |
| 免除 | 个体经营残疾人行政事业性收费 | 第36条 |

## 维权流程卡

```
残疾人权益受侵害
    │
    ├─→ 向残联投诉（第59条）──→ 残联要求主管部门查处
    │
    ├─→ 要求有关部门处理（第60条）
    │
    ├─→ 申请劳动仲裁（第60条）
    │
    └─→ 直接向法院起诉（第60、64条）
         │
         └─→ 经济困难 → 申请法律援助（第60条）
```

**就业歧视特别提示**：第64条明确残疾人劳动者可直接起诉，**无需仲裁前置**。
