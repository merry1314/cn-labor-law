# ch01 总则与平等权利（第1–16条）

## Core Idea
总则奠定全法的"权利+保障"地基：**残疾定义**（第2条：视力、听力、言语、肢体、智力、精神、多重和其他残疾8类，残疾标准由国务院规定）、**平等权**（第3条：政治、经济、文化、社会和家庭生活等方面享有同其他公民平等的权利，公民权利和人格尊严受法律保护；**禁止基于残疾的歧视**、禁止侮辱侵害、禁止通过大众传播媒介或者其他方式贬低损害残疾人人格）、**特别扶助**（第4条：国家采取辅助方法和扶持措施，减轻或者消除残疾影响和外界障碍）、**制度保障**（第5条：残疾人事业纳入国民经济和社会发展规划、经费列入财政预算）、**残联角色**（第8条：代表残疾人共同利益、维护合法权益、动员社会力量）、**家庭义务**（第9条：扶养人履行扶养义务、监护人履行监护职责，禁止家庭暴力、虐待、遗弃）、**特别保障对象**（第12条：残疾军人、因公致残人员等实行特别保障、给予抚恤和优待）、**全国助残日**（第14条：每年5月的第三个星期日）。

## Key Concepts

### 1. 残疾人定义（第2条）
- **残疾人**：在心理、生理、人体结构上，某种组织、功能丧失或者不正常，全部或者部分丧失以正常方式从事某种活动能力的人
- **残疾类型**：视力残疾、听力残疾、言语残疾、肢体残疾、智力残疾、精神残疾、多重残疾和其他残疾
- **残疾标准**：由国务院规定

### 2. 平等权利与反歧视（第3条）★核心
- 残疾人在政治、经济、文化、社会和家庭生活等方面享有**同其他公民平等的权利**
- 残疾人的公民权利和**人格尊严受法律保护**
- **禁止基于残疾的歧视**；禁止侮辱、侵害残疾人；禁止通过大众传播媒介或者其他方式贬低损害残疾人人格

### 3. 特别扶助原则（第4条）
- 国家采取辅助方法和扶持措施，对残疾人给予特别扶助，减轻或者消除残疾影响和外界障碍，保障残疾人权利的实现

### 4. 残联职责（第8条）
- 中国残疾人联合会及其地方组织，**代表残疾人的共同利益**，维护残疾人的合法权益，团结教育残疾人，为残疾人服务
- 依照法律、法规、章程或接受政府委托，开展残疾人工作

### 5. 特别保障对象（第12条）
- 残疾军人、因公致残人员以及其他为维护国家和人民利益致残的人员，实行特别保障，给予抚恤和优待

### 6. 立法目的与制度保障（第1、5条）
- **立法目的**（第1条）：维护残疾人合法权益，发展残疾人事业，保障残疾人平等地充分参与社会生活、共享社会物质文化成果
- **制度保障**（第5条）：县级以上政府将残疾人事业纳入国民经济和社会发展规划，残疾人事业经费列入财政预算，建立稳定的经费保障机制

### 适用场景（When to use）

- 残疾人主张平等就业权、人格尊严受侵害时
- 用人单位以残疾为由拒绝录用或差别对待时
- 需要援引"禁止基于残疾的歧视"作为请求权基础时

## Anti-patterns

- ❌ 将残疾等同于无劳动能力 → 第30条：国家保障残疾人劳动的权利，各级人民政府应当对残疾人劳动就业统筹规划、创造劳动就业条件
- ❌ 认为残疾人只能在福利企业就业 → 第33条按比例就业制度要求国家机关、社会团体、企业事业单位、民办非企业单位**所有**用人单位按规定比例安排残疾人就业（1.5%※省比例）
- ❌ 以"关爱扶持"之名行排斥之实 → 第3条禁止基于残疾的歧视；第4条辅助方法和扶持措施正是要减轻或消除残疾影响和外界障碍，不是排斥的理由
- ❌ 大众传播媒介贬低损害残疾人人格 → 第3条明令禁止；罚则由文化、广播电视、电影、新闻出版或其他有关主管部门依据职权责令改正并依法给予行政处罚（第62条）

## Worked Example

**场景**：某公司招聘简章写明"肢体残疾人谢绝"，残疾人王某投递简历被拒。

**分析**：
1. 公司行为违反第3条"禁止基于残疾的歧视"
2. 同时违反第38条"在职工的招用等方面不得歧视残疾人"
3. 王某可依第64条向法院提起诉讼，也可依就业促进法第62条直接起诉
4. 可同时援引民法典第109条一般人格权主张精神损害赔偿

场景展开：2023年，某科技公司发布"运营专员（月薪1万–1.5万元）"招聘简章，简章载明"肢体残疾人谢绝"；王某（持残疾人证，肢体残疾，计算机专业毕业）在线投简历被拒，HR拒绝理由载明"不符合身体健康要求"。
→ 判定与处理：
1. 招聘简章"肢体残疾人谢绝"表述违反第3条（禁止基于残疾的歧视）与第38条第2款（招用等方面不得歧视）——该岗位本身无肢体残疾的法定职业禁忌
2. 王某可要求有关主管部门责令改正（第64条）
3. 王某可依法向人民法院提起诉讼（第64条），主张停止侵害、赔礼道歉、赔偿损失
4. 可同时援引民法典第109条一般人格权主张精神损害赔偿 ※（数额由法院按侵权人过错、行为方式与后果酌定）
5. 经济困难的可申请法律援助（第60条）
→ 举证要点：固定招聘简章（截图/公证）、投递记录、拒绝理由；公司若不能证明岗位对该残疾类别有客观职业禁忌，一般承担不利后果 ※（结果视具体案情）

## Key Takeaways
1. 第2条残疾定义8类，残疾标准由国务院规定
2. 第3条"三禁止"：禁止基于残疾的歧视、禁止侮辱侵害、禁止通过大众传播媒介贬低损害人格
3. 第4条特别扶助原则：辅助方法+扶持措施，减轻或消除残疾影响和外界障碍
4. 第5条制度保障：残疾人事业纳入发展规划、经费列入财政预算
5. 第8条残联代表残疾人共同利益、维护合法权益
6. 第12条残疾军人、因公致残人员等特别保障、抚恤和优待
7. 第14条每年5月第三个星期日为全国助残日
