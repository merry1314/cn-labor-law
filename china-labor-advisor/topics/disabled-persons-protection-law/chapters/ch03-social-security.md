# ch03 社会保障与无障碍环境（第41–58条）

## Core Idea
本章是"物质保障+参与便利"双轮：社会保障层（第46–51条）落实残疾人社会保障权——社会保险参加+社保补贴（第47条）、多渠道生活/教育/住房救助（第48条）、贫困残疾人基本医疗/康复/辅助器具救助+生活不能自理者护理补贴（第48条）、"三无"残疾人政府供养（第49条）、公共交通便利优惠+**盲人持有效证件免费乘坐**市内公共汽车、电车、地铁、渡船+盲人读物邮件免费寄递（第50条）；无障碍层（第52–58条）覆盖**设施无障碍**（新建、改建、扩建建筑物、道路、交通设施等应当符合国家无障碍设施工程建设标准，第53条）与**信息交流无障碍**（国家举办的各类升学考试、职业资格考试和任职考试有盲人参加的，应当提供盲文试卷、电子试卷或者专人协助，第54条）、公共服务语音/文字提示/手语/盲文+优先服务（第55条）、无障碍停车位（第55条）、导盲犬出入公共场所（第58条）。

## Key Concepts

### 1. 文化生活权（第41-45条）
- 国家保障残疾人享有**平等参与文化生活**的权利
- 措施：盲文读物、有声读物、电视手语节目、字幕、残疾人体育运动会等

### 2. 社会保障（第46-51条）
- **社会保险**（第47条）：残疾人及其所在单位应参加社保；生活困难残疾人给予**社会保险补贴**
- **社会救助**（第48条）：
  - 生活困难残疾人 → 生活、教育、住房救助
  - 贫困残疾人 → 基本医疗、康复、辅助器具救助
  - 生活不能自理的残疾人 → **护理补贴**
- **供养**（第49条）：无劳动能力、无扶养人、无生活来源的残疾人 → 政府供养
- **公共交通优惠**（第50条）：
  - 残疾人搭乘公共交通工具 → 便利和优惠
  - **盲人持有效证件免费乘坐**市内公共汽车、电车、地铁、渡船
  - 盲人读物邮件**免费寄递**
  - 可免费携带随身必备辅助器具
- **电信/广电优惠**（第50条）：鼓励对盲人、听力残疾人、言语残疾人给予优惠

### 3. 无障碍环境（第52-58条）
- **建设标准**（第53条）：新建、改建、扩建建筑物、道路、交通设施等，应当符合国家无障碍设施工程建设标准
- **已建成设施改造**（第53条）：逐步推进已建成设施改造，优先推进与残疾人日常工作、生活密切相关的公共服务设施
- **信息交流无障碍**（第54条）：
  - 为残疾人获取公共信息提供便利
  - 升学考试、职业资格考试、任职考试有盲人参加的 → 提供**盲文试卷、电子试卷或专人协助**
- **公共服务**（第55条）：公共服务机构和公共场所应提供语音和文字提示、手语、盲文等信息交流服务
- **无障碍停车位**（第55条）：有条件的公共停车场应当为残疾人设置**专用停车位**
- **导盲犬**（第58条）：盲人携带导盲犬出入公共场所，应当遵守国家有关规定

### 4. 供养红线与考试便利（第49、54条）
- **供养红线**（第49条）：残疾人供养、托养机构及其工作人员不得侮辱、虐待、遗弃残疾人——罚则为处分+构成违反治安管理行为的行政处罚（第65条）
- **考试合理便利**（第54条）：国家举办的各类升学考试、职业资格考试和任职考试，有盲人参加的，应当为盲人提供盲文试卷、电子试卷或者由专门的工作人员予以协助

### 适用场景（When to use）

- 残疾人申请社保补贴、护理补贴时
- 盲人免费乘车被拒时
- 公共建筑/场所无障碍设施不符合标准时
- 盲人参加考试需要合理便利时
- 残疾人专用停车位被占用时

## Anti-patterns

- ❌ 认为无障碍设施只是"方便"而非"义务" → 第53条：新建、改建和扩建建筑物、道路、交通设施等应当**符合**国家无障碍设施工程建设标准——强制性标准；不符合或未对无障碍设施及时维修和保护造成后果的，由有关主管部门依法处理（第66条）
- ❌ 拒绝导盲犬进入公共场所 → 第58条：盲人携带导盲犬出入公共场所应当遵守国家有关规定——导盲犬不是"宠物"，"遵守国家有关规定"是合规前提而非拒绝理由
- ❌ 要求盲人购票乘坐地铁 → 第50条第2款：盲人持有效证件**免费**乘坐市内公共汽车、电车、地铁、渡船等公共交通工具
- ❌ 占用残疾人专用停车位 → 第55条：有条件的公共停车场应当为残疾人设置专用停车位，车位应专用专用 ※（占用处罚按当地公共停车管理规定）

## Worked Example

**场景**：盲人李某持有效证件乘坐地铁被要求购票，且携带导盲犬被车站拒绝入内。

**分析**：
1. 盲人持有效证件免费乘坐市内地铁是第50条明确规定的权利
2. 盲人携带导盲犬出入公共场所受第58条保护
3. 车站行为违反第50、58条，李某可向残联投诉（第59条）或要求主管部门处理

场景展开：2023年，盲人李某（持残疾人证、导盲犬工作证）携带导盲犬到地铁站上班，车站工作人员要求其购票进站，并以"禁止携带动物"为由拒绝导盲犬入内，李某被拦在安检口约20分钟后放弃进站。
→ 判定与处理：
1. 免费乘车权：第50条第2款——盲人持有效证件免费乘坐市内地铁，车站要求购票违反规定
2. 导盲犬入内：第58条——盲人携带导盲犬出入公共场所应当遵守国家有关规定，车站不得以"禁带动物"笼统拒绝（导盲犬不属于普通宠物）
3. 维权路径：向残联投诉（第59条），残联有权要求有关部门或者单位查处，有关部门应当依法查处并予以答复
4. 替代路径：要求有关部门依法处理、依法申请仲裁、依法向法院提起诉讼（第60条三选一）
5. 结果：车站纠正要求，李某免费进站；若车站行为给李某造成损失（如改乘出租车费用、误工），可依法主张民事责任（第67条）※（赔偿范围由法院按实际损失认定）

## Key Takeaways
1. 第47条：残疾人及其所在单位按规定参加社会保险；生活确有困难的给予社会保险补贴
2. 第48条：生活/教育/住房多渠道救助+贫困残疾人医疗/康复/辅助器具救助+生活不能自理者护理补贴
3. 第49条："三无"（无劳动能力、无扶养人、无生活来源）残疾人政府供养；供养托养机构禁止侮辱、虐待、遗弃
4. 第50条：盲人持有效证件免费乘坐市内公交；盲人读物邮件免费寄递；可免费携带随身必备辅助器具
5. 第53条：新建、改建、扩建须符合无障碍建设标准；已建成设施逐步改造（优先公共服务设施）
6. 第54条：国家举办的考试有盲人参加的，提供盲文试卷、电子试卷或专人协助
7. 第55条：公共服务信息交流服务（语音/文字提示、手语、盲文）+无障碍停车位
8. 第58条：导盲犬出入公共场所遵守国家有关规定
