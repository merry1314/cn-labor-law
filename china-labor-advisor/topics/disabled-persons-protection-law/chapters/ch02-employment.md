# ch02 劳动就业（第30–40条）★核心章

## Core Idea
第四章劳动就业是本法核心章，构建"就业权—安置义务—扶持措施—在职保护—强迫劳动禁止"全链条：**劳动权**（第30条：国家保障残疾人劳动的权利）、**总方针**（第31条：集中与分散相结合，优惠政策和扶持保护措施，多渠道、多层次、多种形式）、**集中就业**（第32条：残疾人福利企业、盲人按摩机构和其他福利性单位）、**按比例就业**（第33条：国家机关、社会团体、企业事业单位、民办非企业单位按规定比例安排，**1.5%**※省比例，达不到比例按国家规定履行保障残疾人就业义务即缴纳残疾人就业保障金，鼓励超比例）、**扶持措施**（第34–37条：自主创业、税收优惠、个体经营免行政事业性收费、政府采购优先、公益性岗位、免费就业服务）、**在职保护**（第38–39条：8个方面不得歧视、适当劳动条件和设施改造、盲人按摩权益保障、岗位技术培训）、**红线**（第40条：不得以暴力、威胁或者非法限制人身自由的手段强迫残疾人劳动）。

## Key Concepts

### 1. 劳动就业权（第30-31条）
- **国家保障残疾人劳动的权利**（第30条）
- **方针**：集中与分散相结合，采取优惠政策和扶持保护措施，通过多渠道、多层次、多种形式就业

### 2. 集中就业（第32条）
- 政府和社会举办**残疾人福利企业**、盲人按摩机构和其他福利性单位，集中安排残疾人就业

### 3. 按比例安排残疾人就业（第33条）★核心制度
- **国家实行按比例安排残疾人就业制度**
- 用人单位范围：国家机关、社会团体、企业事业单位、民办非企业单位
- **比例不低于1.5%**※（各省具体比例由省政府规定）
- 达不到比例的，按照国家有关规定履行保障残疾人就业义务（缴纳**残疾人就业保障金**）
- 国家鼓励超过比例安排

### 4. 扶持措施（第34-37条）
- **自主创业**（第34条）：鼓励和扶持残疾人自主择业、自主创业
- **税收优惠**（第36条）：
  - 安排残疾人就业达到/超过比例或集中安排的用人单位 → 税收优惠
  - 从事个体经营的残疾人 → 税收优惠 + **免除行政事业性收费**
- **政府采购优先**（第36条）：同等条件下优先购买残疾人福利性单位产品或服务
- **公益性岗位**（第36条）：开发适合残疾人就业的公益性岗位
- **优先核发执照**（第36条）：申请个体经营的残疾人，优先核发营业执照
- **免费就业服务**（第37条）：
  - 公共就业服务机构 → 为残疾人免费提供就业服务
  - 残联就业服务机构 → 免费职业指导、职业介绍、职业培训

### 5. 在职反歧视与劳动保护（第38条）★
- **禁止歧视**：招用、转正、晋级、职称评定、劳动报酬、生活福利、休息休假、社会保险等方面，**不得歧视残疾人**
- **适当劳动条件**：根据残疾职工特点提供适当劳动条件和劳动保护，改造劳动场所、设备和生活设施
- **盲人按摩**：保障盲人保健和医疗按摩人员从业的合法权益

### 6. 岗位培训（第39条）
- 残疾职工所在单位应当对残疾职工进行**岗位技术培训**，提高劳动技能和技术水平

### 7. 禁止强迫劳动（第40条）
- 任何单位和个人不得以**暴力、威胁或者非法限制人身自由**的手段强迫残疾人劳动

### 8. 按比例就业具体办法（第33条）
- 残疾人就业的具体办法由国务院规定——具体比例（1.5%※各省不同，如北京1.7%、上海1.6%）与保障金的计征、减免办法按国务院规定及省级政府规定执行 ※（集中安排单位残疾人职工占比≥25%的认定见就业促进法第55条）

### 适用场景（When to use）

- 用人单位不按比例安排残疾人就业时
- 残疾人遭遇就业歧视（招用、转正、晋级等）时
- 残疾人申请创业税收优惠、行政事业性收费减免时
- 残疾人需要免费职业培训、就业服务时
- 残疾职工劳动条件不适当、被强迫劳动时

## Anti-patterns

- ❌ 只按1.5%最低线安排残疾人而不提供适当劳动条件 → 第38条第3款：残疾职工所在单位应当根据残疾职工的特点提供适当劳动条件和劳动保护，并根据实际需要对劳动场所、劳动设备和生活设施进行改造——"安排到位"不是终点
- ❌ 认为安排残疾人就业纯粹是负担 → 第36条：达到/超过比例或集中安排可享受税收优惠、政府采购同等条件优先、开发公益性岗位；从事个体经营的残疾人免行政事业性收费+优先核发营业执照
- ❌ "挂名就业"——签劳动合同但不实际用工，或安排与残疾特点不符的岗位不提供合理便利 → 第33条要求"为其选择适当的工种和岗位"，核心是**实际就业+适当岗位** ※（按比例计入的认定口径按地方办法）
- ❌ 以"照顾扶持"名义强迫残疾人劳动 → 第40条：任何单位和个人不得以暴力、威胁或者非法限制人身自由的手段强迫残疾人劳动——可投诉举报，构成犯罪的依法追究刑事责任（第67条）

## Worked Example

**场景**：某企业有职工200人，未安排任何残疾人就业，也未缴纳残疾人就业保障金。

**分析**：
1. 按1.5%比例，该企业应安排至少3名残疾人就业（200×1.5%=3）
2. 未安排也未缴纳保障金，违反第33条
3. 残疾人联合会可要求有关部门查处（第59条）
4. 企业应补缴残疾人就业保障金，并可能面临行政处罚

场景展开：2023年度，某信息技术公司在职职工200人，未安排任何残疾人就业，连续3个年度未申报缴纳残疾人就业保障金。
→ 计算与判定：
1. 应安排人数：200×1.5%=**3人**（本地比例1.5%※各省不同）
2. 实际安排：0人
3. 应缴保障金（按保障金管理规定的计算公式※）：（应安排3人−实际0人）×当地上年职工年平均工资（假设9万元/年）=**27万元/年**，3年累计**81万元** ※（具体比例、计算基数、征收标准与减免措施按省级办法；安排1名残疾人全日制就业按安排1人计，按比例分计口径按地方规定）
4. 违规判定：违反第33条按比例就业制度——达不到规定比例的，应当**按照国家有关规定履行保障残疾人就业义务**（缴纳保障金）；既不安排又不缴纳=双重不合规
5. 救济与处理：残联可要求有关部门查处（第59条）；企业应补缴保障金并缴滞纳金 ※（滞纳金与追缴程序按当地征收办法，违规后果见本模块patterns）
6. 合规路径：招用3名残疾人（订立劳动合同+缴纳社会保险+实际用工※认定口径按地方规定）或足额缴金；达到/超过比例的可依法申请税收优惠（第36条）

## Key Takeaways
1. 第30条劳动权+第31条集中与分散相结合方针——双轨就业制度
2. 第33条按比例就业：1.5%※省比例，达不到缴纳保障金，鼓励超比例
3. 第36条扶持包：税收优惠+个体经营免行政事业性收费+政府采购优先+公益性岗位+优先核发执照
4. 第37条免费就业服务：公共就业服务机构+残联就业服务机构（职业指导/职业介绍/职业培训）
5. 第38条在职保护：8个方面不得歧视+适当劳动条件与设施改造+盲人按摩权益保障
6. 第39条岗位技术培训是用人单位义务
7. 第40条禁止强迫劳动是红线
