# ch04 法律责任与救济（第59–68条）

## Core Idea
本章是全法的最后保障：**"先投诉、再三选一救济、法律援助兜底+具体违法行为的具体责任"**。救济结构：第59条残联投诉（残联有权要求有关部门或者单位查处，有关部门应当依法查处**并予以答复**；对诉讼维权给予支持；对侵害特定残疾人群体利益的行为有权要求依法查处）→ 第60条**三选一**（要求有关部门依法处理/依法向仲裁机构申请仲裁/依法向人民法院提起诉讼）+法律援助/司法救助（有经济困难或者其他原因确需援助的，当地法律援助机构或者人民法院**应当**给予帮助）→ 第64条就业歧视特别救济（有关主管部门**责令改正**+残疾人劳动者可以依法向人民法院**直接提起诉讼**，无需仲裁前置）。责任面覆盖六类主体：申诉控告检举推诿压制或打击报复（第61条）、媒介贬低损害人格（第62条）、教育机构拒收残疾学生（第63条）、招用歧视（第64条）、供养托养机构侮辱虐待遗弃（第65条）、无障碍设施违法（第66条），以及兜底责任（第67条：行政从其规定+民事赔偿+刑事追究）。

## Key Concepts

### 1. 维权途径（第59-60条）★
- **残联投诉**（第59条）：残疾人合法权益受侵害的，可向残疾人组织投诉；残联有权要求有关部门查处，有关部门应当依法查处并答复
- **诉讼支持**（第59条）：残联对残疾人通过诉讼维权需要帮助的，应当给予支持
- **三选一维权**（第60条）：
  1. 要求有关部门依法处理
  2. 依法向仲裁机构申请仲裁
  3. 依法向人民法院提起诉讼
- **法律援助/司法救助**（第60条）：经济困难或其他原因确需援助的残疾人，法律援助机构或法院应当提供帮助

### 2. 就业歧视救济（第64条）★核心
- 违反本法规定，在职工的**招用等方面歧视残疾人**的，由有关主管部门责令改正
- **残疾人劳动者可以依法向人民法院提起诉讼**

### 3. 各类法律责任（第61-67条）
| 违法行为 | 责任 | 条文 |
|---|---|---|
| 推诿/拖延/压制查处申诉控告检举，或打击报复 | 责令改正+处分 | 第61条 |
| 国家工作人员未履职造成严重后果 | 处分 | 第61条 |
| 大众传播媒介贬低损害残疾人人格 | 责令改正+行政处罚 | 第62条 |
| 教育机构拒接残疾学生或附加条件 | 责令改正+处分 | 第63条 |
| **招用方面歧视残疾人** | 责令改正+可起诉 | 第64条 |
| 供养托养机构侮辱虐待遗弃残疾人 | 处分+行政处罚 | 第65条 |
| 无障碍设施不符合标准或未及时维修 | 依法处理 | 第66条 |
| 其他侵害残疾人权益 | 行政处罚/民事责任/刑事责任 | 第67条 |

### 4. 附则（第68条）
- 本法自2008年7月1日起施行

### 5. 救济要点（第60、64、67条）
- **无仲裁前置**（第64条）：就业歧视案件可直接向法院起诉——不同于一般劳动争议的仲裁前置 ※（个案属"招用"还是"在职"争议，决定适用劳动争议程序还是直接起诉）
- **兜底责任**（第67条）：其他法律法规规定行政处罚的从其规定；造成财产损失或者其他损害的，依法承担民事责任；构成犯罪的，依法追究刑事责任——行政、民事、刑事三级责任
- **答复义务**（第59条）：有关部门对残联要求的查处，应当依法查处**并予以答复**——"受理不处理"本身可追责（第61条）

### 适用场景（When to use）

- 残疾人需要维权时，选择投诉/仲裁/诉讼途径
- 残疾人遭遇就业歧视需要起诉时
- 残疾人申请法律援助时
- 无障碍设施违法需要追责时

## Anti-patterns

- ❌ 认为残疾人就业歧视必须先仲裁 → 第64条明确残疾人劳动者可以直接向人民法院提起诉讼——就业歧视案件不适用一般劳动争议的仲裁前置
- ❌ 忽视残联的维权支持作用 → 第59条：残联对投诉有权要求有关部门或者单位查处，有关部门应当依法查处**并予以答复**；对诉讼维权需要帮助的，残联应当给予支持
- ❌ "投诉了就等于处理了" → 第59条要求有关部门依法查处**并予以答复**；推诿、拖延、压制不予查处或对投诉人打击报复的，对直接负责的主管人员和其他直接责任人员给予处分（第61条）
- ❌ 认为侵害残疾人权益没有民事后果 → 第67条：造成财产损失或者其他损害的，依法承担民事责任；构成犯罪的，依法追究刑事责任

## Worked Example

**场景**：残疾人张某应聘被拒，理由是"不招残疾人"，张某想维权。

**维权路径**：
1. **行政投诉**：向当地残疾人联合会投诉（第59条），残联要求主管部门查处
2. **直接起诉**：依第64条直接向法院提起诉讼（无需仲裁前置）
3. **法律援助**：如经济困难，向法律援助机构申请法律援助（第60条）
4. **请求权基础**：第3条（平等权）+ 第38条（招用不得歧视）+ 第64条（起诉权）
5. **附加请求**：可援引民法典第109条主张精神损害赔偿

场景展开：2023年6月，张某（持残疾人证，肢体残疾，计算机专业毕业）应聘某公司"数据分析师"岗位（月薪8000元），通过两轮面试，6月10日收到录用意向，6月13日改收拒录邮件，理由"该岗位不接收残疾人员"。
→ 维权时间线：
1. 2023-06：固定证据（招聘页截图、投递与面试记录、录用意向、拒录邮件）
2. 2023-06-20：向市残联投诉（第59条），残联要求人社部门查处，部门应当依法查处并予以答复
3. 2023-07：向法院直接起诉（第64条，无仲裁前置），主张停止侵害、赔礼道歉、赔偿损失 ※（精神损害赔偿数额由法院按过错、行为方式与后果酌定）
4. 张某经济困难 → 申请法律援助（第60条），当地法律援助机构或法院应当给予法律援助或司法救助
5. 请求权基础：第3条（平等权）+ 第38条（招用等方面不得歧视）+ 第64条（起诉权）+ 民法典第109条（一般人格权）
→ 结果：公司"该岗位不接收残疾人员"的表述缺乏岗位职业禁忌的客观依据，法院一般认定构成就业歧视，支持赔礼道歉及适当赔偿等诉请；同时有关主管部门按第64条责令改正 ※（裁判结果视具体案情）

## Key Takeaways
1. 三选一救济（第60条）：要求部门处理/仲裁/起诉，按案情选择，可并行启动
2. 第59条残联投诉：残联要求查处+部门必须**答复**+残联支持诉讼
3. 第64条就业歧视：主管部门责令改正+可直接向法院起诉（无仲裁前置）
4. 第60条法律援助：经济困难或其他原因确需援助的，法律援助机构或法院**应当**提供法律援助/司法救助
5. 责任主体矩阵：部门推诿（第61条）、媒介（第62条）、学校（第63条）、用人单位（第64条）、供养托养机构（第65条）、无障碍设施（第66条）、兜底（第67条）
6. 第67条三级责任：行政处罚（从其规定）+民事责任+刑事责任
7. 本法自2008-07-01施行（第68条）
