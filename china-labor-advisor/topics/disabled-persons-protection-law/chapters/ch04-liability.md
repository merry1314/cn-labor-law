# ch04 法律责任与救济（第59–68条）

## 核心框架

### 1. 维权途径（第59-60条）★
- **残联投诉**（第59条）：残疾人合法权益受侵害的，可向残疾人组织投诉；残联有权要求有关部门查处，有关部门应当依法查处并答复
- **诉讼支持**（第59条）：残联对残疾人通过诉讼维权需要帮助的，应当给予支持
- **三选一维权**（第60条）：
  1. 要求有关部门依法处理
  2. 依法向仲裁机构申请仲裁
  3. 依法向人民法院提起诉讼
- **法律援助/司法救助**（第60条）：经济困难或其他原因确需援助的残疾人，法律援助机构或法院应当提供帮助

### 2. 就业歧视救济（第64条）★核心
- 违反本法规定，在职工的**招用等方面歧视残疾人**的，由有关主管部门责令改正
- **残疾人劳动者可以依法向人民法院提起诉讼**

### 3. 各类法律责任（第61-67条）
| 违法行为 | 责任 | 条文 |
|---|---|---|
| 推诿/拖延/压制查处申诉控告检举，或打击报复 | 责令改正+处分 | 第61条 |
| 国家工作人员未履职造成严重后果 | 处分 | 第61条 |
| 大众传播媒介贬低损害残疾人人格 | 责令改正+行政处罚 | 第62条 |
| 教育机构拒接残疾学生或附加条件 | 责令改正+处分 | 第63条 |
| **招用方面歧视残疾人** | 责令改正+可起诉 | 第64条 |
| 供养托养机构侮辱虐待遗弃残疾人 | 处分+行政处罚 | 第65条 |
| 无障碍设施不符合标准或未及时维修 | 依法处理 | 第66条 |
| 其他侵害残疾人权益 | 行政处罚/民事责任/刑事责任 | 第67条 |

### 4. 附则（第68条）
- 本法自2008年7月1日起施行

## When to use

- 残疾人需要维权时，选择投诉/仲裁/诉讼途径
- 残疾人遭遇就业歧视需要起诉时
- 残疾人申请法律援助时
- 无障碍设施违法需要追责时

## Anti-patterns

- ❌ 认为残疾人就业歧视必须先仲裁——第64条明确残疾人劳动者可以直接向法院起诉
- ❌ 忽视残联的维权支持作用——第59条残联有权要求查处并支持诉讼

## Worked Example

**场景**：残疾人张某应聘被拒，理由是"不招残疾人"，张某想维权。

**维权路径**：
1. **行政投诉**：向当地残疾人联合会投诉（第59条），残联要求主管部门查处
2. **直接起诉**：依第64条直接向法院提起诉讼（无需仲裁前置）
3. **法律援助**：如经济困难，向法律援助机构申请法律援助（第60条）
4. **请求权基础**：第3条（平等权）+ 第38条（招用不得歧视）+ 第64条（起诉权）
5. **附加请求**：可援引民法典第109条主张精神损害赔偿
