# Cheatsheet — 中华人民共和国劳动争议调解仲裁法

## 时限总表（背诵级）

| 环节 | 时限 | 条文 |
|---|---|---|
| 仲裁时效（一般） | **1年**（知道或应当知道权利被侵害起） | 第27条 |
| 欠薪时效 | **存续期间不受限**；**离职起1年** | 第27条 |
| 调解不成转仲裁 | 收到调解申请**15日**未达成协议 | 第14条 |
| 仲裁委受理决定 | 收到申请起**5日**（受理/书面不受理） | 第29条 |
| 送达申请书副本 | 受理后**5日**内 | 第30条 |
| 被申请人答辩 | **10日**内（不交不影响） | 第30条 |
| 开庭通知 | 开庭**5日**前；延期申请**3日**前 | 第35条 |
| **裁决时限** | 受理起**45日**；复杂可延**15日**（上限60日）；**超期可起诉** | 第43条 |
| 对裁决起诉期 | **15日**（终局：劳动者可诉；非终局：双方可诉） | 第48、50条 |
| 单位申请撤销终局裁决 | **30日**内向**中院**（六事由） | 第49条 |
| 撤销后起诉 | 收到裁定书**15日**内 | 第49条 |
| 生效文书履行 | 按期限；逾期不履行→法院**强制执行** | 第51条 |

## 程序一图流

```
劳动争议发生
   ├─ 协商（可选）
   ├─ 调解（可选）──── 欠薪/工伤医疗费/补偿/赔偿金调解协议
   │                        └─ 单位逾期不履行 → 持协议【申请支付令】(第16条)
   ├─ 行政投诉（欠薪等，第9条，与仲裁并行）
   └─ 仲裁（必经，免费）
        ├─ 受理5日 → 送达5日 → 答辩10日 → 开庭
        ├─ 先行调解（第42条，签收前可反悔）
        ├─ 45+15日裁决（超期→可起诉）
        └─ 裁决
             ├─ 一裁终局（≤12个月最低工资 / 执行劳动标准类）
             │    ├─ 劳动者不服 → 15日起诉（第48条）
             │    └─ 单位不服 → 30日内中院申请撤销（第49条，六事由）
             └─ 非终局
                  ├─ 不服 → 15日起诉（第50条）
                  └─ 期满不诉 → 生效 → 不履行 → 法院强制执行（第51条）
```

## 一裁终局"12个月"限额速算
**终局限额 = 当地月最低工资 × 12**（第47条一）
- 例：月最低工资2590元 → 限额31080元
- 请求金额 ≤ 限额（报酬/工伤医疗费/补偿/赔偿金类）→ 终局
- 注意：**各请求分别还是合计**按各地口径（多数按单项请求金额判断）

## 举证责任速查（第6、39条）

| 证据类型 | 通常在哪 | 劳动者动作 |
|---|---|---|
| 劳动合同 | 双方各执一份 | 没有→要求单位提供 |
| 工资发放台账/银行流水 | 单位+自己 | 自己拉流水；台账要求单位提供 |
| 考勤记录 | **单位** | 明确要求提供（不提供=不利后果） |
| 社保缴费记录 | 单位/经办机构 | 自己查询打印（第4条社保法） |
| 规章制度文本 | **单位** | 要求提供+核实公示签收 |
| 解除/终止通知 | **单位** | 要求提供；自己录音留证 |
| 工作成果/沟通记录 | 双方 | 自己保存（微信/邮件/录音） |

## 仲裁申请书请求构造模板（劳动者常用组合）

1. 确认/否认劳动关系（如未签合同）
2. 支付违法解除赔偿金 2N＝____元（第87条劳动合同法）
3. 支付拖欠工资 ____元（附计算式）
4. 支付未签书面劳动合同二倍工资差额 ____元
5. 支付加班费 ____元（150%/200%/300%分档）
6. 支付未休年休假工资 ____元
7. 支付经济补偿 N＝____元（如走38条被迫解除）
8. 支付因未缴社保导致的损失 ____元（医疗费不能报销等）
9. 出具离职证明+办理档案社保转移

**同一事实、多项请求、一次列足**；每项注明事实依据+证据编号。

## 劳动者"六不"红线
1. 不拖过**离职后1年**（欠薪清算窗）
2. 不**拒不到庭**（视为撤回，第36条）
3. 不在**签收调解书**前随意签字（签收前可反悔）
4. 不签"**个人原因辞职**"（丧失38条补偿资格）
5. 不把**私下和解**当执行依据（要走调解书/支付令）
6. 不对**录音剪辑**（完整原件才是证据）

## 费用
- 仲裁：**0元**（第53条）
- 诉讼：劳动争议案件受理费 **10元/件**（※收费标准）
- 支付令：免收申请费（※民诉法规定）
