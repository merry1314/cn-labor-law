# Chapter 4: 仲裁（二）开庭与裁决 (Arbitration: Hearing & Award, 第31–51条)

## Core Idea
裁决实行**仲裁庭制**（3人，简单案件独任）；核心时限：**受理之日起45日内结束，复杂经批准可延15日**（第43条）——超期不裁决，当事人可**直接起诉**。裁决前**应当先行调解**（第42条）。三类关键制度：**一裁终局**（第47条，小额+执行劳动标准类，劳动者15日可诉、单位只能30日申请**撤销**）、**先予执行**（第44条，追索劳动报酬等，劳动者**可不提供担保**）、**逾期履行可申请法院强制执行**（第51条）。

## Frameworks Introduced
- **仲裁庭制（第三十一、三十二条）**：
  - 3名仲裁员+首席；**简单案件独任**
  - 受理后**5日内**书面通知当事人仲裁庭组成
- **回避（第三十三、三十四条）**：
  - 四情形：当事人/近亲属；与本案有利害关系；其他可能影响公正的关系；私自会见/请客送礼
  - 当事人可**口头或书面**申请回避；仲裁委及时决定并通知
  - 仲裁员索贿受贿、徇私舞弊、**枉法裁决** → 法律责任+**解聘**
- **开庭程序（第三十五至四十条）**：
  - 开庭**5日前**书面通知日期地点；正当理由可**3日前**请求延期
  - **申请人**无正当理由拒不到庭/中途退庭 → **视为撤回**申请
  - **被申请人**无正当理由拒不到庭/中途退庭 → **缺席裁决**
    - When to use: 单位"装死"不来开庭 → 缺席裁决照出（劳动者胜诉概率高，但**证据**仍要自己提交充分——缺席不免除申请人的举证责任）
  - **鉴定**：专门性问题→当事人约定或仲裁庭指定鉴定机构（第37条）
  - **质证辩论**：有权质证辩论，终结时征询最后意见（第38条）
  - **证据规则**：查证属实→认定事实根据；**劳动者无法提供单位掌握管理的证据 → 仲裁庭可要求单位指定期限内提供，不提供→不利后果**（第39条——第6条倒置规则的开庭落地）
  - **笔录补正**：对记录遗漏差错可申请补正，不补正的记入申请（第40条）
- **自行和解（第41条）**：申请仲裁后可自行和解；达成和解 → 可**撤回仲裁申请**
  - When to use: 庭下谈成比裁决快——注意和解后**撤诉**，若对方不履行只能**重新申请仲裁**（和解协议不是执行依据；对比第16条**调解**协议有支付令通道）
- **先行调解（第42条）**：裁决前**应当**先行调解；调解成 → **调解书**（载明请求与协议结果，仲裁员签名+仲裁委印章，**双方签收后生效**）；调解不成或**签收前反悔** → 及时裁决
  - 注意：调解书**签收**生效——签收前可反悔（与第14条调解协议书"达成即生效"不同）
- **裁决时限（第43条）**——超期即解锁诉讼：
  - 自**受理之日起45日内**结束
  - 案情复杂 → 经主任批准**延期**+书面通知，**延长期限≤15日**（合计上限60日）
  - **逾期未作出裁决** → 当事人可就该事项**向法院起诉**
  - 部分事实清楚 → **先行裁决**该部分
- **先予执行（第44条）**——劳动者的"急救阀"：
  - 适用：**追索劳动报酬、工伤医疗费、经济补偿或赔偿金**案件
  - 依当事人申请，可裁决**先予执行**，移送**法院执行**
  - 两条件：① 权利义务关系**明确** ② 不先予执行将**严重影响申请人的生活**
  - **劳动者申请先予执行的，可以不提供担保**
  - When to use: 工伤职工急需医疗费、生活困难急需工资——不等45日裁决，先执行一部分
- **裁决规则（第四十五、四十六条）**：
  - 按**多数仲裁员**意见；不能形成多数 → 按**首席仲裁员**意见
  - 少数意见记入笔录；不同意见的仲裁员可签可不签
  - 裁决书载明：请求、争议事实、理由、结果、日期
- **一裁终局（第四十七、四十八、四十九条）**——双轨救济：
  - **终局裁决两类**（裁决书自**作出之日**起生效）：
    1. 追索劳动报酬、工伤医疗费、经济补偿或赔偿金，**不超过当地月最低工资标准12个月金额**
    2. 因执行国家劳动标准在**工作时间、休息休假、社会保险**等方面的争议
  - **劳动者救济**（第48条）：对终局裁决不服 → **15日内**向法院**起诉**（劳动者不受终局限制！）
  - **单位救济**（第49条）：有证据证明存在六情形之一 → **30日内**向仲裁委所在地**中级人民法院**申请**撤销**：
    1. 适用法律法规确有错误 2. 仲裁委无管辖权 3. 违反法定程序 4. 证据是伪造的 5. 对方隐瞒足以影响公正裁决的证据 6. 仲裁员索贿受贿徇私舞弊枉法裁决
  - 法院合议庭审查核实有其一 → **裁定撤销**；撤销后 → 当事人自收到裁定书**15日内**起诉
  - **不对称设计**：劳动者不服可**起诉**（进入诉讼程序重新审理）；单位只能**撤销**（有限审查、举证在单位）——倾斜保护劳动者
- **非终局裁决救济（第50条）**：
  - 对第47条以外的裁决不服 → **15日内**向法院起诉；**期满不起诉 → 裁决生效**
  - When to use: 超标的（>12个月最低工资）或一般争议——15日是"起诉闹钟"，不起诉裁决即生效，单位可申请强制执行
- **生效文书执行（第51条）**：
  - 生效的**调解书、裁决书**应依期限履行
  - 一方逾期不履行 → 另一方依**民事诉讼法**向法院**申请执行**；受诉法院应当执行
  - When to use: 裁决赢了单位不付 → 申请强制执行（冻结、划扣、限高、纳失）——仲裁文书与法院判决有同等执行力

## Key Concepts
- **45+15日裁决时限**：超期→可起诉（第43条）
- **先行调解**：裁决前必经（第42条）
- **缺席裁决**：被申请人不到庭照裁（第36条）
- **一裁终局**：小额（≤12个月最低工资）+执行劳动标准类（第47条）
- **双轨救济**：劳动者15日**起诉** vs 单位30日**撤销**（第48、49条）
- **先予执行**：权利义务明确+严重影响生活；劳动者免担保（第44条）
- **强制执行**：生效调解书/裁决书→法院执行（第51条）

## Mental Models
- "60日时钟"模型：受理→45日→（批准延15日）→60日——超60日不裁决=自动获得**起诉权**（第43条）；单位"拖"没有程序红利
- "终局不对称"模型：同样一份终局裁决——劳动者不服=**起诉**（全审）；单位不服=**撤销**（六事由+举证）——法律把"推翻裁决"的成本压在单位侧
- "15日闹钟"双份：① 对非终局裁决15日内不起诉=生效（第50条）② 对终局裁决15日内可起诉（第48条）——收到裁决书当天就开始倒计时
- "急救阀"模型（第44条）：工伤医疗费、救命工资→**先予执行**免担保→不等裁决全额——程序正义不挡生存需求

## Anti-patterns
- **裁决后"等等看"**: 15日起诉期是硬窗口——不起诉裁决生效，单位不履行你只能申请执行（结果一样但被动）；不服就**15日内起诉**
- **单位不到庭就"万事大吉"**: 缺席裁决有利，但**你的证据**决定结果——庭前把证据交足（单位掌握的部分写明要求提供）
- **和解撤诉后对方反悔**: 和解协议≠执行依据——只能重新仲裁（时效重新起算但白等一轮）；想要"支付令"通道用**调解**（第16条）而非私下和解
- **小额案件以为"一裁终局=没救"**: 终局只限**单位**的救济方式（撤销）；**劳动者**仍可15日起诉（第48条）
- **工伤医疗费干等**: 符合条件的用**先予执行**（第44条）——救命钱不必等60日

## Worked Example
老赵工伤（九级）被单位拒付工伤医疗费5万元。处理：
1. **仲裁请求**：支付工伤医疗费5万（+其他待遇）；管辖：履行地仲裁委
2. **先予执行**（第44条）：申请仲裁同时申请先予执行——权利义务明确（工伤认定+医疗费发票）+不付严重影响生活（治疗中断）→ 仲裁庭裁决先予执行 → **移送法院执行**（冻结划扣单位账户）——**无需提供担保**
3. **裁决**：45日内裁决；假设30日作出，支持5万——超当地月最低工资12个月？（如月最低2590×12=31080<50000）→ **非终局** → 单位15日内可起诉（第50条）；老赵不服也可15日起诉
4. **单位不履行**：老赵持生效裁决书向法院**申请执行**（第51条）→ 划扣/限高
5. **若单位伪造证据**：单位对终局裁决的撤销事由（第49条四）——反过来说，单位若拿伪造证据"赢"，老赵可主张对方隐瞒/伪造并申请法院撤销（49条对等适用审查）

## Key Takeaways
1. 裁决时限**45日**（可延**15日**）；**超期不裁决→可起诉**（第43条）
2. 裁决前**应当先行调解**；调解书**签收**生效（第42条）
3. 被申请人不到庭 → **缺席裁决**（第36条）
4. **一裁终局**两类：≤12个月最低工资的金钱请求 + 执行劳动标准类（第47条）
5. 终局裁决：**劳动者15日可起诉**；单位30日内向**中院申请撤销**（六事由）（第48、49条）
6. **先予执行**：报酬/工伤医疗费/补偿/赔偿金+权利义务明确+严重影响生活；劳动者**免担保**（第44条）
7. 生效调解书/裁决书不履行 → 法院**强制执行**（第51条）
