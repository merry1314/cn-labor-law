# Chapter 2: 调解 (Mediation, 第10–16条)

## Core Idea
调解是**可选**前置（可跳过直接仲裁），三类调解组织受理（企业调解委员会、基层人民调解组织、乡镇街道调解组织）；**15日**是调解的时限边界——15日未达成协议即可申请仲裁；调解协议有约束力但不具强制执行力；**关键武器**（第16条）：因**拖欠劳动报酬、工伤医疗费、经济补偿或赔偿金**达成调解协议，单位逾期不履行的，劳动者可持调解协议书向法院**申请支付令**——把调解协议变成可执行的"催款令"。

## Frameworks Introduced
- **三类调解组织（第10条）**：
  1. **企业劳动争议调解委员会**（职工代表+企业代表；职工代表由工会成员或全体职工推举，企业代表由负责人指定；**主任由工会成员或双方推举人员担任**）
  2. 依法设立的**基层人民调解组织**
  3. 乡镇、街道设立的具有劳动争议调解职能的组织
  - When to use: 单位内无工会/调解委员会 → 走基层人民调解或街道调解组织（多数街道司法所/劳资调解室承担）
- **调解员资格（第11条）**：公道正派、联系群众、热心调解+一定法律知识政策水平文化水平的成年公民
- **申请形式（第12条）**：**书面或口头**均可；口头申请的，调解组织**当场记录**（申请人基本情况、争议事项、理由、时间）
  - When to use: 降低启动门槛——不写申请书也能调
- **调解方式（第13条）**：充分听取双方陈述、耐心疏导、帮助达成协议
- **调解协议书与生效（第14条）**：
  - 达成协议 → 制作**调解协议书**
  - 双方**签名/盖章** + **调解员签名** + **加盖调解组织印章** → **生效**，对双方有**约束力**，应当履行
  - **15日规则**：自调解组织**收到调解申请之日起15日内**未达成协议 → 当事人可依法**申请仲裁**
  - When to use: 单位"拖调解"超过15日 → 直接转仲裁，不被调解程序拖死时效节奏（注意：申请调解本身构成时效**中断**事由，见第27条二）
- **不履行调解协议（第15条）**：一方在约定期限内不履行 → 另一方可以依法**申请仲裁**
- **支付令衔接（第16条）**——本章王牌条款：
  - 适用范围：**拖欠劳动报酬、工伤医疗费、经济补偿或赔偿金**四类金钱事项
  - 达成调解协议 + 单位在约定期限内不履行
  - → 劳动者持**调解协议书**向法院**申请支付令**，法院应当依法发出
  - When to use: 欠薪调解成协议后单位"画饼"——支付令比仲裁+诉讼+执行快得多（见下 Mental Models）
  - 支付令程序（※民事诉讼法）：法院15日内审查发出 → 单位15日内不提出书面异议又不履行 → 申请**强制执行**；单位提出书面异议且成立的 → 支付令失效，转普通程序（此时可转仲裁）

## Key Concepts
- **调解可选性**：非必经程序（第5条对照）
- **15日边界**：调解不成即转仲裁的时限（第14条）
- **调解协议约束力**：合同性约束，无直接强制执行力（第14条）
- **支付令**：特定金钱调解协议不履行的快捷执行通道（第16条）

## Mental Models
- "调解15日时钟"模型：调解申请受理 → 15日 → 没谈拢就仲裁——调解是"快速通道"不是"无限期等待室"；且申请调解行为本身**中断仲裁时效**（第27条二），谈崩也不亏时效
- "支付令直通车"模型（第16条）：调解协议（欠薪/工伤医疗费/补偿/赔偿金）→ 单位逾期不付 → 支付令 → 15日异议期 → 强制执行——**跳过仲裁**直达执行的最短路径；前提是调解协议写明**金额、期限**（可执行内容明确）
- 支付令失效的备份：单位提异议 → 失效 → 转仲裁（此时时效已中断重算，不亏）

## Anti-patterns
- **调解协议"无限期履行"**: 协议不写明确履行期限 → 第16条支付令与第15条转仲裁都难启动——协议必须写明**金额+日期**
- **口头调解"各表各的": 第14条要"书面调解协议书+三方签章"——口头和稀泥没有约束力凭证
- **被调解拖超时效**: 调解本身中断时效，但"反复调解不立案不记录"可能损失证据时点——15日到了就转仲裁，别恋战
- **支付令申请材料不全**: 需持**调解协议书原件**+申请——协议丢失先向调解组织申请补发

## Worked Example
老陈被公司辞退，双方到街道劳资调解室调解，达成协议：公司10日内支付经济补偿金42000元+拖欠工资15000元。第12天公司未付。处理：
1. **定性**：属第16条四类事项（经济补偿+劳动报酬）+ 单位逾期未履行
2. **支付令**：持调解协议书向公司所在地基层法院申请支付令 → 法院审查发出 → 公司15日内不书面异议且不履行 → 老陈申请**强制执行**（冻结账户、划扣）
3. **若公司提书面异议**：支付令失效（※民诉法）→ 转**仲裁**：请求支付42000+15000；调解行为已**中断时效**（第27条二）从中断时起重新计算1年——不亏
4. **全程成本**：调解不收费、支付令免诉讼费用——比"仲裁45日+诉讼数月"快且省

## Key Takeaways
1. 调解**可选**（可跳过直接仲裁）；三类调解组织（企业调委会/基层人民调/街道调）
2. 申请可书面可**口头**（第12条）
3. **15日**未达成协议 → 可转仲裁（第14条）
4. 调解协议要**书面+签章**才生效有约束力（第14条）
5. 不履行调解协议 → 申请仲裁（第15条）
6. **欠薪/工伤医疗费/补偿/赔偿金**调解协议单位逾期不履行 → 持协议**申请支付令**（第16条）——最快通道
