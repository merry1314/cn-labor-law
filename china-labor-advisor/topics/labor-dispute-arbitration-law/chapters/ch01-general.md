# Chapter 1: 总则 (General Provisions, 第1–9条)

## Core Idea
劳动争议处理确立了"**协商→调解→仲裁→诉讼**"的递进路径，且**仲裁是诉讼的法定前置程序**（第5条）——不经过仲裁不能直接起诉。六类争议受本法调整（第2条），**举证责任倒置**是劳动者最重要的程序武器（第6条：单位掌握管理的证据，单位不提供承担不利后果），10人以上集体争议可**推举代表**（第7条），欠薪/欠工伤医疗费/欠补偿赔偿金可直接**向劳动行政部门投诉**（第9条）——行政投诉与仲裁并行。

## Frameworks Introduced
- **六类受案范围（第二条）**：
  1. **确认劳动关系**
  2. 劳动合同**订立、履行、变更、解除、终止**
  3. **除名、辞退和辞职、离职**
  4. **工作时间、休息休假、社会保险、福利、培训、劳动保护**
  5. **劳动报酬、工伤医疗费、经济补偿或赔偿金**
  6. 法律法规规定的其他劳动争议
  - When to use: 判断纠纷是否"够格"进仲裁——六类之内直接申请；注意"社会保险"列入第4项（但**单纯补缴**在实务中多走行政通道，见 social-insurance-law ch10 路由表）
- **解决原则（第三条）**：根据事实，合法、公正、及时、**着重调解**
- **协商（第四条）**：劳动者可与单位协商，也可请**工会或第三方**共同协商，达成**和解协议**
- **四步递进路径（第五条）**——全书总纲：
  - 不愿协商/协商不成/和解协议不履行 → 申请**调解**
  - 不愿调解/调解不成/调解协议不履行 → 申请**仲裁**
  - 对仲裁裁决不服 → 除另有规定外 → **向法院起诉**
  - **关键**：调解**不是**必经程序（可跳过直接仲裁）；**仲裁是诉讼的必经前置**（除法律另有规定）
  - When to use: 任何劳动争议的程序规划起点——"先仲裁、后诉讼"是铁律
- **举证责任分配（第六条）**——劳动者核心武器：
  - 一般规则：谁主张谁举证
  - **倒置规则**：与争议事项有关的证据**属于用人单位掌握管理的，用人单位应当提供；不提供的，承担不利后果**
  - When to use: 考勤、工资台账、社保缴费记录、规章制度文本、解除通知等证据在单位手里——劳动者主张后，单位拿不出就输（※司法解释进一步明确工资支付凭证由单位负举证责任，且单位应保存2年）
- **集体争议代表制（第七条）**：劳动者一方**10人以上**并有共同请求 → 推举**代表**参加调解、仲裁或诉讼
  - When to use: 集体欠薪、集体裁员、集体未参保——10人团体的代表制降低维权成本
- **三方机制（第八条）**：县级以上劳动行政部门+工会+企业代表 → 协调劳动关系三方机制
- **行政投诉通道（第九条）**：单位**拖欠或未足额支付劳动报酬**，或**拖欠工伤医疗费、经济补偿或赔偿金** → 劳动者可向**劳动行政部门投诉**，部门应当依法处理
  - When to use: 欠薪的"双轨"——投诉（行政，快）+ 仲裁（拿钱，有执行力）并行不冲突；投诉可形成行政压力（责令支付、加付赔偿金※劳动合同法85条）

## Key Concepts
- **仲裁前置**：劳动争议未经仲裁不得直接起诉（第5条）
- **六类受案范围**：确认劳动关系/合同/离职/工时社保/报酬补偿/其他（第2条）
- **举证责任倒置**：单位掌握管理的证据，单位不提供→不利后果（第6条）
- **集体争议代表制**：10人以上推举代表（第7条）
- **着重调解**：贯穿全流程的原则（第3条）
- **行政投诉并行**：欠薪等可投诉劳动行政部门（第9条）

## Mental Models
- "四步阶梯"模型：协商（可选）→ 调解（可选）→ **仲裁（必经）** → 诉讼（可选）——只有仲裁是"卡点"；跳步的后果：直接起诉会被法院告知先仲裁
- "证据地图"模型：开庭前画一张表——每项主张需要什么证据→证据在谁手里？在单位手里的（考勤、工资单、解除通知）→ 直接写进申请要求单位提供（第6条），自己拿不到的不慌
- "双轨并行"模型：行政投诉（9条）与仲裁不互斥——欠薪案件"投诉施压+仲裁锁请求"是标准打法

## Anti-patterns
- **直接去法院起诉**: 未先仲裁 → 法院不受理/告知仲裁（第5条）——先申请仲裁，对裁决不服再起诉
- **以为"社保争议仲裁不受理"**: 第2条四明确**社会保险**争议受本法调整——**损失赔偿**类（医疗费不能报销）可仲裁；**单纯补缴**类走行政更顺（两轨分流）
- **自己拿不到证据就放弃主张**: 第6条倒置规则——把单位掌握的证据写明，单位不提供它承担不利后果；不要因"我没证据"自我否决
- **10人集体各打各的官司**: 推举代表（第7条）——共同请求合并处理，证据复用、口径一致
- **和解协议"口头化"**: 和解/调解协议要书面（第14条调解协议书、第41条和解后可撤回申请）——口头承诺无凭证

## Worked Example
某公司2025年拖欠销售部20名员工2025年6–8月工资（人均约8000元/月）。处理：
1. **定性**：拖欠劳动报酬 → 第2条五（受案）+ 第9条（可投诉）
2. **集体组织**：20人>10人 → 推举3名代表（第7条），统一证据（工资流水、考勤、劳动合同、欠薪通知）
3. **双轨启动**：
   - **投诉**（第9条）：向劳动监察投诉 → 责令限期支付 → 逾期不付加付50–100%赔偿金（※劳动合同法85条）
   - **仲裁**：代表申请仲裁，请求支付工资差额；时效：劳动关系存续期间拖欠报酬**不受1年时效限制**，离职后**自离职之日起1年**（第27条三）
4. **举证**：工资发放台账、考勤由**单位掌握**（第6条）→ 申请中要求单位提供；单位不提供→不利后果
5. **结果**：调解不成→裁决（45日+15日）；裁决生效不履行→法院**申请执行**（第51条）

## Key Takeaways
1. 程序铁律：**仲裁前置**——协商、调解可选，仲裁必经，诉讼在后（第5条）
2. 六类受案范围（第2条）：确认劳动关系、合同、离职、工时社保、报酬补偿、其他
3. **举证倒置**：单位掌握管理的证据，单位不提供→不利后果（第6条）
4. 10人以上集体争议→推举代表（第7条）
5. 欠薪/欠工伤医疗费/欠补偿赔偿金→可向劳动行政部门投诉（第9条），与仲裁并行
6. 着重调解是全程原则（第3条）
