# Chapter 3: 仲裁（一）一般规定与申请受理 (Arbitration: Organs & Filing, 第17–30条)

## Core Idea
仲裁委按"统筹规划"设立（**不按行政区划层层设立**）；管辖铁律：**劳动合同履行地或用人单位所在地**，两地都申请的**履行地优先**（第21条）——劳动者通常在自己干活的地方就能立案。**仲裁时效1年**（第27条）：**拖欠劳动报酬**在劳动关系存续期间**不受1年限制**，离职后**自离职之日起1年**——这是劳动者最关键的"宽限条款"。仲裁**不收费**（第53条，见附则）。

## Frameworks Introduced
- **仲裁委设立（第十七、十八、十九条）**：
  - 省市/直辖市/设区的市可设立，**不按行政区划层层设立**
  - 三方组成：劳动行政部门代表+工会代表+企业方面代表，人数**单数**
  - 职责：聘任解聘仲裁员、受理案件、讨论重大疑难案件、监督仲裁活动
  - 下设**办事机构**（日常）——实务中立案、通知、送达多由办事机构（仲裁院）办理
- **仲裁员名册与资格（第二十条）**：
  - 曾任审判员 / 法律教研中级以上职称 / 法律知识+人力资源或工会等专业满5年 / **律师执业满3年**（满足其一）
- **管辖（第二十一条）**——立案第一问：
  - 仲裁委管辖本区域内争议
  - **劳动合同履行地** 或 **用人单位所在地**的仲裁委管辖
  - 双方分别向两地申请 → **劳动合同履行地**管辖
  - When to use: 外地公司+本地干活 → 直接在**干活的地方**申请仲裁（履行地优先，且对劳动者便利——送达、开庭、执行就近）
- **当事人（第二十二、二十三条）**：
  - 劳动者与用人单位为双方
  - **劳务派遣**：派遣单位与用工单位为**共同当事人**（第22条二）——告谁？两个一起告
  - 有利害关系的**第三人**可申请参加或被通知参加（第23条）
- **代理（第二十四、二十五条）**：
  - 可委托代理人（书面委托书载明事项权限）
  - 丧失/部分丧失民事行为能力 → 法定代理人；无法定代理人的仲裁委**指定**
  - 劳动者死亡 → **近亲属或代理人**参加
- **公开原则（第二十六条）**：仲裁**公开**进行；当事人协议不公开或涉国家秘密、商业秘密、**个人隐私**的除外
  - When to use: 涉及个人隐私（如性骚扰取证、病历）可申请不公开
- **仲裁时效（第二十七条）**——全书最重要的时限条款：
  - **一般时效1年**：自**知道或应当知道权利被侵害之日**起算
  - **中断**：一方向对方主张权利 / 向有关部门请求权利救济 / 对方同意履行 → **重新计算**
  - **中止**：不可抗力或其他正当理由 → 原因消除后**继续计算**
  - **拖欠劳动报酬的特别规则**：**劳动关系存续期间**不受1年限制；**劳动关系终止的，自终止之日起1年内提出**
  - When to use: 在职期间被慢慢欠薪——不用担心时效滚动流失；**离职时是"总清算"节点**——离职起1年内把在职期间的欠薪、补偿一并主张
- **仲裁申请（第二十八条）**：
  - **书面**申请+按被申请人人数提交副本（书写困难可**口头**，仲裁委记入笔录）
  - 申请书三要素：① 双方基本信息（劳动者姓名性别年龄职业单位住所/单位名称住所法定代表人）② **仲裁请求+事实理由** ③ **证据和来源、证人姓名住所**
- **受理（第二十九、三十条）**——5+10+5 时限链：
  - 仲裁委收到申请起**5日内**：符合受理 → **受理并通知**；不符合 → **书面通知不予受理+说明理由**
  - **不予受理或逾期未决定** → 申请人可就该事项**向法院起诉**（第29条——"不立案就能告"的救济）
  - 受理后**5日内**将申请书副本**送达**被申请人
  - 被申请人**10日内**提交**答辩书**（不交**不影响**程序进行）
  - 仲裁委**5日内**将答辩书副本送达申请人

## Key Concepts
- **履行地优先管辖**：两地仲裁委竞争时劳动合同履行地管辖（第21条）
- **1年仲裁时效**：知道或应当知道权利被侵害起算（第27条）
- **欠薪时效宽限**：存续期间不限+离职后1年（第27条三）
- **中断/中止**：主张权利/请求救济/同意履行→重算；不可抗力→续算（第27条二）
- **5+10+5时限链**：受理5日→送达5日→答辩10日→送达5日（第29、30条）
- **不受理即起诉**：不予受理或逾期不决定→可起诉（第29条）
- **共同当事人**：派遣+用工单位同告（第22条）

## Mental Models
- "时效三段记忆"：① 一般：知道被侵害→1年 ② 中断：主张/救济/同意→重算 ③ 欠薪特例：在职不算+离职起1年——离职日=清算闹钟
- "管辖就近"模型：在干活的地方立案（履行地）——开庭、送达、后续执行都近；公司在外地不构成障碍
- "程序时限链"模型：5（受理决定）→5（送达副本）→10（答辩）→5（送达答辩）——单位不答辩程序照走，不拖；仲裁委逾期不决定=给你"直诉权"
- 派控告法：**派遣+用工一起告**（共同当事人）——避免两单位踢皮球（与 social-insurance-law ch04 派遣连带、劳动合同法 ch05 联动）

## Anti-patterns
- **离职拖过1年再主张欠薪**: 存续期间虽不限，但**离职之日起1年**是硬窗口——离职时一次性把欠薪、加班费、补偿全部主张，别"先找事做"
- **把时效起算点搞错**: 起算点是"知道或应当知道权利被侵害"——解除通知送达日/欠薪到期日，不是"闹僵日"
- **只告用工单位不告派遣单位**: 派遣争议两单位共同当事人（第22条）——漏告一个可能来回补正
- **不交答辩书就以为"没影响"**: 单位不答辩不影响程序（第30条），但劳动者收到副本后应**核对请求是否被完整受理**
- **仲裁委不立案就放弃**: 第29条——不予受理/逾期不决定 = 法院起诉资格自动解锁

## Worked Example
小王在外地某公司（注册地A市）工作，实际在B市项目上干活。2025-07 被口头辞退，公司说"补偿下个月谈"。处理：
1. **管辖**：劳动合同履行地=**B市**（干活地）→ 向B市仲裁委申请（第21条）——不必去A市
2. **时效核对**：辞退日=知道权利被侵害日 → 1年内（至2026-07前）；在职期间的欠薪（如有）离职起1年一并主张（第27条三）
3. **申请书**：写明请求（违法解除赔偿金2N+欠薪差额+加班费）+事实理由+证据清单（劳动合同、工资流水、考勤截图、辞退录音/微信）——证据在单位的（考勤台账、工资表）注明"由被申请人提供"（第6条）
4. **受理**：B市仲裁委5日内决定——受理→5日内送达公司副本→公司10日答辩→开庭；若不受理/超期 → 直接起诉（第29条）
5. **中断留痕**：等待期间发书面催告（微信/EMS"请于X日前支付"）→ 即使最后计算起算点有争议，催告行为也**中断时效**重算（第27条二）

## Key Takeaways
1. 管辖：**劳动合同履行地**或单位所在地；冲突时**履行地优先**（第21条）
2. 时效**1年**（知道或应当知道起）；**中断**（主张/救济/同意）重算、**中止**（不可抗力）续算
3. **欠薪特例**：存续期间不限；**离职起1年**（第27条三）
4. 派遣争议：派遣+用工**共同当事人**（第22条）
5. 5+10+5时限链；不答辩不影响程序（第29、30条）
6. 不受理/逾期不决定 → **可起诉**（第29条）
7. 仲裁**不收费**（第53条）
