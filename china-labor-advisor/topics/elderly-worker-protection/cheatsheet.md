# Cheatsheet: 超龄劳动者基本权益保障

## 速查表

### 适用判断
| 问题 | 判断 |
|---|---|
| 超过法定退休年龄？ | 是 → 继续 |
| 受单位劳动管理？ | 是 → 继续 |
| 有报酬劳动？ | 是 → **适用本规定** |
| 弹性延迟退休期间？ | 是 → **不适用**，走劳动合同法（第23条） |

### 四项基本权益
| 权益 | 法条 | 要点 |
|---|---|---|
| 劳动报酬 | 第10-12条 | 不低于最低工资；货币按月足额 |
| 休息休假 | 第9条 | 法定工时/节假日；一般不加班 |
| 安全卫生 | 第13-14条 | 合适岗位；不得危险作业 |
| 工伤保障 | 第15条 | 单位缴工伤保险；工伤认定+鉴定+待遇 |

### 争议程序
| 争议事项 | 程序 | 法条 |
|---|---|---|
| 报酬/休假/安全/工伤 | **仲裁前置** → 诉讼 | 第19条第1款 |
| 其他事项 | **直接民事诉讼** | 第19条第2款 |

### 用工协议必备条款（第6条）
协议期限 / 工作内容 / 工作地点 / 工作时间 / 休息休假 / 劳动报酬 / 社会保险 / 劳动保护 / 劳动条件 / 职业危害防护

### 社会保险衔接
| 险种 | 已享受待遇 | 未享受待遇 | 法条 |
|---|---|---|---|
| 工伤保险 | — | 单位必须缴，个人不缴 | 第15条 |
| 养老保险 | 不改变 | 个人缴或协商单位缴 | 第16条 |
| 医疗保险 | 不改变 | 个人缴或协商单位缴 | 第17条 |

## 2026-07-01 前后对比

| 事项 | 2026-07-01 前（旧口径） | 2026-07-01 后（本规定） |
|---|---|---|
| 法律性质 | 退休返聘=劳务关系 | 第三类用工（非劳动关系，有基本权益） |
| 争议程序 | 一律民事诉讼 | 四项权益仲裁前置；其他民事诉讼 |
| 工伤保障 | 多数地区无法参保 | 单位必须缴工伤保险（第15条） |
| 最低工资 | 不适用 | 适用（第11条） |
| 加班限制 | 不适用 | 一般不安排；安排的遵守劳动法（第9条） |
