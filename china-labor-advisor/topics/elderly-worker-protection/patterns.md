# Patterns: 超龄劳动者权益

## 场景路由

### 场景1：超龄劳动者被拖欠工资
1. 定位：劳动报酬争议 → 第19条第1款 → **仲裁前置**
2. 投诉/仲裁：
   - 向人社部门投诉（第20条 → 劳动合同法第85条 → 劳动保障监察条例）
   - 或直接申请劳动仲裁（调解仲裁法）
3. 金额：不低于最低工资标准（第11条）；货币按月足额（第12条）

### 场景2：超龄劳动者工伤
1. 参保险证：单位应当缴工伤保险（第15条）→ 个人不缴
2. 工伤认定：因工作原因受事故伤害或患职业病 → 工伤认定 + 劳动能力鉴定
3. 待遇：享受工伤保障待遇
4. 争议：工伤保障争议 → 第19条第1款 → **仲裁前置**
5. 地方口径※：各省超龄劳动者工伤保障办法不一，查 LOCAL-PRACTICE.md

### 场景3：超龄劳动者被安排加班
1. 原则：一般不安排加班（第9条）
2. 例外：安排加班须遵守劳动法第41条（时限）、第42条（不受限情形）、第44条（加班费150%/200%/300%）
3. 争议：休息休假争议 → 第19条第1款 → **仲裁前置**

### 场景4：超龄劳动者被随意辞退
1. 用工协议终止条件：第8条（期限届满/工作完成/约定条件/协商解除）
2. 争议性质：终止争议不属于四项基本权益 → 第19条第2款 → **直接民事诉讼**
3. 主张：依用工协议约定追究违约责任
