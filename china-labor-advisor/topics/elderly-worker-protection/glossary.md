# Glossary: 超龄劳动者基本权益保障

| 术语 | 定义 | 法条 |
|---|---|---|
| 超龄劳动者 | 超过法定退休年龄、受用人单位劳动管理、从事用人单位安排的有报酬的劳动者 | 第2条 |
| 第三类用工 | 非劳动关系亦非纯劳务关系——基本权益保障型用工 | 第2/5条 |
| 用工协议 | 超龄劳动者与用人单位的书面协议（非劳动合同） | 第6条 |
| 四项基本权益 | 劳动报酬、休息休假、劳动安全卫生、工伤保障 | 第5条 |
| 仲裁前置 | 四项基本权益争议须先经劳动仲裁，不服才可起诉 | 第19条第1款 |
| 弹性延迟退休 | 根据国家规定弹性延迟退休的劳动者，适用劳动合同法，不适用本规定 | 第23条 |
