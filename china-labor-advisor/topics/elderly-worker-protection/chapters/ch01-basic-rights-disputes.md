# ch01: 基本权益与争议处理（第1-24条）

## Core Idea
超龄劳动者规定确立**第三类用工**：超过法定退休年龄 + 受用人单位劳动管理 + 从事有报酬劳动（三要件，第2条）——不是劳动关系（不签劳动合同），但**劳动报酬、休息休假、劳动安全卫生、工伤保障**四项基本权益受法律保护。关键设计：书面用工协议必签（第6条）、工资不低于最低工资（第11条）、**工伤保险单位缴个人不缴**（第15条）、争议**双通道**（四项基本权益仲裁前置，其他直接民事诉讼，第19条）。2026-07-01 施行。

## Key Concepts
- **第三类用工**（第2条）：区别于"劳动关系"与"劳务关系"的独立法律地位；提前退休后被招用的同样适用
- **书面用工协议**（第6条）：期限、工作内容、劳动报酬、工伤保障等十项必约定
- **四项基本权益**（第4条）：劳动报酬、休息休假、劳动安全卫生、工伤保障——本规定的保护范围
- **超龄工伤特别规则**（第15条）：用人单位应当参加工伤保险并缴费，个人不缴——超龄群体核心突破
- **争议双通道**（第19条）：四项基本权益争议→仲裁前置；其他事项→直接民事诉讼
- **弹性延迟退休除外**（第23条）：弹性延迟退休期间适用劳动合同法/人事管理条例，不适用本规定

## 一、总则（第1-3条）

### 立法目的（第1条）
保障超过法定退休年龄劳动者的合法权益，明确权利义务。依据：渐进式延迟法定退休年龄决定及有关法律。

### 适用范围（第2条）——核心
- **三要件**：①超过法定退休年龄 ②受用人单位劳动管理 ③从事用人单位安排的有报酬的劳动
- **提前退休人员**：已提前退休后被招用的，同样适用
- **法律性质**：非劳动关系（不签劳动合同），但享有基本劳动权益——**第三类用工**
- **排除**：弹性延迟退休期间适用劳动合同法（第23条），不适用本规定

### 职责分工（第3条）
人社/卫健/税务/医保部门 + 负有安全生产监管职责的部门 + 工会/企业代表组织 → 协同保障

## 二、用工协议（第4-8条）

### 招用原则（第4-5条）
- 根据知识/技能/经验提供适合岗位
- 合法、公平、平等自愿、协商一致、诚实信用
- **四项基本权益**：劳动报酬、休息休假、劳动安全卫生、工伤保障

### 书面协议（第6条）——必签
书面用工协议必须明确：协议期限、工作内容、工作地点、工作时间、休息休假、劳动报酬、社会保险、劳动保护、劳动条件、职业危害防护

### 变更与终止（第7-8条）
- 变更：协商一致
- 终止：期限届满或工作完成；约定条件出现或协商解除

## 三、劳动条件四件套（第9-14条）

### 工时与加班（第9条）
- 遵守《职工工作时间规定》和《年节纪念日放假办法》
- **一般不安排超龄劳动者加班**
- 安排加班的：遵守劳动法第41条（协商/一般每日1小时/特殊3小时/每月36小时）、第42条（不受41条限制情形）、第44条（加班费150%/200%/300%）

### 劳动报酬（第10-12条）
- 明确约定数额/计酬标准/支付周期/支付时间/支付方式（第10条）
- **不低于当地最低工资标准**（第11条）
- 货币形式、按月支付、不得克扣拖欠（第12条）

### 劳动安全卫生（第13-14条）
- 根据身体状况安排合适岗位和劳动强度
- **不得安排**危害身心健康的劳动或危险作业
- 安全生产/职业卫生教育培训

## 四、社会保险（第15-18条）

### 工伤保险（第15条）——核心突破
- 用人单位**应当**参加工伤保险并缴费
- 个人**不缴**
- 工伤认定 → 劳动能力鉴定 → 工伤保障待遇
- 具体办法另行制定

### 养老保险（第16条）
- 已享受待遇：不改变
- 未享受/需延长缴费：可个人缴 或 协商由单位缴（代扣代缴）

### 医疗保险（第17条）
- 已享受待遇：不改变
- 未享受：可个人缴 或 协商由单位缴

### 经办服务（第18条）
优化流程 + 适老化设施

## 五、争议处理与监督（第19-24条）

### 争议双通道（第19条）——核心
| 争议类型 | 程序 |
|---|---|
| 劳动报酬、休息休假、劳动安全卫生、工伤保障 | **仲裁前置**（调解仲裁法） |
| 其他事项 | **直接民事诉讼** |

> **重要变更**：旧口径"退休返聘一律走民事诉讼"已被突破——四项基本权益争议走仲裁前置。

### 人社监察（第20条）
违反第9条第2款（加班）、第11条（最低工资）、第12条（足额支付）→ 人社部门依劳动合同法第85条(1)-(3)项 + 劳动保障监察条例监察

### 安全/职业病监管（第21条）
依安全生产法、职业病防治法处理

### 工会监督（第22条）
- 维护合法权益、监督保障情况
- 有权提出意见/要求纠正
- 支持仲裁诉讼

### 弹性延迟退休除外（第23条）
弹性延迟退休期间 → 适用劳动合同法/事业单位人事管理条例，**不适用本规定**

### 施行（第24条）
2026年7月1日起施行

## Anti-patterns

- ❌ 认为退休返聘是"纯劳务"无保护——三要件成立的，四项基本权益受法律保护（第2、4条）
- ❌ 不签书面用工协议——第6条必签；口头约定发生争议举证困难
- ❌ 让超龄个人缴工伤保险——工伤保险仅由用人单位缴纳，个人不缴（第15条）
- ❌ 所有争议一律走民事诉讼——劳动报酬/休息休假/劳动安全卫生/工伤保障四项争议仲裁前置（第19条）
- ❌ 安排超时加班或危险作业——一般不安排加班（第9条）；不得安排危害身心健康的劳动或危险作业（第13条）

## Worked Example

**场景**：周某62岁（2024年退休、已领养老金），2026年被物流公司返聘，未签书面用工协议，月薪4,500元（当地最低工资4,000元），月均加班10小时；3个月后公司单方终止且未足额结清工资。

**维权**：
1. **加班费**：加班依劳动法第41/44条——10小时×150%×(4,500÷21.75÷8)≈389元/月，3个月可主张约1,167元（第9条）
2. **足额支付**：克扣拖欠的，人社部门可依劳动合同法第85条1、3项责令限期支付，逾期加付50%–100%赔偿金（第20条 + 劳动保障监察条例）
3. **书面协议**：要求补签并明确十项内容（第6条）；同时保存工资流水、考勤记录、工作指令作为协议内容证据
4. **争议路径**：劳动报酬争议→**仲裁前置**（第19条），注意调解仲裁法1年时效
5. **工伤保障**：受雇期间发生工伤的，单位本应参保缴费（第15条）；未参保的工伤保障由用人单位承担（※ 各地超龄工伤试点办法口径）

## Key Takeaways

1. 第三类用工三要件：超龄 + 受劳动管理 + 有报酬（第2条）
2. 四项基本权益（报酬/休假/安全卫生/工伤）受保护，书面用工协议必签（第4、6条）
3. 工资不低于当地最低工资，货币按月支付、不得克扣拖欠（第11、12条）
4. 超龄工伤：单位缴、个人不缴（第15条）；一般不安排加班（第9条）
5. 争议双通道：四项仲裁前置，其他直接民事诉讼（第19条）；2026-07-01施行（第24条）
