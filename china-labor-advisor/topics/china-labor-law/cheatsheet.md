## 决策规则（When → Do）

1. **When** 任何用工争议 → **Do** 先查"劳动关系"是否成立（第2条），否则走民事路径
2. **When** 劳动者诉求模糊 → **Do** 映射第3条八项权利清单，按权利跳转对应章节
3. **When** 考虑解除 → **Do** 走决策树：过错(25条即时) / 无过错(26条+30日预告) / 裁员(27条+报告) → 再叠加29条保护性禁止检查
4. **When** 排班涉及加班 → **Do** 先算月度总量（>36h违法），再分三档计价（150/200/300）
5. **When** 发工资 → **Do** 过四要素：货币/按月/本人/不克扣不拖欠；再查≥最低工资
6. **When** 排班涉及女职工/未成年工 → **Do** 先定位期间（经期/孕期第几月/产期/哺乳期），再对照禁忌表
7. **When** 发生争议 → **Do** 协商→调解(自愿)→仲裁(必经)→诉讼(15日内)→强制执行
8. **When** 集体合同争议 → **Do** 先分清"签订"(行政部门协调)还是"履行"(仲裁诉讼)
9. **When** 违法行为定责 → **Do** 对号入座第89–105条，看升级关键词（情节严重/造成损害/构成犯罪）
10. **When** 历史用工问题 → **Do** 核对施行日(1995-01-01)、地方实施步骤、2018修正版本

## 红线表（触发即最重责任）

| 行为 | 后果 | 条文 |
|---|---|---|
| 招用童工（<16岁） | 罚款；情节严重吊销营业执照 | 第94条 |
| 强迫劳动（暴力/威胁/限制自由） | 15日以下拘留；构成犯罪追刑责 | 第96条 |
| 侮辱、体罚、殴打、非法搜查、拘禁劳动者 | 拘留/罚款/警告；构成犯罪追刑责 | 第96条 |
| 强令违章冒险作业致重大伤亡 | 对责任人员追究刑事责任 | 第93条 |
| 安卫隐患不采取措施致重大事故 | 对责任人员追究刑事责任 | 第92条 |
| 挪用社会保险基金 | 构成犯罪追究刑事责任 | 第104条 |
| 公职人员滥用职权/玩忽职守/徇私舞弊 | 构成犯罪追刑责；否则行政处分 | 第103条 |
| 打击报复举报人员 | 罚款；构成犯罪追刑责 | 第101条 |

## 高频"坑"识别（Tells & Smells）

- 合同没签/口头用工 → 第98条：责令改正+赔偿（建立劳动关系应当订立合同）
- "自愿加班"无记录 → 仍按安排加班认定；月度>36h即违法（第41、43条）
- 休息日加班"已补休"但法定节假日也"补休" → 300%不可补休替代（第44条）
- 计件工资实际到手<最低工资 → 违规，须补足（第48条）
- 孕期/产期/哺乳期员工被解除 → 第29条硬禁止（26/27条通道关闭）
- "不能胜任"直接解除、无培训/调岗记录 → 程序违法（第26条二）
- 约定"放弃社保换补贴" → 无效；工伤等费用单位自担（第72条）
- 16–18岁员工被安排井下/有毒有害 → 未成年工绝对禁忌（第64条）
- 技术工种未培训上岗 → 事故追责放大单位责任（第68条）
- 监察人员未出示证件 → 单位可要求核验，但不得以"商业秘密"拒绝法定检查（第86、101条）
- 仲裁申请超过时效 → 请求权面临丧失（本法60日；《劳动争议调解仲裁法》1年）
- 旧文书出现"工商行政管理部门" → 2018修正已改为"市场监督管理部门"（第94条）
