# 劳动者维权行动手册 (Worker's Playbook)

本文件是技能的**劳动者视角层**：当用户是劳动者（或为劳动者咨询）且发生或可能发生劳动纠纷时，按本手册组织回答——先定位诉求，再配证据，再选路径，最后提示风险。所有条文均指向《劳动法》（2018修正）；涉及特别法的以"※"标注。

## 0. 使用原则

1. **先确认身份与关系**：用户是劳动者本人/家属/HR代问？是否成立"劳动关系"（ch01）？不成立则提示走民事/劳务路径，不套用本手册。
2. **先算时效，再谈实体**：时效过期则实体再强也难以主张（见 §6 时限表）。
3. **诉求具体化**：把"公司欺负我"翻译成可请求事项——补发工资 X 元 / 支付加班费 X 元 / 确认违法解除并支付赔偿金 / 补缴社保等。
4. **双轨并行不冲突**：行政投诉（劳动监察）与仲裁/诉讼可同时走，行政处理不免除单位支付义务（ch11/12）。
5. **诚实边界**：本技能依据《劳动法》文本组织信息，不构成法律意见；金额计算、地方标准（最低工资、补偿基数）需用户确认当地口径；重大案件提示咨询律师或申请法律援助。

## 1. 诉求定位表（把处境翻译成请求）

| 处境 | 对应诉求 | 法条依据 | 章节 |
|---|---|---|---|

| 加班没给加班费 | 按150%/200%/300%补付加班费 | 第44、91条 | ch04 |
| 工资低于最低工资 | 补足至当地最低工资标准 | 第48、91条 | ch05 |

| 以"不能胜任"被解除 | 核查有无培训/调岗前置程序；无则违法解除 | 第26条 | ch03 |

| 医疗期内被解除 | 不得依26/27条解除 | 第29条 | ch03 |
| 被裁员但程序缺失 | 核查30日说明+工会/职工意见+报告劳动部门；缺程序则违法 | 第27条 | ch03 |

| 被强迫劳动/人身侵害 | 立即报警（公安拘留/刑责）+投诉+仲裁 | 第96条 | ch12 |

| 举报后被打击报复 | 独立处罚事由（罚款乃至刑责）；保留报复证据 | 第101条 | ch11, ch12 |
| 集体合同标准高于个人合同却被压低 | 个人合同标准不得低于集体合同 | 第35条 | ch03 |

## 2. 证据清单（按证据类型）

**固定证据总原则**：能书面的不依赖口头；原件拍照+电子件双备份；微信/钉钉记录截图时包含对方账号信息；录音在多数地区作为一方当事人录制可作证据（※具体以当地司法实践为准）。

| 证明事项 | 关键证据 | 来源 |
|---|---|---|
| 劳动关系存在 | 劳动合同、工资流水（银行/支付宝/微信）、社保缴费记录、考勤记录、工牌/工服照片、工作群聊天记录、入职登记表 | 自行保存 |
| 工资标准 | 工资条、银行工资入账记录、个税APP扣缴记录、录用通知/offer | 自行保存 |
| 加班事实 | 考勤打卡记录、排班表、加班审批单、工作群深夜/节假日工作消息、出差记录 | 注意：考勤记录由用人单位掌握管理，可申请仲裁委责令提供 |
| 解除事实与理由 | 解除通知书（书面最好）、辞退谈话录音、交接单、停发工资/收回工牌记录 | 尽量取得书面 |
| 未签合同 | 入职时间证明（首月工资、社保起缴时间、首条聊天记录） | ※未签合同二倍工资请求见《劳动合同法》 |
| 三期/医疗期 | 医院诊断证明、病假条、孕检记录、病历 | 医疗单据 |
| 工伤 | 事故现场证据、目击者、急诊记录、事故报告 | 30日内单位申报，单位不报的**劳动者/近亲属/工会1年内可直接申请工伤认定**（※《工伤保险条例》） |
| 单位规章制度 | 员工手册、签收记录（用于判断25条"严重违纪"是否有据） | 注意：规章制度须民主程序+公示告知才可作为依据 |

**举证责任分配要点**：
- 与争议事项有关的证据属于**用人单位掌握管理**的（考勤、工资台账、社保台账、规章制度签收），单位应当提供；不提供的承担不利后果（※《劳动争议调解仲裁法》第6条）
- 劳动者仍需为**基本事实**举证：劳动关系存在、主张金额的计算基础（出勤、加班时长的大致证明）
- 被辞退者重点固定"解除理由"：单位依25条主张"严重违纪"的，**由单位举证**违纪事实与制度依据
- **电子证据注意**：微信/钉钉/企业微信聊天记录、录音录像要保留**原始载体**（原手机、原始录音文件）；不得以非法窃听、侵入、窃取方式取证；必要时用**时间戳或公证**固定电子证据，防止被删除或篡改

## 3. 维权路径选择（决策表）

### 前提：纠纷是否属于仲裁受理范围（选路径前必查）
- **属于仲裁受理范围**：因确认劳动关系；订立/履行/变更/解除劳动合同；工作时间、休息休假；社会保险；劳动报酬；工伤医疗费；经济补偿或赔偿金等发生的争议 → 走仲裁
- **不属于仲裁受理范围 → 民事起诉**：劳务关系（给个人老板干活、按项目结算、无考勤不受管理）、退休返聘人员、大学生实习等 → 按民法典合同编处理，直接向人民法院起诉
- **常见误区**：没有书面劳动合同也能维权——劳动关系看实际用工事实，工资流水、考勤、工牌、工作群聊天记录、社保缴费记录等都能证明

### 申请仲裁要准备的材料（※《劳动人事争议仲裁办案规则》）
1. **《劳动人事争议仲裁申请书》**：正本一份 + 按被申请人人数提交副本；写明申请人与被申请人的姓名/名称、住所、法定代表人，仲裁请求及事实理由，证据和证据来源、证人姓名和住所
2. **申请人身份证明**：身份证复印件一份
3. **委托材料**（如有代理人）：授权委托书；委托律师的另需律师执业证复印件和律所函
4. **证据材料及清单**：重点为证明劳动关系的资料（劳动合同、工作证、工资表/单、社保缴费清单、考勤记录、解除通知等），注明页码，提供正本并按被申请人人数提交副本
- **管辖**：向劳动合同履行地或用人单位所在地的劳动人事争议仲裁委员会申请（※劳动争议司法解释一）

| 路径 | 适用 | 成本/速度 | 依据 |
|---|---|---|---|
| **协商** | 事实清楚、金额不大、关系可维系 | 免费最快；无强制力 | 第77条 |
| **调解** | 希望不伤和气、留有余地 | 免费；协议靠自觉履行 | 第79–80条 |
| **劳动监察投诉** | 拖欠工资、不缴社保、超时加班、安卫违法等**行政违法**事实；想快速施压 | 免费；处理有时限；责令改正/支付 | 第85–88条 |
| **劳动仲裁** | 解除争议、补偿/赔偿金、加班费、工资差额等**权利义务争议**——必经前置 | 免费（仲裁不收费※）；受理起45日内裁决，延期不超过15日（※调解仲裁法） | 第79–83条 |
| **诉讼** | 对仲裁裁决不服 | 周期长；一审15日内起诉 | 第83条 |
| **报警** | 强迫劳动、人身侵害、非法拘禁 | 立即保护人身安全 | 第96条 |
| **工会/法律援助** | 工会支持仲裁诉讼；经济困难可申请法律援助 | 免费 | 第30、88条 |

**组合策略**：
- 欠薪类：监察投诉（责令支付）+ 仲裁（个人追偿）并行；欠薪且生活困难的，※可主张"拖欠工资加付赔偿金"（50%–100%，见《劳动合同法》第85条）
- 被违法解除类：直接仲裁（监察对解除行为一般无权直接干预），诉请"确认违法解除+支付赔偿金（※2N）或继续履行合同"二选一
- 工伤类：先走工伤认定行政程序（人社局），后仲裁/诉讼争待遇；期间工资按停工留薪期处理
- 人身安全类：报警优先，法律程序随后

## 4. 仲裁请求书写法（骨架）

```
申请人：姓名/身份证号/联系方式
被申请人：公司全称/统一社会信用代码/法定代表人/注册地址（查企业信用信息公示系统）

请求事项（具体、可执行、列金额）：
1. 裁决被申请人支付 20XX年X月 至 20XX年X月 拖欠工资 XXX 元；
2. 裁决被申请人支付 20XX年X月 至 20XX年X月 加班费 XXX 元（计算式：基数×150%×X小时÷21.75÷8）；
3. 裁决确认被申请人 20XX年X月X日 解除行为违法，支付违法解除赔偿金 XXX 元；
4. 裁决被申请人出具离职证明/办理社保转移手续；
5. （如有）利息/损失。

事实与理由：
入职时间→岗位→工资标准→争议经过（时间线）→解除事实与理由→请求依据（逐条引用法条）

证据清单：证据1 劳动合同（原件）……
```

**计算口径提示**（实务常用，※具体以司法解释/地方口径为准）：
- 加班费基数：劳动合同约定工资；未约定按正常出勤月工资
- 月计薪天数 21.75 天、日工资 = 月工资÷21.75、时薪 = 日工资÷8
- 经济补偿/赔偿金基数：解除前12个月平均工资（含奖金津贴）；月工资高于当地社平工资3倍的按3倍封顶、年限最高12年（※《劳动合同法》第47条）
- 违法解除赔偿金 = 2 × 经济补偿（※《劳动合同法》第87条）
- 地方口径差异大：计算前让用户确认所在地

## 5. 风险点与反制（劳动者常见"坑"）

1. **时效陷阱**：争议发生起1年内申请仲裁（※《劳动争议调解仲裁法》第27条；《劳动法》原文为60日，已被特别法更新）；拖欠劳动报酬的，在劳动关系存续期间不受1年限制，离职后1年内提出
2. **"自愿"文件**：自愿加班申请、自愿放弃社保声明、离职申请（含"个人原因辞职"）——签前确认内容；被迫签的保留胁迫证据
3. **离职文书措辞**：离职证明/交接单上被写"严重违纪""自动离职"会影响失业金与下家背调；坚持按真实原因书写
4. **竞业限制与保密**：未签竞业协议的一般无此义务；约定了保密的，离职交接时保留"已归还资料"的书面记录
5. **报复性管理**：投诉/仲裁后遭调岗降薪、边缘化——本身可能构成新的违法（※《劳动合同法》不得因维权降低待遇）；保留前后对比证据
6. **工会通道别忽视**：工会对违法解除有权要求重新处理并支持仲裁（第30条）；没有工会的可向当地总工会反映
7. **证据灭失**：离职前备份工作相关证据（合规范围内）；被清退出办公区前完成取证
8. **金额不要漫天要价**：请求事项以计算得通的金额为准，过高的无据请求拖慢程序
9. **口头辞退别直接走人**：口头通知不算正式解除劳动合同，一旦自行离岗，公司可能反咬你旷工、自动离职。应：① 要求公司出具**书面解除通知书并加盖公章** ② 期间照常**打卡上班**并保存考勤记录 ③ 对口头辞退内容录音（尽量让对方确认）
10. **离职协议看清再签**：逐条确认补偿金额、支付时间、放弃权利的范围，**不要签空白协议**；一旦签字生效，后续很难再主张赔偿
11. **分清 N、N+1、2N**：N＝经济补偿金（每满一年支付1个月工资，6个月以上不满1年按1年，不满6个月支付半个月※《劳动合同法》第47条）；N+1＝合法无过失性辞退（26条情形）额外1个月代通知金；2N＝违法解除赔偿金（※《劳动合同法》第87条）。很多公司用"N"代替"2N"诱导签字——先确认解除性质再签
12. **别拖过时效（再强调）**：离职两三年后才想起维权，早已错过1年窗口期，仲裁委大概率驳回

## 6. 时限速查（劳动者视角）

| 事项 | 时限 | 依据 |
|---|---|---|
| 申请劳动仲裁 | 知道或应当知道权利被侵害起 **1年**（※《劳动争议调解仲裁法》；《劳动法》原文60日） | 第82条 |
| 拖欠劳动报酬仲裁 | 劳动关系存续期间不受1年限制；**离职后1年内** | ※调仲裁法27条 |
| 仲裁审理期限 | 受理之日起 **45日**内作出裁决；案情复杂经批准可延期，延长期限**不超过15日**；逾期未裁决的申请人可向法院起诉（※《劳动争议调解仲裁法》；《劳动法》第82条原文60日，特别法优先） | 第82条 |
| 对仲裁裁决不服起诉 | 收到裁决书起 **15日** | 第83条 |
| 用人单位不起诉又不履行 | 可申请法院**强制执行** | 第83条 |
| 工伤认定申请 | 单位30日内；单位不报的劳动者/近亲属/工会**1年内** | ※《工伤保险条例》 |
| 工伤认定→鉴定→待遇 | 各阶段另有时限，越早启动越好 | ※ |
| 劳动者预告辞职 | 提前 **30日** 书面通知 | 第31条 |
| 试用期即时辞职 | 随时通知（建议留书面痕迹） | 第32条 |
| 加班月度上限 | ≤ **36小时**（超过即可主张违法+加班费） | 第41条 |

## 7. 回答劳动者咨询时的标准流程

1. **问清五件事**：① 是否签了书面合同 ② 入职时间与工资标准 ③ 争议发生的具体时间与经过 ④ 目前在职还是已离职 ⑤ 手头有什么证据
2. **定位诉求**：用 §1 表把处境翻译成请求事项与法条
3. **算时效**：用 §6 表确认是否过期
4. **盘证据**：用 §2 清单列缺口，优先补强"劳动关系+核心事实"两类
5. **选路径**：先按 §3 前提确认是否属仲裁受理范围（不属→民事起诉），再用 §3 决策表推荐组合路径（监察/仲裁/报警/工会）
6. **给请求书骨架**：参照 §4 起草，金额让用户按当地口径确认
7. **提示风险**：从 §5 中挑与案情相关的2–3条
8. **声明边界**：本技能基于《劳动法》文本，具体金额、地方口径、最新司法解释请以当地人社局/12333/执业律师确认为准

## 8. 法条依据地图（什么问题引哪部法）

**一句话记忆**：先用《劳动法》《劳动合同法》定权利义务，走程序靠《劳动争议调解仲裁法》，社保工伤看《社会保险法》《工伤保险条例》，劳务关系或人格权问题才轮到《民法典》。

| 层次 | 法律/法规 | 何时引用 |
|---|---|---|
| 核心实体法 | 《劳动法》（母法） | 基本权利；最低工资、加班时长（日1h/特殊3h/月36h）、安全卫生等底线标准 |
| 核心实体法 | 《劳动合同法》（最常用） | 合同订立（未签书面合同双倍工资※）、试用期、解除与终止、N/N+1/2N |
