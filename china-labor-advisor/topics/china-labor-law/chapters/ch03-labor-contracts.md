# Chapter 3: 劳动合同和集体合同 (Labor Contracts & Collective Contracts, 第16–35条)

## Core Idea
劳动合同是劳动关系的核心载体：必须书面订立、七项必备条款、三类期限；解除规则按"过错即时解 / 无过错预告解 / 经济性裁员 / 保护性不得解 / 劳动者辞职"五条通道分别适用，并配套经济补偿规则。

## Frameworks Introduced
- **劳动合同七项必备条款（第十九条）**：合同期限、工作内容、劳动保护和劳动条件、劳动报酬、劳动纪律、终止条件、违约责任
  - When to use: 起草/审查劳动合同的完整性清单
  - How: 逐项核对；缺少必备条款不必然无效，但会被仲裁/法院依事实劳动关系认定
- **合同三期限类型（第二十条）**：有固定期限、无固定期限、以完成一定的工作为期限
  - 无固定期限触发器：劳动者在同一用人单位连续工作满十年以上 + 双方同意续延 + 劳动者提出 → 应当订立无固定期限合同
  - When to use: 续签决策、老员工合同管理
- **试用期上限（第二十一条）**：试用期最长不得超过六个月
- **无效合同两事由（第十八条）**：违反法律、行政法规；采取欺诈、威胁等手段订立
  - 部分无效不影响其余部分效力；无效由劳动争议仲裁委员会或人民法院确认
- **用人单位解除五通道**：
  - 即时解除（第二十五条，无需预告、无补偿）：试用期不符合录用条件 / 严重违反纪律或规章制度 / 严重失职营私舞弊致重大损害 / 被依法追究刑事责任
  - 预告解除（第二十六条，提前30日书面通知，有补偿）：医疗期满不能从事原工作也不能从事另行安排工作 / 不能胜任工作经培训或调岗仍不能胜任 / 客观情况重大变化致合同无法履行且协商不成
  - 经济性裁员（第二十七条，提前30日向工会或全体职工说明+报告劳动行政部门，有补偿）：濒临破产法定整顿期或生产经营严重困难
  - 协商解除（第二十四条，有补偿）
  - 保护性禁止（第二十九条）：患职业病或因工负伤丧失/部分丧失劳动能力 / 医疗期内 / 女职工孕期产期哺乳期 → 不得依第二十六、二十七条解除
- **劳动者解除两通道**：预告辞职（第三十一条，提前30日书面通知）；即时辞职（第三十二条，随时通知）：试用期内 / 被强迫劳动（暴力、威胁、非法限制人身自由）/ 未按约支付报酬或提供劳动条件
- **经济补偿触发（第二十八条）**：依第24、26、27条解除的，应依照国家有关规定给予经济补偿
- **集体合同制度（第三十三至三十五条）**：可就劳动报酬、工作时间、休息休假、劳动安全卫生、保险福利签订；草案经职工代表大会或全体职工讨论通过；工会代表签订（无工会由职工推举代表）；报送劳动行政部门15日内未提出异议即生效；个人劳动合同标准不得低于集体合同

## Key Concepts
- **劳动关系**：确立即应订立劳动合同（第十六条）
- **平等自愿、协商一致**：订立和变更合同的基本原则（第十七条）
- **商业秘密约定**（第二十二条）：可在合同中约定保守用人单位商业秘密的事项
- **优先录用义务**（第二十七条第二款）：依裁员条款裁减人员后六个月内录用的，应优先录用被裁减人员
- **工会监督权**（第三十条）：用人单位解除合同，工会认为不适当有权提出意见；违法的有权要求重新处理

## Mental Models
- "解除五通道"决策树：先问劳动者有无过错 → 有过错走25条即时解；无过错走26条（须30日预告+补偿）；企业困难走27条裁员（程序最重）；再叠加29条保护性禁止检查——命中即通道失效
- 把"程序"与"实体"分开记忆：25条重实体事由，27条重程序（说明+报告），26条两者兼具——程序瑕疵是违法解除的常见原因

## Anti-patterns
- **以"不能胜任"直接解除**: 必须先培训或调岗，仍不能胜任才能走第26条，否则构成违法解除
- **跳过预告期解除**: 第26条情形未提前30日书面通知即解除，程序违法
- **孕期解除**: 第二十九条（三）是硬禁止，"协商一致"之外依26/27条解除一律无效
- **口头用工不签合同**: 建立劳动关系应当订立劳动合同；故意拖延不订立的，劳动行政部门责令改正，造成损害须赔偿（第98条）

## Worked Example
员工张某工作8个月（试用期已过），被认定"业绩连续两季度不达标"。合规解除路径：不能依25条（不属于四事由之一）→ 走26条（二）"不能胜任工作"→ 先安排培训或调整岗位 → 复评仍不能胜任 → 提前30日书面通知（或依法代通知）→ 支付经济补偿（第28条）。若公司直接发解除通知，属违法解除。若张某在医疗期内，则26条通道整体关闭（第29条二）。

## Key Takeaways
1. 书面 + 七项必备条款是合同有效运行的底线，建立劳动关系必须签合同
2. 解除权是分类授权：25条即时、26条预告、27条裁员、31条预告辞职、32条即时辞职，各自有独立的事由和程序
3. 第二十九条保护性禁止优先于一切无过错解除通道（孕期产期哺乳期、医疗期、工伤职业病）
4. 协商解除、无过错解除、经济性裁员三类的解除都触发经济补偿（第28条）
5. 集体合同设定"地板"：个人合同的劳动条件和报酬标准不得低于集体合同（第35条）
