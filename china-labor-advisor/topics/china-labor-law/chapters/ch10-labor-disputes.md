# Chapter 10: 劳动争议 (Labor Disputes, 第77–84条)

## Core Idea
劳动争议处理遵循"协商—调解—仲裁—诉讼"阶梯：调解贯穿全程（含仲裁和诉讼程序），仲裁是诉讼的前置程序（一般先仲裁后起诉），并设有明确的时限数字——申请仲裁60日、裁决60日、起诉15日、强制执行。

## Frameworks Introduced
- **争议处理四通道（第七十七条）**：协商、调解、仲裁、诉讼均可依法选择
  - 关键规则：调解原则适用于仲裁和诉讼程序——调解不是一次性前置步骤，而是贯穿全程的原则
- **争议处理三原则（第七十八条）**：合法、公正、及时处理
- **调解-仲裁-诉讼主流程（第七十九条）**：
  1. 可向本单位劳动争议调解委员会申请调解
  2. 调解不成、一方要求仲裁的 → 向劳动争议仲裁委员会申请仲裁
  3. 一方也可以**直接**申请仲裁（调解非必经）
  4. 对仲裁裁决不服 → 向人民法院提起诉讼
  - 程序定性：仲裁前置、诉讼终局（对裁决不服方可起诉）
- **调解委员会构成（第八十条）**：职工代表 + 用人单位代表 + 工会代表三方组成，主任由工会代表担任；调解达成协议的当事人应当履行
- **仲裁委员会三方构成（第八十一条）**：劳动行政部门代表 + 同级工会代表 + 用人单位方面代表，主任由劳动行政部门代表担任
- **争议时限四数字（第八十二、八十三条）**：
  - 申请仲裁：自劳动争议发生之日起 **60日** 内提出书面申请（※实务按《劳动争议调解仲裁法》：时效1年，自知道或应当知道权利被侵害之日起算）
  - 仲裁裁决：一般应在收到申请之日起 **60日** 内作出（※实务按《劳动争议调解仲裁法》：自受理之日起45日内裁决，延期不超过15日；逾期未裁决的申请人可向法院起诉）
  - 提起诉讼：对裁决不服的，自收到裁决书之日起 **15日** 内向法院起诉
  - 一方逾期不起诉又不履行裁决 → 另一方可申请法院**强制执行**
- **集体合同争议双轨（第八十四条）**：
  - 因**签订**集体合同发生争议 → 协商不成由劳动行政部门组织有关各方协调处理（行政协调轨）
  - 因**履行**集体合同发生争议 → 协商不成申请仲裁 → 不服可15日内起诉（普通仲裁诉讼轨）

## Key Concepts
- **劳动争议**：用人单位与劳动者之间因劳动关系产生的争议（第77条）
- **劳动争议调解委员会**：设在用人单位内的三方调解机构（第80条）
- **劳动争议仲裁委员会**：三方组成的仲裁机构，劳动行政部门代表任主任（第81条）
- **仲裁前置**：不经过仲裁直接起诉的，法院不予受理（第79条流程结构）
- **强制执行**：生效仲裁裁决可申请法院强制执行（第83条）

## Mental Models
- "阶梯模型"：协商（自愿）→ 调解（自愿，可跳过）→ 仲裁（必经）→ 诉讼（不服才走）→ 强制执行——每一级都有明确的进入条件和时限
- 三个时限各管一段：60日（申请窗口，※实务按调仲裁法为1年时效）+ 60日（裁决时限，※实务按调仲裁法为45+15日）+ 15日（起诉窗口）——超窗口的后果是失权：错过申请期丧失仲裁请求权，错过15日起诉期裁决即生效
- 集体合同争议看"签"还是"履"：签订争议走行政协调（不进仲裁），履行争议走普通仲裁诉讼——同一份合同的两种争议类型，程序完全不同

## Anti-patterns
- **跳过仲裁直接起诉**: 仲裁是前置程序（第79条），直接起诉将被程序驳回
- **错过60日申请期**: 劳动争议发生之日起60日内须提出书面仲裁申请；超时则请求权面临丧失风险（注意《劳动争议调解仲裁法》已将时效调整为1年，实务以其为准）
- **把调解当必经程序**: 第79条明确"可以直接申请仲裁"——调解自愿，不调解不影响仲裁受理
- **集体合同"签订"争议误入仲裁**: 签订争议应由劳动行政部门组织协调（第84条第一款），走仲裁轨会走错程序
- **以为裁决不自动生效**: 对裁决无异议的当事人必须履行（第82条）；一方不起诉又不履行的，另一方可申请强制执行（第83条）

## Worked Example
员工李某被违法解除劳动合同后，1月10日得知解除决定。程序路径：(1) 可先与公司协商（第77条），协商不成或不愿协商均可直接申请仲裁（第79条，调解非必经）；(2) 须在法定期限内向劳动争议仲裁委员会提交书面申请（本法第82条：自争议发生之日起60日内；《劳动争议调解仲裁法》将时效改为自知道或应当知道权利被侵害之日起1年——实务从其规定）；(3) 仲裁委一般在收到申请之日起60日内作出裁决（第82条；※实务按《劳动争议调解仲裁法》为受理后45日、延期不超过15日，逾期未裁决可起诉）；(4) 若李某对裁决不服，收到裁决书之日起15日内向法院起诉（第83条）；(5) 若公司逾期不起诉又不履行生效裁决，李某可申请法院强制执行（第83条）。委员会构成提醒：仲裁委由劳动行政、工会、用人单位三方代表组成（第81条），主任为劳动行政部门代表。

## Key Takeaways
1. 处理阶梯：协商→调解（自愿）→仲裁（必经前置）→诉讼（不服才走）→强制执行
2. 三个时限：申请60日（本法；《劳动争议调解仲裁法》已改1年时效）、裁决60日（※实务按调仲裁法为45日+15日延期，逾期不裁决可起诉）、起诉15日
3. 调解委员会与仲裁委员会均为三方构成；前者主任=工会代表，后者主任=劳动行政部门代表
4. 集体合同争议分轨：签订争议走劳动行政部门协调，履行争议走仲裁诉讼
5. 生效裁决可申请法院强制执行；调解达成的协议当事人应当履行
6. 调解原则贯穿仲裁与诉讼程序（第77条）
