# Chapter 4: 工作时间和休息休假 (Working Hours, Rest & Leave, 第36–45条)

## Core Idea
法定工时基线为"日8小时 / 周平均44小时 + 每周至少休1日"；加班须协商且有严格上限（日1h / 特殊3h / 月36h），加班费按150%/200%/300%三档计付——这是劳动法中最常被引用、数字最精确的一章。

## Frameworks Introduced
- **标准工时制（第36条）**：每日不超过8小时，平均每周不超过44小时
  - When to use: 一切工时合规计算的基准
- **加班三档上限（第41条）**：
  - 一般：经与工会和劳动者协商，每日延长≤1小时
  - 特殊原因：在保障健康条件下每日≤3小时
  - 月度硬顶：每月≤36小时
  - 前提：生产经营需要 + 与工会和劳动者协商——"协商"是程序要件，单方强制加班违法
- **加班费三档标准（第44条）**：
  - 延时加班（工作日延长）：≥150% 工资
  - 休息日加班且不能补休：≥200% 工资（可先安排补休替代）
  - 法定休假日加班：≥300% 工资（不得以补休替代）
  - When to use: 核算加班工资、审计用工成本
- **不受限加班例外（第42条）**：自然灾害/事故威胁生命健康财产安全需紧急处理；生产设备、交通线路、公共设施故障必须抢修；法律行政法规规定的其他情形
- **法定休假节日（第40条）**：元旦、春节、国际劳动节、国庆节、法律法规规定的其他休假节日——用人单位应当依法安排休假
- **综合计算/不定时工时的例外通道（第39条）**：因生产特点不能实行36/38条的，经劳动行政部门批准可实行其他工作和休息办法
- **计件工时折算（第37条）**：计件工作须按36条工时制度合理确定劳动定额和计件报酬标准
- **带薪年休假（第45条）**：连续工作一年以上的劳动者享受带薪年休假，具体办法由国务院规定

## Key Concepts
- **休息日**：用人单位应保证每周至少休息一日（第38条）
- **补休**：休息日加班的替代性补偿，优先于200%工资；但法定节假日加班不可补休替代，必须付300%
- **劳动定额**：计件制的产出标准，必须与法定工时挂钩（第37条）
- **其他工作和休息办法**：需行政审批，非企业自治事项（第39条）

## Mental Models
- "36小时月度红线"：任何排班表先算月度加班总量，>36h 即违法，无论员工是否"自愿"——自愿不能治愈违法（第43条不得违反规定延长工作时间）
- 加班费判断先分"日"：工作日延时→150%；休息日→200%（可补休）；法定节假日→300%（不可补休）——三档互不替代
- 把"协商"理解为程序证据：企业应留存与工会/劳动者的协商记录，否则第41条要件不满足

## Anti-patterns
- **以"自愿加班"规避补偿**: 安排加班的事实由用人单位举证，"自愿"抗辩在仲裁中通常不被采信；第43条禁止违规延长工时
- **用补休抵付法定节假日加班费**: 300%只适用于法定节假日，补休替代仅适用于休息日（200%档）
- **单方实行不定时工时**: 未经劳动行政部门批准实行"其他工作和休息办法"的，仍按标准工时制认定加班
- **排班突破月度36h**: 大促/旺季集中排班是高频违法场景，行政责任见第90条（警告、责令改正、可罚款）

## Worked Example
某公司安排员工3月：(1) 3个工作日各延时2小时（共6h）；(2) 周六上班一天（8h，后补休）；(3) 国庆10月1日上班一天（8h）。核算：延时加班 6h × 150% 小时工资；周六已补休 → 不另付 200%；国庆上班 8h × 300% 日工资（不可补休）。另核对月度加班总量：6+8+8=22h < 36h，未突破月度红线；但若国庆前一周再排10h延时，则达32h，再加即违法。

## Key Takeaways
1. 工时基线：日8h、周均44h、周休1日——三个数字构成合规底线
2. 加班三要件：生产经营需要 + 协商 + 上限（日1h/特殊3h/月36h），缺一即违规
3. 加班费三档：150%（延时）/ 200%（休息日，可补休替代）/ 300%（法定节假日，不可替代）
4. 第42条紧急情形可突破时限，但属例外而非常态
5. 年休假触发点：连续工作一年以上；具体天数由国务院规定（见《职工带薪年休假条例》）
