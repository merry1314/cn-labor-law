# Chapter 1: 总则 (General Provisions, 第1–9条)

## Core Idea
劳动法以"保护劳动者合法权益"为第一立法目的，构建了"劳动者权利清单 + 用人单位义务清单"的双边结构；凡判断任何用工争议，先回到第3条的权利/义务对照表。

## Frameworks Introduced
- **劳动者八项法定权利（第3条）**：平等就业和选择职业、取得劳动报酬、休息休假、获得劳动安全卫生保护、接受职业技能培训、享受社会保险和福利、提请劳动争议处理、法律规定的其他劳动权利
  - When to use: 任何"劳动者能否主张 X"的问题，先在此清单定位
  - How: 逐项核对权利名称 → 找到对应章节（工资→第五章、休假→第四章、社保→第九章）
- **适用范围双层结构（第2条）**：
  - 第一层：企业、个体经济组织（统称"用人单位"）与形成劳动关系的劳动者 → 直接适用
  - 第二层：国家机关、事业组织、社会团体与建立劳动合同关系的劳动者 → "依照本法执行"
  - When to use: 判断某单位是否落入劳动法调整范围（如公务员、事业编制人员）
  - How: 先看单位性质 → 再看是否建立"劳动合同关系"（编制外用工按劳动合同关系处理）
- **民主管理通道（第八、七条）**：劳动者通过职工大会/职工代表大会参与民主管理或就权益保护平等协商；工会代表和维护劳动者合法权益
  - When to use: 涉及规章制度制定、裁员说明、集体合同程序时

## Key Concepts
- **用人单位**：境内的企业、个体经济组织（第2条）
- **劳动关系**：本法适用性的核心判断标准（第2条）
- **劳动纪律和职业道德**：劳动者的法定义务之一（第3条第二款）
- **劳动行政部门**：国务院劳动行政部门主管全国劳动工作；县级以上地方政府劳动行政部门主管本区域（第9条）

## Mental Models
- 把第3条当成"权利字典"：遇到诉求先查字典再查条文
- 把第4条（用人单位依法建立和完善规章制度）当作一切内部管理的合法性前提——规章制度本身必须合法，否则按第89条承担后果

## Anti-patterns
- **混淆"劳动关系"与"劳务关系"**: 个人之间、承揽/承包关系不形成劳动关系，不适用本法（第2条）
- **以内部规章排除法定权利**: 规章制度违反法律、法规的，由劳动行政部门警告、责令改正，造成损害须赔偿（第89条）

## Worked Example
某个体工商户招用一名帮工。判断路径：单位性质=个体经济组织（第2条第一层）→ 形成劳动关系 → 适用本法。帮工主张"被克扣工资"，先在第3条定位"取得劳动报酬的权利"，再跳转第五章第50条（不得克扣或无故拖欠）与第十二章第91条（责令支付+可责令支付赔偿金）。

## Key Takeaways
1. 本法的适用锚点是"劳动关系"，不是"单位性质"——编制外、劳务派遣用工人员同样受保护
2. 第3条是全书的索引：八项权利各自对应一个专门章节
3. 劳动者义务（完成任务、提高技能、执行安全规程、遵守纪律和职业道德）与权利并列，仲裁时会被双向引用
4. 劳动行政部门是法定的"执法者"角色，劳动者可向其投诉举报（第十一章展开）
