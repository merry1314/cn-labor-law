# Chapter 5: 工资 (Wages, 第46–51条)

## Core Idea
工资制度三条硬规则：按劳分配与同工同酬、最低工资保障（不得低于当地标准）、货币形式按月支付且不得克扣拖欠；法定休假期间工资照付。

## Frameworks Introduced
- **工资分配双原则（第46条）**：按劳分配 + 同工同酬；工资水平随经济发展逐步提高，国家对工资总量实行宏观调控
  - When to use: 薪酬体系设计、同工不同酬争议审查
- **企业工资自主权（第47条）**：用人单位根据生产经营特点和经济效益，依法自主确定工资分配方式和工资水平
  - 边界：自主权受第46条（同工同酬）和第48条（最低工资）双向约束
- **最低工资保障制度（第48条）**：具体标准由省级政府规定、报国务院备案；用人单位支付工资不得低于当地最低工资标准
  - When to use: 薪酬合规底线审查——最低工资是"地板"而非"参考"
- **最低工资五因素（第49条）**：劳动者本人及平均赡养人口最低生活费用、社会平均工资水平、劳动生产率、就业状况、地区经济发展水平差异
  - When to use: 理解最低工资标准的构成逻辑与调整周期
- **工资支付四规则（第50条）**：货币形式 + 按月支付 + 支付给劳动者本人 + 不得克扣或无故拖欠
  - When to use: 工资发放方式审查（实物抵扣、代付第三方、跨月发放均属违规）
- **法定期间工资照付（第51条）**：法定休假日、婚丧假期间、依法参加社会活动期间，用人单位应依法支付工资

## Key Concepts
- **克扣**：无正当理由减少应发工资
- **无故拖欠**：无正当理由逾期不支付工资（与"克扣"并列为第91条责令支付+赔偿金的四大情形之二）
- **工资总量宏观调控**：国家层面的工资指导机制（第46条）
- **同工同酬**：相同工作岗位、相同劳动量应得相同报酬（第46条）

## Mental Models
- "地板-自主"双层模型：最低工资（48条）是法定地板，地板以上企业自主（47条），但自主必须同酬（46条）——三层判断顺序：先查地板，再查同酬，后看自主空间
- 支付合规用"四要素检查表"：货币？按月？本人？无克扣拖欠？四问全"是"才合规
- 把"休假工资"理解为对价延续：法定休假日不提供劳动但工资照付，因为这是劳动者对企业的整体对价的一部分

## Anti-patterns
- **实物/产品抵扣工资**: 第50条要求货币形式，以公司产品抵薪属违规
- **低于最低工资"综合计件"**: 计件制下实际工资仍不得低于最低工资标准（第48条+第37条劳动定额须按法定工时确定）
- **以"经营困难"拖欠工资**: 经营困难不构成"克扣或无故拖欠"的免责事由，第91条责令支付并可责令支付赔偿金
- **休假日扣薪**: 法定休假日、婚丧假、参加社会活动期间扣发工资违反第51条

## Worked Example
某地最低工资标准为2000元/月。员工小王某月实际出勤15天（其余为法定节假日+调休），计件工资折算1850元。审查：(1) 支付形式为货币、当月发放、付给本人——合规；(2) 1850元 < 2000元最低工资——即使部分未出勤为法定休假日（第51条工资照付），月工资仍不得低于最低工资标准，公司应补足至2000元，否则触发第91条（三）"低于当地最低工资标准支付"——劳动行政部门责令支付并可责令支付赔偿金。

## Key Takeaways
1. 最低工资是硬性地板：省级标准，任何计件、提成、绩效结构下实际到手不得低于该标准
2. 支付四要素：货币、按月、本人、不克扣不拖欠——缺一即违规
3. 法定休假日、婚丧假、依法参加社会活动期间工资照付，不得扣减
4. 克扣/无故拖欠/低于最低工资/拒付加班工资四类行为，均可被责令支付并加付赔偿金（第91条）
5. 工资自主权有边界：企业定的是"方式和水平"，定不了"是否同酬"和"能否低于最低工资"
