## Core Frameworks & Mental Models

### 1. 协议效力审查五关（总则第143–157条）
- **有效三要素**（第143条）：行为能力 + **意思真实** + 不违反**效力性**强制规定、不背公序良俗
- **无效**（第153、154、146条）：违反效力性强制规定（放弃社保/工伤条款）/公序良俗/恶意串通/**通谋虚假**（"假辞职真解除"表面行为无效）
- **可撤销**（第147–151条）：重大误解/欺诈/胁迫/显失公平——离职协议"翻盘"的请求权基础（经**法院/仲裁机构**行使，不是单方通知）
- **除斥期间**（第152条）：**重大误解90日**、其他**1年**、胁迫自终止起1年、**5年兜底**——不中止不中断
- **后果**（第155、157条）：自始无效 + 返还 + **过错赔偿**
- 配套：**职务行为**（第170条：员工签字=公司行为，内部限制不抗善意相对人）、**表见代理**（第172条：离职员工持公章仍可能有效）、**履行即追认**（第503条）

### 2. 双时效与时效抗辩（第188–193条）
- **3年诉讼时效**（第188条）：知道受损+义务人起；20年最长——**民事**请求（侵权/普通合同）
- 劳动争议仍走**1年仲裁时效**（调解仲裁法第27条；欠薪=在职不受限+离职起1年）——**按争议性质分流**
- **分期债务**：最后一期届满起算（第189条）
- **法院不得主动适用时效**（第193条）+ 解释二第20条**失权规则**（单位仲裁阶段不提=诉讼/再审不得提）+ 届满后同意/自愿履行不得反悔（第192条）
- **未成年人受性侵**：18周岁起算（第191条）

### 3. 合同编五件套（第463–988条，选劳动关联高频）
- **订立**：数据电文（微信/邮件）=**书面形式**（第469条）；未签名但**已履行主要义务+对方接受**=合同成立（第490条）；预约合同独立责任（第495条）
- **格式条款三刀**（第496–498条）：未提示说明→条款**不成为合同内容**；不合理免责/限权→**无效**；两种以上解释→**不利于提供方**（单位模板合同审查核心工具）
- **免责条款无效**（第506条）：造成**人身损害**/**故意重大过失**财产损失的免责约定
- **履行抗辩三件套**（第525–528条）：同时履行/先履行/**不安**抗辩（须确切证据+通知）——停工的民法依据（注意与劳动法38条程序配合）
- **情势变更**（第533条）：不可预见非商业风险重大变化→再协商→变更/解除
- **变更不明=未变更**（第544条）vs 解释一第43条"实际履行超1个月=锁死"——口头降薪攻防的两条时间线
- **法定解除**（第563条）五情形（不可抗力/预期违约/催告后仍不履行/根本违约/法定）；**解除通知到达=解除日**（第565条，可直接起诉主张：起诉状副本送达日解除）
- **解除后果**（第566条）：终止+恢复原状+赔偿；**违约解除→违约责任并行**
- **违约救济**（第577–593条）：继续履行（金钱债务必给，第579条）+补救+**损失赔偿**（实际+可得利益，上限可预见，第584条）+**违约金酌增酌减**（第585条：超过损失30%即>损失×130%为过分高于※）+**定金**（20%上限+罚则+与违约金择一，第586–588条——劳动关系禁止向劳动者收财物，定金制度不适用）+减损义务（第591条）+不可抗力只免违约责任（第590条）

### 4. 人格权编——职场权益武器库（第989–1039条）
- **性骚扰**（第1010条）：言语/文字/图像/肢体+违背意愿=侵权；**单位法定三义务**：预防、**受理投诉**、**调查处置**——利用**职权、从属关系**点名；单位不作为=自身违法
- **人身自由**（第1011条）：非法拘禁/限制行动自由/**非法搜查身体**（搜身）=侵权
- **肖像与声音**（第1018–1023条）：未经同意不得制作使用公开；**AI换脸**（信息技术手段伪造）入法；**声音**参照肖像保护
- **名誉**（第1024–1026条）：侮辱诽谤=侵权；**舆论监督免责**+三例外（捏造/严重失实未核实/侮辱性言辞）；**合理核实义务**六因素——员工维权帖与被告单位的**双向**攻防
- **隐私**（第1032、1033条）：生活安宁+私密空间/活动/信息；六禁止（电话侵扰/闯入私密空间/窃听/私密部位/私密信息）——查手机、翻宿舍、卫生间摄像头=红线；办公区监控工作行为=一般合理
- **个人信息**（第1034–1039条）：能识别特定自然人的信息（含**健康、行踪、生物识别**）；处理须**合法正当必要**+**同意**+公开规则+明示目的；个人**查阅复制/更正/删除**三权；处理者安全+泄露**补救告知报告**义务；边界=劳动合同法第8条"**与劳动合同直接相关**"

### 5. 侵权责任编——赔偿总库（第1164–1260条）
- **归责**：过错责任+**过错推定**（第1165条二，举证倒置总开关）+无过错责任（第1166条）
- **用人单位责任**（第1191条）：员工**执行工作任务**致害=**单位**担责（对外）；单位可向**故意/重大过失**员工**追偿**；**劳务派遣**=**用工单位**担责+派遣单位过错相应
- **个人劳务**（第1192条）：提供劳务方受损害→**过错分担**；第三人致害→**第三人赔或接受方补偿**双通道
- **受害人因素**：**过失相抵**（第1173条，工伤行政轨道不适用，民事轨道适用）/受害人故意免责（第1174条）
- **自甘风险**（第1176条）：文体活动**参加者之间**限缩——**单位作为组织者**的安保责任（第1198条）不减
- **人身损害项目**（第1179条）：医疗/护理/交通/营养/伙食+**误工**；残+辅助器具+**残疾赔偿金**；死+丧葬+**死亡赔偿金**
- **精神损害赔偿**（第1183条）：**严重**精神损害（侮辱/性骚扰/致残）；人身意义特定物（故意/重大过失）
- **惩罚性赔偿三入口**：知产故意（第1185条）/产品明知缺陷致死残（第1207条）/环境故意（第1232条）
- **第三人+安保义务→补充责任**（第1198条、1201条、1233条）：先找有偿付能力的单位/经营者
- **交通事故**（第1213条）：**交强险→商业险→侵权人**；挂靠**连带**（第1211条）；好意同乘**减轻**（第1217条）
- **医疗损害**（第1218–1228条）：医疗机构过错担责；**过错推定**（违规/隐匿/伪造病历，第1222条）；患者**病历查阅复制权**（第1225条）——工伤医疗中的医疗事故与工伤**责任切割**
- **环境**（第1229、1230条）：无过错+**因果举证倒置**
- **建筑物物件**（第1252–1258条）：搁置物坠落/堆放物/地下施工=**过错推定**；**高空抛物**（第1254条）：侵权人赔+难确定时可能加害人补偿+物业安保义务
- **本数规则**（第1259条）：以上/以下/以内/届满=**含本数**；不满/超过/以外=不含
- **2021-01-01施行**（第1260条）：跨期案件按**行为时法**

### 6. 物权/婚姻/继承编——劳动关联点（未逐条展开，需时查法条）
- **物权编**：
  - **居住权**（第366–371条）：以居住为目的的用益物权，可书面合同+登记设立，与劳动者住房保障相关
  - **租赁权**（第703–734条）："买卖不破租赁"（第725条）、承租人优先购买权（第726条）、转租规则——劳动者租房权益
  - **抵押权**（第394–424条）：劳动者贷款购房/购车的抵押关系，与工资收入偿债相关
- **婚姻家庭编**：
  - **夫妻共同财产**（第1062条）：工资、奖金、劳务报酬、生产经营投资收益属**夫妻共同所有**——劳动者工资收入归属
  - **夫妻共同债务**（第1064条）：共债共签/事后追认/家庭日常生活所需——劳动者对外债务责任
  - **离婚经济补偿**（第1088条）：一方因抚育子女/照料老人/协助另一方工作等负担较多义务的，离婚时有权请求补偿
- **继承编**：
  - **法定继承顺序**（第1127条）：第一顺序配偶/子女/父母——工亡职工遗产分配
  - **抚恤金/工亡补助金分配**：虽非遗产（第1122条遗产定义），但实践中参照继承规则在近亲属间分配
  - **遗嘱**（第1133–1144条）：劳动者可通过遗嘱处分个人财产

## Scope & Limits

本技能覆盖民法典**全部7编**，但以**劳动者视角**深度展开总则、合同、人格权、侵权责任四编；**物权编**（居住权、租赁权、抵押权）、**婚姻家庭编**（夫妻共同财产中工资归属、夫妻共同债务、离婚经济补偿）、**继承编**（工亡职工遗产分配、抚恤金/工亡补助金分配）已整理劳动关联点（见 Core Frameworks 第6点），未逐条展开——需要时直接查法条原文。

适用边界：
- **特别法优先**：劳动法、劳动合同法、社保法、工伤保险条例、调解仲裁法有规定的，**优先适用**；民法典是**补充层**
- **时点**：2021-01-01 前的事实按**行为时法**（旧法）；跨期案件先定**时点**
- **双轨分界**：工伤认定/待遇走**行政法轨道**（无过错、法定项目）；人身损害赔偿走**民事轨道**（本技能）——同一事故可能**并行**（第三人侵权致工伤），双赔/补差按**地方口径**
- **司法解释衔接**：最高法民法典合同编/人格权编/侵权责任编**各分编司法解释**（2021、2022、2024施行）有细化规则的，以司法解释为准

本技能不构成法律意见；个案结论受证据与地方实践影响，重大争议请咨询执业律师。
