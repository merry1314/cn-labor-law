# Glossary — 中华人民共和国民法典（劳动者视角重点条文）

## 总则编（第3–204条）
- **有效三要素** — 行为能力+意思真实+不违法不背俗（第143条）
- **虚假意思表示** — 双方通谋虚假→无效；隐藏行为另判（第146条）
- **可撤销四事由** — 重大误解/欺诈/胁迫/显失公平（第147–151条）
- **除斥期间** — 1年/重大误解90日/胁迫终止起1年/5年兜底（第152条）
- **效力性强制规定** — 违反才无效；管理性强制规定不当然无效（第153条）
- **自始无效** — 无效/被撤销→自始无约束力（第155条）
- **职务行为** — 员工职权内行为=公司行为；内部限制不抗善意相对人（第170条）
- **表见代理** — 有理由相信有代理权→有效（第172条）
- **责任竞合** — 违约损人身财产→违约/侵权二选一（第186条）
- **民事优先** — 财产不足时优先承担民事责任（第187条）
- **不可抗力** — 不能预见不能避免不能克服（第180条）
- **3年诉讼时效** — 知道受损+义务人起；20年最长（第188条）
- **分期债务时效** — 最后一期届满起算（第189条）
- **法院不主动适用时效**（第193条）
- **特别授权** — 代为承认/放弃/变更请求/和解/上诉（第165条+诉讼法）
- **交邮主义** — 期满前交邮不算过期（第204条）

## 合同编（第463–988条）
- **数据电文** — 微信/邮件等视为书面形式（第469条）
- **事实合同成立** — 未签名但已履行主要义务+对方接受（第490条）
- **格式条款** — 预先拟定未协商；未提示说明→不进合同；限权免责→无效；不利解释（第496–498条）
- **免责条款无效** — 人身损害/故意重大过失财产损失（第506条）
- **全面履行+附随义务** — 通知、协助、保密（第509条）
- **同时履行抗辩**（第525条）/ **先履行抗辩**（第526条）/ **不安抗辩**（第527、528条）
- **情势变更** — 不可预见非商业风险重大变化→再协商→变更/解除（第533条）
- **变更不明=未变更**（第544条）
- **债务转移须同意** — 债权人同意才生效（第551条）
- **代位权**（第535条）/ **撤销权**（第538、539条，1年/5年）
- **法定解除五情形**（第563条）/ **解除通知到达生效**（第565条）
- **解除+违约责任并行**（第566条二）
- **可得利益** — 履行后可获利益，上限=可预见（第584条）
- **违约金酌增酌减** — 低于损失可增、过分高于可减（第585条）
- **定金** — 实际交付成立；20%上限；罚则；与违约金择一（第586–588条）
- **减损义务** — 不防扩大→扩大部分不赔（第591条）

## 人格权编（第989–1039条）
- **性骚扰三义务** — 单位预防+受理投诉+调查处置（第1010条）
- **人身自由保护** — 非法拘禁/搜查身体（第1011条）
- **AI换脸** — 信息技术手段伪造肖像=侵权（第1019条）
- **声音保护** — 参照肖像权（第1023条）
- **名誉** — 社会评价；侮辱诽谤侵权（第1024条）
- **舆论监督免责** — 公共利益+三例外（第1025条）
- **合理核实义务** — 六因素（第1026条）
- **隐私** — 生活安宁+私密空间/活动/信息；六禁止（第1032、1033条）
- **个人信息** — 能识别特定自然人的信息；合法正当必要+同意+明示（第1034、1035条）
- **个人三权** — 查阅复制/更正/删除（第1037条）
- **匿名化** — 无法识别+不能复原→可对外提供（第1038条）

## 侵权责任编（第1164–1260条）
- **过错推定** — 依法推定过错，自证无过错免责（第1165条二）
- **无过错责任**（第1166条）
- **教唆帮助连带**（第1169条）/ **共同危险连带**（第1170条）
- **过失相抵** — 受害人对发生/扩大有过错→减轻（第1173条）
- **受害人故意** — 免责（第1174条）
- **自甘风险** — 文体活动参加者之间；组织者安保不减（第1176条）
- **自助行为** — 紧迫+必要范围+立即请求公力（第1177条）
- **人身损害项目** — 医疗/护理/交通/营养/伙食/误工；残+辅助器具+残疾赔偿金；死+丧葬+死亡赔偿金（第1179条）
- **同死同价**（第1180条）
- **精神损害赔偿** — 严重精神损害；人身意义特定物（第1183条）
- **惩罚性赔偿** — 知产故意/产品明知/环境故意（第1185、1207、1232条）
- **用人单位责任** — 职务致害单位赔+故意重大过失追偿（第1191条一）
- **派遣致害** — 用工单位赔+派遣单位过错相应（第1191条二）
- **个人劳务** — 接受方赔/过错分担/第三人双通道补偿（第1192条）
- **承揽** — 定作人一般不赔；选任指示定作过错担责（第1193条）
- **通知-删除** — 网络侵权平台程序（第1195、1196条）
- **安全保障义务** — 经营者管理者组织者；第三人致害→补充责任（第1198条）
- **教育机构推定** — 无民事行为能力人受害→学校自证尽责（第1199条）
- **产品责任** — 生产者无过错；产销择一（第1202、1203条）
- **保险先行顺序** — 交强险→商业险→侵权人（第1213条）
- **好意同乘** — 无偿搭乘减轻（故意重大过失除外，第1217条）
- **医疗过错推定** — 违规/隐匿/伪造病历（第1222条）
- **环境举证倒置** — 行为人证免责+无因果（第1230条）
- **高度危险** — 无过错为主；受害人故意免责（第1236条起）
- **烈性犬绝对责任**（第1247条）
- **建筑物脱落坠落** — 所有人管理人使用人过错推定（第1253条）
- **高空抛物** — 侵权人赔；难确定→可能加害人补偿；物业安保义务（第1254条）
- **本数规则** — 以上以下以内届满含本数（第1259条）
- **2021-01-01施行** — 九法废止（第1260条）
