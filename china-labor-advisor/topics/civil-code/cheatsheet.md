## 劳动者高频条文速查

| 场景 | 条文 | 结论 |
|---|---|---|
| 离职协议被胁迫/欺诈 | 150、148条 | **可撤销**（法院/仲裁行使） |
| 离职协议"亏大了" | 151条 | **显失公平**→可撤销 |
| 签错协议（重大误解） | 147条 | 可撤销——**90日**除斥期间 |
| 撤销倒计时 | 152条 | 1年/重大误解90日/胁迫终止起1年/**5年**兜底 |
| 放弃社保/放弃工伤条款 | 143条三+153条 | **无效**（效力性强制规定） |
| 协议无效后果 | 155、157条 | 自始无效+返还+过错赔偿 |
| 部门经理签的协议 | 170条 | **职务行为**=公司行为（内部限制不抗善意） |
| 离职员工持公章签约 | 172条 | **表见代理**有效（有理由相信有权） |
| 公司"开始履行" | 503条 | 视为**追认** |
| 微信/邮件录用通知 | 469条 | 数据电文=**书面形式** |
| 没签合同已上班 | 490条 | 履行主要义务+对方接受=**合同成立** |
| 单位模板小字条款 | 496条 | 未提示说明→**不成为合同内容** |
| "放弃异议权/最终解释权" | 497条 | 排除主要权利→**无效** |
| 格式条款两种解释 | 498条 | **不利于单位**解释 |
| "工伤自负/风险自担" | 506条 | 人身损害免责条款**无效** |
| 对方不付钱我先停工 | 525、526条 | **同时/先履行抗辩** |
| 单位转移资产逃债 | 527、528条 | **不安抗辩**（确切证据+通知） |
| 行业巨变降薪 | 533条 | **情势变更**→再协商→变更/解除 |
| 口头变更说不清 | 544条 | 推定**未变更**（对照解释一43条实际履行锁死） |
| 单位把欠薪转给关联公司 | 551条 | 债务转移须**你同意** |
| 单位转移资产逃欠薪 | 538、539条 | **撤销权**（1年/5年） |
| 单位长期欠薪要解除 | 563条（三）（四） | 催告后合理期限未履行/根本违约→**法定解除** |
| 解除通知 | 565条 | **到达日**=解除日；可直接起诉主张（起诉状副本送达日解除） |
| 解除后还能索赔吗 | 566条二 | 因违约解除→**违约责任并行** |
| 损失怎么算 | 584条 | 实际+**可得利益**，上限**可预见** |
| 违约金天价/过低 | 585条 | **酌增酌减**（超过损失30%即>损失×130%为过分高于※） |
| 定金 | 586–588条 | 交付成立/**20%上限**/罚则/与违约金**择一**（劳动关系禁止收财物——劳动合同法9条） |
| 不可抗力免责 | 590条 | 只免**违约责任**；须通知+证明；**迟延后**发生不免责 |
| 对方违约我不管了 | 591条 | **减损义务**——扩大部分不赔；合理止损费用由违约方出 |
| 3年诉讼时效 | 188条 | 知道受损+义务人起；20年最长 |
| 分期补偿 | 189条 | **最后一期**起算 |
| 时效过了还能要吗 | 192、193条 | 单位不提=**不抗辩**；法院**不主动适用**；事后同意履行不得反悔 |
| 委托律师 | 165条 | 委托书载明权限期限；**特别授权**才能和解/上诉 |
| 最后一天是节假日 | 200–204条 | **顺延**；**交邮**不算过期 |
| 性骚扰 | 1010条 | 行为人担责；单位**预防+受理投诉+调查处置**法定义务 |
| 搜身/扣留 | 1011条 | 非法限制自由/搜查身体=侵权 |
| 偷看手机/查宿舍 | 1032、1033条 | 侵犯**隐私**（私密空间/信息/生活安宁） |
| AI换脸/声音合成 | 1019、1023条 | 未经同意=侵权（肖像/**声音**参照） |
| 单位通报"小偷"失实 | 1024、1025条 | **名誉侵权**（舆论监督免责+三例外） |
| 发维权帖被告 | 1025、1026条 | 真实+公共利益+无侮辱言辞→**免责抗辩** |
| 收集全家信息/全套生物识别 | 1035条+劳动合同法8条 | **必要原则**/直接相关——可拒绝+留痕 |
| 我的信息被泄露 | 1038条 | 处理者**补救+告知+报告**义务；可**删除/更正/查阅复制**（1037条） |
| 同事职务行为伤了我 | 1191条一 | **单位**担责（对外）；单位可向故意/重大过失者**追偿** |
| 派遣员工致害 | 1191条二 | **用工单位**担责；派遣单位过错**相应** |
| 劳务（非劳动关系）受伤 | 1192条 | **过错分担**；第三人致害→**第三人赔/接受方补偿** |
| 外包装修砸伤人 | 1193条 | 承揽人担责；单位**选任/指示/定作**过错担责（呼应解释二1条） |
| 平台发诽谤帖 | 1195、1196条 | **通知-删除**程序；平台未及时处理→**扩大部分**连带 |
| 工作场所滑倒/被外人伤害 | 1198条 | 单位**安保义务**；第三人致害→单位**补充责任** |
| 团建/运动会受伤 | 1176、1198条 | 自甘风险只限**参加者之间**；**组织者**安保责任不减 |
| 人身损害赔什么 | 1179条 | 医疗/护理/交通/营养/伙食/**误工**；残+辅助器具+**残疾赔偿金**；死+丧葬+**死亡赔偿金** |
| 精神损害 | 1183条 | **严重**精神损害；人身意义特定物（故意/重大过失） |
| 惩罚性赔偿 | 1185、1207、1232条 | 知产故意/产品明知缺陷/环境故意 |
| 分期赔不起 | 1187条 | 可分期，但你**有权要求担保** |
| 上下班交通事故 | 1213条+1179条 | **交强险→商业险→侵权人**；与工伤**双轨并行** |
| 挂靠车辆事故 | 1211条 | 挂靠人+被挂靠人**连带**（呼应解释二2条） |
| 好意同乘 | 1217条 | 无偿搭乘**减轻**（故意重大过失除外） |
| 工伤医疗再出医疗事故 | 1218、1222条 | **医疗过错**与工伤**切割**；违规/隐匿/伪造病历→**过错推定** |
| 病历 | 1225条 | 患者**查阅复制权**（及时提供） |
| 工厂污染致健康损害 | 1229、1230条 | 无过错责任+**因果举证倒置**（行为人自证无因果） |
| 车间吊件坠落砸伤 | 1253条 | 所有人/管理人/使用人**过错推定**（自证无过错） |
| 高空抛物 | 1254条 | 侵权人赔；难确定→**可能加害人补偿**；物业安保义务 |
| "满10年""30日以上" | 1259条 | **以上/以下/以内/届满=含本数**；不满/超过/以外=不含 |

## 协议效力审查卡（总则）

```
签了的协议/声明，按顺序过五关：
① 形式与主体：签字人有权吗？（170/172/503条 职务行为/表见代理/追认）
② 内容合法吗：碰效力性强制规定/公序良俗/恶意串通？
   → 碰 = 【无效】（153/154条）自始无效
③ 意思真实吗：欺诈/胁迫/显失公平/重大误解？
   → 有 = 【可撤销】（147–151条）经法院/仲裁撤销
④ 虚假通谋吗："假辞职真解除"？
   → 是 = 表面行为【无效】，按隐藏的真实关系处理（146条）
⑤ 倒计时：撤销 = 90日（重大误解）/ 1年（其他）/ 5年兜底（152条）
撤销后果：自始无效 + 返还 + 过错赔偿（155/157条）
```

## 违约救济"五件套"（合同编第八章）

```
1. 继续履行（577/580条）——金钱债务必给（579条）；人身性质劳务不得强制
2. 补救措施（582条）——修理/重作/更换/退货/减少价款报酬
3. 赔偿损失（584条）——实际 + 可得利益，上限 = 可预见
4. 违约金（585条）——酌增酌减；迟延违约金付了还得履行
5. 定金（586–588条）——20%上限 + 罚则 + 与违约金择一（民事场景）
附随：减损义务（591条）/ 不可抗力（590条，只免违约责任）
```

## 工伤 vs 侵权双轨决策卡（第1179、1191、1213条）

```
受伤/出事故
  │
  ├─ 工作原因（含上下班途中交通事故）→ 【工伤轨道】
  │     认定 → 鉴定 → 工伤保险待遇（无过错；单位未缴社保 = 单位全额）
  │
  ├─ 有【第三人】致害（肇事方/产品缺陷/同事之外的人）→ 【侵权轨道并行】
  │     人身损害项目（1179条）+ 精神损害（1183条）
  │     交通事故：交强险 → 商业险 → 侵权人（1213条）
  │     已赔项目不重复；残疾/死亡赔偿金、精神抚慰金 通常可并行
  │     （地方口径：双赔 / 补差）
  │
  └─ 单位设施/管理致害（吊件坠落/地滑/安保缺失）→ 侵权轨道
        过错推定场景（1253条等）：单位自证无过错
        第三人+安保缺失 → 第三人赔 + 单位【补充责任】（1198条）
```

| 争议类型 | 时效 | 起算 |
|---|---|---|

## 与劳动法体系的适用关系

```
特别法优先：劳动法 / 劳动合同法 / 社保法 / 调解仲裁法 / 工伤保险条例
     ↓ 特别法有规定 → 适用特别法
     ↓ 特别法无规定 → 民法典（一般法）补充
典型"民法典补位"场景：
· 保密协议 / 培训服务期协议 / 竞业限制协议 的【违约救济】（违约金酌减585条、损失584条）
· 离职协议的【撤销】请求权基础（147–151条）
· 职场性骚扰 / 人格权侵害 的【赔偿】（1010/1032/1179/1183条）
· 劳务派遣【致害】责任（1191条二）——劳动法体系只讲用工责任，不讲对外侵权
· 用人单位对外【职务侵权】（1191条一）
· 工伤+第三人侵权【双轨】赔偿计算（1179/1213条）
```
