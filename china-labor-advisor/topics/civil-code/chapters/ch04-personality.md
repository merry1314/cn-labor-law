# Chapter 4: 人格权编——隐私、个人信息与职场人格权益（第989–1039条）

## Core Idea
人格权编是民法典**独立成编**的首创。劳动者视角的四个武器：**性骚扰**条款（第1010条——**单位的预防、受理投诉、调查处置义务**，职场反性骚扰的核心法条）、**隐私权**（第1032、1033条——单位查手机、装摄像头、翻私人物品）、**个人信息保护**（第1034–1039条——人事档案、考勤定位、健康信息的收集使用边界）、以及**姓名/肖像/名誉**（第1012–1031条——商誉贬损、AI换脸、名誉纠纷的合理核实义务）。

## Frameworks Introduced

### 生命权、身体权、健康权与人身自由
- **性骚扰（第一千零一十条）**——职场核心条款：
  - 违背他人**意愿**，以**言语、文字、图像、肢体行为**等方式实施性骚扰→受害人有权请求行为人承担**民事责任**
  - **机关、企业、学校等单位**应当采取**合理的预防、受理投诉、调查处置**等措施，**防止和制止**利用**职权、从属关系**等实施性骚扰
  - When to use: ① 被性骚扰→**投诉到单位**（单位有法定义务受理调查）→单位不作为=二次违法 ② 直接民事索赔（精神损害赔偿，第1183条）③ 单位以"性骚扰"为由**解除**员工（被投诉方/投诉方）→解除须**查实**，否则违法解除（举证在单位，解释一44条）
  - 配套：《妇女权益保障法》（2022修订）第25条细化单位义务（明确定义+投诉渠道+不得打击报复）
- **人身自由保护（第一千零一十一条）**：以**非法拘禁**等方式剥夺、限制他人**行动自由**，或**非法搜查身体**→受害人有权请求民事责任
  - When to use: 单位保安**搜身**、扣留员工"问话"数小时——直接侵权；与劳动合同法第38条（二）"以暴力、威胁或非法限制人身自由强迫劳动→可立即解除"联动

### 姓名权与名称权（第一千零一十二至一千零一十七条条）
- 自然人享有**姓名权**：决定、使用、变更、**许可他人使用**（第1012条）
- 法人、非法人组织享有**名称权**：决定、使用、变更、**转让**、许可使用（第1013条）
- 禁止**干涉、盗用、假冒**（第1014条）
- 变更姓名/名称→**变更前**的民事法律行为仍对其有约束力（第1016条）——员工改名后，原劳动合同**不受影响**
- **笔名、艺名、网名、译名、字号、简称**具有一定社会知名度+足以造成混淆的→**参照**姓名权保护（第1017条）——网红员工/主播的网名被冒用

### 肖像权（第一千零一十八至一千零二十三条条）
- **肖像**=可识别的特定自然人外部形象（影像、雕塑、绘画等载体，第1018条）
- **三禁止**（第1019条）：不得**丑化、污损**或**利用信息技术手段伪造**（**AI换脸**点名入法）；**未经同意**不得**制作、使用、公开**
- **合理使用五情形**（第1020条，无需同意）：个人学习/艺术欣赏/课堂教学/科研必要使用已公开肖像；新闻报道不可避免；国家机关依法履职必要范围；展示公共环境不可避免；维护公共利益或其他
- **肖像许可合同**（第1021、1022条）：使用条款争议→**有利于肖像权人**解释；期限不明→**随时解除**（合理期限前通知）；有约定期限+肖像权人有**正当理由**→可解除（合理期限前通知+赔偿对方损失，不可归责事由除外）
- **声音保护**（第1023条）：姓名等许可使用参照肖像规则；**自然人声音**参照**肖像权**保护——员工声音被AI合成用于广告

### 名誉权与荣誉权（第一千零二十四至一千零三十一条条）
- **名誉**=对品德、声望、才能、信用等的**社会评价**（第1024条）；禁止**侮辱、诽谤**
- **舆论监督免责+三例外**（第1025条）：为**公共利益**实施**新闻报道、舆论监督**影响他人名誉→不担责，**但**：①捏造歪曲事实 ②对他人提供的**严重失实**内容**未尽合理核实义务** ③使用**侮辱性言辞**贬损
  - When to use: 员工发**维权帖/差评**被单位告"名誉侵权"——本条+合理核实义务是抗辩核心；反之单位在**内部通报/朋友圈**散布员工"小偷""诈骗"未核实=诽谤
- **合理核实义务六因素**（第1026条）：内容来源可信度/是否必要调查/时限性/与公序良俗关联/名誉贬损可能性/核实能力与成本
- **文学作品**（第1027条）：以真人真事/特定人为对象含侮辱诽谤→担责；不特定人仅情节相似→不担责
- **媒体更正删除**（第1028条）：证明媒体报道**失实**侵权→请求**及时更正或删除**
- **信用评价**（第1029条）：可依法**查询**自己信用评价；发现**不当**→**异议+更正删除**；信用评价人应及时核查
- **荣誉权**（第1031条）：不得**非法剥夺**荣誉称号、诋毁贬损；应记载未记载→请求**记载**；记载错误→请求**更正**

### 隐私权（第一千零三十二、一千零三十三条条）
- **隐私权**：自然人私人生活**安宁**+不愿为他人知晓的**私密空间、私密活动、私密信息**（第1032条）
- 禁止**刺探、侵扰、泄露、公开**
- **六禁止行为**（第1033条，除法律另有规定或权利人**明确同意**）：
  1. 电话、短信、即时通讯、电子邮件、传单等方式**侵扰私人生活安宁**
  2. **进入、拍摄、窥视**住宅、宾馆房间等**私密空间**
  3. **拍摄、窥视、窃听、公开**私密活动
  4. 拍摄、窥视身体**私密部位**
  5. **处理**私密信息
  6. 其他方式
  - When to use: 单位**偷看员工手机/微信**、**私拆信件**、宿舍**装摄像头**、翻个人背包——逐项对照；单位**办公场所**监控工作区域的**工作行为**一般属合理管理（非隐私），但**卫生间、更衣室**=私密空间红线

### 个人信息保护（第一千零三十四至一千零三十九条条）
- **个人信息定义**（第1034条）：电子或其他方式记录的能**单独或结合识别特定自然人**的各种信息——姓名、出生日期、**身份证件号码**、**生物识别信息**、住址、电话号码、电子邮箱、**健康信息**、**行踪信息**等
  - **私密信息**适用隐私权规定；没规定的适用个人信息规定
  - When to use: 员工**健康档案**（体检报告、病历）、**行踪**（钉钉/企业微信定位）、**身份证复印件**——都是个人信息，收集使用有边界
- **处理五条件**（第1035条）：**合法、正当、必要**+不得**过度处理**：
  1. **征得同意**（法律行政法规另有规定除外——如社保征缴、依法令）
  2. **公开**处理规则
  3. **明示**目的、方式、范围
  4. 不违反法律法规和约定
  - 处理=**收集、存储、使用、加工、传输、提供、公开**
  - When to use: 入职要求"全家信息、无犯罪记录证明（无法律依据时）、指纹+人脸+声纹**全套**采集——**必要原则**抗辩：与履行劳动合同**无必要关联**的采集可拒绝（劳动合同法第8条：单位只能了解**与劳动合同直接相关**的基本情况）
- **免责三情形**（第1036条）：同意范围内合理处理；合理处理**自行公开/已合法公开**信息（明确拒绝或侵害重大利益除外）；维护公共利益或本人合法权益的合理处理
- **个人三权**（第1037条）：**查阅、复制**自己信息；发现**错误**→**异议+更正**；处理者**违法/违约处理**→请求**删除**
- **处理者义务**（第1038条）：不得**泄露、篡改**；未经同意**不得向他人非法提供**（**匿名化**——无法识别特定个人且**不能复原**——除外）；应采取**技术措施**确保安全；发生或可能发生**泄露、篡改、丢失**→**及时补救+告知自然人+报告主管部门**
- **国家机关保密**（第1039条）：履职中知悉的隐私和个人信息→**保密**，不得泄露或非法提供
  - When to use: 社保、税务、公安系统里查得到你的信息——泄露即可追责

## Key Concepts
- **性骚扰**：单位"预防+受理投诉+调查处置"三义务；利用职权从属关系点名（第1010条）
- **非法搜查身体/限制行动自由**=侵权（第1011条）
- **AI换脸**入法：信息技术手段伪造肖像=侵权（第1019条）；**声音**参照肖像保护（第1023条）
- **名誉**=社会评价；**舆论监督**免责+**合理核实义务**（第1024–1026条）
- **隐私**=生活安宁+私密空间/活动/信息；**六禁止**（第1032、1033条）
- **个人信息**：合法正当必要+**同意+公开规则+明示目的**（第1034、1035条）
- **个人三权**：查阅复制/更正/删除（第1037条）
- **匿名化例外**：无法识别+不能复原（第1038条）

## Mental Models
- "职场人格权地图"：身体（搜身/性骚扰/暴力）→自由（拘禁/扣留）→隐私（查手机/装摄像头）→个人信息（定位/体检/身份证）→名誉（通报/通报批评的边界）→肖像声音（培训视频/广告/AI换脸）——每一格都是独立请求权
- "单位义务从'不侵权'升级为'要作为'"（第1010条）：性骚扰条款的特殊设计——单位**不止**不能自己骚扰，还**必须**建立预防+投诉+调查机制；单位"装聋"=自己的违法
- "必要原则"过滤器（第1035条+劳动合同法第8条）：单位收集信息的边界=**与劳动合同直接相关/履行所必要**——"直接相关"是劳动法表述，"必要"是民法典表述，两条线同一把尺
- "维权发声的免责区"（第1025条）：为公共利益（含**舆论监督**）发表内容→不担责，除非捏造/严重失实未核实/侮辱性言辞——员工**如实**曝光欠薪（有证据）≠诽谤；**骂人+编造**=侵权

## Anti-patterns
- **单位"内部通报"=想写啥写啥**: 通报内容**失实**（把"疑似"写成"确定"）+**侮辱性言辞**→名誉侵权（第1024、1025条）；通报范围还涉及**隐私/个人信息**扩散（把体检结果贴公告栏）→双重侵权
- **入职"全家桶"信息收集**: 身份证号+人脸+指纹+家庭成员+病史**全套**——超出"直接相关/必要"→第1035条+劳动合同法第8条抗辩；**健康信息**（乙肝携带等）与岗位无关的收集=违法（传染病防治法+就业促进法另有禁用规定）
- **"我们装了监控你该知道"**: 办公区域**工作行为**监控可合理，但**卫生间/更衣室/宿舍**=**私密空间**（第1033条二）红线；监控**画面**对外提供/用于非工作目的→个人信息侵权
- **性骚扰"私了"**: 第1010条单位**受理投诉+调查处置**是**法定义务**——"双方调解别声张"不免除单位义务；被投诉方被**未查实**即开除=违法解除
- **AI换脸/声音合成"只是恶搞"**: 第1019、1023条——**未经同意**的制作使用公开=侵权，"恶搞"不是抗辩；**丑化、污损**同样入罪（治安管理处罚法/刑法侮辱罪另有衔接）

## Worked Example
小宋（客服主管）遭遇部门经理连续数月的言语性骚扰（微信"开黄腔"+下班"单独吃饭"肢体接触）。处理：
1. **证据固定**：微信记录（完整不删）、录音（自己参与的对话）、时间线——**私密信息**不公开，仅提交给投诉渠道/仲裁
2. **单位投诉**（第1010条二款）：向HR/工会/监察渠道**书面投诉**——单位**必须**受理+调查+处置；单位"和稀泥"不处理→保留投诉回执（单位违法的**证据**）
3. **民事索赔**：对行为人——**精神损害赔偿**（第1183条，严重精神损害）+**赔礼道歉**（第179条）
4. **解除关联**：若单位以"影响团队"为由解除小宋（投诉方）→**打击报复**——违法解除（2N）；若解除**被投诉方**→须**查实**（举证在单位）
5. **并行保护**：性骚扰涉及**威胁、限制自由**的→第1011条+劳动合同法第38条（二）**立即解除**（不需30日）+报警（治安/刑事）
6. **个人信息边界**：单位调查时调取小宋**全部**私人聊天记录（与骚扰无关部分）→**过度处理**（第1035条）——调查范围应**限于必要**

## Key Takeaways
1. **性骚扰**：言语/文字/图像/肢体+违背意愿=侵权（第1010条一）；单位**预防+受理投诉+调查处置**法定义务，**利用职权从属关系**点名（第1010条二）
2. **非法拘禁/搜身**=侵权（第1011条）
3. **肖像**：未经同意不得制作使用公开；**AI换脸**=侵权（第1019条）；**声音**参照保护（第1023条）
4. **名誉**：侮辱诽谤=侵权（第1024条）；**舆论监督**免责+三例外（捏造/严重失实未核实/侮辱言辞，第1025条）；**合理核实义务**六因素（第1026条）
5. **隐私**：生活安宁+私密空间/活动/信息；**六禁止**（电话侵扰/闯入私密空间/窃听/私密部位/私密信息，第1033条）
6. **个人信息**：合法正当**必要**+**同意**+**公开规则**+**明示目的**（第1035条）；**查阅复制/更正/删除**三权（第1037条）；处理者**安全保障**+泄露**补救告知报告**（第1038条）
7. 单位收集员工信息的边界=**与劳动合同直接相关**（劳动合同法8条）+**必要**（民法典1035条）
