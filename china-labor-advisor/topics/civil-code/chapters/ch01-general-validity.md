# Chapter 1: 总则——民事法律行为效力与撤销（劳动者视角重点条文）

## Core Idea
民法典总则（第3–200条）为一切"协议/声明"的效力判断提供底层规则。**劳动者高频场景**：离职协议的撤销（欺诈/胁迫/显失公平/重大误解）、虚假意思表示无效、违反强制性规定无效、撤销权的一年/九十日/五年期间、无效后的返还与赔偿（第157条）、**履行职务行为的效力归属**（第170条：员工签字=公司行为）、**表见代理**（第172条：离职员工持公章签合同公司可能仍要认）。

## Frameworks Introduced
- **有效要件三要素（第一百四十三条）**：
  1. 行为人具有相应的民事行为能力
  2. **意思表示真实**
  3. **不违反法律、行政法规的强制性规定**，不违背公序良俗
  - When to use: 任何"这份协议有没有效"的总审查框架——离职协议、保密协议、竞业限制协议、放弃社保声明都套这三问
- **虚假意思表示（第一百四十六条）**：
  - 行为人与相对人以**虚假的意思表示**实施的民事法律行为**无效**
  - 以虚假的意思表示**隐藏**的民事法律行为，效力依有关法律规定处理
  - When to use: "假辞职真解除"（单位要求员工写辞职信实际是单位裁掉）——表面行为（辞职）无效，按实际法律关系（单位解除）处理
- **可撤销四事由（第一百四十七至一百五十条）**——离职协议"翻盘"的实体法根基：
  - **重大误解**（第147条）：基于重大误解实施
  - **欺诈**（第148、149条）：一方欺诈；第三人欺诈+对方知道或应当知道
  - **胁迫**（第150条）：一方或第三人胁迫
  - **显失公平**（第151条）：利用对方**危困状态、缺乏判断能力**，致使成立时**显失公平**
  - 撤销权人→请求**人民法院或仲裁机构**撤销（注意：不是单方通知）
  - When to use: 与劳动争议司法解释一第35条联动——离职协议"显失公平/重大误解"可撤销的**请求权基础**就是第151、147条
- **撤销权消灭期间（第一百五十二条）**——硬倒计时：
  - 一般事由：**知道或应当知道撤销事由之日起1年**内不行使→消灭
  - **重大误解：90日**
  - 胁迫：**胁迫行为终止之日起1年**
  - 知道后明示或行为表明放弃→消灭
  - 兜底：行为**发生之日起5年**内不行使→消灭
  - When to use: 签了不利离职协议发现后要**快**——1年（重大误解90日）除斥期间，**不适用中止中断**
- **无效事由（第一百五十三、一百五十四条）**：
  - 违反法律、行政法规**强制性规定**→无效（但该强制性规定**不导致无效**的除外——效力性 vs 管理性强制规定区分）
  - 违背**公序良俗**→无效
  - **恶意串通**损害他人合法权益→无效
  - When to use: "自愿放弃社保"约定的无效基础（违反社保法强制规定，解释二第19条直接确认）；"放弃一切权利"条款排除劳动者主要权利→可结合第506条/格式条款规则主张无效
- **无效/被撤销的后果（第一百五十五、一百五十七条）**：
  - **自始没有法律约束力**（第155条）
  - 部分无效不影响其他部分（第156条）
  - 后果（第157条）：**返还**财产；不能/不必返还的**折价补偿**；**有过错方赔偿**损失；双方都有过错各自承担相应责任
  - When to use: 离职协议被撤销后——已付的补偿/工资处理、损失赔偿按过错分担
- **职务行为（第一百七十条）**——"员工签字算公司的吗"：
  - 执行法人或者非法人组织**工作任务**的人员，就其**职权范围内**的事项，以法人名义实施的民事法律行为，**对法人发生效力**
  - 法人对职权范围的**限制，不得对抗善意相对人**
  - When to use: 劳动者与**部门负责人/HR**签的协议、收到的解除通知——即使其"权限"有内部限制，对善意劳动者仍有效；反过来劳动者对外签约也代表公司
- **无权代理与表见代理（第一百七十一、一百七十二、五百零三条、五百零四条条）**：
  - 无权代理未经追认→对被代理人不发生效力；善意相对人可请求行为人履行或赔偿（第171条）
  - **表见代理**：相对人**有理由相信**行为人有代理权→**代理行为有效**（第172条）
  - 被代理人**已经开始履行或接受履行**→视为追认（第503条）
  - 法定代表人**超越权限**签约，相对人不知情的→有效（第504条）
  - When to use: **已离职员工**持公章/空白合同签约、**被辞退的HR**以公司名义结算——公司"内部已撤销其权限"不能对抗善意劳动者；反过来劳动者也要盯住"签字人是谁"
- **民事责任方式（第一百七十九条）**：停止侵害、排除妨碍、消除危险、返还财产、恢复原状、修理重作更换、**继续履行**、**赔偿损失**、**支付违约金**、消除影响恢复名誉、**赔礼道歉**；惩罚性赔偿依法规定；可单独或合并适用
- **责任竞合（第一百八十六条）**：一方**违约**行为损害对方**人身/财产权益**→受损害方**选择**违约之诉或侵权之诉
  - When to use: 工伤场景（单位违约未缴社保致损失 vs 侵权）的诉由选择
- **民事责任优先（第一百八十七条）**：同一行为承担民事+行政+刑事责任的，承担行政/刑事责任**不影响**民事责任；**财产不足时优先用于承担民事责任**
  - When to use: 单位欠薪又涉刑（如拒不支付劳动报酬罪）——民事债权优先受偿
- **不可抗力（第一百八十条）**：不能预见、不能避免且不能克服的客观情况→不承担民事责任（法律另有规定除外）
- **紧急救助免责（第一百八十四条）**：自愿实施紧急救助造成受助人损害→救助人**不承担**民事责任（"好人法"条款）

## Key Concepts
- **有效三要素**：行为能力+意思真实+合法合规（第143条）
- **可撤销四事由**：重大误解/欺诈/胁迫/显失公平（第147–151条）
- **除斥期间**：1年/90日（重大误解）/胁迫终止起1年/5年兜底（第152条）
- **自始无效**：无效或被撤销→自始无约束力（第155条）
- **职务行为**：员工职权内行为=公司行为；内部限制不抗善意相对人（第170条）
- **表见代理**：有理由相信有代理权→有效（第172条）
- **责任竞合**：违约损人身财产→二选一（第186条）
- **民事优先**：财产不足先赔民事（第187条）

## Mental Models
- "协议效力审查三问"（第143条）：签的人有行为能力吗？意思真实吗（被坑了吗）？内容合法吗（碰强制规定了吗）——三问任一不过=无效或可撤销
- "翻盘倒计时"（第152条）：发现被骗/被胁迫/签亏了→**90日（重大误解）或1年**内起诉/申请仲裁撤销——这是**除斥期间**，不中止不中断，过了就锁死
- "签字人决定归属"（第170、172条）：劳动者拿到的每一份文件，先问"签字的人以谁的名义签的、有没有理由相信他有权"——部门经理签的解除通知、离职员工盖的章，都可能锁死公司
- "双轨诉由"（第186条）：同一事实既能告违约又能告侵权→选**举证更顺、赔偿更全**的通道（如精神损害赔偿只在侵权之诉中支持）

## Anti-patterns
- **签完才发现不对但"等等看"**: 第152条除斥期间不等人——重大误解只有**90日**
- **以为撤销是"单方通知"**: 撤销权必须经**法院或仲裁机构**行使（第147–151条）——自己发函"我撤销协议"不发生撤销效力
- **公司内部"授权有限"挡劳动者**: 第170条——内部限制**不得对抗善意相对人**；劳动者只要不知道也不应知道越权，行为有效
- **把"管理性强制规定"当无效**: 第153条但书——只有**效力性**强制规定才导致无效（如放弃社保=效力性→无效；某些备案程序=管理性→不当然无效）——个案要具体判断
- **违约+侵权都告**: 第186条是**选择**——不能两个都要；选定前比较：精神损害（侵权独有）、举证责任、赔偿范围

## Worked Example
小郑被公司逼签"自愿辞职+放弃全部补偿"协议（实际是公司裁员，HR以"不签就记入档案"施压）。处理：
1. **定性**：辞职声明=受**胁迫**（第150条）+**虚假意思表示**（第146条，双方明知是裁员却写成辞职）→ 可撤销/无效
2. **撤销路径**：向仲裁/法院请求撤销——**1年**内（知道胁迫事由起，胁迫终止起算）
3. **撤销后果**（第155、157条）：辞职声明**自始无效**→按**单位解除**处理→经济补偿/赔偿金重新计算；已收款项按过错返还
4. **签字人效力**：即使签字的HR"无权代表公司做这个决定"→第170条**职务行为**对公司有效（劳动者善意）——但协议内容违法可独立击穿
5. **诉由选择**：如协商不成——按劳动争议仲裁（解除性质+补偿）为主；若涉及人身权益受损（如搜身、限制自由）→第1011条侵权并行（第186条竞合选择）

## Key Takeaways
1. 有效三要素：行为能力+意思真实+不违法不背俗（第143条）
2. 可撤销：重大误解/欺诈/胁迫/显失公平（第147–151条）——经**法院/仲裁**行使
3. 除斥期间：1年（重大误解**90日**、胁迫自终止起1年）+5年兜底（第152条）
4. 违反**效力性**强制规定/公序良俗/恶意串通→无效（第153、154条）
5. 无效/被撤销→自始无效+返还+过错赔偿（第155–157条）
6. 职务行为=公司行为，内部限制不抗善意相对人（第170条）；表见代理有效（第172条）
7. 违约损人身财产→违约/侵权**二选一**（第186条）；财产不足**民事优先**（第187条）
