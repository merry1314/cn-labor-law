# 速查表（Cheatsheet）— 就业促进法

## 基本信息
- **通过**：2007-08-30 | **修正**：2015-04-24 | **条文**：9章69条

## 六类禁止歧视

| 类型 | 条文 | 核心规则 |
|---|---|---|
| 性别 | 第27条 | 不得拒绝录用/提高标准；合同不得限制结婚生育 |
| 民族 | 第28条 | 对少数民族适当照顾 |
| 残疾 | 第29条 | 不得歧视；按比例安置≥1.5%※ |
| 传染病病原携带 | 第30条 | 不得以此拒录（乙肝携带者典型） |
| 农村劳动者 | 第31条 | 进城就业平等权利，不得设限 |
| 宗教/种族 | 第3条 | 不得因宗教信仰等受歧视 |

## 维权流程卡

```
遭遇就业歧视
    │
    ├─ 行政投诉 → 劳动行政部门（第60条）
    │
    └─ 直接起诉 → 人民法院（第62条，无需仲裁前置）
         ├─ 法律依据：就业促进法第62条
         ├─ 案由：人格权侵权
         └─ 可主张：停止侵害+赔礼道歉+损失+精神损害赔偿
```

## 高频数字卡

| 数字 | 含义 | 条文 |
|---|---|---|
| 1.5%※ | 残疾人按比例就业最低比例 | 第55条 |
| 25% | 集中使用残疾人单位中残疾人职工比例 | 第55条 |
| 1千–1万 | 职业中介违法罚款 | 第64、65条 |
| 1万–5万 | 无证从事职业中介罚款 | 第64条 |
| 500–2000 | 扣证件/收押金每人罚款 | 第66条 |

## 公共就业服务免费清单（第35条）
- ✅ 就业政策法规咨询
- ✅ 职业供求信息发布
- ✅ 职业指导和职业介绍
- ✅ 就业援助
- ✅ 就业登记/失业登记
- ❌ 不得向劳动者收费

## 高频误判卡

| 误判 | 正解 |
|---|---|
| 就业歧视要先仲裁 | ❌ 第62条可直接起诉，无需仲裁前置 |
| 中介可以收"介绍费" | ❌ 不得向劳动者收押金/扣证件 |
| 乙肝携带者不能就业 | ❌ 第30条保护，除特定行业外不得拒录 |
| 单位安排培训就能约定服务期 | ❌ 只有"专项培训费用"才能约定 |
| 公共就业服务可以收费 | ❌ 第37条，公共就业服务免费 |
