# 术语表（Glossary）— 就业促进法

| 术语 | 条文 | 含义 |
|---|---|---|
| 平等就业权 | 第3条 | 劳动者不分民族、种族、性别、宗教信仰，享有平等就业的权利 |
| 自主择业权 | 第3条 | 劳动者根据自身意愿选择职业的权利 |
| 就业歧视 | 第26条 | 用人单位/中介基于与岗位无关的个人特征给予差别对待 |
| 公共就业服务 | 第35条 | 政府公共就业服务机构向劳动者提供的免费就业服务 |
| 职业中介机构 | 第39条 | 依法设立、经许可从事职业中介活动的经营性机构 |
| 就业困难人员 | 第52条 | 因身体、技能、家庭、失地等原因难以就业的人员（具体范围省级规定※） |
| 公益性岗位 | 第53条 | 政府投资开发、安置就业困难人员的非营利性岗位，给予岗位补贴 |
| 零就业家庭 | 第56条 | 法定劳动年龄内家庭成员均失业的城市居民家庭 |
| 职工教育经费 | 第47条 | 企业按规定提取用于职工培训的专项费用 |
| 职业资格证书 | 第51条 | 特殊工种劳动者上岗须持有的资格证书 |
