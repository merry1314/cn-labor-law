# Chapter 4: 监督检查与法律责任（第60–69条）

## Core Idea

就业促进法的法律责任核心是**就业歧视可直接起诉**（第62条），以及对职业中介违法行为的行政处罚。本章是劳动者维权的程序依据。

## Frameworks

### 框架1：就业歧视维权双通道

```
就业歧视发生
    │
    ├─ 途径A：行政投诉（第60条）
    │    → 向劳动行政部门投诉举报
    │    → 行政部门调查处理
    │
    └─ 途径B：直接起诉（第62条）★重点
         → 直接向人民法院提起诉讼（无需仲裁前置）
         → 案由：人格权侵权纠纷
         → 可主张：停止侵害、赔礼道歉、赔偿损失、精神损害赔偿
         → 法律依据：就业促进法第62条 + 民法典第109/990/1183条
```

### 框架2：职业中介违法处罚

| 违法行为 | 处罚 | 条文 |
|---|---|---|
| 未经许可从事职业中介 | 责令停止+没收违法所得+1万–5万罚款 | 第64条 |
| 提供虚假信息/介绍未满16周岁 | 责令改正+1千–1万罚款+没收违法所得；情节严重吊销许可证 | 第65条 |
| 扣押证件/收取押金 | 责令退还+扣押证件每人500–2000元罚款；收押金每人500–2000元罚款 | 第66条 |
| 公共就业服务机构收费 | 责令退还+对责任人处分 | 第63条 |

## Key Concepts

- **就业歧视直接起诉权**（第62条）：劳动者认为遭受就业歧视的，可以**直接向人民法院提起诉讼**，无需经过劳动仲裁前置程序
- **人格权侵权之诉**：就业歧视同时侵害劳动者的一般人格权（民法典第109、990条），可主张精神损害赔偿
- **举证责任**：劳动者初步举证存在差别对待，用人单位举证证明用工决定的合法性合理性

## Mental Models

**"仲裁非必经"思维**：与一般劳动争议不同，就业歧视案件**无需仲裁前置**，可直接起诉。这是就业促进法第62条的特殊规定。

**"行政+司法"双救济思维**：行政投诉处理效率高但赔偿有限；司法诉讼可主张精神损害赔偿但周期较长。劳动者可选择或并用。

## Anti-patterns

- ❌ **认为就业歧视必须先仲裁** —— 第62条明确可直接起诉
- ❌ **认为歧视只能要经济损失** —— 可同时主张**精神损害赔偿**（民法典第1183条）
- ❌ **职业中介收押金/扣证件不追究** —— 第66条，每人数百元罚款+退还
- ⚠️ **注意**：精神损害赔偿需达到"严重"程度（民法典第1183条），需举证证明精神损害后果

## Worked Example

**场景**：小陈应聘某公司财务岗位，招聘简章写明"限男性"。小陈（女）投递简历被拒，认为遭受性别歧视。

**分析**：
1. 财务岗位不属于"国家规定的不适合妇女的工种或岗位"
2. 公司以性别为由拒绝录用，违反第27条
3. 小陈可以：
   - 向劳动行政部门投诉（第60条）
   - 直接向法院起诉（第62条），主张：
     - 就业歧视侵权（就业促进法第3、27、62条）
     - 一般人格权侵害（民法典第109、990条）
     - 精神损害赔偿（民法典第1183条）
4. 举证：招聘简章截图、投递记录、拒录通知
5. 公司抗辩：需证明财务岗位确实不适合女性（一般难以成立）

## Key Takeaways

- 就业歧视**可直接起诉**，无需仲裁前置（第62条）
- 可同时主张**精神损害赔偿**（民法典第1183条）
- 举证责任：劳动者初步举证→用人单位证明合法性
- 职业中介违法处罚力度：1千–5万元，情节严重吊销许可证
