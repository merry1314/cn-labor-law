# 操作模式（Patterns）— 就业促进法

## 1. 就业歧视维权三步法

**适用**：遭遇性别/乙肝/残疾/户籍等就业歧视时

**步骤**：

1. **固定证据**
   - 招聘简章/广告截图（限男性、体检要求等）
   - 投递记录、面试通知、拒录通知
   - 体检报告（如乙肝检测）
   - 与HR沟通的微信/邮件记录

2. **选择维权途径**
   - **行政投诉**（第60条）：向用人单位所在地劳动行政部门投诉，处理较快
   - **直接起诉**（第62条）：向法院起诉，可主张精神损害赔偿
   - 两者可并用：先投诉获取行政认定，再起诉索赔

3. **主张权利**
   - 停止侵害、赔礼道歉
   - 经济损失（交通费、体检费等）
   - **精神损害赔偿**（民法典第1183条，需证明严重精神损害）

**关键**：就业歧视**无需仲裁前置**，可直接起诉（第62条）。

## 2. 职业中介合规审查五问

**适用**：通过职业中介找工作时

1. 是否有《职业中介许可证》和营业执照？
2. 是否向你收取押金/扣押身份证？→ 违法（第41条）
3. 招聘信息是否真实？→ 虚假信息违法
4. 是否介绍未满16周岁就业？→ 违法
5. 是否有歧视性要求？→ 违法

**维权**：违法可向劳动行政部门投诉，处1千–1万元罚款；退还费用和证件。

## 3. 就业援助申请流程

**适用**：就业困难人员、零就业家庭

1. 到户籍所在地/居住地公共就业服务机构进行失业登记
2. 申请认定为就业困难人员（需符合当地认定条件※）
3. 申请公益性岗位或职业培训
4. 如自谋职业，申请税收优惠/收费减免/小额担保贷款

**材料**：身份证、户口本、失业登记证明、困难证明等（各地要求不同※）

## 4. 职业培训与服务期判断

**适用**：单位要求签订培训服务期协议时

| 培训类型 | 能否约定服务期 | 依据 |
|---|---|---|
| 日常岗位培训/入职培训 | ❌ 不能 | 劳动合同法第22条"专项培训费用"不包括 |
| 专项技术培训（外部付费、有凭证） | ✅ 可以 | 劳动合同法第22条 |
| 职业资格考证培训 | 视情况 | 看是否单位支付专项费用 |

**判断标准**：是否使用了单位的**专项培训费用**（有支付凭证），培训内容是否超出日常岗位需要。
