# Chapter 4: 监督管理、法律责任与争议处理（第46–67条）

## Core Idea
收尾章三条线：**监管**（第46–53条：经办机构职责+服务协议+财政审计监督+举报+工会监督）、**法律责任**（第56–63条：挪用基金/行政人员/经办机构/机构骗取/鉴定造假/未参保/**拒不协助调查**的罚则）、**争议处理**（第54–55条：待遇争议走**劳动争议**程序；五类行为**可复议可诉讼**）。劳动者视角最关键的是**第62条**（未参保=单位全额自付+滞纳金+1–3倍罚款）、**第66条**（无照单位/吊销单位/童工=**一次性赔偿不低于工伤标准**）与**第55条**（工伤认定结论可诉）。

## Frameworks Introduced

### 监督管理（第46–53条）
- **经办机构职责（第46条）**：①征收工伤费（省级规定）②核查工资总额与职工人数、办理登记、保存缴费与待遇记录 ③调查统计 ④管理基金支出 ⑤**核定**待遇 ⑥为工伤职工或近亲属**免费提供咨询服务**
- **服务协议（第四十七、四十八条）**：经办机构与**医疗机构、辅助器具配置机构**平等协商签**服务协议**+**公布**名单；按协议和目录标准**核查**费用使用并**按时足额结算**
- **信息公开与意见听取（第四十九、五十条）**：定期公布基金收支+提费率调整建议；定期听取**工伤职工、医疗机构、辅助器具机构及社会各界**意见
- **监督检查（第51条）**：社保行政部门监督**征缴+基金支付**；**财政部门、审计机关**监督基金**收支管理**
- **举报（第52条）**：任何组织和个人对工伤保险违法行为有权**举报**；社保行政部门**及时调查、按规定处理、为举报人保密**
  - When to use: 单位未参保/低报基数/拖延救治——**举报**是低成本施压通道（12333/社保行政部门）；保密条款保护举报人
- **工会监督（第53条）**：工会依法维护工伤职工合法权益，对单位工伤保险工作**实行监督**

### 法律责任（第56–63条）
- **挪用基金（第56条）**：单位或个人违反第12条**挪用**工伤保险基金→**构成犯罪**追究刑事责任；不构成→**处分或纪律处分**；被挪用基金由社保行政部门**追回并入基金**；违法所得**没收上缴国库**
- **社保行政部门工作人员（第57条）**：①无正当理由**不受理**申请或**弄虚作假**认定工伤 ②**未妥善保管**证据材料致灭失 ③**收受**当事人财物→**处分**；情节严重构成犯罪→刑事责任
  - When to use: 申请被"不受理"且无正当理由→本条是追责依据+第55条一（不予受理决定可复议可诉讼）
- **经办机构（第58条）**：①未按规定保存缴费/待遇记录 ②不按规定**核定待遇** ③收受财物→责令改正+**纪律处分**；构成犯罪→刑责；造成**经济损失**→**赔偿**
- **医疗机构/辅助器具机构（第59条）**：不按协议提供服务→经办机构可**解除服务协议**；经办机构**不按时足额结算**→社保行政部门责令改正；机构可解除协议
- **骗取待遇（第60条）**：用人单位、工伤职工或近亲属**骗取**工伤保险待遇；医疗机构、辅助器具机构**骗取**基金支出→责令**退还**+处**骗取金额2倍以上5倍以下罚款**；情节严重构成犯罪→**刑事责任**（诈骗类犯罪※）
  - 红线：伪造病历/重复报销/虚构工伤——**2–5倍罚款+刑事风险**
- **鉴定造假（第61条）**：从事劳动能力鉴定的组织或个人：①虚假**鉴定意见** ②虚假**诊断证明** ③收受财物→责令改正+**2000元以上1万元以下罚款**；构成犯罪→刑责
- **未参保（第62条）**——单位侧最重罚则：
  - 应参加未参加→责令**限期参加**+**补缴**+自欠缴之日起按日加收**万分之五滞纳金**；逾期仍不缴纳→处**欠缴数额1倍以上3倍以下罚款**
  - **未参保单位职工发生工伤**→由**该用人单位按照本条例规定的工伤保险待遇项目和标准支付费用**（=基金+单位本应分担的**全部**）
  - **补缴后**→**新发生**的费用回到基金+单位分担
  - When to use: 未参保=单位**裸奔**——劳动者待遇**不打折**，付款人变单位；谈判/诉讼时先查**参保状态**决定执行对象
- **拒不协助调查（第63条）**：单位违反第19条**拒不协助**社保行政部门调查核实→责令改正+**2000元以上2万元以下罚款**

### 争议处理（第54–55条）
- **待遇争议=劳动争议（第54条）**：职工与用人单位发生**工伤待遇方面**的争议→按**处理劳动争议**的有关规定处理（仲裁前置→诉讼；时效1年，调解仲裁法27条）
  - 边界：**待遇标准/项目/金额**争议（单位少付两金、停工留薪工资）=劳动争议；**认定结论**争议=**行政**争议（第55条）；**基金支付**争议（经办机构核定）=**行政**争议（第55条五）
- **可复议可诉讼五情形（第55条）**——行政救济入口：
  1. 对工伤认定申请**不予受理**决定不服
  2. 对**工伤认定结论**不服
  3. 单位对经办机构确定的**缴费费率**不服
  4. 签订服务协议的**医疗机构、辅助器具机构**认为经办机构未履行协议或规定
  5. 工伤职工或近亲属对经办机构**核定的工伤保险待遇**有异议
  - When to use: **复议与诉讼可任选**（复议前置？——本条表述"可以依法申请行政复议，也可以依法向人民法院提起行政诉讼"=**选择型**，不强制复议前置※按行政诉讼法一般规则）；起诉对象=**社保行政部门**（认定）或**经办机构/其主管部门**（核定待遇）

### 附则（第56–67条余款）
- **工资总额与本人工资（第64条）**：工资总额=单位直接支付给全部职工的劳动报酬总额；**本人工资**=伤前12个月平均月**缴费**工资，**60%–300%**夹逼（Ch 3 已展开——待遇计算基数）
- **公务员（第65条）**：公务员和参公事业单位、社团工作人员因工受伤或患职业病→由**所在单位支付费用**（办法由国务院社保行政部门会同财政部门规定）——**不纳入**工伤保险基金
- **无照/吊销单位与童工（第66条）**——兜底条款：
  - **无营业执照**或未经依法登记、备案的单位+被依法**吊销营业执照**或撤销登记、备案的单位的职工→受事故伤害或患职业病→由**该单位**向伤残职工或死亡职工近亲属给予**一次性赔偿**，**赔偿标准不得低于**本条例规定的工伤保险待遇
  - **童工**：单位**不得使用童工**；使用童工造成童工**伤残、死亡**的→由该单位向童工或其近亲属给予**一次性赔偿**，**标准不得低于**工伤保险待遇
  - 赔偿**数额争议**→按**劳动争议**处理
  - When to use: 与劳动争议解释一第29条（无照/吊销→**单位或出资人**为当事人）联动——"皮包单位"背后的**出资人**是执行对象；童工场景=**一次性赔偿**（不建立劳动关系认定问题，赔偿**不得低于**工伤标准）
- **施行（第67条）**：本条例自**2004年1月1日**起施行；施行前已受伤患职业病**尚未完成工伤认定**的→按本条例执行（2010修订决定：决定施行前受伤**尚未完成认定**的→按修订后执行——**从新从宽**）

## Key Concepts
- **经办机构**：征收/登记/核查/核定/免费咨询（第46条）
- **服务协议**：定点医疗+辅助器具机构；不按时足额结算→机构可解除协议（第47、48、59条）
- **举报+保密**（第52条）/ **工会监督**（第53条）
- **挪用基金**：追回+没收+刑责（第56条）
- **骗取待遇**：退还+**2–5倍罚款**+刑责（第60条）
- **未参保三罚**：限期参加+补缴+**日万分之五滞纳金**+逾期**1–3倍罚款**；**工伤=单位全额自付**；补缴后**新发生**费用回基金（第62条）
- **拒不协助调查**：2000–2万罚款（第63条）
- **待遇争议=劳动争议**（第54条）；**五类行政行为可复议可诉讼**（第55条）
- **无照/吊销/童工**：一次性赔偿**不得低于**工伤标准（第66条）
- **2004-01-01施行**；未完成认定的**从新**（第67条+修订决定）

## Mental Models
- "争议三分流"模型（第54、55条+劳动争议法）：
  ```
  ① 工伤【认定结论】不服 → 行政：复议 或 诉讼（被告=社保行政部门，55条二）
  ② 工伤【待遇金额】争议（单位少付）→ 劳动争议：仲裁→诉讼（54条，时效1年）
  ③ 经办机构【核定待遇】异议 → 行政：复议 或 诉讼（55条五）
  ④ 劳动能力【鉴定结论】不服 → 15日内省级再鉴定 = 最终（第26条，不可诉）
  ```
  同一个工伤案件里**四条路**可能并行——先定**卡在哪一环**再选通道
- "未参保=单位全额+三罚"模型（第62条）：未参保不改变**待遇标准**，只改变**付款人**（基金→单位）；同时叠加**行政三罚**（限期+滞纳金+1–3倍罚款）——劳动者的筹码：**投诉触发行政程序**+**仲裁主张待遇**双轨
- "皮包穿透"模型（第66条+解释一29条）：无照/吊销/撤销登记→**单位**一次性赔偿（不低于工伤标准）→执行不能时→**出资人**（解释一29条当事人规则）——找**出资人**是执行落地的关键
- "举报杠杆"模型（第52、62条）：举报→社保行政部门**调查**→单位面临**限期+罚款**——行政压力常比仲裁更快推动单位**补缴+结算**（谈判筹码）
- "红线双罚"模型（第60、56条）：骗取待遇=**退+罚（2–5倍）+刑**；挪用基金=**追+没收+刑**——工伤待遇的**钱袋子**双向保护（防单位挪用+防个人骗取）

## Anti-patterns
- **认定结论不服去仲裁**: 第55条二——**认定**是行政行为→**复议/诉讼**，不是劳动仲裁（仲裁管**待遇**争议，第54条）——通道错=白跑
- **鉴定结论不服起诉**: 第26条——省级鉴定**最终**，**不可诉**；唯一通道=**15日内**申请省级再鉴定——**逾期=锁死**（复查鉴定要**1年后**且以"情况变化"为前提）
- **待遇争议去告社保局**: 单位少付两金/停工留薪工资=**劳动争议**（第54条）——告**单位**走仲裁；只有**经办机构核定**问题才走行政（第55条五）
- **未参保就"自认倒霉"**: 第62条二——单位**全额自付**，标准**不打折**——先**投诉**（触发行政程序）+**仲裁**（主张待遇）双线；单位**补缴**只影响**新发生**费用（第62条三），**已发生**的仍是单位付
- **童工案件"没劳动关系就不赔"**: 第66条——童工**一次性赔偿不得低于工伤标准**——童工不认定工伤（**不得**使用童工），但**赔偿标准**锚定工伤待遇；数额争议走**劳动争议**程序
- **举报不谨慎**: 第52条保护**举报人**——但**捏造**事实的举报可能承担相应责任（治安管理/诽谤）——**有据再举报**
- **骗取待遇的"小聪明"**: 第60条——**2–5倍罚款+刑事**——伪造材料骗保是**红线中的红线**

## Worked Example
小吴（物流公司装卸工）腰伤被认定工伤（九级），单位**从未参保**。单位只愿"私了2万"。处理：
1. **查参保**：社保行政部门查询/12333——确认**未参保**→全部待遇**单位自付**（第62条二）
2. **算法定账**（假设本人工资7000/月，省级标准九级=医疗补助金3个月+就业补助金6个月※示例）：
   - 一次性伤残补助金=9×7000=**63000**（本应基金→现**单位**）
   - 两金（合同期满终止或本人提出解除时）：医疗补助3×7000=**21000**+就业补助6×7000=**42000**→**单位**付**全部**
   - 停工留薪期工资（假设3个月）：3×7000=**21000**（单位）
   - 医疗费：三目录内部分本应基金→**单位**
   - 合计（不含医疗费）≈**14.7万**——"2万私了"=**显失公平**（对比法定≈14.7万+医疗费）→协议可撤销（解释一35条+民法典151条）
3. **双线施压**：
   - **行政**：向社保行政部门**投诉**未参保→责令限期参加+补缴+**日万分之五滞纳金**+逾期**1–3倍罚款**（第62条一）
   - **仲裁**：主张**全部待遇**（第54条走劳动争议程序）——执行对象=**单位**
4. **拒赔升级**：单位拒不支付且**拒不协助调查**→第63条**2000–2万罚款**；单位转移资产→撤销权（民法典538、539条）+**执行**
5. **若单位是无照/吊销的"黑公司"**: 第66条——**单位**一次性赔偿**不低于工伤标准**；执行不能→**出资人**（解释一29条）——告**出资人**

## Key Takeaways
1. 经办机构六职责+**免费咨询**（第46条）；服务协议+**按时足额结算**（第47、48条）
2. **举报**通道+**保密**（第52条）；**工会监督**（第53条）
3. **挪用基金**=追回+没收+刑责（第56条）；**骗取待遇**=退还+**2–5倍罚款**+刑责（第60条）
4. **未参保三罚**（第62条）：限期+补缴+**日万分之五滞纳金**+逾期**1–3倍罚款**；**工伤=单位全额自付**；补缴后**新发生**费用回基金
5. **拒不协助调查**=2000–2万罚款（第63条）
6. **争议三分流**：认定结论→**行政**（55条）；待遇金额→**劳动争议**（54条）；经办机构核定→**行政**（55条五）；鉴定结论→**省级最终**（26条）
7. **无照/吊销/童工**：一次性赔偿**不低于工伤标准**（第66条）+数额争议走劳动争议
8. **2004-01-01施行**；未完成工伤认定的**从新执行**（第67条）
9. 公务员工伤=**单位支付**（第65条）
