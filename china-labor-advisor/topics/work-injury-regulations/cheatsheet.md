# Cheatsheet — 工伤保险条例（2010修订）速查

## 版本信息

| 项 | 内容 |
|---|---|
| 全称 | 工伤保险条例 |
| 公布 | 2003-04-27 国务院令第375号 |
| 修订 | 2010-12-20 国务院令第586号修改，**2011-01-01**施行 |
| 施行 | **2004-01-01**起（第67条） |
| 条文 | 8章67条 |
| 定位 | 社保法（第33–41条母法）的**实施细则**——待遇标准以本条例为准 |
| 特殊 | **唯一单位全额缴费**（个人不缴，第10条） |

## 工伤认定速查（14–16条）

| 情形 | 定性 | 条文 |
|---|---|---|
| 工作时间+场所+工作原因受伤 | **认定** | 14条一 |
| 岗前岗后预备/收尾工作受伤 | **认定** | 14条二 |
| 履职受暴力等意外 | **认定** | 14条三 |
| 患职业病（目录内） | **认定** | 14条四 |
| 因工外出受伤害/下落不明 | **认定** | 14条五 |
| 上下班途中交通事故（合理时间+路线+**非本人主责**） | **认定** | 14条六 |
| 岗位突发疾病**死亡/48h内抢救无效死亡** | **视同** | 15条一 |
| 抢险救灾等公益活动受伤 | **视同** | 15条二 |
| 军残旧伤复发 | **视同**（除一次性伤残补助外） | 15条三 |
| **故意犯罪**（非过失） | **排除** | 16条一 |
| 醉酒/吸毒 | **排除** | 16条二 |
| 自残/自杀 | **排除** | 16条三 |

## 程序时限卡

| 事项 | 时限 | 条文 |
|---|---|---|
| **单位**申请工伤认定 | 事故/诊断之日起**30日** | 17条 |
| **劳动者/近亲属/工会**申请 | **1年**（单位不申请时） | 17条 |
| 单位超期→期间费用 | **单位负担** | 17条四 |
| 社保部门作出认定决定 | 受理起**60日**（简单15日） | 20条 |
| 司法结论依赖期间 | 认定时限**中止** | 20条 |
| 市级鉴定结论 | 申请起**60日**（+延长30日） | 25条 |
| **再次鉴定**申请 | 收到结论起**15日**→省级=**最终** | 26条 |
| **复查鉴定** | 结论起**1年后**（情况变化） | 28条 |
| 停工留薪期 | 一般≤**12月**+延长≤**12月** | 33条 |
| 下落不明照发工资 | 事故当月起**3个月** | 41条 |

## 伤残待遇梯度表（35–37条）

| 等级 | 一次性伤残补助金 | 后续待遇 | 两金触发 |
|---|---|---|---|
| 1级 | **27个月**本人工资（基金） | 保留关系退出岗位；津贴**90%**/月（基金，低于最低工资补足）；退休转养老金+补足差额；津贴基数缴医保 | 不适用（不解除） |
| 2级 | **25个月**（基金） | 津贴**85%**/月（基金） | 同上 |
| 3级 | **23个月**（基金） | 津贴**80%**/月（基金） | 同上 |
| 4级 | **21个月**（基金） | 津贴**75%**/月（基金） | 同上 |
| 5级 | **18个月**（基金） | 保留关系；单位**安排工作**；难安排→津贴**70%**/月（**单位**）+补最低工资+缴社保 | **本人提出**解除→基金医疗补助+**单位**就业补助 |
| 6级 | **16个月**（基金） | 津贴**60%**/月（难安排时，单位） | **本人提出**解除→两金 |
| 7级 | **13个月**（基金） | 保留关系（期内不得解除） | **期满终止或本人解除**→两金 |
| 8级 | **11个月**（基金） | 同上 | **期满终止或本人解除**→两金 |
| 9级 | **9个月**（基金） | 同上 | **期满终止或本人解除**→两金 |
| 10级 | **7个月**（基金） | 同上 | **期满终止或本人解除**→两金 |

- **两金标准**：一次性工伤**医疗**补助金（基金）+一次性伤残**就业**补助金（单位）——**各省标准**（必须查本地）
- **本人工资**=伤前12月平均月**缴费**工资，**60%–300%**夹逼（64条）
- **停工留薪期**：原工资福利**单位**付（33条）；期内护理**单位**负责
- **生活护理费**（评残后，基金）：完全不能自理**50%**/大部分**40%**/部分**30%**×统筹地区上年度职工月均工资（34条）

## 工亡三费（39条，基金/单位付）

| 项目 | 标准 |
|---|---|
| 丧葬补助金 | **6个月**×统筹地区上年度职工月平均工资 |
| 供养亲属抚恤金（按月） | 配偶**40%**/其他亲属每人**30%**/孤寡老人或孤儿**+10%**（×本人工资）；**合计≤**生前工资 |
| 一次性工亡补助金 | **上一年度全国城镇居民人均可支配收入×20倍**（全国统一。适用年度标准：2024年度=1,036,420元≈103.64万；2025年度=1,083,760元≈108.376万；2026年度=1,130,040元≈113.004万，已确定，2026全年适用）※**数据基准日 2026-09-27，每年以国家统计局公布的上年度城镇居民人均可支配收入为准，更新见 ../../../DYNAMIC-DATA.md** |
| 停工留薪期内因工伤死亡 | 享受**全部三费** |
| 1–4级伤残期满死亡 | 仅丧葬+抚恤金（**无**一次性工亡） |
| 下落不明 | 3个月工资→抚恤金；困难可**预支工亡50%**；宣告死亡=工亡（41条） |

## 停止待遇三情形（42条）
丧失享受条件 / **拒不接受劳动能力鉴定** / **拒绝治疗**

## 责任主体速查

| 情形 | 谁付 |
|---|---|
| 已参保 | **基金**+单位分担（按梯度表） |
| **未参保** | **单位全额**按法定标准（62条二）+滞纳金+1–3倍罚款（62条一）；补缴后**新发生**费用回基金（62条三） |
| 分立/合并/转让 | **承继单位**（43条） |
| 承包经营 | **劳动关系所在单位**（43条） |
| 借调 | **原用人单位**（内部补偿约定不影响对外，43条） |
| 破产 | 清算时**依法拨付**（43条） |
| 无照/吊销/撤销登记 | **单位**一次性赔偿**不低于**工伤标准（66条）→执行穿透**出资人**（解释一29条） |
| 童工致残死亡 | **单位**一次性赔偿**不低于**工伤标准（66条） |
| 公务员/参公 | **所在单位**支付（65条） |

## 争议分流卡

| 争议 | 通道 | 条文 |
|---|---|---|
| 认定**不予受理** | 复议或**诉讼** | 55条一 |
| **认定结论** | 复议或**诉讼**（被告=社保部门） | 55条二 |
| 缴费**费率** | 复议或诉讼（单位侧） | 55条三 |
| 协议机构**履行** | 复议或诉讼（机构侧） | 55条四 |
| 经办机构**核定待遇** | 复议或**诉讼** | 55条五 |
| 单位**少付待遇** | **劳动争议**：仲裁→诉讼（1年时效） | 54条 |
| **鉴定结论** | **15日内**省级再鉴定=**最终**（不可诉） | 26条 |
| 无照/童工**赔偿数额** | **劳动争议** | 66条二 |

## 罚则速查

| 行为 | 后果 |
|---|---|
| 挪用基金 | 追回+没收违法所得+**刑责**（56条） |
| 骗取待遇 | 退还+**2–5倍罚款**+刑责（60条） |
| 鉴定造假 | 2000–1万罚款+刑责（61条） |
| 未参保 | 限期+补缴+**日万分之五滞纳金**+逾期**1–3倍罚款**（62条） |
| 拒不协助调查 | 2000–2万罚款（63条） |
| 行政人员渎职 | 处分+刑责（57条） |
