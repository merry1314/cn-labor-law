# Chapter 12: 附则 (Supplementary Provisions, 第95–98条)

## Core Idea
附则处理三类特殊主体的参保：**进城务工农村居民**（依法参加，第95条）、**被征地农民**（征收集体土地时足额安排社保费、纳入相应制度，第96条）、**外国人**（境内就业**参照**参加，第97条）；施行日期2011年7月1日（第98条），2018年12月29日修正（主要调整：将"新型农村社会养老保险/城镇居民社会养老保险"相关表述与**城乡居民基本养老保险**制度衔接，并调整社保费征收主体表述等）。

## Frameworks Introduced
- **进城务工农村居民（第95条）**：
  - 进城务工的农村居民**依照本法规定参加社会保险**
  - 定位：与城镇职工同权的法律确认——农民工与城镇职工在五险参保上**无差别**，单位不得以"农村户口"为由不缴或低缴
  - When to use: 建筑行业、制造业等农民工集中行业——"同工同保"的法定依据
- **被征地农民（第96条）**：
  - 征收农村集体所有土地，应当**足额安排**被征地农民的社会保险费
  - 按照国务院规定将被征地农民**纳入相应的社会保险制度**
  - When to use: 征地补偿谈判中的社保权益——社保费必须"足额安排"在征地补偿安置方案中（※《土地管理法》第48条+国务院被征地农民社会保障配套规定）
- **外国人参保（第97条）**：
  - 外国人在中国境内就业的，**参照**本法规定参加社会保险
  - ※2011年人社部、外交部《在中国境内就业的外国人参加社会保险暂行办法》：持《外国人来华工作许可证》/《外国人永久居留身份证》就业的外国人应参加五险；与我国缔结/参加**社会保险双边协定**的国家（德国、韩国、芬兰、荷兰、瑞士等）人员按协定处理（部分险种可豁免）
- **施行与修正（第98条）**：
  - 自**2011年7月1日**起施行
  - **2018年12月29日**第十三届全国人大常委会第七次会议修正：主要涉及城乡居民养老保险制度衔接表述、社保费征收主体调整（配合税务征收改革）等
  - When to use: 引用版本——现行版本为**2018修正本**

## Key Concepts
- **进城务工农村居民同权参保**（第95条）
- **被征地农民社保足额安排**（第96条）
- **外国人参照参保**（第97条）
- **双边协定**：特定国家人员险种豁免（※暂行办法+协定）
- **2018修正**：现行有效版本

## Mental Models
- "无差别参保"模型：95条+97条共同确认——**户籍**（农村/城镇）与**国籍**都不构成不缴社保的理由；唯一合法的不缴情形是**非劳动关系**（劳务、承揽、实习等不构成劳动关系的，另按规定处理）
- 被征地农民的"社保优先"：征地补偿不是"给现金了事"——社保费足额安排+纳入制度是法定要求，缺项的补偿安置方案不完整

## Anti-patterns
- **以"农村户口"拒缴**: 单位对农民工不缴/低缴五险 → 违反第95条同权原则——投诉征收机构（第83条+63条）
- **外国人"不能参保"的误解**: 持工作许可就业的外国人**应**参保（参照本法）；双边协定国家人员按协定——HR应核对工作许可与协定适用
- **征地补偿漏掉社保**: 被征地农民只拿青苗补偿、无社保安排 → 违反第96条——可要求将社保费纳入补偿安置方案

## Worked Example
某建筑公司在某县承包项目，招用30名农村籍工人，其中12名"自愿签署放弃社保声明"，公司按月发500元"社保补贴"。处理：
1. **声明无效**：第95条进城务工农村居民**依法参加**——强制险不可约定放弃
2. **行政通道**：投诉 → 责令补缴+滞纳金（第86条）；若未办登记 → 第84条应缴1–3倍罚款+责任人罚款
3. **现金补贴不能替代**：500元/月补贴不产生参保记录，工伤生育待遇无法享受
4. **工伤风险敞口**：未缴工伤保险 → 发生工伤全部待遇由**单位支付**（第41条）——建筑行业工伤高发，这是单位最大风险
5. **劳动者选择**：被迫解除（劳动合同法38条三）+经济补偿N；或继续工作+主张待遇损失

## Key Takeaways
1. 进城务工农村居民与城镇职工**同权参保**（第95条）——户籍不是不缴的理由
2. 征收集体土地须**足额安排**被征地农民社保费并纳入制度（第96条）
3. 外国人境内就业**参照**参保（第97条）；双边协定国家按协定处理
4. 施行2011-07-01；2018-12-29修正——现行版本为2018修正本
