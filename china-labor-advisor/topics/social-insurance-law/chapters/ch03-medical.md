# Chapter 3: 基本医疗保险 (Basic Medical Insurance, 第23–32条)

## Core Idea
职工医保强制参保、单位+个人共同缴费；达到**规定缴费年限**后退休不再缴费、终身享受待遇；医保基金只付"目录内"费用（药、诊疗、设施）；**四类费用不纳入**（工伤、第三人责任、公共卫生、境外就医）；第三人不付时**基金先行支付后追偿**——劳动者不因第三人逃逸而自担医疗费。

## Frameworks Introduced
- **强制参保（第二十三条）**：
  - 职工**应当**参加职工基本医疗保险，单位+职工**共同缴纳**
  - 无雇工个体户、未参保非全日制、其他灵活就业人员**可以**参加（个人缴）
- **其他制度（第二十至二十五条）**：
  - 新型农村合作医疗（新农合）→ 后与城镇居民医保合并为**城乡居民基本医疗保险**
  - 待遇标准按国家规定执行
- **退休医保待遇（第二十七条）**：
  - 达到法定退休年龄时**累计缴费达到国家规定年限** → **退休后不再缴费**，按规定享受医保待遇
  - 未达年限 → **可以缴费至规定年限**
  - When to use: 退休前核查医保累计年限（各地规定年限不同，常见男25–30年/女20–25年，以当地口径为准）
- **基金支付范围（第二十八条）**：符合**药品目录、诊疗项目、医疗服务设施标准**以及**急诊、抢救**的医疗费用，从基金支付
  - "三个目录"是报销边界——目录外费用（进口药、特需服务）需自费
- **直接结算与异地就医（第二十九条）**：
  - 应基金支付部分由经办机构与医疗机构、药品经营单位**直接结算**（患者不再"先垫后报"，普通门诊住院已基本实现）
  - 国家建立**异地就医医疗费用结算制度**
  - When to use: 长期在外地居住的退休人员/流动就业人员——办理异地就医备案后可直接结算
- **四类不纳入 + 先行支付（第三十条）**：
  1. 应从**工伤保险基金**支付的
  2. 应由**第三人负担**的
  3. 应由**公共卫生**负担的
  4. **境外就医**
  - 关键规则：医疗费用依法应由第三人负担，**第三人不支付或无法确定**的 → 由**基本医疗保险基金先行支付**，基金支付后**有权向第三人追偿**
  - When to use: 交通事故等第三人致伤——第三人逃逸/无赔偿能力时，医保基金兜底，劳动者不必自掏腰包
- **服务协议与合理诊疗（第三十一条）**：经办机构与医疗机构/药店签服务协议规范行为；医疗机构应提供**合理、必要**的医疗服务
- **关系转移（第三十二条）**：跨统筹地区就业 → 医保关系**随本人转移**，**缴费年限累计计算**

## Key Concepts
- **职工基本医疗保险**：强制险，单位+个人共缴（第23条）
- **累计缴费年限**：退休后免缴的门槛（第27条，各地口径）
- **三个目录**：药品目录、诊疗项目、医疗服务设施标准（第28条）
- **先行支付**：第三人致伤时医保基金的兜底支付（第30条）
- **异地就医直接结算**：备案后跨省直接结算（第29条）

## Mental Models
- "目录内报销、目录外自费"模型：医保不是全额报销——先问费用是否落入三个目录+急诊抢救
- "基金先行支付"是劳动者保护条款：第三人致伤而第三人失联/无赔偿能力时，医保基金先付、再向第三人追偿——劳动者不用自己打官司垫钱
- 退休前"年限双查"：养老查15年、医保查当地累计年限——两个门槛独立，退休前一年都要核对
- 跨省流动同样适用"随人转移、累计计算"（第32条）

## Anti-patterns
- **工伤费用拿去走医保报销**: 工伤医疗费应由**工伤保险基金**支付（第30条一）——混用可能被追回，且影响工伤待遇完整性
- **第三人致伤时单位说"医保不报"**: 第三人不付/无法确定 → 医保基金**先行支付**（第30条）——单位不能以此推诿垫付义务之外的部分
- **断缴医保后看病**: 职工医保断缴次月一般即停待遇（各地细则）——流动就业空窗期注意衔接灵活就业参保
- **退休前不查医保年限**: 退休时医保年限不足 → 需一次性补缴或继续缴费（各地政策）——提前核对避免退休"裸奔"
- **异地就医不备案**: 未备案直接结算比例降低或无法直接结算——长居外地先办备案

## Worked Example
员工小冯被同事货车倒车撞伤（单位内第三人责任），肇事方拒不赔偿，单位未缴工伤保险。医疗费12万元（目录内10万元、目录外2万元）。处理：
1. **定性**：工作中受事故伤害 → 工伤（※《工伤保险条例》第14条）→ 医疗费应由**工伤保险基金**支付，不走医保（第30条一）
2. **未缴工伤保险** → 由**用人单位支付**全部工伤保险待遇（第41条）；单位不支付 → 基金先行支付后追偿
3. **目录外2万元**：属医保"不纳入"范围，工伤待遇中按规定由单位承担
4. 若该案被认定为**第三人侵权**（如外来交通事故）而非工伤：第三人不付 → 医保基金先行支付目录内部分（第30条二+先行支付条款）→ 基金再向第三人追偿
5. 劳动者双通道：工伤认定（人社部门）+ 向单位主张待遇/向第三人主张侵权赔偿（工伤与第三人侵权可主张的部分并行，※司法解释有具体规则）

## Key Takeaways
1. 职工医保强制参保，单位+个人共缴；退休达累计年限后免缴终身享待遇
2. 报销边界=三个目录+急诊抢救；目录外自费
3. 四类不纳入：工伤、第三人责任、公共卫生、境外就医
4. 第三人致伤而不付/无法确定 → **医保基金先行支付**后追偿（第30条）
5. 跨省就业医保关系随人转移、年限累计；异地就医备案后直接结算
6. 工伤医疗费与医保基金互斥——别混用

## Connects To
