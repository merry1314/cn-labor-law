# Chapter 1: 总则 (General Provisions, 第1–9条)

## Core Idea
社保法确立"五险"制度框架（养老、医疗、工伤、失业、生育），覆盖年老、疾病、工伤、失业、生育五情形；方针是"广覆盖、保基本、多层次、可持续"；用人单位和个人**依法缴费**是法定义务，同时赋予劳动者**查询权、监督权**（第4条）——这是劳动者维权最常被忽略的武器。

## Frameworks Introduced
- **五险与五情形（第2条）**：国家建立基本养老保险、基本医疗保险、工伤保险、失业保险、生育保险等社会保险制度，保障公民在**年老、疾病、工伤、失业、生育**等情况下依法从国家和社会获得物质帮助的权利
  - When to use: 一切社保争议的定性起点——先确认风险落入哪一情形
- **方针（第3条）**：广覆盖、保基本、多层次、可持续；社保水平与经济社会发展水平相适应
- **缴费义务 + 劳动者三权（第4条）**：
  - 用人单位和个人**依法缴纳**社会保险费
  - 劳动者有权：**查询缴费记录、个人权益记录**；要求经办机构提供**咨询**服务
  - 个人**依法享受待遇**；有权**监督本单位为其缴费情况**
  - When to use: 怀疑单位漏缴少缴时——先行使查询权固定证据（社保查询记录是仲裁/投诉的核心证据）
- **政府责任（第五、六条）**：社保事业纳入国民经济和社会发展规划；多渠道筹资+必要经费支持+税收优惠；基金**严格监管**
- **管理体制（第七、八条）**：
  - 国务院社保行政部门（人社部）负责全国社保管理；县级以上地方社保行政部门负责本区域
  - **社会保险经办机构**负责登记、个人权益记录、待遇支付
- **工会监督（第9条）**：工会有权参与社保重大事项研究、参加**社会保险监督委员会**、对职工社保权益相关事项进行监督

## Key Concepts
- **五险**：养老、医疗、工伤、失业、生育（第2条）
- **依法缴费**：强制义务，不可约定排除
- **查询权/监督权**：劳动者的程序性权利（第4条）
- **个人权益记录**：经办机构必须完整准确记录并定期免费寄送个人权益记录单（第74条）
- **监督委员会**：用人单位代表+参保人员代表+工会代表+专家组成（第80条）

## Mental Models
- "义务-权利对位"模型：单位缴费义务 ↔ 劳动者享受待遇权+查询权+监督权——维权第一步永远是**查询并保存缴费记录**
- 五险分工记忆：养老（老）、医疗（病）、工伤（伤）、失业（失业金+医保）、生育（医疗费+津贴）——每险只保对应情形，张冠李戴是常见误区（如工伤医疗费走工伤基金而非医保基金）
- 救济分层：经办争议→行政复议/行政诉讼（第83条）；单位侵害→**调解、仲裁、诉讼**+可要求社保行政部门/征收机构处理（第83条三款）

## Anti-patterns
- **"自愿放弃社保"约定**: 第4条"依法缴纳"是强制规定——放弃声明无效；发生工伤、生育、失业等情形时单位仍须承担本应由基金支付的费用
- **以"社保补贴"替代缴费**: 补贴不能替代参保；单位仍面临责令补缴+滞纳金（第86条）
- **忽视查询权**: 不查询缴费记录就离职，漏缴少缴难以追溯举证——在职期间定期（至少每年一次）查询并截图/打印留存
- **认为社保"退休才用得上"**: 工伤、生育、失业金都是即时待遇——断缴直接损失当期权利

## Worked Example
员工小吴入职3年，公司一直"以现金形式发放社保补贴"，从未实际参保。2025-08 小吴工作中受伤。处理：
1. **查询固定证据**（第4条）：登录社保经办机构/APP查询缴费记录——确认"无参保"事实并打印保存
2. **工伤待遇**（第41条）：单位未缴工伤保险费 → 发生工伤的**由用人单位支付工伤保险待遇**；单位不支付的，从工伤保险基金**先行支付**后向单位追偿
3. **行政通道**（第86条）：向社保费征收机构/社保行政部门投诉 → 责令限期补缴 + **自欠缴之日起按日加收万分之五滞纳金** + 逾期不缴处欠缴数额1–3倍罚款
4. **被迫解除选项**（※《劳动合同法》第38条三）：未依法缴纳社保 → 劳动者可解除并主张**经济补偿N**
5. 注意：补缴一般走行政通道（征收机构），仲裁委对"单纯要求补缴"通常不予受理——双轨并行：行政催缴 + 仲裁主张被迫解除补偿

## Key Takeaways
1. 五险对应五情形：养老（老）、医疗（病）、工伤（伤）、失业（失业）、生育（生育）
2. 依法缴费是强制义务，"放弃声明""现金补贴"均无效
3. 劳动者三权：查询缴费记录、要求咨询、监督单位缴费（第4条）——维权第一步是查询留证
4. 经办争议可复议/诉讼；单位侵害可调解、仲裁、诉讼，也可要求行政部门/征收机构处理（第83条）
5. 工会参与社保监督（第9条、第80条）
