# Chapter 5: 失业保险 (Unemployment Insurance, 第44–52条)

## Core Idea
失业金三条件"**缴满一年 + 非因本人意愿中断 + 登记求职**"；领取期限按累计缴费分三档（**12/18/24个月**）；失业期间**医保个人部分由失业基金代付**（个人不缴医保）；领取期间再就业的，缴费重新计算、剩余期限**合并**但**总封顶24个月**；五情形停发。

## Frameworks Introduced
- **强制参保（第四十四条）**：职工应当参加失业保险，单位+职工**共同缴纳**
- **失业金三条件（第四十五条）**——缺一不发：
  1. 失业前单位和本人**累计缴费满一年**
  2. **非因本人意愿中断就业**（被辞退、裁员、合同期满单位不续、单位过错被迫解除等；**主动辞职一般不算**）
  3. 已进行**失业登记**并有**求职要求**
  - When to use: 判断"我能领失业金吗"——先查缴费是否满1年，再确认解除性质是否"非因本人意愿"
- **领取期限三档（第四十六条）**：
  - 累计缴**满1年不足5年** → 最长**12个月**
  - 满**5年不足10年** → 最长**18个月**
  - 满**10年以上** → 最长**24个月**
  - **再就业后再次失业**：缴费时间**重新计算**，领取期限与**前次应领未领**的期限**合并计算**，**最长不超过24个月**
  - When to use: 断缴-再就业-再失业的连环情形下计算总领取额度
- **标准底线（第四十七条）**：失业金标准由省级政府确定，**不得低于城市居民最低生活保障标准**
  - ※各地一般按当地最低工资的70–90%左右确定
- **失业期间医保（第四十八条）**——关键福利：
  - 领取失业金期间**参加职工基本医疗保险**，享受医保待遇
  - 个人应缴的医保费**从失业保险基金中支付**，**个人不缴纳**
  - When to use: 失业期不断保——这是法定自动衔接，无需自己办
- **遗属待遇（第四十九条）**：领取期间死亡的 → 参照当地**在职职工死亡**规定，发给一次性丧葬补助金和抚恤金（失业基金支付）
  - **三险丧葬补助金不兼得**：同时符合养老/工伤/失业三险丧葬补助金条件的，遗属**只能选领一项**
- **单位义务与失业登记程序（第五十条）**：
  - 单位应**及时出具终止/解除劳动关系证明**
  - 并将失业人员名单自终止/解除之日起**15日内**告知社保经办机构
  - 失业人员持证明到公共就业服务机构**办理失业登记** → 凭失业登记证明+身份证明到经办机构**办理领取手续**
  - **领取期限自办理失业登记之日起计算**
  - When to use: 离职时单位不办手续 → 影响失业登记与领金起算，可投诉（第84、85条）
- **停发五情形（第五十一条）**：
  1. **重新就业**
  2. **应征服兵役**
  3. **移居境外**
  4. **享受基本养老保险待遇**（到龄退休）
  5. **无正当理由拒不接受**当地指定部门/机构介绍的**适当工作**或提供的**培训**
  - When to use: 第5项是"积极求职"义务的边界——拒接"适当"工作会停发；"不当"安排（明显不合理的工作）可拒绝
- **关系转移（第五十二条）**：跨统筹地区就业 → 失业保险关系随本人转移，缴费年限累计计算

## Key Concepts
- **非因本人意愿中断就业**：失业金的核心定性要件（第45条二）
- **累计缴费满一年**：领取门槛（第45条一）
- **24个月总封顶**：多次失业合并计算的硬上限（第46条）
- **失业期医保代付**：基金代付个人医保部分（第48条）
- **失业登记**：领金程序要件，期限起算点（第50条）

## Mental Models
- "三条件门槛"模型：满1年 × 非本人意愿 × 登记求职——三个开关全开才发钱；主动辞职=第一个开关外的"自愿"挡掉第二条
- "再就业不断档"模型：失业金不是"一次用光"——剩余期限在再次失业时合并（总封顶24月），但缴费年限重新从新工作起算
- 失业期"社保不断"设计：医保由失业基金代付（第48条）——失业期间医保待遇不断档，这是很多人不知道的权利
- 单位"15日报名单"义务：单位不报 → 经办机构仍可依据个人申请处理，但单位面临行政责任（第84条：不办理登记处应缴1–3倍罚款）

## Anti-patterns
- **"自己辞职就领不到"的误传**: 一般主动辞职确实不满足"非因本人意愿"——但**第38条被迫解除**（欠薪、不缴社保、不提供劳动条件）属于**非因本人意愿**中断就业，仍可领失业金
- **离职不办失业登记**: 领金期限自登记之日起算，拖延登记=损失可领月份——离职后尽快办（※目前多地已支持网上办理）
- **领金期间"打零工不申报"**: 重新就业（含灵活就业）应停发；冒领 → 责令退回+骗取金额2–5倍罚款（第88条）
- **拒接所有介绍工作**: 第51条五项"适当工作"——长期无故拒接适当安排会被停发；对明显不当的安排可书面说明理由拒绝
- **单位不出离职证明就不让办**: 第50条是单位义务；拒不出具 → 按《劳动合同法》处理（第85条援引）+ 可向社保行政部门投诉

## Worked Example
老周在某公司工作6年（累计缴失业险6年），2025-09 公司以其"不能胜任"为由解除（未履行培训/调岗前置程序，属违法解除）。老周：
1. **失业金资格**：缴满6年（>1年）✓；被单位解除=非因本人意愿✓；办失业登记并求职✓ → 可领，期限**最长18个月**（满5年不足10年档）
2. **失业期间医保**：自动参加职工医保，个人部分由失业基金支付——不断保
3. **违法解除并行主张**：2N赔偿金（劳动合同法87条）与失业金**不冲突**——拿了赔偿金不影响失业金资格（"非因本人意愿"解除成立）
4. **单位不办手续**：公司不出证明、不报名单 → 投诉社保行政部门（第84条：责令改正+逾期处应缴1–3倍罚款、责任人500–3000元罚款）；老周凭其他解除证据（解除通知书、仲裁裁决）申请领取
5. **再就业后**：2026-06 再入职新单位，失业金停发（第51条一）；新工作重新缴失业险；若2年后再次失业，前次未领完的期限与新期限**合并**，总≤24个月

## Key Takeaways
1. 失业金三条件：缴满1年 + 非因本人意愿 + 失业登记求职（第45条）
2. 期限三档：1–5年→12月；5–10年→18月；10年以上→24月；再失业合并、总封顶24月（第46条）
3. 标准≥城市低保标准（第47条）
4. 失业期间职工医保个人部分由失业基金代付（第48条）
5. 单位15日内报名单+出具证明（第50条）；拒不出按劳动合同法处理
6. 停发五情形：再就业/服役/移居/退休/拒接适当工作（第51条）
7. 被迫解除（38条）=非因本人意愿，仍可领失业金

- **Ch 3**: 失业期医保待遇的衔接（第23条职工医保）
- **公共就业服务**: 失业登记、职业介绍、培训的经办渠道
