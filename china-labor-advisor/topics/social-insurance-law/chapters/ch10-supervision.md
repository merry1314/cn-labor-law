# Chapter 10: 社会保险监督 (Supervision, 第76–83条)

## Core Idea
社保监督是"**五层结构**"：人大监督（76条）→ 行政部门监督检查（77、79条）→ 财政审计监督（78条）→ **社会保险监督委员会**社会监督（80条）→ **任何组织或个人举报投诉**（82条）。配套两条关键规则：**信息保密**（81条，经办等部门不得泄露单位和个人信息）与**争议救济三通道**（83条：对征收机构行为→复议/诉讼；对经办机构不作为→复议/诉讼；与单位发生社保争议→**调解、仲裁、诉讼**，也可要求行政部门/征收机构处理）。

## Frameworks Introduced
- **人大监督（第七十六条）**：各级人大常委会听取政府社保基金收支、管理、投资运营及监督检查的**专项工作报告**，组织**执法检查**
- **行政监督检查（第七十七条）**：
  - 县级以上社保行政部门加强对**用人单位和个人**遵守社保法律法规情况的监督检查
  - 被检查单位和个人应**如实提供**资料，**不得拒绝检查或谎报、瞒报**
- **财政审计监督（第七十八条）**：财政部门、审计机关按职责对基金收支、管理、投资运营实施监督
- **行政部门基金检查权（第七十九条）**：
  - 对基金收支管理投资运营监督检查，发现问题 → **整改建议** + **依法处理决定**（或向有关部门提出处理建议）
  - **检查结果定期向社会公布**
  - 检查中三项措施：① **查阅、记录、复制**相关资料，对可能转移隐匿灭失的资料**封存**；② **询问**有关单位和个人并要求说明、提供证明材料；③ 对**隐匿、转移、侵占、挪用**基金的行为**制止并责令改正**
- **社会保险监督委员会（第八十条）**：
  - 统筹地区政府成立：由**用人单位代表、参保人员代表、工会代表、专家**组成
  - 职能：掌握分析基金收支管理投资运营情况；对社保工作提出**咨询意见和建议**；实施**社会监督**
  - 经办机构**定期**向监督委员会**汇报**
  - 监督委员会可聘请**会计师事务所**年度审计+专项审计，**审计结果向社会公开**
  - 发现问题有权**提出改正建议**；对经办机构及工作人员违法行为，有权向有关部门**提出依法处理建议**
  - When to use: 参保人代表进入监督委员会是职工参与社保治理的法定渠道——职工可通过工会/选举进入
- **信息保密（第八十一条）**：社保行政部门、其他有关部门、经办机构、征收机构及其工作人员应**依法保密**单位和个人信息，**不得以任何形式泄露**
  - 责任：泄露 → 直接责任人处分；造成损失 → **赔偿**（第92条）
- **举报投诉（第八十二条）**：
  - **任何组织或个人**有权对违反社保法律法规的行为**举报、投诉**
  - 属于本部门职责的 → **依法处理**；不属于的 → **书面通知并移交**有权部门；有权部门应**及时处理，不得推诿**
  - When to use: 不知道找哪个部门时——向任一接收窗口投诉，有"书面移交"义务，部门之间不能踢皮球
- **争议救济三通道（第八十三条）**——本章最实务条款：
  1. 单位/个人**对征收机构行为**（如核定、追缴、处罚）侵害权益 → **行政复议或行政诉讼**
  2. **对经办机构**不依法办理**登记、核定、待遇支付、转移接续**或其他侵害 → **行政复议或行政诉讼**
  3. **个人与用人单位发生社会保险争议** → **依法申请调解、仲裁、提起诉讼**；用人单位侵害个人社保权益的，个人**也可以要求社保行政部门或征收机构依法处理**
  - When to use: 社保争议的"路由表"——对手是政府机构（征收/经办）走复议诉讼；对手是**用人单位**走调解仲裁诉讼**或**行政处理（补缴类走行政更直接）

## Key Concepts
- **五层监督**：人大/行政/财政审计/监督委员会/社会举报（第76–82条）
- **封存权**：行政检查中对可能灭失资料的强制保全（第79条）
- **监督委员会**：含职工代表（参保人员代表）的社会监督组织（第80条）
- **不得推诿**：举报投诉的部门移交义务（第82条）
- **争议路由**：对公→复议诉讼；对单位→调解仲裁诉讼+行政处理（第83条）

## Mental Models
- "路由表"模型（83条）：先问"侵害我的人是谁"——征收机构/经办机构（政府）→ 复议/行政诉讼；**单位** → 调解/仲裁/诉讼，**且**可要求行政部门或征收机构处理（补缴、欠费这类事项行政通道最顺）
- "举报不踢皮球"模型：第82条书面移交+不得推诿——投诉选错部门不可怕，部门有义务移交；保留投诉回执作为"已启动行政程序"的证据
- 监督委员会=劳动者的"代表席位"：职工通过参保人员代表参与基金监督——比个体投诉更结构性，适合行业性、系统性问题

## Anti-patterns
- **把"补缴"写成仲裁请求**: 对单位的**单纯补缴**争议，仲裁委通常不予受理（属行政管理范畴）——正确路由是**投诉征收机构**（第83条三款后段+第63条）；把"因未缴社保造成的损失/被迫解除补偿"写进仲裁
- **对经办不作为"等"**: 经办机构拖延支付待遇/不办转移 → 第83条复议诉讼可直接启动，无需先找单位
- **个人信息被经办泄露**: 第81条保密义务+第92条责任——发现泄露（如单位名单、缴费明细外泄）可向监督渠道反映
- **只走单位协商**: 单位"拖"补缴时，行政投诉（83条+63条强制链条）比私下谈判有效——投诉后单位面临滞纳金与划拨风险

## Worked Example
某单位被征收机构作出"责令限期补缴+按日万分之五滞纳金"决定，单位不服；同时员工小张因单位未缴医保导致其住院费用无法报销。处理：
1. **单位侧**：对征收机构行为不服 → **行政复议或行政诉讼**（第83条一款）——单位是行政相对人
2. **小张侧**（对单位争议）：
   - 未缴医保属**单位侵害个人社保权益** → 可**要求社保行政部门或征收机构依法处理**（责令补缴，第83条三款+第63条）
   - **损失赔偿**（本可报销而未报销的医疗费）→ 走**仲裁/诉讼**主张由单位赔偿（※司法实践：因单位未缴社保导致劳动者不能报销的损失，由单位承担）
3. **举报兜底**：任何组织或个人可举报该单位未缴行为（第82条）——向任一部门投诉，部门不得推诿，书面移交
4. **程序并行**：行政追缴（补缴+滞纳金）与民事赔偿（损失）可并行，互不替代

## Key Takeaways
1. 五层监督：人大（76）、行政（77、79）、财政审计（78）、监督委员会（80）、社会举报（82）
2. 行政部门检查三措施：查阅封存、询问、制止责令改正（第79条）
3. 监督委员会含**参保人员代表**，可聘会计师事务所审计并公开（第80条）
4. 信息保密（第81条）；泄露→处分+赔偿（第92条）
5. 举报投诉不得推诿，书面移交（第82条）
6. 争议路由：对征收/经办→复议诉讼；对单位→调解仲裁诉讼+行政处理（第83条）
