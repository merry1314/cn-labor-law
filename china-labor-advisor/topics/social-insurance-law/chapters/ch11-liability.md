# Chapter 11: 法律责任 (Legal Liability, 第84–94条)

## Core Idea
罚则按"**谁违法**"分四组：**单位**（84不办登记、85不出证明、86欠缴+滞纳金+罚款）、**骗保主体**（87机构骗保、88个人骗待，均2–5倍罚款）、**经办及政府侧**（89经办渎职、90征收机构擅自改基数费率、91挪用基金、92泄露信息、93国家工作人员渎职）、**兜底刑责**（94构成犯罪追究刑责）。劳动者最常用的是 **86条**（欠费：责令补缴+**按日万分之五滞纳金**+逾期1–3倍罚款）与 **84条**（不办登记：应缴1–3倍罚款+责任人500–3000元罚款）。

## Frameworks Introduced
- **单位不办社保登记（第84条）**：
  - 社保行政部门**责令限期改正**
  - 逾期不改正 → 对单位处**应缴社会保险费数额1–3倍罚款**
  - 对直接负责的主管人员和其他直接责任人员处**500–3000元罚款**
- **拒不出具离职证明（第85条）**：依照《劳动合同法》处理（→ 劳动合同法第89条：责令改正+赔偿损失）
  - 定位：与《劳动合同法》第50条离职证明义务衔接
- **单位欠缴（第86条）**——最高频条款：
  - 征收机构**责令限期缴纳或补足**
  - 自欠缴之日起**按日加收万分之五的滞纳金**
  - 逾期仍不缴纳 → 有关行政部门处**欠缴数额1–3倍罚款**
  - 滞纳金计算：日万分之五≈年化18.25%——欠缴越久成本越高
- **骗取基金支出（第87条）**——机构侧：
  - 经办机构、医疗机构、药品经营单位等以**欺诈、伪造证明材料**或其他手段**骗取基金支出**
  - → 责令**退回**骗取的社会保险金 + 处骗取金额**2–5倍罚款**
  - 属社会保险服务机构的 → **解除服务协议**
  - 直接责任人员有执业资格的 → **吊销执业资格**
- **骗取社会保险待遇（第88条）**——个人侧：
  - 以欺诈、伪造证明材料或其他手段**骗取社会保险待遇**
  - → 责令**退回** + 处骗取金额**2–5倍罚款**
  - When to use: 劳动者自查红线——伪造病历、虚构工伤/生育、冒用他人身份领待均落入本条；同时是劳动者**反查**机构骗保的依据（如医院虚构项目）
- **经办机构及其工作人员责任（第89条）**：
  - 五行为：① 未履行法定职责；② 未将基金存入财政专户；③ **克扣或拒不按时支付待遇**；④ **丢失或篡改缴费记录、待遇记录、个人权益记录**；⑤ 其他违反社保法律法规行为
  - 责任：责令改正；造成基金、单位或个人损失的 → **赔偿**；直接责任人**处分**
  - When to use: 待遇被克扣/拖延、记录被篡改 → 本条+第77条投诉+第83条复议诉讼
- **征收机构擅自改基数费率（第90条）**：
  - 擅自更改缴费基数、费率导致**少收或多收**
  - → 责令**追缴应缴的**或**退还不应收的**；直接责任人处分
- **隐匿、转移、侵占、挪用基金或违规投资（第91条）**：
  - 社保行政部门、财政部门、审计机关**责令追回**
  - 有违法所得 → **没收**
  - 直接责任人处分
- **泄露信息（第92条）**：
  - 行政部门/经办/征收机构及其工作人员**泄露**单位或个人信息
  - → 直接责任人处分；造成损失 → **赔偿**
- **国家工作人员渎职（第93条）**：滥用职权、玩忽职守、徇私舞弊 → 依法处分
- **刑责兜底（第94条）**：违反本法构成犯罪的 → **依法追究刑事责任**
  - 关联罪名：骗取医保/社保待遇→诈骗罪（※刑法266条及相关司法解释）；挪用社保基金→挪用公款罪等

## Key Concepts
- **滞纳金**：欠缴按日**万分之五**（第86条）
- **1–3倍罚款**：不办登记（84）/欠缴逾期（86）的单位罚则
- **2–5倍罚款**：骗保（机构87/个人88）罚则
- **责任人员双罚**：单位罚款+直接责任人个人罚款（84条）
- **五行为清单**：经办机构渎职行为（89条）
- **刑责衔接**：第94条兜底

## Mental Models
- "按违法主体路由"模型：单位违法（84/85/86）→ 行政部门处理+劳动者投诉触发；骗保（87/88）→ 退回+倍数罚款；政府侧渎职（89–93）→ 处分+赔偿+刑责
- 劳动者投诉的"成本武器"：单位欠费 → 滞纳金（年化18.25%）+ 1–3倍罚款 + 责任人个人罚款（84/86条）——投诉不是"帮忙"，是让单位承担**递增成本**的法定手段
- 双罚记忆：84条是"单位+责任人"同时罚款的典型——责任人500–3000元虽不大，但留痕于个人
- 骗保双向红线：机构（87）与个人（88）都罚2–5倍——劳动者**不得**虚构病情骗医保定期待遇，否则退金+罚款+可能刑责

## Anti-patterns
- **劳动者"小骗"**: 伪造材料多领失业金/生育津贴 → 第88条退金+2–5倍罚款；数额较大的可能触及诈骗罪（第94条）
- **认为"单位欠费与我无关"**: 单位欠缴 → 劳动者待遇（医保报销、工伤、失业金、生育）直接受损——投诉（83条+63条）是维权起点，单位滞纳金与罚款由单位承担
- **机构拖延即认**: 经办克扣/拖延支付 → 第89条（三）责令改正+赔偿——不要等，走83条复议诉讼+82条举报双轨
- **对骗保医院沉默**: 医院虚构诊疗项目套取医保 → 第87条退金+2–5倍罚款+解除服务协议——保留发票病历，可向医保部门举报

## Worked Example
某公司欠缴全员社保费6个月（合计48万元），期间员工小孙住院2万元无法医保报销。处理：
1. **行政追缴**（第86条）：员工投诉 → 征收机构责令限期补缴 → 滞纳金=48万×0.05%×180天≈4.32万（按日万分之五逐日累计）→ 逾期仍不缴 → 处欠缴1–3倍罚款（48–144万）
2. **强制措施**（第63条）：查询账户→申请划拨→不足则担保或申请法院查封拍卖
3. **小孙的医疗费损失**：因单位未缴医保导致本可报销的2万元无法报销 → 仲裁/诉讼主张由**单位赔偿**（第83条三款"对单位争议走调解仲裁诉讼"）
4. **被迫解除选项**：未依法缴纳社保 → 劳动合同法38条（三）→ 解除+经济补偿N
5. **责任人**：若公司根本未办社保登记（第84条）→ 单位应缴1–3倍罚款+直接责任人500–3000元罚款

## Key Takeaways
1. 单位三罚则：不办登记（84：应缴1–3倍+责任人500–3000）/欠费（86：补缴+日万分之五滞纳金+逾期1–3倍）/不出离职证明（85：按劳动合同法）
2. 骗保双向2–5倍：机构（87）与个人（88）——劳动者不得虚构骗取待遇
3. 经办渎职五行为（89）：克扣拖延支付、篡改记录等 → 改正+赔偿+处分
4. 征收机构擅自改基数费率 → 追缴/退还（90）；挪用基金 → 追回+没收（91）
5. 泄露信息 → 处分+赔偿（92）；构成犯罪 → 刑责（94）
