# Chapter 4: 工伤保险 (Work-Related Injury Insurance, 第33–43条)

## Core Idea
工伤保险是**唯一完全由用人单位缴费**的险种（职工不缴）；核心规则是"**因工负伤+工伤认定**→待遇"；**未缴工伤保险的，全部待遇由用人单位支付**（第41条）——这是劳动者面对"没给我买工伤险"时最有力的条款。费用分"基金付"（9项）与"单位付"（3项）；第三人致伤时基金先行支付；三种情形停发待遇。

## Frameworks Introduced
- **强制参保 + 单位独缴（第33条）**：
  - 职工**应当**参加工伤保险
  - **由用人单位缴纳**工伤保险费，**职工不缴纳**
  - When to use: "单位没缴工伤保险"不是劳动者损失——第41条把全部待遇责任压给单位
- **差别费率（第三十四、三十五条）**：行业差别费率+行业内费率档次（根据工伤风险、基金使用、发生率浮动）；单位按工资总额×核定费率缴纳
  - 定位：费率是单位成本设计，不影响劳动者待遇
- **待遇触发（第36条）**：
  - **因工作原因**受事故伤害或患**职业病** + **经工伤认定** → 享受工伤保险待遇
  - 经**劳动能力鉴定**丧失劳动能力的 → 享受**伤残待遇**
  - 工伤认定和劳动能力鉴定应当**简捷、方便**
- **四情形不认定工伤（第37条）**：
  1. **故意犯罪**
  2. **醉酒或者吸毒**
  3. **自残或者自杀**
  4. 法律、行政法规规定的其他情形
  - When to use: 单位抗辩"不算工伤"时对照——注意是"四情形之一**导致**伤亡"，因果关系须成立
- **基金支付九项（第38条）**：
  1. 治疗工伤的**医疗费用和康复费用**
  2. **住院伙食补助费**
  3. 到统筹地区以外就医的**交通食宿费**
  4. 安装配置**伤残辅助器具**费用
  5. 生活不能自理的**生活护理费**（经鉴定确认）
  6. **一次性伤残补助金** + **一至四级伤残**按月领取的**伤残津贴**
  7. 终止或解除劳动合同时（五至十级）的**一次性工伤医疗补助金**
  8. **因工死亡**遗属待遇：丧葬补助金、供养亲属抚恤金、因工死亡补助金
  9. **劳动能力鉴定费**
- **单位支付三项（第39条）**：
  1. 治疗工伤期间的**工资福利**（即停工留薪期工资，※条例：原工资福利待遇不变，一般不超过12个月）
  2. **五级、六级伤残**按月领取的**伤残津贴**
  3. 终止或解除劳动合同时的**一次性伤残就业补助金**
  - 记忆口诀："**留薪工资、五六津贴、就业补助**找单位；其余找基金"
- **与养老保险衔接（第40条）**：工伤职工符合领取基本养老金条件 → **停发伤残津贴**，改享养老待遇；养老待遇**低于**伤残津贴的 → 从**工伤保险基金补足差额**
- **未缴险的兜底（第41条）**——劳动者核心武器：
  - 单位未依法缴纳工伤保险费，发生工伤 → **由用人单位支付工伤保险待遇**
  - 单位不支付 → 从**工伤保险基金先行支付** → 单位应当偿还；不偿还的，经办机构可依法**追偿**（第63条：查询账户、划拨、查封拍卖财产）
- **第三人致伤（第42条）**：第三人原因造成工伤，第三人不支付工伤医疗费或无法确定第三人 → **工伤保险基金先行支付**后追偿
- **停发待遇三情形（第43条）**：
  1. 丧失享受待遇条件的
  2. **拒不接受劳动能力鉴定**的
  3. **拒绝治疗**的
  - When to use: 劳动者自查——拒绝鉴定/拒绝治疗会直接停发待遇，不可因"闹情绪"而放弃程序性义务

## Key Concepts
- **单位独缴**：五险中唯一职工不缴费的险种（第33条）
- **工伤认定**：待遇的法定前提（人社部门作出）
- **劳动能力鉴定**：伤残等级（1–10级）与护理依赖评定的依据
- **停工留薪期**：治疗工伤期间，原工资福利待遇不变，由单位支付（第39条一+※条例33条）
- **先行支付**：未缴险或第三人致伤时基金的兜底机制（第41、42条）
- **一次性工伤医疗补助金/一次性伤残就业补助金**：五至十级解除时的"双金"（基金/单位各付一项）

## Mental Models
- "未缴险≠没保障"模型：第41条把基金责任**整体转移给单位**，再加基金先行支付兜底——劳动者两头都有靠山；单位反而两头受追
- 费用三分法：基金付（医疗、康复、伙食、交通、辅具、护理、一次性伤残补助金、1-4级伤残津贴、死亡三金、鉴定费）/ 单位付（停工留薪工资、5-6级伤残津贴、一次性伤残就业补助金）/ 个人无（保费不缴）
- 伤残等级决定待遇结构：1–4级保留劳动关系、按月领伤残津贴至退休；5–6级单位安排工作（难安排则发津贴）；5–10级解除时领"双金"
- 程序义务红线：配合鉴定、配合治疗——否则停发待遇（第43条）

## Anti-patterns
- **单位"私了"工伤**: 未做工伤认定就签"一次性了结"协议——金额远低于法定待遇的，可主张撤销/确认无效（显失公平+损害社保基金权益）；正确顺序：工伤认定→劳动能力鉴定→按法定标准谈
- **错过申报时限**: 单位应在30日内申请工伤认定；单位不申请的，**劳动者/近亲属/工会在1年内可直接申请**（※《工伤保险条例》第17条）——1年是硬窗口
- **拒绝鉴定/拒绝治疗**: 第43条直接停发待遇——对单位不满可以走投诉/仲裁，但程序性义务必须履行
- **工伤走医保报销**: 第30条明确工伤费用不纳入医保——应走工伤基金/单位，混用影响待遇完整性
- **"四情形"扩大解释**: 单位常把"醉酒""故意犯罪"当挡箭牌——注意须是**导致**伤亡的直接原因，且"醉酒"有鉴定标准（血液酒精含量），单位举证
- **1–4级职工被"劝退"**: 1–4级保留劳动关系至退休、按月领伤残津贴——单位不能随意解除（※条例第36条+劳动合同法第42条二）

## Worked Example
某工厂未给员工老李缴纳工伤保险。2025-06 老李在车间被落物砸伤，腰椎骨折，住院40天，经鉴定**七级伤残**。处理：
1. **工伤认定**：单位30日内未申请 → 老李在**1年内**自行向人社局申请（※条例17条）——保存事故证明、病历、劳动关系证据
2. **待遇拆分**（七级）：
   - **基金项目**（因单位未缴→全部由**单位支付**，第41条）：医疗费、住院伙食补助、一次性伤残补助金（13个月本人工资※条例37条）
   - **单位项目**：停工留薪期工资（原待遇不变，最长12个月）、解除时一次性伤残就业补助金（省级标准）
   - **基金一次性工伤医疗补助金**（解除时，第38条七）：单位未缴 → 仍由单位支付
3. **单位赖账** → 向征收机构/社保经办机构申请**基金先行支付**（第41条）→ 基金付后向单位追偿（第63条划拨/查封）
4. **仲裁并行**：主张上述待遇差额；单位"私了"协议金额明显偏低的，主张无效/撤销
5. **解除选择**：七级伤残可由**劳动者提出**解除劳动关系（※条例37条）→ 领"双金"；单位不得依40/41条解除（劳动合同法42条）

## Key Takeaways
1. 工伤保险单位独缴，职工不缴费（第33条）
2. 未缴工伤保险 → 全部待遇由**用人单位支付**；单位不付 → 基金**先行支付**后追偿（第41条）
3. 费用三分：基金九项 / 单位三项（留薪工资、5-6级津贴、就业补助金）
4. 四情形不认定：故意犯罪、醉酒吸毒、自残自杀——须"导致"伤亡
5. 第三人致伤 → 基金先行支付医疗费后追偿（第42条）
6. 拒不接受鉴定、拒绝治疗 → 停发待遇（第43条）
7. 1–4级伤残保留劳动关系至退休；养老待遇低于伤残津贴的基金补差（第40条）
