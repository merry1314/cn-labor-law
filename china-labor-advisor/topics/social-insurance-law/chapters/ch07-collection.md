# Chapter 7: 社会保险费征缴 (Fee Collection, 第57–63条)

## Core Idea
征缴章是社保法的"征管程序"：单位**成立30日内**办社保登记、**用工30日内**为职工办登记（未办登记的由经办机构**核定**应缴数额）；单位**自行申报、按时足额**缴纳，**非不可抗力不得缓缴减免**；职工个人部分由单位**代扣代缴**且**按月告知明细**；未申报的按**上月缴费额110%**核定；欠缴的"责令限期→查询账户→划拨→担保延期→查封拍卖"四级递进追缴——单位欠缴社保不是"民事扯皮"，是有强制执行力链条的行政事项。

## Frameworks Introduced
- **单位社保登记（第五十七条）**：
  - 单位自**成立之日起30日内**凭营业执照/登记证书/单位印章办理社保登记；经办机构**15日内**审核发证
  - 登记事项变更或单位终止 → 自变更/终止之日起**30日内**办理变更/注销
  - 市监、民政、编办部门通报单位成立终止；公安通报个人出生死亡户口迁移注销
  - When to use: 判断新设单位"未参保"是否已超期——超30日未登记即违反第57条（罚则见第84条）
- **职工登记 + 个人社会保障号码（第五十八条）**：
  - 单位应自**用工之日起30日内**为职工办理社保登记
  - **未办理登记的，由社会保险经办机构核定其应缴纳的社会保险费**
  - 灵活就业人员自愿参保的自行办理登记
  - **全国统一个人社会保障号码 = 公民身份号码**
  - When to use: 入职超30日未参保 → 单位违法；"没登记"不能成为不缴的理由——经办机构可直接核定
- **统一征收（第五十九条）**：社保费实行**统一征收**（2019年后由税务部门统一征收）；步骤办法由国务院规定
- **申报缴纳规则（第六十条）**——核心义务条款：
  - 单位**自行申报、按时足额**缴纳
  - **非因不可抗力等法定事由不得缓缴、减免**
  - 职工个人部分由单位**代扣代缴**
  - 单位应**按月将缴费明细告知本人**
  - 灵活就业人员直接向征收机构缴纳
  - When to use: "降基数""自愿缓缴""协商减免"——除不可抗力法定事由外均无依据；**按月告知明细**是劳动者核对缴费的依据（不告知可投诉）
- **征收机构义务（第六十一条）**：依法**按时足额**征收；将缴费情况**定期告知**用人单位和个人
- **未申报的核定（第六十二条）**：
  - 单位未按规定申报应缴数额 → 按**该单位上月缴费额的110%**确定应缴数额
  - 补办申报后按规定结算
  - When to use: 单位"不申报"想逃费的，征收机构直接按110%核定——逃不掉
- **欠缴追缴四级链条（第六十三条）**——强制执行升级：
  1. **责令限期缴纳或补足**
  2. 逾期仍不缴 → 向银行/金融机构**查询存款账户**；申请县级以上有关行政部门作出**划拨决定**，书面通知开户银行**划拨**
  3. 账户余额不足 → 要求单位**提供担保**，签订**延期缴费协议**
  4. 未足额缴纳且未提供担保 → 申请**人民法院扣押、查封、拍卖**价值相当于应缴社保费的财产，以拍卖所得**抵缴**
  - When to use: 单位欠费的"杀手锏"——劳动者投诉后，征收机构有完整强制手段；个人无需自己垫付或打民事官司

## Key Concepts
- **30日登记**：单位成立/用工后的登记窗口（第57、58条）
- **核定**：未登记/未申报时经办机构的单方核定权（第58、62条）
- **代扣代缴**：个人缴费部分由单位扣除（第60条）
- **按月告知明细**：单位的告知义务（第60条）
- **110%核定**：未申报时的应缴数额推定（第62条）
- **划拨/查封拍卖**：欠缴社保的行政强制链条（第63条）

## Mental Models
- "征缴是行政事项"模型：社保费的征缴、补缴、滞纳是**社保行政部门/征收机构**的职权——劳动者维权的第一动作是**投诉**（让行政机关启动第63条链条），而不是把"补缴"写成仲裁请求（仲裁对单纯补缴一般不受理）
- 强制升级阶梯：限期缴纳 → 查账户划拨 → 担保延期 → 查封拍卖——单位"没钱"不是挡箭牌，担保和财产处置是后手
- 劳动者的"三个30日"：单位成立30日登记（57条）、用工30日为职工登记（58条）——超过30日未参保即构成违法，投诉有事实基础
- 基数申报的"110%推定"：单位不申报 → 按上月110%核定——不申报反而可能多缴，单位没有"沉默"的套利空间

## Anti-patterns
- **"缓缴/减免"口头承诺**: 第60条——非不可抗力等法定事由**不得**缓缴减免；单位与员工"协商不缴"无效
- **按最低基数申报**: 应按**职工工资总额/本人工资**如实申报（第12条养老、第60条）——少报基数的，征收机构责令补足（第63条）+ 滞纳金（第86条）
- **不代扣个人部分**: 单位只缴单位部分、不代扣个人部分 → 缴费不完整，影响个人权益记录与累计年限——劳动者应核对（第60条、第74条权益记录）
- **用"私了"替代补缴**: 单位承诺"补发现金"不实际参保 → 现金替代不产生参保记录，工伤生育失业待遇仍无法享受
- **个人以为"社保是单位的事"**: 个人也有"依法缴费"义务（第4条）——但个人部分由单位代扣（第60条）；单位不办的，个人可自愿到征收机构办理（灵活就业身份缴养老医疗）

## Worked Example
某科技公司2025-01 成立，至今未办社保登记，也未给10名员工参保。2026-08 员工集体投诉。处理：
1. **违法事实**：成立超30日未办单位登记（第57条）+ 用工超30日未为职工登记（第58条）
2. **行政处理**（第84条）：社保行政部门**责令限期改正**；逾期不改正 → 对单位处**应缴数额1–3倍罚款**，对直接负责主管人员和其他直接责任人员处**500–3000元罚款**
3. **补登记+核定**（第58条）：经办机构为其办理登记并**核定**应缴数额——未申报的按上月缴费额110%核定（第62条，首月按申报核定）
4. **追缴**（第63条）：责令限期补缴 → 逾期查询账户/申请划拨 → 不足则要求担保或申请法院查封拍卖
5. **滞纳金**（第86条）：自欠缴之日起**按日加收万分之五**
6. **员工并行权利**：未缴社保 → 《劳动合同法》第38条（三）被迫解除 + 经济补偿N（仲裁）；期间发生工伤/生育的，单位直接承担待遇（第41条逻辑）

## Key Takeaways
1. 双30日登记：单位成立30日内（第57条）+ 用工30日内为职工（第58条）
2. 单位自行申报、按时足额；非不可抗力不得缓缴减免（第60条）
3. 个人部分单位代扣代缴+按月告知明细（第60条）
4. 未申报 → 按上月110%核定（第62条）
5. 欠缴追缴四级：限期缴纳→查户划拨→担保延期→查封拍卖（第63条）
6. 欠缴滞纳金：按日万分之五（第86条）
7. 全国统一个人社会保障号码=身份证号（第58条）

## Connects To
- **Ch 11**: 第84条（不办登记罚则）、第86条（欠缴罚则+滞纳金）
- **税务征收改革（2019）**: 社保费由税务统一征收后，征缴能力与合规压力上升
- **劳动合同法 ch04/ch07**: 未缴社保的被迫解除（38条）与责令支付（85条逻辑对应）
- **《社会保险费征缴暂行条例》**: 征缴程序的上位配套（2019年部分职能移交税务后仍适用未抵触部分）
