# Chapter 6: 生育保险 (Maternity Insurance, 第53–56条)

## Core Idea
生育保险**单位独缴**（职工不缴，同工伤保险）；待遇就两项——**生育医疗费用**与**生育津贴**；**未就业配偶**也可享受生育医疗费用待遇（不享受津贴）；生育津贴按**单位上年度职工月平均工资**计发——不是按本人工资，这是谈判和核算的关键点。

## Frameworks Introduced
- **强制参保 + 单位独缴（第五十三条）**：
  - 职工应当参加生育保险，**由用人单位缴纳**，**职工不缴纳**
  - When to use: 单位"让职工个人缴生育险"是违法的——生育险只能单位缴
- **待遇享有条件（第五十四条）**：
  - 单位**已缴纳**生育保险费 → 其职工享受生育保险待遇
  - **职工未就业配偶**按照国家规定享受**生育医疗费用待遇**（注意：只有医疗费，**没有生育津贴**）
  - 资金从生育保险基金支付
  - **生育保险待遇 = 生育医疗费用 + 生育津贴**
  - When to use: 已婚员工配偶未就业——生育医疗费可由生育保险覆盖（各地对"缴纳满一定期限"等条件有细化）
- **生育医疗费用三项（第五十五条）**：
  1. 生育的医疗费用
  2. **计划生育**的医疗费用
  3. 法律、法规规定的其他项目费用
- **生育津贴三情形（第五十六条）**：
  1. 女职工生育享受**产假**
  2. 享受**计划生育手术休假**
  3. 法律、法规规定的其他情形
  - **计发标准：按职工所在用人单位上年度职工月平均工资计发**
  - When to use: 核算产假收入——津贴=单位上年度月均工资×产假天数/30；若本人工资高于月均工资的，差额部分由单位补足（※各地口径，如《女职工劳动保护特别规定》配套办法）
  - **未缴生育保险的**：生育待遇（含津贴）由**用人单位支付**（※《女职工劳动保护特别规定》第8条——与工伤第41条同逻辑）
- **产假法定天数**：基本产假**98天**（产前可休15天）+ 难产加15天 + 多胞胎每多1胎加15天（※《女职工劳动保护特别规定》）；各地另有**生育奖励假/延长产假**（30–120天不等，以地方人口与计划生育条例为准）
  - 当地产假总天数 = 98天基本 + 地方奖励假——津贴覆盖范围各地不同（多数地区奖励假工资由单位按原待遇支付）

## Key Concepts
- **单位独缴**：职工不缴费（第53条）
- **生育医疗费用**：含计划生育医疗费（第55条）
- **生育津贴**：产假/计生手术休假期间的工资替代（第56条）
- **单位上年度职工月平均工资**：津贴计发基数（第56条）
- **未就业配偶**：享受生育医疗费用（第54条）

## Mental Models
- "津贴是工资替代"模型：生育津贴本质是产假期间的收入替代，但**基数是单位月均工资而非本人工资**——高收入员工可能拿到的津贴低于本人工资，差额依地方规则由单位补足；低收入员工则可能高于本人工资
- "未缴险→单位全赔"模型：与工伤保险同构（第41条逻辑）——单位没缴生育险，生育医疗费+津贴全部由单位自付（※特别规定第8条）
- 双险独缴记忆：五险中**工伤、生育**两险职工不缴费——"生伤"两险单位全包
- 未就业配偶保护：男性职工配偶未就业的生育医疗费也有保障（第54条）——这是家庭维度的设计

## Anti-patterns
- **产假按"基本工资"发**: 津贴应按**单位上年度月平均工资**计发（第56条）；单位只发基本工资、不发/少发津贴 → 差额可主张
- **未缴生育险让职工自己扛**: 未缴 → 单位支付全部生育待遇（※特别规定第8条）——投诉+仲裁双通道
- **把奖励假工资算成津贴**: 津贴只覆盖法定产假期间；地方奖励假期间待遇按地方规定（多为单位按原工资支付）——两笔钱别混
- **未就业配偶被拒**: 第54条明确未就业配偶享受生育医疗费用待遇——单位/经办拒付的，投诉纠正
- **诱导"放弃生育险"**: 与放弃养老险同理——强制险不可约定排除

## Worked Example
小何（女）在某公司工作，单位上年度职工月平均工资9000元，其本人月薪12000元。2026-03 生育（单胎、无难产），当地奖励假60天，产假合计158天。单位未缴生育保险。处理：
1. **定性**：单位未缴生育险 → 全部生育待遇**由用人单位支付**（※特别规定第8条，与第41条工伤逻辑一致）
2. **生育津贴**：9000元/月为基数（第56条）→ 9000×158/30 = 47400元（按当地计发口径）
3. **本人工资差额**：本人月薪12000 > 津贴折算月均（9000）→ 差额部分依地方规定由单位补足（产假期间工资待遇不低于原标准——※各地细则）
4. **生育医疗费用**：产检、分娩、计划生育手术费用 → 本应由生育基金支付 → 未缴 → 单位支付（第54、55条）
5. **行政通道**：向征收机构投诉补缴+滞纳金（第86条）
6. **男方视角**：若小何未就业而其配偶（有职工身份）单位已缴生育险 → 小何的生育医疗费可由配偶的生育保险基金支付（第54条）

## Key Takeaways
1. 生育保险单位独缴，职工不缴（第53条）
2. 待遇=生育医疗费用+生育津贴（第54条）；未就业配偶仅享医疗费（第54条）
3. 生育津贴按**单位上年度职工月平均工资**计发（第56条），非本人工资
4. 未缴生育险 → 全部待遇由单位支付（※特别规定第8条）
5. 基本产假98天+难产/多胞胎加+地方奖励假（※特别规定+地方条例）
6. 单位拒不出具/不配合的，按劳动合同法处理（第85条援引）
