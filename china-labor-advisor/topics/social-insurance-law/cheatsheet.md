# Cheatsheet — 中华人民共和国社会保险法（2018修正）

## 五险速查

| 险种 | 缴费主体 | 待遇核心 | 关键条文 |
|---|---|---|---|
| 养老 | 单位（统筹）+个人（账户） | 退休+累计15年→按月领养老金；账户可继承 | 第10–22条 |
| 医疗 | 单位+个人 | 三个目录内报销；达年限退休免缴；第三人致伤基金先行支付 | 第23–32条 |
| 工伤 | **单位独缴** | 认定+鉴定→九项基金待遇+三项单位待遇；未缴→单位全付 | 第33–43条 |
| 失业 | 单位+个人 | 缴满1年+非自愿+登记→失业金12/18/24月；期间医保基金代付 | 第44–52条 |
| 生育 | **单位独缴** | 生育医疗费+生育津贴（单位上年度月均工资计发）；未就业配偶仅医疗费 | 第53–56条 |

## 五险缴费比例速查（※地方口径）

**回答"社保应该交多少"的入口**。全国通行比例区间如下；**具体比例、档次以当地（省市）现行规定为准**，且部分费率处于阶段性调整中。

| 险种 | 单位缴费 | 个人缴费 | 备注 |
|---|---|---|---|
| 养老 | **16%**（2019-05起全国统一，国办发〔2019〕13号） | **8%**（全部进个人账户） | 灵活就业：20%全自担（8%进账户） |
| 医疗 | 约 **6%–10%**（各地差异大，常含大病统筹） | **2%**（+大额互助数元/月） | 退休缴满年限后免缴（第27条） |
| 失业 | **0.5%–1%**（阶段性降费率期多为0.5%） | **0.2%–0.5%** | 总费率阶段性1%左右 |
| 工伤 | **0.2%–1.9%**（八类行业基准费率+浮动±50%/150%） | **0**（个人不缴，第33条） | 2015年八类基准：0.2/0.4/0.7/0.9/1.1/1.3/1.6/1.9% |
| 生育 | 约 **0.5%–1%**（与职工医保**合并征缴**，国办发〔2019〕10号） | **0**（个人不缴，第53条） | 合并后费率按两项之和确定 |
| 合计参考 | 约 **25%–30%** | 约 **10%** | 单位部分为用工隐性成本 |

**缴费基数规则（比例 × 基数 = 实缴）**：
- 基数 = 职工本人**上年度月平均工资**（新入职 = 首月工资，国发〔2005〕38号口径）
- **夹逼区间**：当地社平工资的 **60%（下限）– 300%（上限）**——低于60%按60%缴，高于300%按300%缴
- **核对入口**：单位**按月告知**缴费明细（第60条）；社保APP/12333查缴费记录——**低基数申报=欠缴**（可责令补缴，第63条）

> **公积金不属于社保**：住房公积金按《住房公积金管理条例》缴存（单位+个人**各5%–12%**），争议走**公积金管理中心**行政通道，不走社保——见 [housing-fund-regulations](../housing-fund-regulations/INDEX.md)。

## 费用三分法（工伤）

```
基金支付（第38条，9项）        单位支付（第39条，3项）
├─ 医疗费 + 康复费             ├─ 停工留薪期工资福利
├─ 住院伙食补助费              ├─ 5–6级伤残津贴（按月）
├─ 外地就医交通食宿费          └─ 一次性伤残就业补助金
├─ 伤残辅助器具费
├─ 生活护理费（经鉴定）
├─ 一次性伤残补助金（1–10级）
├─ 1–4级伤残津贴（按月）
├─ 一次性工伤医疗补助金（5–10级解除时）
├─ 因工死亡三金（丧葬/供养抚恤/死亡补助）
└─ 劳动能力鉴定费
未缴工伤险 → 以上全部由【用人单位支付】（第41条）→ 不付则基金先行支付后追偿
```

## 争议路由速查（第83条）

```
对手是政府？
├─ 征收机构行为（核定/追缴/处罚） → 行政复议 或 行政诉讼
├─ 经办机构不作为（登记/核定/支付/转移） → 行政复议 或 行政诉讼
└─ 用人单位 → 调解 / 仲裁 / 诉讼  【且】可要求行政部门或征收机构依法处理
   ├─ 补缴/欠费类 → 行政通道最顺（第63条强制链条）
   └─ 损失赔偿类（医疗费不能报销、待遇差额）→ 仲裁/诉讼
举报兜底：任何组织或个人 → 任一部门（第82条书面移交，不得推诿）
```

## 劳动者社保维权请求清单（仲裁/行政示例）

**行政投诉（征收机构/社保行政部门）**
1. 责令限期补缴五险/指定险种（第63条）+ 滞纳金（第86条）
2. 责令更正缴费基数（第60、62条）
3. 责令办理社保登记（第57、58条）
4. 责令出具离职证明（第50、85条援引劳动合同法）

**仲裁/诉讼（对单位）**
5. 未缴社保被迫解除 + 经济补偿N（※劳动合同法38条三、46条）
6. 因未缴医保导致医疗费不能报销的损失（第83条三款）
7. 因未缴工伤险的工伤保险待遇（第41条）
8. 因未缴生育险的生育医疗费+津贴（※特别规定8条）
9. 未缴失业险导致无法领取失业金的损失（※司法实践口径不一）
10. 低基数缴费导致个人账户少计的差额（补缴优先，损失视地方口径）

**对经办/征收（复议/诉讼）**
11. 经办机构克扣/拖延支付待遇（第73、89条）
12. 不办登记、核定、转移接续（第83条二款）

## 单位侧合规红线（HR自查）
- 入职30日内办登记参保（57/58条）——"过试用期再缴"违法
- 按实际工资申报基数（12/60条）——最低基数申报=欠缴
- 工伤、生育险单位独缴（33/53条）——让个人缴生育险违法
- 不得约定放弃、不得现金替代（4条"依法缴纳"）
- 离职15日内报失业名单（50条）
- 按月告知缴费明细（60条）
