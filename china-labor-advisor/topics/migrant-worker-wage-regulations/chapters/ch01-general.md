# Chapter 1: 总则（第1–10条）

## Core Idea
确立农民工工资支付的基本原则、适用范围和部门职责分工。本条例是劳动法体系中专门保障农民工工资支付的行政法规，优先于一般劳动法规适用。结构骨架：**一项权利**（第3条：按时足额获得工资的权利，任何单位和个人不得拖欠农民工工资）、**一项政府责任**（第4条：县级以上地方人民政府对本行政区域负总责，乡镇人民政府、街道办事处负责拖欠矛盾排查调处）、**一项方针**（第5条：市场主体负责、政府依法监管、社会协同监督，源头治理、预防为主）、**一个基础**（第6条：用工实名制+书面约定工资支付标准、时间、方式）；第7–9条划分部门职责（人社主管、住建/交通/水利行业监管、发改管政府投资与信用体系、公安管拒不支付劳动报酬刑事案件）与社会力量（工会、共青团、妇联、残联、新闻媒体），第10条给出投诉、申请调解仲裁、提起诉讼三通道，并对举报投诉处理确立首问负责制。

## Key Concepts
- **立法目的**（第1条）：规范农民工工资支付行为，保障农民工按时足额获得工资
- **适用范围**（第2条）：保障农民工工资支付适用本条例；农民工=为用人单位提供劳动的农村居民；工资=劳动报酬
- **核心权利**（第3条）：农民工有按时足额获得工资的权利，任何单位和个人不得拖欠
- **政府责任**（第4条）：县级以上地方人民政府对本行政区域内保障农民工工资支付工作负责
- **工作方针**（第5条）：市场主体负责、政府依法监管、社会协同监督；源头治理、预防为主、防治结合、标本兼治
- **实名制+书面约定**（第6条）：用人单位实行劳动用工实名制管理，书面约定工资支付标准、时间、方式
- **部门职责**（第7条）：人社部门主管；住建/交通/水利行业监管；发改委/财政/公安/司法等部门协同
- **特别法优先**：本条例是农民工工资支付的特别规定，优先于《劳动法》《劳动合同法》一般规定适用
- **政府属地责任**：地方政府对辖区内农民工工资支付负总责
- **维权通道**（第10条）：农民工有权依法投诉、申请劳动争议调解仲裁和提起诉讼；任何单位和个人对拖欠行为有权举报；举报、投诉处理实行**首问负责制**（属于本部门依法及时处理，不属于本部门及时转送相关部门并将处理结果告知举报、投诉人）
- **社会力量**（第8、9条）：工会、共青团、妇女联合会、残疾人联合会等组织按职责依法维护农民工获得工资的权利；新闻媒体开展公益宣传+对拖欠违法行为舆论监督

## Anti-patterns
- ❌ 以实物、有价证券替代工资支付 → 第11条明确工资应以货币形式通过银行转账或现金支付给农民工本人，实物/有价证券替代是禁止的支付形式（罚则见ch06第54条）
- ❌ 将工资支付义务推给包工头/个人而不承担连带责任 → 本条例建立清偿责任链（第16–22条）+工程建设领域总包先行清偿（第30条），"个人承包"模式不豁免发包单位/总包责任
- ❌ 认为欠薪是劳资双方私事、政府不介入 → 第3、4条：任何单位和个人不得拖欠；地方政府对辖区工作负总责，并纳入对有关部门和下级政府的考核监督（第4条）
- ❌ 向主管部门举报后无人受理 → 第10条首问负责制：属于本部门受理的依法及时处理，不属于的及时转送，并将处理结果告知举报、投诉人

## Worked Example
某建筑公司将工程分包给包工头王某，王某拖欠农民工工资。农民工应向谁主张？
→ 根据本条例，建筑公司（发包单位）对王某（个人承包）招用的农民工工资承担清偿责任（第22条）；工程建设领域总包单位还应先行清偿（第30条）。

场景展开：2021年3月，某建筑公司将某楼盘精装修工程分包给无劳务分包资质的个人王某，王某招用12名工人（月工资约8000元/人）。年底工程验收，建筑公司尚欠王某工程款30万元，12名工人被欠工资共15万元，王某无力支付。
→ 处理链：
1. 先向直接雇主王某主张（第16条：拖欠工资应当依法清偿）
2. 王某不清偿 → 建筑公司（发包单位）对王某招用农民工的工资承担清偿责任（第22条）；工程建设领域发包给个人导致欠薪的，由建设单位或者施工总承包单位清偿（第36条）
3. 若项目存在转包 → 施工总承包单位先行清偿，再依法向责任方追偿（第30条）
4. 通道：向人社部门投诉（第10条首问负责制），或申请调解仲裁、提起诉讼；人社部门作出责令支付决定后不支付的，可申请人民法院强制执行（第42条）

## Key Takeaways
- 农民工工资支付是行政法规强制保障领域，用人单位不得拖欠
- 实名制管理和书面工资约定是合规基础
- 维权三通道（第10条）：投诉/申请调解仲裁/提起诉讼；举报投诉处理实行首问负责制
- 特别法优先：工资支付问题优先适用本条例（第2条），本条例未涉及的适用《劳动法》《劳动合同法》
