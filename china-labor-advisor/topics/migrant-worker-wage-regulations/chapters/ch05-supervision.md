# Chapter 5: 监督检查（第40–49条）

## Core Idea
赋予人社部门及相关部门监督检查权，建立失信联合惩戒和刑事移送机制，确保农民工工资支付法规落到实处。三层执法工具箱：**调查手段**——查询相关单位金融账户和相关当事人拥有的房产、车辆等，须经设区的市级以上人社部门负责人批准，金融机构和登记部门应当配合（第40条）；用人单位拒不配合调查、责任主体无法联系的，可请求公安机关协助（第41条）；作出责令支付被拖欠工资的决定后相关单位不支付的，可依法申请人民法院强制执行（第42条）；**信用手段**——守法诚信档案+等级评价（第47条），严重拖欠的向社会公布并可公开曝光（第47条），情节严重的将单位及其法定代表人、主要负责人、直接负责的主管人员等列入失信联合惩戒名单（第48条）；**刑事手段**——拖欠违法行为涉嫌构成拒不支付劳动报酬罪的，及时移送公安机关审查（第41条）。另有：政府监控预警平台（第38条）、行业部门查处违法发包、转包、违法分包、挂靠（第43条）、财政审计监督政府投资资金拨付（第44条）、农民工列为法律援助重点对象（第45条）。

## Key Concepts
- **主管部门**（第40条）：人社部门负责组织协调、管理指导和监督检查，查处拖欠工资案件；住建/交通/水利等行业部门履行行业监管责任
- **检查措施**（第41条）：可进入现场检查、询问当事人、查阅复制资料、查询银行账户；必要时可申请**法院查封、扣押**相关财物
- **信用监管**（第47条）：建立用人单位及相关责任人守法诚信档案
- **失信联合惩戒**（第48条）：拖欠农民工工资**情节严重**的，列入失信联合惩戒对象名单，在政府资金支持、政府采购、招投标、融资贷款、税收优惠等方面予以限制
- **刑事移送**（第49条）：发现涉嫌拒不支付劳动报酬罪的，应当及时移送公安机关立案侦查
- **保证金动用**（第45条）：总包单位拖欠工资且符合条件的，人社部门可动用工资保证金支付
- **失信联合惩戒**：行政+市场+司法的多维度限制，是最严厉的非刑事处罚
- **拒不支付劳动报酬罪**：刑法第276条之一，以转移财产、逃匿等方法逃避支付或有能力支付而不支付，数额较大，经责令支付仍不支付的，处3年以下有期徒刑或拘役，并处或单处罚金；造成严重后果的，处3–7年有期徒刑
- **监控预警**（第38条）：县级以上地方政府建立监控预警平台，跨部门共享工程审批、资金落实、施工许可、劳动用工、工资支付信息；人社部门按水电燃气、物业、信贷、税收等指标监控预警 ※（平台功能各地有差异）
- **法律援助**（第45条）：司法行政部门和法律援助机构将农民工列为法律援助重点对象，为请求支付工资的农民工提供便捷法律援助
- **政府投资监督**（第44条）：财政、审计机关和相关行业工程建设主管部门对政府投资项目建设单位向专户拨付资金情况依法监督

## Anti-patterns
- ❌ 拒绝、阻碍人社部门监督检查 → 第41条：拒不配合调查的可请求公安机关协助处理；金融机构不配合查询金融账户的，由金融监管部门责令改正，拒不改正的处2万–5万元罚款（第58条）
- ❌ 隐匿、销毁工资支付台账等证据 → 第50条：欠薪争议中用人单位应提供依法保存的劳动合同、职工名册、工资台账和清单等材料，不提供的承担不利后果
- ❌ 转移财产、逃匿以逃避支付工资 → 拒不支付劳动报酬罪的核心行为（涉嫌犯罪的移送公安，第41条）；逃匿的，政府可动用应急周转金先行垫付部分工资或基本生活费，再依法追偿（第63条）※（地方标准）
- ❌ "罚了款就两清了" → 行政处罚不替代清偿：责令支付决定不执行的，申请法院强制执行（第42条）；工资债务不因缴纳罚款而消灭，情节严重的还列入失信名单（第48条）

## Worked Example
某公司拖欠农民工工资50万元，人社部门责令支付后仍不支付，并转移银行账户资金。如何处理？
→ ① 人社部门可申请法院查封、扣押相关财物（第41条）。② 公司行为涉嫌拒不支付劳动报酬罪，人社部门应移送公安机关（第49条）。③ 将公司列入失信联合惩戒名单（第48条）。

场景展开：2023年，某劳务公司拖欠30名工人工资共50万元。3月，工人集体投诉，人社局立案并责令限期支付；4月，公司转出基本账户48万元，法定代表人失联；5月，人社局请求公安协助、移送案件，并将公司及其法定代表人、直接负责的主管人员等列入失信联合惩戒名单。
→ 结果链：
1. 强制执行：公司不支付责令支付决定 → 人社部门申请人民法院强制执行（第42条）
2. 刑事程序：公安机关受理侦办拒不支付劳动报酬案件（移送依据第41条）※（构成标准按刑法及司法解释）
3. 失信惩戒：单位与相关自然人**双列入**（第48条），在招投标、融资贷款、市场准入、交通出行等方面受限制
4. 工人兜底：仍无法获付的可申请法律援助（第45条）；公司逃匿的可请求政府动用应急周转金垫付基本生活费（第63条）※（地方标准）
5. 成本对比：欠薪总成本（工资+罚款+强制执行+刑事记录+失信限制）≫ 按时支付50万

## Key Takeaways
- 人社部门有查询账户、申请查封扣押的强制手段
- 拒不支付劳动报酬罪是欠薪的刑事底线，经责令支付仍不支付即触发
- 三层执法工具：调查（账户/房产车辆查询、强制执行）→信用（诚信档案/失信联合惩戒）→刑事（移送）（第40–42、47–48、41条）
- 失信惩戒对象是"单位+自然人"双列入（第48条），限制覆盖政府资金支持、招投标、融资贷款、市场准入、税收优惠、评优评先、交通出行等8个方面
- 监控预警平台+水电燃气/信贷/税收多指标监控，实现欠薪"发生前预警"（第38条）※（地方接口）
