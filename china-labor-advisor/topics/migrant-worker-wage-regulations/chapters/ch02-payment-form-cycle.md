# Chapter 2: 工资支付形式与周期（第11–16条）

## Core Idea
规范工资支付的形式、周期、方式和台账管理，是防止欠薪的源头性制度。三项强制要求：**货币支付**（第11条：通过银行转账或者现金支付给农民工本人，不得以实物或者有价证券等其他形式替代）、**按约定足额**（第12、13条：按书面约定或依法制定的规章制度规定的工资支付周期和具体支付日期足额支付；实行月、周、日、小时工资制的按月、周、日、小时周期支付，计件工资支付周期由双方依法约定）、**节假日提前**（第14条：具体支付日期遇法定节假日或者休息日的，应当在法定节假日或者休息日**前**支付；因不可抗力未能在支付日期支付的，应当在不可抗力消除后及时支付）；第15条确立书面工资支付台账制度（**至少保存3年**）与工资清单义务——台账和清单是欠薪案件的核心证据（争议中用人单位不提供其依法保存的材料，依法承担不利后果，第50条）。

## Key Concepts
- **货币支付**（第11条）：工资应当以**法定货币**形式支付，不得以实物、有价证券替代
- **银行转账**（第12条）：鼓励使用银行转账等方式支付；工程建设领域**必须**通过银行转账（总包代发，第31条，见ch04）
- **按月支付**（第13条）：工资至少**每月支付一次**；具体支付日期由双方约定
- **节假日提前**（第14条）：支付日期遇法定节假日或休息日的，应当在**法定节假日或者休息日前**支付；因不可抗力未能在支付日期支付的，应当在不可抗力消除后及时支付
- **书面台账**（第15条）：用人单位应按支付周期编制书面工资支付台账，至少保存 **3 年**；向农民工提供工资清单
- **不得克扣**（第16条）：用人单位克扣或者无故拖欠农民工工资的，依法承担责任
- **法定货币**：人民币，不得以实物、购物卡、有价证券替代
- **工资支付台账**：记录支付对象、支付数额、支付时间等的书面凭证，保存期3年
- **工资清单**（第15条）：用人单位向农民工支付工资时，应当提供农民工本人的工资清单——本人可逐项核对应发项目、数额与代扣、代缴、扣除项
- **台账内容清单**（第15条）：用人单位名称、支付周期、支付日期、支付对象姓名/身份证号码/联系方式、工作时间、应发工资项目及数额、代扣/代缴/扣除项目和数额、实发工资数额、银行代发工资凭证或农民工签字
- **不可抗力**（第14条第2款）：因不可抗力未能在支付日期支付工资的，"不可抗力消除后及时支付"——只豁免迟延时点，不豁免支付义务

## Anti-patterns
- ❌ 以实物、购物卡、有价证券替代工资 → 第11条禁止以实物或有价证券替代；罚则：责令限期改正，逾期不改正的，对单位处2万–5万元罚款、对法定代表人/主要负责人/直接负责的主管人员和其他直接责任人员处1万–3万元罚款（第54条）
- ❌ 按月支付但拖延至次月下旬甚至更晚 → 第12、13条：应按工资支付周期和具体支付日期**足额**支付；"每月支付一次"是周期上限，不是"月+α"缓冲
- ❌ 遇节假日不提前支付反而延后 → 第14条：具体支付日期遇法定节假日或者休息日的，应当在**前**支付
- ❌ 不编制或不保存工资支付台账 → 第15条要求按支付周期编制+至少保存3年；欠薪争议中用人单位不提供台账、清单等材料的，依法承担不利后果（第50条）
- ❌ 克扣工资不做逐项说明 → 台账须逐项记载代扣、代缴、扣除项目和数额（第15条），工资清单提供本人核对（第15条）※（可扣除项目范围依法及地方口径执行）

## Worked Example
某工厂约定每月15日发工资，遇春节假期（初一为1月22日），1月15日为周日。工厂应在何时支付1月工资？
→ 1月15日为休息日，应提前至1月14日（周五）支付。若延后至春节后支付，违反第14条。

场景展开：工人老赵在该工厂务工（12月工资5500元），工厂工资支付日期为每月15日。今年1月15日为休息日，春节假期自1月21日至27日。
→ 判定与处理：
1. 支付时点：按第14条，具体支付日期遇休息日，应当在1月15日之前（即1月14日或更早完成转账）支付
2. 若工厂拖延至春节假期结束后（如2月1日）才转账 → 构成拖欠农民工工资（第3条），老赵有权依法投诉、申请调解仲裁或提起诉讼（第10条）
3. 证据：工厂应当已按该支付周期编制书面工资支付台账并至少保存3年（第15条），并向老赵提供工资清单；老赵争议仲裁/诉讼的，工厂应当提供劳动合同、职工名册、工资支付台账和清单等材料，不提供的依法承担不利后果（第50条）
4. 后果：人社部门可责令限期支付；逾期仍不支付的，依照有关法律规定执行（第53条）；情节严重的，可列入失信联合惩戒名单（第48条）

## Key Takeaways
- 货币支付+按月支付+节假日提前支付是三项强制要求
- 工资台账保存3年是举证关键，无台账可能承担不利后果
- 台账须"按周期编制"（第15条），应发/实发、代扣代缴扣除项目逐项列明——核对工资计算的底线
- 不可抗力只顺延支付时点（第14条第2款"消除后及时支付"），不豁免支付义务
