# Chapter 6: 法律责任（第50–62条）

## Core Idea
对违反本条例的行为设定行政处罚、处分与刑事移送，形成"行政处罚+双罚+处分+刑事移送"的威慑。关键数字：**单位罚款2万–5万元（第54条）或5万–10万元（第55–57条）、金融机构2万–5万元（第58条）；责任人罚1万–3万元（第54条）**；工程领域违规逾期不改正的**责令项目停工**（第55、57条），情节严重限制承接新工程、降低或吊销资质（第55条）。另有：拖欠工资本身"依照有关法律规定执行"（第53条，衔接劳动合同法）；涉嫌拒不支付劳动报酬罪移送公安（第41条）；情节严重列入失信名单（第48条）；建设单位未提供支付担保或政府投资项目拖欠工程款的，限制新建项目并记入信用记录公示（第49条）。

## Key Concepts
- **双罚制**：对单位罚款 **2万–20万元**，对法定代表人/主要负责人/直接责任人罚款 **1万–5万元**（第53–60条）
- **违反工资支付形式/周期**（第53条）：未以货币支付、未按月支付、未提前支付等
- **违反台账管理**（第54条）：未编制或未保存工资支付台账
- **违反工程领域五项制度**（第55–58条）：未实名制、未开专用账户、未总包代发、未存保证金、未公示等
- **违反监督检查**（第59条）：拒绝、阻碍检查，隐匿销毁证据
- **恶意欠薪加重**（第60条）：有能力支付而拒不支付或以转移财产等方法逃避支付
- **信用惩戒**（第48条）：列入失信联合惩戒名单
- **刑事移送**（第49条）：涉嫌拒不支付劳动报酬罪的移送公安机关
- **双罚制**：同时处罚单位和直接责任人，防止"单位担责、个人脱身"
- **情节严重**：拖欠金额大、人数多、时间长、造成恶劣社会影响等
- **罚则矩阵**（第54–58条）：①实物/有价证券代付、未编台账/未提供清单、扣押工资卡→责令改正，逾期单位罚2万–5万元、责任人罚1万–3万元（第54条）；②总包未开专户/未存保证金/未实名制、建设单位未担保/未拨人工费/拒供资料→责令改正，逾期**项目停工**+罚5万–10万元，情节严重限接新工程、降低或吊销资质（第55、57条）；③分包未编表签字、总包未监督、未公示→罚5万–10万元（第56条）；④金融机构不配合查询→罚2万–5万元（第58条）
- **建设单位特别责任**（第57、49条）：未提供工程款支付担保、未足额拨付人工费用→停工+罚款（第57条）；政府项目拖欠工程款→限制新建、记入信用公示（第49条）
- **政府追责**（第59–61条）：政府投资资金不到位→限期拨付，逾期约谈、通报、处分（第59条）；建设单位未批先建、扩规模、增概算、未拨付→约谈负责人并作为业绩考核、晋升依据（第60条）；社会投资违规开工→处罚建设单位、处分负责人（第61条）
- **虚假讨薪禁止**（第52条）：编造虚假事实、非法讨薪，或以欠薪为名讨要工程款的，依法处理
- **用人单位举证义务**（第50条）：欠薪争议中用人单位应提供依法保存的劳动合同、职工名册、工资台账和清单，不提供的承担不利后果

## Anti-patterns
- ❌ 认为"罚款比发工资划算" → 欠薪总成本=拖欠工资本金+加付赔偿金（第53条依有关法律规定）+行政罚款+失信惩戒（第48条）+强制执行（第42条）+刑事风险（第41条移送），远高于支付工资
- ❌ 法定代表人试图以"不知情"为由逃避个人责任 → 双罚制：第54条对法定代表人/主要负责人等罚款，第48条将上述人员一并列入失信名单——"不知情"不是免责事由
- ❌ "处罚完就结案" → 行政处罚不替代清偿：责令支付决定不执行→申请法院强制执行（第42条）；工资债务不因罚款消灭
- ❌ 借工资争议之名讨要工程款 → 第52条：以欠薪为名讨要工程款依法处理——工程款争议走合同结算渠道（第24、25条）

## Worked Example
某总包单位未存储工资保证金且未实行总包代发，导致分包单位拖欠农民工工资80万元。可能面临什么处罚？
→ ① 对单位罚款5万–20万元（第55条）；② 对法定代表人/负责人罚款1万–5万元；③ 责令限期存储保证金、实行代发；④ 列入失信联合惩戒名单；⑤ 涉嫌犯罪的移送公安机关。

场景展开：某总包甲（法定代表人周某）某项目未开设工资专用账户、未存工资保证金、未实行实名制；劳务分包乙公司拖欠25名工人工资共80万元。
→ 处罚分解（按条）：
1. 甲未开设/使用专户、未存保证金/保函、未实名制 → 责令限期改正，逾期**项目停工**+处5万–10万元罚款，情节严重限制承接新工程、降低或吊销资质（第55条）
2. 乙未按月考核、编表并经工人签字 → 责令改正，逾期罚5万–10万元（第56条）
3. 清偿：甲对80万元**先行清偿**，再依法向乙追偿（第30条）
4. 失信：情节严重→甲、周某及直接责任人员列入失信名单，在招投标、融资贷款、市场准入等受限（第48条）
5. 刑事：乙责任人转移财产、逃匿或经责令仍不支付 → 涉嫌拒不支付劳动报酬罪，移送公安（第41条）※（构成标准按刑法及司法解释）
6. 兜底：责令支付决定不执行→申请法院强制执行（第42条）；甲一时难付→政府应急周转金垫付（第63条）※（地方标准）

## Key Takeaways
- 法律责任采用双罚制，单位和个人都要担责
- 欠薪的法律总成本（罚款+赔偿+失信+刑事）远高于按时支付工资
- 罚则矩阵：形式/台账/扣卡→2万–5万+1万–3万（第54条）；工程五制度→停工+5万–10万（第55、57条）/5万–10万（第56条）；金融机构→2万–5万（第58条）
- "单位+自然人"双线：罚款（第54条）+列失信名单（第48条）
- 政府项目特别追责：资金不到位→限期足额拨付、约谈、通报、处分（第59–60条）；社会投资→处罚建设单位+处分负责人（第61条）
