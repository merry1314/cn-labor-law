# Chapter 3: 工资清偿（第17–22条）

## Core Idea
确立欠薪清偿的责任主体链条，解决"找谁要工资"的核心问题。当用人单位发生主体变更或不具备资格时，明确由谁承担清偿责任。结构逻辑：**先找用人单位**（第16条：用人单位拖欠农民工工资的，应当依法予以清偿）；**再按主体形态穿透**——不具备合法经营资格的单位、个人/无资质单位派遣、发包给个人或无资质单位，依有关法律规定执行或由用人单位清偿并可追偿（第17–19条）；合伙企业、个人独资企业、个体经济组织不清偿的，由出资人依法清偿（第20条）；合并或分立的，实施前依法清偿，经与农民工书面协商一致的，由承继其权利义务的用人单位清偿（第21条）；主体资格消失（被吊销营业执照或登记证书、被责令关闭、被撤销或依法解散）的，申请注销登记前清偿，未清偿的主要出资人注册新用人单位前必须先清偿（第22条）。清偿链"用人单位→出资人/开办人→承继单位→发包单位"层层兜底；工程建设领域另加总包先行清偿、建设单位以未结清工程款为限先行垫付（第29–30、36–37条，见ch04）。

## Key Concepts
- **第一责任人**（第17条）：用人单位应当按照与农民工的书面约定或依法制定的规章制度，按时足额支付工资
- **不具备合法经营资格**（第18条）：单位招用农民工→**出资人或开办人**清偿；劳务派遣单位派遣农民工→**派遣单位**清偿；合伙企业/个人独资企业/个体经济组织→**出资人/经营者**清偿
- **合并/分立**（第19条）：用人单位合并或分立→**承继单位**清偿
- **主体资格消失**（第19条）：用人单位被吊销营业执照、责令关闭、撤销或决定提前解散→**出资人**清偿
- **建设单位/总包**（第20、21条）：工程建设领域按特别规定承担清偿责任（见 ch04）
- **个人承包/违法分包**（第22条）：不具备合法经营资格的单位或个人招用农民工→**发包单位**清偿
- **清偿责任链**：用人单位→出资人/开办人→承继单位→发包单位，层层兜底
- **先行清偿**：工程建设领域总包单位、建设单位有先行清偿义务，清偿后可追偿
- **追偿权**：清偿后可依法追偿（第18、19、30条）——"先行清偿"是对农民工的法定垫付，责任主体之间的内部分担另行处理
- **主体变更先清偿**（第21条）：合并或者分立时，应当**实施前**依法清偿拖欠工资；仅当经与农民工**书面协商一致**，才可由承继其权利义务的用人单位清偿——未经书面协商，清偿义务不自动转移
- **注销前清偿+新设限制**（第22条）：被吊销营业执照或登记证书、被责令关闭、被撤销或依法解散的，申请注销登记前清偿；未依规定清偿的主要出资人，应当在**注册新用人单位前**清偿——"先清旧账、再开新灶"

## Anti-patterns
- ❌ 以"包工头跑路"为由拒绝支付工资 → 清偿链不断裂：工程建设领域发包给个人导致欠薪的，由建设单位或者施工总承包单位清偿（第36条）；转包的，总包先行清偿（第30条）
- ❌ 以"工程款未到账"为由拖欠农民工工资 → 第29条：建设单位未按合同约定及时拨付工程款导致欠薪的，应当以未结清的工程款为限先行垫付；第35条：因工程数量、质量、造价争议，建设单位不得因此不拨付人工费用，总包不得因此不代发工资
- ❌ 主体变更后相互推诿清偿责任 → 第21条：合并/分立实施前清偿或书面协商由承继单位清偿；第22条：注销登记前清偿、主要出资人注册新单位前清偿
- ❌ "公司注销了=工资债消灭" → 第22条第2款：未清偿的，主要出资人应当在注册新用人单位前清偿拖欠工资——个人责任穿透到底

## Worked Example
甲公司将装修工程分包给无资质的乙（个人），乙招用10名农民工后拖欠工资20万元。农民工应向谁主张？
→ 根据第22条，甲公司（发包单位）应对乙招用的农民工工资承担清偿责任。若甲公司是总包单位，还应按第30条先行清偿。

场景展开：2022年，甲公司（具有一般承包资质）将某楼盘精装修工程分包给无资质个人乙，乙招用10名工人（月均工资1万元）自3月施工至11月。期满后拖欠工资20万元，12月乙失联。
→ 处理链：
1. 先向乙主张（第16条：拖欠工资应当依法清偿）——已失联，无法清偿
2. 甲公司将工程发包给不具备合法经营资格的个人导致欠薪 → 甲公司承担清偿责任（第22条）；工程建设领域发包给个人导致欠薪的，由建设单位或者施工总承包单位清偿（第36条）
3. 若甲公司为项目总包 → 先行清偿20万元，再依法向乙追偿（第30条）
4. 若甲公司仍不支付：工人向人社部门投诉，部门作出责令支付决定；不支付的，可申请人民法院强制执行（第42条）
5. 情节严重或造成严重不良社会影响的 → 甲公司及其法定代表人、直接负责的主管人员等列入拖欠农民工工资失信联合惩戒对象名单（第48条）；涉嫌拒不支付劳动报酬罪的，移送公安机关（第41条）

## Key Takeaways
- 欠薪清偿不随主体变更而消灭，总有兜底责任主体
- 个人承包/违法分包的，发包单位承担清偿责任——"选任不当，自行担责"
- 清偿时点=主体变更时点：合并/分立实施前（第21条）、注销登记申请前（第22条第1款）、主要出资人注册新单位前（第22条第2款）
- 先行清偿后有追偿权（第18、19、30条）；建设单位垫付以未结清工程款为限（第29条）
