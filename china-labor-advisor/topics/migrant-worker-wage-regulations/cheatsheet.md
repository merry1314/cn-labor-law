# 速查表（Cheatsheet）

## 核心数字

| 事项 | 数字 | 条文 |
|---|---|---|
| 工资台账保存期限 | ≥ 3 年 | 第15条 |
| 工资支付周期 | 至少每月 1 次 | 第13条 |
| 对单位罚款 | 2万–20万元 | 第53–60条 |
| 对法定代表人/负责人罚款 | 1万–5万元 | 第53–60条 |

## 工程建设领域五项制度

| 制度 | 要求 | 条文 |
|---|---|---|
| 实名制管理 | 总包单位对招用农民工实名登记 | 第23、24条 |
| 工资专用账户 | 总包开立专项账户支付工资 | 第26条 |
| 总包代发 | 总包代分包支付工资至农民工账户 | 第30条 |
| 工资保证金 | 按规定存储，可用银行保函替代 | 第31条 |
| 维权信息公示 | 施工现场设维权信息告示牌 | 第34条 |

## 欠薪清偿责任链

| 情形 | 清偿主体 | 条文 |
|---|---|---|
| 一般拖欠 | 用人单位 | 第17条 |
| 不具备合法经营资格 | 出资人/开办人 | 第18条 |
| 劳务派遣 | 派遣单位 | 第18条 |
| 合伙企业/独资企业/个体 | 出资人/经营者 | 第18条 |
| 合并/分立 | 承继单位 | 第19条 |
| 主体资格消失 | 出资人 | 第19条 |
| 建设单位未拨付工程款 | 建设单位先行清偿 | 第29条 |
| 分包单位欠薪 | 总包单位先行清偿 | 第30条 |
| 违法分包 | 发包/总包单位清偿 | 第22、36条 |
