# 操作模式（Patterns）

## "欠薪维权"四步走

**When to use**: 农民工被拖欠工资时

**How**:
1. **确认欠薪事实**：收集劳动合同/考勤记录/工资条/转账记录等证据；确认用人单位名称、欠薪金额、欠薪时段
2. **协商催讨**：向用人单位书面催讨（保留送达证据）；要求出具工资欠条
3. **行政投诉**：
   - 向当地**人力资源社会保障行政部门**投诉（劳动保障监察）
   - 工程建设领域可同时向**住建/交通/水利**行业主管部门投诉
   - 拨打 **12333** 或登录**全国根治欠薪线索反映平台**
4. **司法途径**：
   - 申请**劳动仲裁**（工资争议，时效1年）
   - 涉嫌拒不支付劳动报酬罪的，要求人社部门**移送公安机关**

**Trade-offs**: 行政投诉处理较快但执行力有限；仲裁周期较长（45+15日）但有强制执行力；两者可并行

## "工程建设领域欠薪"责任链锁定

**When to use**: 建设工程项目中农民工被拖欠工资

**How**:
1. **锁定总包单位**：工程建设领域总包单位对农民工工资支付负总责
2. **查五项制度**：
   - 是否已开立**工资专用账户**（第26条）
   - 是否实行**总包代发**（第30条）
   - 是否存储**工资保证金**/保函（第31条）
   - 是否实行**实名制管理**（第23条）
   - 是否设立**维权信息告示牌**（第34条）
3. **清偿主体顺位**：
   - 分包单位欠薪→**总包单位先行清偿**（第30条）
   - 建设单位未按约定拨付工程款导致欠薪→**建设单位先行清偿**（第29条）
   - 总包单位将工程违法分包给不具备资质的单位→**总包单位清偿**（第36条）
4. **动用保证金**：总包单位拖欠工资且符合条件的，人社部门可**动用工资保证金**支付（第45条）

**Trade-offs**: 工程领域清偿链长，需先确定欠薪发生的环节；保证金动用需满足法定条件，周期较长

## "工资支付合规审计"清单

**When to use**: 用人单位自查农民工工资支付合规性

**How**:
1. **支付形式**：是否以货币支付（第11条）；是否银行转账（第12条）
2. **支付周期**：是否至少每月支付一次（第13条）；节假日是否提前支付（第14条）
3. **台账管理**：是否编制书面工资支付台账并保存3年（第15条）
4. **工程领域五项制度**：实名制/专用账户/总包代发/保证金/公示（第23–34条）
5. **清偿预案**：合并分立、主体资格消失时是否安排清偿（第19条）

**Trade-offs**: 合规成本与欠薪风险的平衡；工程领域五项制度是强制要求，违反将面临罚款
