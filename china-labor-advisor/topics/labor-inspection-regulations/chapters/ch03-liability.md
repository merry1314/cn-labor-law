# Chapter 3: 法律责任（第23–32条）

## Core Idea
对违反劳动保障法律法规的行为设定行政处罚，包括责令改正、罚款、加付赔偿金等，是劳动监察的强制力保障。

## Frameworks Introduced
- **女职工/未成年工保护违法**（第23、24条）：每人罚款 **1000–5000元**；包括安排禁忌劳动、不定期体检、延长工时、夜班等
- **违法延长工时**（第25条）：警告+责令限期改正，可按**每人100–500元**罚款
- **拖欠工资/低于最低工资**（第26条）：
  - 责令限期支付工资差额
  - 逾期不付的，加付应付金额 **50%–100%** 赔偿金
- **违反社保规定**（第27条）：按《社会保险法》《社会保险费征缴暂行条例》处罚
- **妨碍监察**（第30条）：
  - 责令改正
  - 处 **2000–2万元** 罚款
  - 构成违反治安管理行为的，由公安机关处罚
  - 构成犯罪的，追究刑事责任
- **骗取社保待遇**（第28条）：责令退还，处骗取金额 **1–3倍** 罚款
- **报复投诉举报人**（第30条）：依法处理

## Key Concepts
- **加付赔偿金**：行政法上的赔偿责任，由人社部门责令，不同于仲裁中的经济补偿
- **双罚倾向**：多数违法行为既处罚单位也可处罚责任人

## Anti-patterns
- ❌ 认为"罚款比发工资划算"——加付赔偿金（50%–100%）+ 罚款 + 失信惩戒，总成本远高于按时支付
- ❌ 拒绝配合监察调查——妨碍监察本身就是违法行为（第30条）

## Worked Example
某公司拖欠10名员工工资合计20万元，人社部门责令限期支付后仍不支付。如何处罚？
→ ① 责令支付20万元工资；② 加付赔偿金10万–20万元（50%–100%）；③ 若有妨碍监察行为，另处2000–2万元罚款；④ 涉嫌拒不支付劳动报酬罪的，移送公安机关。

## Key Takeaways
- 拖欠工资的行政成本=工资本金 + 50%–100%加付赔偿金 + 潜在罚款 + 失信惩戒
- 妨碍监察是独立违法行为，会加重处罚
