# 速查表（Cheatsheet）

## 核心数字

| 事项 | 数字 | 条文 |
|---|---|---|
| 调查期限 | 60 个工作日（可延长 30 个） | 第17条 |
| 查处时效 | 违法行为 2 年内 | 第20条 |
| 拖欠工资加付赔偿金 | 应付金额 50%–100% | 第26条 |
| 违法延长工时罚款 | 每人 100–500 元 | 第25条 |
| 女职工/未成年工保护违法罚款 | 每人 1000–5000 元 | 第23、24条 |

## 监察职责范围（第10条）

| 事项 | 说明 |
|---|---|
| 规章制度 | 内部劳动保障规章制度合法性 |
| 劳动合同 | 订立、履行、解除、终止 |
| 童工 | 禁止使用童工 |
| 女职工/未成年工 | 特殊劳动保护 |
| 工时休假 | 工作时间和休息休假 |
| 工资 | 工资支付和最低工资标准 |
| 社保 | 参保和缴费 |
| 职介/培训 | 职业介绍、技能培训机构 |

## 投诉渠道

| 渠道 | 方式 |
|---|---|
| 12333 | 人社服务热线 |
| 现场 | 用工所在地县级/市级人社部门监察机构 |
| 网络 | 各地人社官网 / 全国根治欠薪线索反映平台 |

## 监察 vs 仲裁选择

| 维度 | 劳动监察 | 劳动仲裁 |
|---|---|---|
| 性质 | 行政执法 | 准司法 |
| 处理 | 责令改正、罚款 | 裁决、调解 |
| 时效 | 2年（第20条） | 1年（仲裁法） |
| 费用 | 免费 | 免费 |
| 适合 | 拖欠工资、违法工时、不缴社保等行政违法 | 经济补偿、赔偿金、合同解除等权利义务争议 |
