# 操作模式

## 模式1：组建工会流程

**步骤**：
1. **发起**：职工自愿联合（25人以上应建基层工会委员会；不足25人可联合建或选组织员）
2. **报批**：基层工会建立必须报上一级工会批准
3. **选举**：工会委员会由会员大会或会员代表大会民主选举产生（企业主要负责人近亲属不得参选）
4. **上级支持**：上级工会可派员帮助和指导组建，单位不得阻挠
5. **法人资格**：具备法人条件的，依法取得社会团体法人资格

**阻挠建会的救济**（第51条）：
- 向劳动行政部门举报 → 责令改正
- 拒不改正 → 提请县级以上政府处理
- 以暴力威胁阻挠 → 刑事责任

---

## 模式2：集体合同协商流程

**步骤**：
1. **提出要约**：工会或用人单位均可提出签订集体合同的要求
2. **平等协商**：双方代表进行平等协商
3. **草案通过**：集体合同草案提交职工代表大会或全体职工讨论通过
4. **签订**：工会代表职工与用人单位签订集体合同
5. **上级支持**：上级工会给予支持和帮助

**违约救济**：
- 用人单位违反集体合同 → 工会要求改正并承担责任
- 履行集体合同争议 → 协商 → 仲裁 → 诉讼

---

## 模式3：工会劳动权益交涉流程（五类侵权）

**适用情形**（第23条）：
1. 克扣、拖欠职工工资
2. 不提供劳动安全卫生条件
3. 随意延长劳动时间
4. 侵犯女职工和未成年工特殊权益
5. 其他严重侵犯职工劳动权益

**流程**：
```
发现侵权 → 工会代表职工交涉 → 要求采取措施改正
                                    │
                    ┌───────────────┴───────────────┐
                    │                               │
              单位研究处理并答复              单位拒不改正
                    │                               │
              （处理完毕）              工会提请当地政府依法处理
```

## 模式4：工会干部保护与维权

**保护措施**（第19条）：
- 专职主席/副主席/委员 → 劳动合同自动延长（相当于任期）
- 非专职主席/副主席/委员 → 劳动合同延长至任期期满

**被侵权时的维权**：
| 侵权行为 | 救济 | 条文 |
|---|---|---|
| 无正当理由调岗 | 劳动行政部门责令改正、恢复原工作、赔偿损失 | 第52条 |
| 侮辱诽谤/人身伤害 | 刑事责任或治安处罚 | 第52条 |
| 因履职被解除合同 | 恢复工作+补发报酬 或 年收入二倍赔偿 | 第53条 |
| 妨碍民主权利 | 县级以上政府责令改正 | 第54条 |

---

## 模式5：工会经费催缴

**流程**：
1. 用人单位按每月全部职工工资总额的**2%**拨缴工会经费（第43条）
2. 无正当理由拖延或拒不拨缴 → 工会向法院申请**支付令**（第44条）
3. 拒不执行支付令 → 申请**强制执行**（第44条）

**关键**：拨缴的经费在**税前列支**
