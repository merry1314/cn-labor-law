# ch01 总则与工会组织（第1–16条）

## Core Idea
工会法总则给劳动者三件套：**结社权**（第3条，任何组织和个人不得阻挠和限制）→ **组建门槛**（会员25人以上应当建立基层工会委员会，不足25人可单独或联合建立，第11条）→ **工会干部保护**（任期内劳动合同自动延长，第19条）。组建须报上一级工会批准（第12条），基层工会依法取得社会团体法人资格（第15条）；阻挠建会属行政违法（第51条），因工会活动被解除合同最高赔**本人年收入二倍**（第53条）。

## Key Concepts
- **结社权**（第3条）：以工资收入为主要生活来源的劳动者依法参加和组织工会的权利，不得被阻挠和限制
- **25人门槛**（第11条）：25人以上应当建立基层工会委员会；不足25人可单独建立、两个以上单位联合建立或选举组织员
- **民主集中制**（第10条）：工会委员会由会员大会或会员代表大会民主选举产生；企业主要负责人的近亲属不得作为本企业基层工会委员会成员人选
- **组建报批**（第12条）：基层工会建立必须报上一级工会批准
- **社团法人**（第15条）：基层工会具备法人条件的依法取得社会团体法人资格
- **任期自动延长**（第19条）：工会干部自任职之日起劳动合同期限自动延长至任期期满（个人严重过失或达到法定退休年龄除外）

## 核心框架

### 1. 工会性质与基本职责（第2、6条）
- **性质**（第2条）：工会是中国共产党领导的职工自愿结合的工人阶级群众组织，是党联系职工群众的桥梁和纽带
- **基本职责**（第6条）：维护职工合法权益、竭诚服务职工群众
- **维权机制**：通过平等协商和集体合同制度，推动健全劳动关系协调机制；通过职工代表大会组织职工参与民主管理

### 2. 结社权（第3条）★核心
- 在中国境内的企业、事业单位、机关、社会组织中以工资收入为主要生活来源的劳动者，不分民族、种族、性别、职业、宗教信仰、教育程度，都有**依法参加和组织工会的权利**
- **任何组织和个人不得阻挠和限制**
- 工会适应企业组织形式、职工队伍结构、劳动关系、就业形态等发展变化，依法维护劳动者参加和组织工会的权利

### 3. 工会组建（第10-12条）
- **民主集中制**（第10条）：工会各级组织按民主集中制原则建立；各级工会委员会由会员大会或会员代表大会民主选举产生；企业主要负责人的近亲属不得作为本企业基层工会委员会成员人选
- **组建条件**（第11条）：
  - 会员 **25人以上** → 应当建立基层工会委员会
  - 不足25人 → 可以单独建立，也可以由两个以上单位联合建立，或选举组织员
  - 女职工较多 → 可建立工会女职工委员会
- **上级工会指导**（第11条）：上级工会可派员帮助和指导职工组建工会，任何单位和个人不得阻挠
- **报批**（第12条）：基层工会、地方总工会、产业工会的建立，必须报上一级工会批准

### 4. 工会法人资格（第15条）
- 基层工会组织具备民法通则规定的法人条件的，依法取得社会团体法人资格

### 5. 工会干部劳动合同保护（第19条）★核心
- **专职主席/副主席/委员**：自任职之日起，劳动合同期限**自动延长**，延长期限相当于任职期间
- **非专职主席/副主席/委员**：自任职之日起，尚未履行的劳动合同期限短于任期的，劳动合同期限自动延长至任期期满
- **例外**：任职期间个人严重过失或达到法定退休年龄的除外

## When to use

- 职工想组建工会但单位阻挠时
- 工会干部任期内被解除劳动合同时
- 咨询工会组建条件和程序时

## Anti-patterns

- ❌ 认为单位可以拒绝建立工会——第11条规定25人以上"应当"建立，上级工会可派员指导
- ❌ 认为工会干部任期内可以正常解除合同——第19条劳动合同自动延长

## Worked Example

**场景**：某公司有职工100人，职工想组建工会，公司老板说"我不同意建工会"。

**分析**：
1. 100人超过25人，符合建立基层工会委员会的条件（第11条）
2. 老板无权拒绝——结社权是法定权利，任何组织和个人不得阻挠（第3条）
3. 上级工会可派员帮助和指导组建（第11条）
4. 阻挠建工会的法律责任（第51条）：劳动行政部门责令改正；拒不改正的，提请县级以上政府处理

**案例2（工会干部合同自动延长）**：张先生选任为基层工会专职主席，任职时其劳动合同还剩6个月未履行；任职3个月后公司以"合同到期不续签"为由通知终止。
1. 第19条：专职主席自任职之日起劳动合同期限**自动延长**，延长期限相当于任职期间——"到期不续签"通知不生效
2. 若公司强行终止：责令恢复工作并**补发报酬**，或给予**本人年收入二倍的赔偿**（第53条）
3. 若公司以调岗方式打击报复（无正当理由调动工作岗位）：责令改正、恢复原工作、赔偿损失（第52条）
4. 边界：任职期间**个人严重过失**或达到法定退休年龄的，自动延长不适用（第19条例外）

## Key Takeaways
1. 结社权是法定权利，单位无权拒绝建会；25人以上"应当"建立（第3、11条）
2. 上级工会可派员帮助指导组建；阻挠建会由劳动行政部门责令改正（第11、51条）
3. 工会干部任期内劳动合同自动延长，"到期不续签"不生效（第19条）
4. 企业主要负责人近亲属不得作为本企业基层工会委员会成员人选（第10条）
5. 因工会活动/履职被解除合同：恢复+补发报酬，或年收入二倍赔偿（第53条）
