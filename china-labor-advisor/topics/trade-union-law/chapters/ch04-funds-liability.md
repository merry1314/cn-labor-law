# ch04 经费财产与法律责任（第42–58条）

## Core Idea
两条主线：**经费保障**（第43条经费来源——会费+用人单位按**工资总额2%**拨缴+税前列支；第44条催缴——支付令→强制执行；第45条经费审查监督）+ **法律责任**（第50–56条：阻挠建会第51条；打击报复调岗工会干部第52条；因参加工会活动/履职被解除第53条——**年收入二倍赔偿**；妨碍民主权利/非法撤销工会/妨碍事故调查/拒绝协商第54条；侵占经费第55条）。

## Key Concepts
- **2%拨缴**（第43条）：建立工会组织的用人单位按每月全部职工工资总额2%向工会拨缴，税前列支
- **支付令路径**（第44条）：拖延/拒不拨缴→基层工会或上级工会向法院申请支付令→拒不执行申请强制执行
- **二倍赔偿**（第53条）：职工因参加工会活动、工会工作人员因履职被解除合同→恢复工作并补发报酬，或本人年收入二倍赔偿
- **阻挠建会行政违法**（第51条）：劳动行政部门责令改正；拒不改正提请县级以上政府处理；暴力威胁阻挠可追刑责

## 核心框架

### 1. 工会经费来源（第43条）★
工会经费的来源：
1. 工会会员缴纳的会费
2. **建立工会组织的用人单位按每月全部职工工资总额的2%向工会拨缴的经费**
3. 工会所属的企业、事业单位上缴的收入
4. 人民政府的补助
5. 其他收入

**税前列支**：拨缴的经费在税前列支
**用途**：主要用于为职工服务和工会活动

### 2. 工会经费催缴（第44条）
- 企业无正当理由拖延或拒不拨缴工会经费，基层工会或上级工会可以向当地人民法院申请**支付令**
- 拒不执行支付令的，工会可以依法申请人民法院**强制执行**

### 3. 经费监督（第45条）
- 工会根据经费独立原则，建立预算、决算和经费审查监督制度
- 各级工会建立经费审查委员会
- 经费收支定期向会员大会或会员代表大会报告，接受监督

### 4. 工会财产保护（第46-49条）
- 政府和用人单位应为工会办公和活动提供必要设施和活动场所（第46条）
- 工会财产、经费和国家拨给工会使用的不动产，任何组织和个人不得侵占、挪用和任意调拨（第47条）
- 工会所属的为职工服务的企事业单位，隶属关系不得随意改变（第48条）

### 5. 法律责任（第50-56条）★

| 违法行为 | 法律责任 | 条文 |
|---|---|---|
| 侵犯工会合法权益 | 提请政府或有关部门处理，或向法院起诉 | 第50条 |
| **阻挠职工参加/组织工会**或阻挠上级工会指导筹建 | 劳动行政部门责令改正；拒不改正的提请县级以上政府处理；以暴力威胁阻挠构成犯罪的追究刑事责任 | 第51条 |
| 对依法履职的工会工作人员**无正当理由调岗**打击报复 | 劳动行政部门责令改正、恢复原工作；造成损失的赔偿 | 第52条 |
| 对工会工作人员侮辱诽谤或人身伤害 | 构成犯罪的追究刑事责任；未构成的治安处罚 | 第52条 |
| **职工因参加工会活动被解除合同** | 责令恢复工作并补发被解除期间应得报酬，或给予**本人年收入二倍的赔偿** | 第53条 |
| **工会工作人员因履职被解除合同** | 同上 | 第53条 |
| 妨碍工会通过职代会行使民主权利 | 县级以上政府责令改正，依法处理 | 第54条 |
| 非法撤销、合并工会组织 | 同上 | 第54条 |
| 妨碍工会参加伤亡事故调查处理 | 同上 | 第54条 |
| 无正当理由拒绝平等协商 | 同上 | 第54条 |
| 侵占工会经费和财产拒不返还 | 工会可起诉，要求返还并赔偿损失 | 第55条 |
| 工会工作人员损害职工或工会权益 | 责令改正或处分；情节严重的罢免；赔偿损失；构成犯罪的追究刑事责任 | 第56条 |

### 6. 附则（第57-58条）
- 中华全国总工会会同有关国家机关制定机关工会实施本法的具体办法
- 本法自公布之日起施行

## When to use

- 单位不拨缴工会经费时
- 职工因参加工会活动被解除合同时
- 工会干部因履职被调岗或辞退时
- 工会组织被非法撤销或合并时
- 妨碍工会参加工伤事故调查时

## Anti-patterns

- ❌ 认为不拨缴工会经费没后果——第44条可申请支付令和强制执行
- ❌ 解除因参加工会活动的职工——第53条可获年收入二倍赔偿

## Worked Example

**场景**：职工王某因参加工会活动被公司解除劳动合同。

**维权**：
1. 依第53条，由劳动行政部门责令恢复工作并补发被解除期间应得报酬
2. 或选择不恢复劳动关系，主张**本人年收入二倍的赔偿**
3. 第53条的"二倍赔偿"是工会法特别规定，可与劳动合同法第87条赔偿金并行主张（具体以地方实践为准）

## Key Takeaways

1. 工资总额2%是工会经费，税前列支，单位无权"不拨"（第43条）
2. 拖延/拒不拨缴：工会可向法院申请支付令，拒不执行申请强制执行（第44条）
3. 阻挠建会/阻挠上级工会指导筹建：劳动行政部门责令改正，拒不改正提请政府处理（第51条）
4. 对工会干部打击报复调岗：责令改正、恢复原工作、赔偿损失（第52条）
5. 因参加工会活动/履职被解除：恢复+补发报酬，或年收入二倍赔偿（第53条）
