# 术语表（按条文）

| 术语 | 条文 | 定义/说明 |
|---|---|---|
| 工会 | 第2条 | 中国共产党领导的职工自愿结合的工人阶级群众组织 |
| 结社权 | 第3条 | 劳动者依法参加和组织工会的权利，不得阻挠限制 |
| 基层工会委员会 | 第11条 | 会员25人以上的用人单位应当建立的工会组织 |
| 民主集中制 | 第10条 | 工会组织的建立原则，委员会由会员民主选举产生 |
| 工会法人资格 | 第15条 | 基层工会具备法人条件的，依法取得社会团体法人资格 |
| 工会干部合同保护 | 第19条 | 工会主席/副主席/委员任职期间劳动合同自动延长 |
| 集体合同 | 第21条 | 工会代表职工与用人单位签订的集体劳动协议 |
| 解除合同通知工会 | 第22条 | 单位单方面解除合同应事先将理由通知工会 |
| 劳动权益交涉 | 第23条 | 工会对五类侵权情形代表职工与单位交涉 |
| 三同时 | 第24条 | 劳动安全卫生设施与主体工程同时设计、施工、投产 |
| 紧急撤离建议 | 第25条 | 危及生命安全时工会有权建议组织职工撤离 |
| 伤亡事故调查 | 第27条 | 工伤事故调查处理必须有工会参加 |
| 三方协商机制 | 第35条 | 劳动行政部门+工会+企业代表共同研究劳动关系问题 |
| 职代会 | 第36条 | 国有企业民主管理的基本形式 |
| 工会活动时间 | 第41条 | 非专职委员每月不超过3个工作日，工资照发 |
| 工会经费 | 第43条 | 会费+单位按工资总额2%拨缴+上缴+补助+其他 |
| 支付令 | 第44条 | 拒不拨缴经费时工会可向法院申请 |
| 二倍赔偿 | 第53条 | 因工会活动/履职被解除合同，可获年收入二倍赔偿 |
