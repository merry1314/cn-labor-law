# 速查表

## 高频数字卡

| 数字 | 含义 | 条文 |
|---|---|---|
| **25人** | 应当建立基层工会委员会的会员数底线 | 第11条 |
| **2%** | 用人单位按每月全部职工工资总额拨缴工会经费的比例 | 第43条 |
| **3个工作日** | 非专职委员每月占用工作时间的上限（工资照发） | 第41条 |
| **二倍** | 因工会活动/履职被解除合同的赔偿倍数（本人年收入） | 第53条 |

## 维权流程卡

### 阻挠建工会
```
阻挠建会 → 劳动行政部门责令改正 → 拒不改正 → 县级以上政府处理 → 暴力威胁 → 刑事责任
```

### 因工会活动被解除合同
```
被解除合同 → 劳动行政部门责令恢复工作+补发报酬
                      或
            主张本人年收入二倍赔偿（第53条）
```

### 工会经费催缴
```
不拨缴经费 → 法院申请支付令 → 拒不执行 → 强制执行
```

## 五类工会交涉情形

1. 克扣、拖欠职工工资
2. 不提供劳动安全卫生条件
3. 随意延长劳动时间
4. 侵犯女职工和未成年工特殊权益
5. 其他严重侵犯职工劳动权益
