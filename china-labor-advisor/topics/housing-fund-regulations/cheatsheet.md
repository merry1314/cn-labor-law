# Cheatsheet — 住房公积金管理条例（2019修订）速查

## 版本信息

| 项 | 内容 |
|---|---|
| 全称 | 住房公积金管理条例 |
| 发布 | 1999-04-03 国务院令第262号 |
| 修订 | 2002-03-24 第一次；**2019-03-24** 第二次 |
| 施行 | 1999-04-03（自发布之日，第47条） |
| 结构 | 7章47条 |
| 定位 | **行政法规**——与社保法并行的独立体系（缴存走公积金管理中心，非社保征收） |
| 热线 | **12329**（公积金） vs 12333（社保） |

## 缴存速查（"交多少"）

| 项 | 规则 | 条文 |
|---|---|---|
| 缴存基数 | 本人**上一年度月平均工资**（新职工首年=**当月工资**） | 16、17条 |
| 基数夹逼 | 地方上下限（下限最低工资/上限常3倍社平※） | ※地方 |
| 缴存比例 | 职工、单位**各≥5%**；实践**上限12%**（超12%不得税前扣除※） | 18条+※ |
| 月缴存额 | 基数 × 比例 × **2**（个人+单位双边）——**全部归职工** | 16、3条 |
| 新职工起缴 | 参加工作**第二个月**起；调入=发工资之日起 | 17条 |
| 单位登记 | 设立起**30日**；录用职工起**30日** | 14、15条 |
| 离职手续 | 终止起**30日**转移或**封存** | 15条二 |
| 汇缴时限 | 发工资起**5日内** | 19条 |
| 计息 | 存入起按国家规定利率（一年期定存※） | 21条 |

## 提取六情形（第24条）

| 情形 | 账户处理 |
|---|---|
| 购买/建造/翻建/大修自住住房 | 部分提取 |
| **离休、退休** | **销户全取** |
| 完全丧失劳动能力+终止劳动关系 | **销户全取** |
| 出境定居 | **销户全取** |
| 偿还购房贷款本息 | 部分提取（冲还贷※） |
| **房租超出家庭工资收入规定比例** | 部分提取（地方比例※） |
| 死亡/宣告死亡 | 继承人/受遗赠人提取（24条三） |
| **离职本身** | ❌ 不是提取情形——**封存/转移**（15条二） |

## 程序时限卡

| 事项 | 时限 | 条文 |
|---|---|---|
| 提取决定 | 受理起**3日** | 25条 |
| 贷款决定 | 受理起**15日** | 26条 |
| 复核答复 | 申请起**5日**（书面） | 36条 |
| 单位不登记→限期办理→罚款 | 逾期处**1万–5万** | 37条 |
| 不缴少缴→责令→强制执行 | 逾期仍不缴→**法院强制执行** | 38条 |

## 劳动者三权（第34、36条）

| 权利 | 内容 |
|---|---|
| **督促权** | 督促单位办登记/设账户/**足额缴存**（34条） |
| **查询复核权** | 查询缴存提取情况**不得拒绝**；异议→银行复核→管理中心复核→**5日书面答复**（36条） |
| **检举权** | 揭发检举控告挪用行为（36条） |

## 投诉路径分流

| 争议 | 通道 | 依据 |
|---|---|---|
| 不办公积金登记/不设账户 | 公积金管理中心→限期→**1万–5万罚款** | 37条 |
| 不缴/少缴/低基数 | 管理中心→责令限期缴存→逾期**法院强制执行** | 38条 |
| 单位拒出提取证明 | 管理中心反映（多地已免单位环节※） | 25条+※ |
| **公积金争议走劳动仲裁？** | ❌ 不属于劳动争议受案范围（※实践口径）——走**行政** | — |
| 社保问题 | 12333（社保稽核/税务） | 社保法 |

## 单位侧合规红线（HR自查）
- 录用30日内办缴存登记+设账户（15条）——"转正才办"违法
- 基数=上年月均工资（16条）——按最低工资/基本工资缴=少缴
- 比例≥5%（18条）；缓缴须**职代会/工会+审核+批准**（20条）
- 发工资5日内汇缴（19条）；离职30日内办封存转移（15条二）
- **不可现金替代**（19条汇缴专户）
- 不办=1万–5万罚款（37条）；不缴=强制执行（38条）

## 关键数字卡

```
5%        比例下限（双边各≥5%）
12%       实践上限（超12%不得税前扣除※）
30日      单位登记 / 录用登记 / 离职封存转移
20日      设立后办账户（新设单位）
5日       发工资后汇缴 / 复核书面答复
3日       提取决定
15日      贷款决定
1万–5万   不登记/不设账户罚款
2倍       月缴存额=基数×比例×2（全归职工）
一年定存   计息利率※
12329     公积金热线
```

## 高频误判卡

| 误判 | 正解 |
|---|---|
| "公积金是福利，可不缴" | 城镇单位+在职职工=**法定义务**（2条）；不缴=责令+强制执行（38条） |
| "试用期不缴" | 录用30日内登记（15条）；第二个月起缴（17条） |
| "单位缴的是公司的钱" | **全部归职工个人所有**（3条） |
| "按最低工资缴合规" | 基数=上年月均工资（16条）——低缴=少缴，可投诉补差 |
| "离职就能全取" | 离职≠提取情形——**封存/转移**；销户仅退休/失能离职/出境（24条） |
| "去劳动仲裁告公积金" | 不属劳动争议受案范围※——找**公积金管理中心**（12329） |
| "公司发现金替代" | 必须汇缴专户（19条）——现金替代=损失双倍缴存+贷款资格 |
| "经营困难可随时停缴" | 缓缴须**民主程序+审核+批准**（20条），好转后补缴 |
