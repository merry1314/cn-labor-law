# 住房公积金管理条例（2026第三次修订）

## Core Frameworks & Mental Models

### 1. "交多少"三要素（第3、16、18条）
- **基数** = 本人**上一年度月平均工资**（新职工首年=**当月工资**，第17条）；地方上下限夹逼※
- **比例** = 职工、单位**各≥5%**；**不得高于国家规定的最高缴存比例**（第18条，2026修订后删除原"原则上不高于12%"的条例内表述，12%仍为实践中执行的全国上限※）
- **月缴存额** = 基数 × 比例 × **2**（双边**同基数**）——个人缴+单位缴**全部归职工个人所有**（第3条）
- 单位缴存部分**按规定计入有关成本费用**，国家机关、事业单位在预算中列支（第23条）——"1:1 翻倍"的隐性薪酬

### 2. 缴存义务与手续（第15、19、20条）
- **录用30日**办登记+设账户；**终止30日**办变更登记+账户**转移或封存**（第15条）
- **新职工第二个月起**缴（试用期必缴）（第17条）
- 发工资起**5日内汇缴**专户（第19条）——**现金替代无效**
- **按时足额**；困难缓缴须**职代会/工会通过+管理中心审核+管委会批准**三道程序（第20条）

### 3. 提取"九把钥匙"（第24条）
- **住房消费类**（不销户）：①支付房租 / ②购建翻修自住住房 / ③偿还购房贷款本息 / ④**装修自住住房（2026新增）** / ⑤**支付自住住房物业费（2026新增）** / ⑨国务院批准的其他住房消费情形
- **销户类**：⑥离休、退休 / ⑦完全丧失劳动能力+终止劳动关系 / ⑧出境定居
- **离职本身≠提取情形**——账户封存/转移，钱还在且计息（第21条）
- 死亡→继承人/受遗赠人可提取（第24条三款）

### 4. 维权闭环（第35、37、39、40、41条）
- **三权**：督促权（35条，管理中心督促+职工有权督促）/ **查询+复核**（37条，复核**5日内书面答复**）/ 检举权
- **第39条**：不登记/不设账户→责令限期→逾期**5万–30万罚款**（2026修订：原1万–5万→5万–30万）
- **第40条**：不缴/少缴→**责令限期缴存**→逾期仍不缴→**申请法院强制执行**
- **第41条（2026新增）**：骗提→责令退回+**3年禁提禁贷**；骗贷→责令返还+**5年禁提禁贷**
- **通道**：公积金争议**不走劳动仲裁**（※实践口径）→ 找**公积金管理中心（12329）**行政投诉
- **公积金贷款**（26、27条）：**10日**决定（2026修订：原15日→10日）+须担保——利率低于商贷，额度与账户余额挂钩（地方细则）

## Scope & Limits

- **※地方口径密集**：缴存比例具体档位与最高比例执行、基数上下限（上限常3倍社平）、租房提取比例与额度、装修/物业费提取细则、贷款额度公式、缴存年限要求——**以当地公积金管理中心现行规定为准**（各城市差异大）
- **2026第三次修订要点（国令第844号，2026-09-20施行）**：提取情形扩至9种（新增装修、物业费）、贷款审批15日→10日、不登记罚款1-5万→5-30万、新增骗提骗贷禁提禁贷（3年/5年）、新增灵活就业人员自愿缴存、新增全国缴存记录互信互认、比例上限改为"国家规定的最高缴存比例"
- **不覆盖**：公积金**贷款纠纷**（民事合同）、**继承**细节（民法典继承编）——本模块止于行政缴存监管
- 2019 修订及之前条文主体现行有效；2026 修订为实体规则重大调整

本模块不构成法律意见；个案以当地公积金管理中心认定为准。
