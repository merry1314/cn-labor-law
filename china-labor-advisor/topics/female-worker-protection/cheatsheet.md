# 速查表（Cheatsheet）— 女职工劳动保护特别规定

## 基本信息
- **公布**：2012-04-28 国务院令第619号 | **条文**：16条+附录

## 三期保护对照表

| 阶段 | 核心保护 | 条文 |
|---|---|---|
| 孕期 | 7个月以上不加班/夜班；产检计工时；可调整岗位 | 第6条 |
| 产期 | 产假98天+难产/多胞胎；生育津贴；医疗费 | 第7、8条 |
| 哺乳期 | 1岁内不加班/夜班；每天1小时哺乳时间 | 第9条 |
| 通用 | 不得因三期降薪、辞退、解除合同 | 第5条 |

## 产假速算卡

```
98天（基础）
  +15天（难产）
  +15天×N（多胞胎，每多1个）
  +地方奖励假※（30–90天，查当地条例）

流产：
  <4个月 → 15天
  ≥4个月 → 42天
```

## 生育津贴公式

| 参保状态 | 计算公式 | 支付主体 |
|---|---|---|
| 已参保 | 单位上年度月均工资 ÷ 30 × 产假天数 | 生育保险基金 |
| 未参保 | 产假前工资 ÷ 30 × 产假天数 | 用人单位 |

※ 差额补足：津贴<本人工资时，部分地区单位补足差额

## 罚款标准

| 违法行为 | 罚款 |
|---|---|
| 违反孕期/产假/哺乳期保护 | 每人1000–5000元 |
| 违反禁忌劳动第1、2条 | 每人1000–5000元 |
| 违反禁忌劳动第3、4条 | 5万–30万元；情节严重关闭 |

## 维权途径卡

```
权益受损
  ├─ 投诉举报 → 人社/安监部门
  ├─ 调解仲裁 → 劳动人事争议仲裁委员会
  └─ 诉讼 → 法院（对仲裁不服；性骚扰可直接起诉）
```

## 高频误判卡

| 误判 | 正解 |
|---|---|
| 产假只有98天 | ❌ 各省另有奖励假30–90天※ |
| 产检算病假扣工资 | ❌ 产检时间计入劳动时间 |
| 哺乳期可以安排加班 | ❌ 1岁内不得加班/夜班 |
| 未参保就没有生育津贴 | ❌ 由单位按产假前工资支付 |
| 三期内绝对不能解除 | ⚠️ 第39条严重违纪仍可解除 |
| 生育津贴就是产假工资 | ⚠️ 已参保按单位月均，可能低于本人工资 |
