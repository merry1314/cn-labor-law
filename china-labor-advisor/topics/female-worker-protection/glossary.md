# 术语表（Glossary）— 女职工劳动保护特别规定

| 术语 | 条文 | 含义 |
|---|---|---|
| 三期 | 第5–9条 | 孕期、产期、哺乳期的合称 |
| 孕期 | 第6条 | 女职工怀孕期间 |
| 产期 | 第7条 | 生育及休产假期间 |
| 哺乳期 | 第9条 | 婴儿未满1周岁期间 |
| 产假 | 第7条 | 女职工生育享受的休假，基础98天 |
| 生育津贴 | 第8条 | 产假期间的工资性收入 |
| 产前检查 | 第6条 | 孕期医疗检查，时间计入劳动时间 |

| 禁忌劳动 | 第4条+附录 | 女职工因生理特点不宜从事的劳动 |
| 性骚扰 | 第11条 | 违背意愿，以言语/文字/图像/肢体等方式实施的骚扰 |
