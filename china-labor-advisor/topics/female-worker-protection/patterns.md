# 操作模式（Patterns）— 女职工劳动保护特别规定

## 1. 三期权益受损维权流程

**适用**：三期被降薪、辞退、解除合同、违法加班等

**步骤**：

1. **固定证据**
   - 劳动合同、工资条（证明原工资标准）
   - 降薪通知、辞退通知、解除通知书
   - 怀孕证明（B超、医院诊断）、出生证明
   - 考勤记录（证明加班/夜班）

2. **选择维权途径**
   - **投诉举报**：向人社部门、安监部门投诉（第14条）
   - **劳动仲裁**：主张补发工资、违法解除赔偿金、加班工资等
   - **诉讼**：对仲裁不服起诉；性骚扰可直接起诉

3. **主张权利**
   - 补发降薪差额
   - 违法解除：2N赔偿金（劳动合同法第87条）
   - 加班工资（150%/200%/300%）
   - 继续履行劳动合同（如愿意）

## 2. 产假天数速算

**步骤**：

1. 基础98天
2. + 难产：+15天（凭医院证明）
3. + 多胞胎：每多1个 +15天
4. + 地方奖励假※（查当地人口与计划生育条例，30–90天）
5. 流产：<4个月15天，≥4个月42天

**注意**：奖励假期间的工资待遇按当地规定执行※。

## 3. 生育津贴计算

**步骤**：

1. 确认参保状态
2. 已参保：
   - 津贴 = 单位上年度月平均工资 ÷ 30 × 产假天数
   - 支付主体：生育保险基金
3. 未参保：
   - 津贴 = 产假前工资 ÷ 30 × 产假天数
   - 支付主体：用人单位
4. 差额补足※：如津贴 < 本人工资，部分地区规定单位补足差额

## 4. 职场性骚扰取证与维权

**步骤**：

1. **取证**
   - 低俗信息截图（微信/短信/邮件）
   - 录音录像（注意合法性）
   - 证人证言
   - 向公司投诉的记录（邮件、聊天记录）

2. **向公司投诉**
   - 书面提交，要求公司调查处理
   - 保留提交证据

3. **外部维权**
   - 向公安机关报案（如构成治安违法）
   - 向妇联、工会求助
   - 申请人格权侵权诉讼（民法典第1010条）
   - 如公司未履行义务，可主张公司承担责任

## 5. 三期调岗合法性判断

| 判断要素 | 合法调岗 | 违法调岗 |
|---|---|---|
| 调岗原因 | 原岗位不适合孕妇（如接触有毒物质） | 因怀孕降职/边缘化 |
| 工资待遇 | 不降低 | 降低工资 |
| 工作强度 | 减轻或相当 | 加重 |
| 程序 | 协商一致或有医疗机构证明 | 单方强制 |
