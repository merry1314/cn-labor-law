# Chapter 1: 适用范围与基本义务（第1–5条）

## Core Idea

本规定适用于所有用人单位及其女职工，核心是确立女职工劳动保护的基本义务，特别是**三期（孕期、产期、哺乳期）内不得降薪、辞退、解除合同**的禁令。

## Frameworks

### 框架1：适用范围

```
适用主体（第2条）：
  国家机关、企业、事业单位、社会团体、个体经济组织、其他社会组织
  及其女职工

排除：无 —— 所有用人单位均适用，不区分所有制/规模
```

### 框架2：用人单位基本义务

| 义务 | 条文 | 内容 |
|---|---|---|
| 劳动保护义务 | 第3条 | 改善劳动安全卫生条件，进行劳动安全卫生知识培训 |
| 禁忌劳动告知义务 | 第4条 | 将属于女职工禁忌从事的劳动范围的岗位**书面告知**女职工 |
| 三期保护义务 | 第5条 | 不得因怀孕、生育、哺乳**降薪、辞退、解除合同** |

### 框架3：三期保护与劳动合同法联动

```
本规定第5条（实体禁令）：
  不得因三期 → 降薪 / 辞退 / 解除合同
      ↓ 配套
劳动合同法第42条（解除禁令）：
  三期女职工 → 不得依第40条（非过失性解除）、第41条（经济性裁员）解除
      ↓ 配套
劳动合同法第45条（顺延规则）：
  合同期满时处于三期 → 续延至三期期满
      ↓ 例外
仍可解除的情形：
  第39条（过失性解除）：严重违纪、严重失职、被追究刑事责任等
```

## Key Concepts

- **三期**：孕期（怀孕期间）、产期（生育及产假期间）、哺乳期（婴儿未满1周岁期间）
- **降薪**：降低工资报酬，包括基本工资、绩效、津贴等
- **辞退/解除**：用人单位单方解除劳动合同或聘用合同
- **禁忌劳动**：女职工因生理特点不宜从事的劳动（见附录，如矿山井下、第四级体力劳动强度等）

## Mental Models

**"三期绝对保护"思维**：三期内，女职工享有**解雇保护**——单位不得因三期原因降薪、辞退、解除。即使劳动合同到期，也必须顺延至三期结束。

**"例外仅第39条"思维**：三期保护不是绝对的，如女职工有严重违纪（第39条），单位仍可解除。但举证责任在单位，且必须有充分证据。

## Anti-patterns

- ❌ **怀孕后调岗降薪** —— 第5条，不得因怀孕降低工资；调岗须合理且不降薪
- ❌ **"三期内合同到期不续签"** —— 劳动合同法第45条，须顺延至三期期满
- ❌ **以"不能胜任工作"为由解除三期女职工** —— 第40条解除不适用于三期女职工
- ❌ **经济性裁员时裁掉三期女职工** —— 第41条裁员不适用于三期女职工
- ⚠️ **注意**：三期内如女职工有严重违纪（如旷工、严重违反规章制度），单位仍可依第39条解除

## Worked Example

**场景**：小李怀孕5个月，公司以"岗位调整"为由将其从主管降为专员，工资降低30%。

**分析**：
1. 公司因怀孕降薪，违反第5条（不得因怀孕降低工资）
2. 调岗合理性：公司需证明调岗基于合理理由（如原岗位不适合孕妇），且不得降低工资待遇
3. 小李可以：
   - 拒绝降薪，要求按原工资标准支付
   - 向劳动行政部门投诉（第14条）
   - 申请劳动仲裁，要求补发工资差额
   - 如因此被迫离职，可主张经济补偿（劳动合同法第38条）

## Key Takeaways

- 第5条是三期保护的**核心条款**：不得降薪、不得辞退、不得解除
- 劳动合同法第42、45条配套：不得非过失性解除/裁员，合同到期顺延
- 例外：第39条过失性解除仍适用，但单位举证责任重
- 调岗可以，但**不得降薪**，且须合理
