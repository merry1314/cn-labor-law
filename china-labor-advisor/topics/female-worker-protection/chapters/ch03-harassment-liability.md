# Chapter 3: 性骚扰防治与法律责任（第11–16条）

## Core Idea

本章规定了用人单位的性骚扰防治义务、违法行为的行政处罚标准，以及女职工的维权途径。性骚扰防治是本规定的一大亮点（第11条）。

## Frameworks

### 框架1：性骚扰防治义务（第11条）

```
用人单位义务：
  在劳动场所，预防和制止对女职工的性骚扰
      ↓ 配套（民法典第1010条）
  性骚扰定义：违背他人意愿，以言语、文字、图像、肢体行为
              等方式实施性骚扰
  单位三义务：预防、受理投诉、调查处置
```

### 框架2：行政处罚标准（第13条）

| 违法行为 | 处罚 | 执法部门 |
|---|---|---|
| 违反孕期保护（第6条2款）、产假（第7条）、哺乳期（第9条1款） | 责令限期改正 + 每人**1000–5000元**罚款 | 人社部门 |
| 违反禁忌劳动范围第1、2条 | 责令限期改正 + 每人**1000–5000元**罚款 | 安监部门 |
| 违反禁忌劳动范围第3、4条 | 责令限期治理 + **5万–30万元**罚款；情节严重责令停止作业或关闭 | 安监部门 |

### 框架3：维权途径（第14条）

```
权益被侵害
    │
    ├─ 投诉、举报、申诉（向人社、安监、工会、妇联）
    │
    ├─ 劳动人事争议调解仲裁（劳动争议仲裁委员会）
    │
    └─ 诉讼（对仲裁裁决不服，向法院起诉）
         └─ 就业歧视/性骚扰可直接起诉
```

## Key Concepts

- **性骚扰**：违背他人意愿，以言语、文字、图像、肢体行为等方式对他人实施性骚扰（民法典第1010条）
- **劳动场所**：办公区域、生产车间、工作相关的社交场合等
- **预防义务**：制定规章制度、开展培训、营造反骚扰文化
- **制止义务**：接到投诉后及时调查、处理、采取措施

## Mental Models

**"单位有义务"思维**：性骚扰防治不仅是个人问题，更是**用人单位的法定义务**。单位未履行预防和制止义务的，需承担责任。

**"多元维权"思维**：女职工权益被侵害时，可选择投诉、仲裁、诉讼等多种途径，也可同时向工会、妇联求助。

## Anti-patterns

- ❌ **单位对性骚扰不管不问** —— 第11条，单位有预防和制止义务
- ❌ **以"自愿"为由安排三期女职工加班/夜班** —— 即使女职工同意，也不得违反强制性规定
- ❌ **罚款协商"私了"不举报** —— 罚款是行政处罚，不因"私了"而免除
- ⚠️ **注意**：女职工三期保护是强制性规定，**不得通过约定排除**（如"自愿放弃哺乳时间"无效）

## Worked Example

**场景**：小张哺乳期（孩子8个月），公司要求其每天加班2小时，否则扣绩效。

**分析**：
1. 小张处于哺乳期（婴儿未满1周岁），公司不得安排加班（第9条）
2. 公司要求加班并以扣绩效相威胁，违反第9条
3. 处罚：人社部门责令限期改正，按每人1000–5000元罚款（第13条）
4. 小张可以：
   - 拒绝加班，保留公司要求加班的证据
   - 向人社部门投诉举报
   - 申请劳动仲裁，主张被扣的绩效
   - 如因此被迫离职，可主张经济补偿

**场景2**：职场性骚扰——同事经常发送低俗信息，向公司投诉后公司未处理。

**分析**：
1. 公司有预防和制止性骚扰的义务（第11条）
2. 公司接到投诉未处理，违反义务
3. 小张可以：
   - 向公安机关报案（如构成治安违法）
   - 申请劳动仲裁/起诉，主张人格权侵权
   - 要求公司承担相应责任
   - 向工会、妇联求助

## Key Takeaways

- **性骚扰防治**是用人单位的法定义务（第11条），不作为需担责
- 违反三期保护的罚款：每人**1000–5000元**；违反禁忌劳动：**5万–30万元**
- 维权途径多元：投诉/举报/仲裁/诉讼
- 三期保护是**强制性规定**，不得约定排除
