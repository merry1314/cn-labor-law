# G06 绩效与调岗审查

## 常见条款形态
- "考核末位者视为不能胜任工作，公司可解除"
- "公司可根据经营需要调整员工岗位与薪酬"
- "连续两个月绩效 C 以下降薪 20%"

## 红牌条款库

- **条款形态**："绩效考核排名末位的员工，视为不能胜任工作，公司可直接解除劳动合同"
- **定级**：🔴 违法（无效）
- **法律依据**：[劳动合同法第40条第二项](../../labor-contract-law/INDEX.md) + [解释一相关口径](../../labor-dispute-judicial-interpretations/INDEX.md)
- **为什么**：末位≠不胜任——排名末位是**相对评价**，总有一个人排末位，不等于**不能胜任**（客观标准）；即便真不胜任，也必须**先培训或调岗→再次不胜任→才能解除+N**——"末位直接解除"跳过法定程序=违法解除（2N）
- **应对**：被末位解除→仲裁主张违法解除（2N 或恢复）；公司须举证①客观考核标准②你确实不胜任③已先培训/调岗④再次考核仍不胜任——四环缺一即败诉

- **条款形态**："公司有权根据经营需要单方调整员工的工作岗位和工作地点"
- **定级**：🟡 有风险（程序/证据依赖）
- **法律依据**：[劳动合同法第35条](../../labor-contract-law/INDEX.md)（变更需协商一致）+ [第40条第一项](../../labor-contract-law/INDEX.md)
- **为什么**：岗位/地点/薪资是合同核心条款——**原则须协商一致**；实务认可"合理性调岗"例外※：①基于经营必需②无侮辱惩罚性③薪资相当④不具歧视侮辱性⑤不实质增加通勤负担——"无限调岗权"条款因排除协商权利而无效，但个案调岗若合理可能被支持
- **应对**：拒绝明显不合理调岗（降薪、边缘化、异地通勤）→ 继续原岗出勤留证；被以"不服从安排"解除→主张调岗本身违法=解除违法（2N）；被变相逼迫离职→按 38 条被迫解除+N

- **条款形态**："绩效连续 X 个月不达标的，公司可下调薪酬"
- **定级**：🟡 有风险（程序/证据依赖）
- **法律依据**：[劳动合同法第35条](../../labor-contract-law/INDEX.md) + [第40条](../../labor-contract-law/INDEX.md)
- **为什么**：①依据**约定明确的浮动薪酬结构**扣减（绩效部分按考核浮动）→ 可为 ②扣减**固定基本工资**或突破 [g04](g04-payroll.md) 底线 → 违法；"不达标"须有客观标准+真实考核
- **应对**：查合同薪酬结构——绩效浮动有约定依据；基本工资被单方下调=变更合同未协商→主张补差

- **条款形态**："公司调整组织架构时，员工应服从岗位安排，拒不服从视为严重违纪"
- **定级**：🟠 损害权益（可主张）
- **法律依据**：[劳动合同法第35条](../../labor-contract-law/INDEX.md) + [第26条](../../labor-contract-law/INDEX.md)
- **为什么**：把"服从一切调岗"包装成纪律义务，再以"严重违纪"解除——规避协商一致义务的组合拳；架构调整≠当然合理调岗（客观情况重大变化应走 40 条第三项：协商→N 解除）
- **应对**：识别该路径（架构调整→调岗→不服从→违纪解除）；拒不合理调岗被解除→主张违法解除；真属"客观情况重大变化"（部门整体撤销）→协商不成也应有 **N 补偿**，公司分文不给即违法

- **条款形态**："考核结果适用范围：晋升、调岗、降级、解除、薪酬全面挂钩，考核标准由公司另行制定"
- **定级**：🟡 有风险（程序/证据依赖）
- **法律依据**：[劳动合同法第4条](../../labor-contract-law/INDEX.md) + [解释一第50条](../../labor-dispute-judicial-interpretations/INDEX.md)
- **为什么**：考核制度直接涉及切身利益→须民主程序+公示；"另行制定"+不公示=考核随时可按需生成，解除依据不可预测
- **应对**：要求考核制度书面化并公示（走 g01 程序审查）；考核结果**签收留证**（不签收≠不知道，但可要求复核）

## 审查要点
1. **末位淘汰三连问**：末位=不胜任？（否）不胜任可直接解除？（否，先培训/调岗）解除有 N 吗？（有）
2. 调岗五要件：经营必需/薪资相当/无惩罚性/无侮辱性/通勤合理
3. 考核：客观标准+民主程序+公示+结果签收，四件套缺一抗辩点
4. "客观情况重大变化"（40 条三项）的正确出口是协商+**N**，不是违纪解除
