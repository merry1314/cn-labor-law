## 事故等级

| 等级 | 标准（《生产安全事故报告和调查处理条例》） |
|---|---|
| 特别重大 | 死亡≥30人 或 重伤≥100人 或 直接损失≥1亿元 |
| 重大 | 死亡10–29人 或 重伤50–99人 或 损失5000万–1亿元 |
| 较大 | 死亡3–9人 或 重伤10–49人 或 损失1000万–5000万元 |
| 一般 | 死亡1–2人 或 重伤1–9人 或 损失100万–1000万元 |
