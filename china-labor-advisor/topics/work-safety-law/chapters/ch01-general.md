# Chapter 1: 总则（第1–19条）

## Core Idea
总则确立全法的价值基础与主体框架：方针"**安全第一、预防为主、综合治理**"（第3条）+ **"管行业必须管安全、管业务必须管安全、管生产经营必须管安全"**（三管三必须）；生产经营单位**主要负责人是本单位安全生产第一责任人**（第5条）；单位必须**具备安全生产条件**、构建**双重预防机制**（第4条，平台经济等新兴领域同样适用）；国家实行**生产安全事故责任追究制度**（第16条）。记忆框架：单位负责（主体）+ 职工参与 + 政府监管 + 行业自律 + 社会监督（第3条）。

## Key Concepts
- **适用范围**（第2条）：境内从事生产经营活动的单位；消防、道路交通、铁路、水上交通、民用航空、核与辐射、特种设备等领域另有规定的，适用其规定
- **方针**（第3条）：安全第一、预防为主、综合治理
- **工作机制**（第3条）：生产经营单位负责、职工参与、政府监管、行业自律、社会监督
- **条件义务**（第4条）：必须具备安全生产条件，构建安全风险分级管控和隐患排查治理双重预防机制；平台经济等新兴行业、领域同样建立全员责任制（第4条第2款）
- **主要负责人责任**（第5条）：主要负责人是本单位安全生产第一责任人，对安全生产工作全面负责；其他负责人对职责范围内负责
- **从业人员权利义务**（第6条）：有依法获得安全生产保障的权利，并应当依法履行义务
- **工会监督**（第7条）：工会依法监督，组织职工民主管理和民主监督；制定或修改安全规章制度应听取工会意见
- **政府职责**（第8–11条）：国务院和县级以上政府制定并实施安全生产规划（第8条）、加强领导、建立协调机制（第9条）、明确乡镇/开发区监管力量
- **部门监管**（第10条）：应急管理部门综合监督管理；交通运输、住建、水利、民航等部门在各自职责范围内行业监管
- **标准义务**（第11条）：必须执行依法制定的保障安全生产的国家标准或者行业标准
- **委托服务**（第15条）：依法设立的技术、管理服务机构可接受委托提供安全生产技术、管理服务；**委托后保证安全生产的责任仍由本单位负责**
- **权责清单**（第17条）：县级以上政府组织编制安全生产权力和责任清单，公开并接受社会监督
- **科技推广**（第18条）：国家鼓励和支持安全生产科学技术研究和安全生产先进技术的推广应用
- **责任追究制度**（第16条）：依照本法和有关法律法规追究事故责任单位和责任人员的法律责任
- **奖励**（第19条）：对改善安全条件、防止事故、参加抢险救护有显著成绩的单位和个人给予奖励

## Anti-patterns
- **"安全交给专业机构就不归我管"**: 第15条第2款——委托技术服务机构提供技术、管理服务的，保证安全生产的责任**仍由本单位负责**
- **"法定代表人扛，我只管业务"**: 主要负责人=实际全面负责的人（通常即法定代表人或实际控制人，※实践口径），设分管副总不能替代第一责任人职责（第5条）
- **"政府会监管，等着检查就行"**: 单位主体责任在前，政府监管在后；"三管三必须"把安全责任压实到行业、业务、生产经营各管理环节（第3条）
- **"平台经济等新形态不受本法约束"**: 第4条第2款明确将平台经济等新兴行业、领域纳入，同样建立全员责任制并履行培训等义务

## Worked Example
五金加工厂（8名员工，老板=主要负责人）未投消防改造资金、无应急预案、未做安全培训。2025-05电气火灾致1人受伤。判定：
1. 厂必须**具备安全生产条件**并改善条件（第4条）；老板作为**第一责任人**全面负责（第5条），"规模小"不能免责
2. 政府侧：县级应急管理部门综合监管（第10条）+ 政府协调机制（第9条）；该行业监管职责不明确的，按业务相近原则确定部门（第10条第2款）
3. 责任追究（第16条落地）：主要负责人未履行安全生产管理职责→责令限期改正，处2万–5万元罚款（第94条第1款）；**导致发生生产安全事故**的→处上一年年收入40%罚款（第95条第1项）
4. 受伤职工依法享受工伤保险待遇（联动 work-injury-regulations）；该厂未依法参保（违反第51条）的，工伤保险待遇由用人单位按标准支付（《工伤保险条例》第62条※）；依照民事法律尚有赔偿权利的，有权提出赔偿要求（第56条第2款）

## Key Takeaways
- 主要负责人是安全生产第一责任人，事故责任最重
- 安全生产是多主体协同：单位负责、职工参与、政府监管
- 平台经济等新兴领域明确纳入适用范围（第4条第2款）
- 委托第三方机构管理安全**不转移**责任（第15条第2款）
- 事故责任追究制度贯穿全法（第16条）；安全国家/行业标准必须执行（第11条）
