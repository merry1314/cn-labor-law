# Chapter 2: 生产经营单位的安全生产保障（第20–51条）

## Core Idea
全法核心章：32条单位义务，按"**制度（第21–22条）→投入（第23条）→机构人员（第24–27条）→培训（第28–30条）→设施三同时（第31–34条）→场所设备（第35–42条）→双重预防（第41条）→特殊义务（第43–51条）**"成链。主要负责人**七项职责**（第21条）是全章总纲：责任制、规章与操作规程、培训计划、投入、双重预防+督查除患、应急预案、事故报告。2021修正要点：**双重预防机制**（第41条）、心理疏导（第44条）、燃气可燃气体报警（第36条第4款）、高危行业**安全生产责任保险强制投保**（第51条）。

## Key Concepts
- **安全条件**（第20条）：必须具备本法和有关法律、行政法规和国家标准/行业标准规定的安全生产条件；不具备的，不得从事生产经营活动
- **全员安全生产责任制**（第21–22条）：明确各岗位责任人员、责任范围和考核标准；**主要负责人七项职责**（责任制、规章制度与操作规程、教育培训计划、投入、双重预防+督查检查除患、应急预案、及时如实报告事故）
- **安全管理机构/人员**（第24条）：矿山、金属冶炼、建筑施工、运输单位和危险物品生产、经营、储存、装卸单位应设机构或配专职人员；其他单位从业人员**超100人**设机构或专职、**100人以下**配专职或兼职
- **安全投入**（第23条）：必需资金由决策机构、主要负责人或个人经营的投资人保证，并对投入不足导致的后果承担责任；安全生产费用按规定提取使用、成本中据实列支
- **"三同时"**（第31条）：建设项目安全设施与主体工程**同时设计、同时施工、同时投入生产和使用**，投资纳入概算；高危项目另需安全评价（第32条）、设计审查（第33条）、竣工验收（第34条）
- **安全教育培训**（第28条）：未经安全生产教育和培训合格的从业人员，**不得上岗作业**；被派遣劳动者纳入统一管理培训，实习学生相应培训
- **特种作业人员**（第30条）：必须经专门安全作业培训、**取得相应资格**，方可上岗作业
- **双重预防机制**（第41条）：安全风险分级管控+隐患排查治理；重大事故隐患排查治理情况向监管部门和职工（代表）大会报告
- **禁"三合一"**（第42条）：危险物品的车间、商店、仓库不得与员工宿舍同建筑内；出口、疏散通道不得占用、锁闭、封堵
- **危险作业安全管理**（第43条）：爆破、吊装、动火、临时用电等危险作业应安排专门人员现场安全管理
- **劳动防护用品**（第45条）：必须提供符合国家标准/行业标准的防护用品，并监督、教育按规则佩戴使用
- **发包出租**（第49条）：不得发包、出租给不具备安全生产条件或相应资质的单位/个人；应签专门安全协议并统一协调、管理、定期检查
- **保险**（第51条）：必须依法参加**工伤保险**；高危行业、领域应当投保**安全生产责任保险**

## Anti-patterns
- **"工程赶工期，先建后补安全设施"**: 第31条三同时——违法的：责令停止建设或停产停业整顿、限期改正，并处10万–50万元罚款；逾期未改正处50万–100万元（第98条）
- **"老师傅干了多年，不用特种作业证"**: 第30条——未持证上岗即违法（第97条第7项可处10万元以下罚款）
- **"宿舍就在厂房二楼，方便"**: 第42条"三合一"禁令+疏散通道不得锁闭（第105条可罚）
- **"包给有资质的队伍，安全与我无关"**: 第49条——发包方仍须签专门安全生产管理协议、统一协调管理、定期检查；未做的按第103条处罚
- **"防护用品发不发看员工意愿"**: 第45条——单位有"提供+监督教育"双重义务；未提供的处5万元以下罚款，逾期不改5万–20万元（第99条第5项）

## Worked Example
建筑公司A（120名从业人员）承建某危险物品仓库项目（2024-03开工）：
1. **三同时缺失**：安全设施未与主体工程同时设计即开工（违反第31条）；作为危险物品储存建设项目，还应进行安全评价（第32条）、安全设施设计报审（第33条）
2. **未验收先用**：2025-05竣工即投入使用，建设单位未组织安全设施验收（违反第34条第2款：验收合格后方可投入生产和使用）
3. **发现路径**：2025-06职工举报（第74条任何单位或个人均有权举报）→ 2025-07应急管理部门现场检查查实（第65条）
4. **单位责任**（第98条）：责令停止建设或停产停业整顿，限期改正，并处**10万–50万元**罚款，直接负责的主管人员和其他直接责任人员处2万–5万元罚款；逾期未改正的，处**50万–100万元**罚款
5. **个人责任**：主要负责人未履行第21条七项职责之一（组织制定并实施应急救援预案/保证投入等）——未发生事故的处2万–5万元，逾期不改5万–10万元并停产停业整顿（第94条第1款）

## Key Takeaways
- "三同时"、教育培训、防护用品是高发违法点
- 双重预防机制（风险管控+隐患排查）是2021年修正的重点制度
- 主要负责人**七项职责**（第21条）是全章总纲，"制度"是责任制的载体
- 不具备安全生产条件的，不得从事生产经营活动（第20条）
- 禁"三合一"（第42条）是小作坊高频事故源
- 不得发包出租给无资质/无条件的单位或个人（第49条）；高危行业强制投保安全生产责任保险（第51条）
