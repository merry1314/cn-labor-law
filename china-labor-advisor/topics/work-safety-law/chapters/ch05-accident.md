# Chapter 5: 生产安全事故的应急救援与调查处理（第81–89条）

## Core Idea
三段链条：**应急准备**（国家应急能力与信息系统第79条→政府应急预案第80条→单位预案+**定期演练**第81条；高危行业**必须建立应急救援组织**、规模小的指定兼职救援人员第82条）→**事故报告**（现场人员**立即**报告单位负责人→单位负责人"立即"如实报告当地应急管理部门第83条；"**1小时内**"的时限依据《生产安全事故报告和调查处理条例》（国令第493号）第9条※；部门逐级上报**每级不超过2小时**）→**调查处理**（科学严谨、依法依规、实事求是、注重实效第86条；调查组**60日内**提交报告493号令第29条；政府**15日内**批复493号令第32条；批复后**1年内**整改评估第86条第3款）。"**四不放过**"（原因未查清、责任人未处理、整改未落实、有关人员未受教育）贯穿全程。

## Key Concepts
- **应急救援预案**（第81条）：生产经营单位应制定本单位生产安全事故应急救援预案，与所在地县级以上政府预案相衔接，并**定期组织演练**
- **应急救援组织**（第82条）：危险物品生产、经营、储存单位和矿山、金属冶炼、城市轨道交通运营、建筑施工单位应建立应急救援组织；规模较小的可指定**兼职**应急救援人员，并配备必要的救援器材、设备、物资
- **事故报告**（第83条）：事故现场有关人员应当**立即**报告本单位负责人；单位负责人接到报告后应当迅速采取有效措施、组织抢救、防止事故扩大，并**立即如实**报告当地负有安全生产监督管理职责的部门；不得隐瞒不报、谎报或者迟报，不得故意破坏事故现场、毁灭有关证据
- **报告时限**（国令第493号※）：单位负责人自接到报告起**1小时内**报告（第9条）；情况紧急时现场人员可直接向政府部门报告（第9条第2款）；部门逐级上报**每级不超过2小时**（第11条）；自事故发生之日起**30日内**（道路交通事故、火灾**7日内**）伤亡人数变化的，及时**补报**（第13条）
- **事故调查**（第86条）：按事故等级由相应级别政府组织调查组（493号令第19条：特别重大国务院或授权部门、重大省级、较大设区的市级、一般县级）；事故调查报告依法及时向社会公布
- **事故等级**（493号令第3条※）：特别重大（死亡30人以上/重伤100人以上/直接经济损失1亿元以上）、重大（10–29人/50–99人/5000万–1亿元）、较大（3–9人/10–49人/1000万–5000万元）、一般（3人以下/10人以下/1000万元以下）；划分标准由国务院规定（本法第118条）
- **批复期限**（国令第493号第32条※）：重大、较大、一般事故，负责调查的政府自收到事故调查报告之日起**15日内**作出批复；特别重大事故**30日内**批复，延长不超过30日
- **整改评估**（第86条第3款）：批复后**1年内**组织对整改和防范措施落实情况评估，并及时向社会公开评估结果
- **政府部门责任**（第87条）：责任事故还应查明负有审查批准和监督职责的行政部门责任，有失职渎职的依法追究
- **禁止阻挠**（第88条）：任何单位和个人不得阻挠和干涉对事故的依法调查处理
- **统计公布**（第89条）：应急管理部门定期统计分析本行政区域事故情况并定期向社会公布

## Anti-patterns
- **"先私了再上报"**: 隐瞒不报、谎报或迟报→对主要负责人处**降级、撤职**+上一年年收入**60%–100%**罚款；逃匿的处**15日以下拘留**（第110条）
- **"小事故不用报"**: 一般事故也须1小时内报告、每级2小时逐级上报（493号令第9、11条※）；瞒报的部门/政府人员同样被处分（第111条）
- **"出事后负责人先离开创业/开会"**: 第50条——主要负责人应当**立即组织抢救**，并不得在事故调查处理期间**擅离职守**
- **"调查是政府的事，我们等着出结果"**: 第86条第2款——事故发生单位应当**及时全面落实整改措施**，落实情况接受工会和职工监督（493号令第33条※），批复后1年内还要被**整改评估**（第86条第3款）
- **"应急救援队只有大厂才要建"**: 第82条——高危行业必须建立应急救援组织；规模较小的至少指定**兼职**救援人员并配备器材物资

## Worked Example
化工物流公司D：2025-06-18 14:32易燃液体仓库起火。
1. **14:32**：现场仓管员**立即**报告总经理（第83条第1款）；总经理启动应急预案、组织疏散扑救，调查处理期间**不得擅离职守**（第50条）
2. **14:48**：总经理向事故发生地县应急管理局报告（**1小时内**，493号令第9条※；若拖到15:45才报=**迟报**，按第110条处罚）
3. **逐级上报**：县应急管理局**2小时内**报市、市报省（493号令第11条※）
4. **定级**：1人死亡、2人重伤、直接经济损失150万元→**一般事故**（493号令第3条※），由**县政府**组织事故调查组（493号令第19条※）
5. **调查与批复**：调查组自事故发生之日起**60日内**提交报告（可延长≤60日，493号令第29条※）；县政府自收到报告之日起**15日内**批复（493号令第32条※）
6. **责任**：单位处**30万–100万元**罚款（第114条第1项）；总经理未履行安全职责导致事故的，另处上一年年收入**40%**罚款（第95条第1项）+**撤职**；若30日内伤亡人数变化，及时**补报**（493号令第13条※）；批复后1年内整改评估结果向社会公开（第86条第3款）

## Key Takeaways
- 事故报告时限1小时，迟报/谎报将加重处罚（第110条：年收入60%–100%+可拘留）
- 事故批复期限15日（特别重大30日，493号令第32条※）
- 预案三段链：国家能力（第79条）→政府预案（第80条）→单位预案+定期演练（第81条）
- 高危行业必须建立应急救援组织，规模小可指定兼职人员（第82条）
- 调查报告60日+可延长60日（493号令第29条※）；每级上报≤2小时（493号令第11条※）
- 批复后1年内整改评估并公开（第86条第3款）
