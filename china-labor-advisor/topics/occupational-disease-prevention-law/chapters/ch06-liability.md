# Chapter 6: 法律责任（第69–84条）

## Core Idea
对违反职业病防治法的行为设定法律责任，包括行政处罚和刑事责任，形成有力威慑。记忆关键＝**罚款梯队**：违规越重罚得越重——1万以内（未报告，第74条）→10万以下（管理义务，第70条）→5万–10万（程序义务，第71条）→5万–20万（防护落实，第72、73条）→5万–30万（严重违规，第75条）→10万–50万（建设单位／严重损害，第69、77条），顶格伴停业、关闭和刑事引流（第78条）。

## Key Concepts
- **未做预评价/未落实三同时**（第69条）：责令限期改正、警告，可并处罚款
- **未如实告知危害**（第71条）：责令限期改正、警告，可并处罚款
- **未做职业健康检查**（第72条）：责令限期改正、警告，可并处罚款
- **未提供防护设施/用品**（第72条）：责令限期改正、警告，可并处罚款
- **造成职业病危害事故**（第77条）：责令限期治理，罚款；情节严重的，责令停止产生职业病危害的作业，或提请关闭
- **刑事责任**（第78条）：造成重大职业病危害事故或其他严重后果，构成犯罪的，追究刑事责任
- **罚款梯队明细**（第70–77条）：
  - 未报告职业病/疑似职业病：限期改正＋警告，可并处1万以内；弄虚作假2万–5万，直接责任人可降级撤职（第74条）
  - 管理义务缺失（检测未存档公布／未采取管理措施／未培训等）：警告＋限期改正，逾期10万以下（第70条）
  - 程序义务（未申报／无专人监测／未告知／未组织健检建档／未提供复印件）：限期改正＋警告，可并处5万–10万（第71条）
  - 防护落实不足（超标／未提供设施用品／未维修检测／未检测评价／未停止作业／未安排诊治／未应急报告／未设警示／拒检／拒供资料／未担费）：警告＋限期改正，逾期5万–20万；严重停业／提请关闭（第72条11项）
  - 严重违规（隐瞒危害采用／隐瞒真实情况／急性害放射场所不合规／用禁止设备材料／转移接受无防护作业／擅拆防护设施／安排未检禁忌未成年孕哺／违章强令）：限期治理＋处5万–30万；严重停业／提请关闭（第75条8项）
  - 严重损害生命健康：令停业／提请关闭＋并处10万–50万（第77条）
- **机构责任**（第79、80条）：无资质技术服务／超范围／虚假证明→没收违法所得＋2–10倍（2–5倍）罚款，吊销资格
- **鉴定委员会成员收财**（第81条）：警告＋没收财物可并处3千–5万，取消资格＋专家库除名
- **渎职追责**（第82、83条）：卫生行政部门未报告→令改正通报警告；虚瞒报处分；政府监管部门渎职致重大事故→记大过至开除
- **刑事引流**（第78、84条）：构成犯罪的依法追究刑事责任

## Anti-patterns
- **"罚款就是成本"**: 梯队顶格10万–50万（第69、77条），还伴停业关闭＋刑事责任（第78条）——违反预防义务的成本远超防护投入
- **"就是没报告而已"**: 未报告职业病疑似职业病→警告＋1万以内；弄虚作假2万–5万，责任人可降级撤职（第74条）——人也要负个人责任
- **"工人得病怪他体质"**: 安排禁忌未成年孕哺接触危害→限期治理＋5万–30万（第75条第（七）项）；造成严重损害→停业关闭＋10万–50万（第77条）
- **"机构出假报告不关我事"**: 技术服务诊断机构虚假证明→没收违法所得＋2–5倍＋吊销资格，构成犯罪刑事责任（第80条）
- **"私了就没什么行政处罚了"**: 行政处罚是公法义务，劳动者与单位私了不免除行政责任；受害者待遇按工伤规定另行办理（接ch04）

## Worked Example
2026年5月，某电池公司熔铅车间3名工人被诊断职业性铅中毒（1名患者重度贫血住院）。
1. **发生什么**（经调查发现）：①公司隐瞒工作场所铅尘浓度达国标4倍仍生产（第75条第（二）项）；②1名工人健检发现铅代谢异常（职业禁忌）仍安排熔铅岗（第75条第（七）项）；③造假工作场所检测报告（第72条第（十）项）；④已对劳动者生命健康造成严重损害（第77条）。
2. **适用哪几条**：第72、75、77、78条。
3. **判定过程**：隐瞒本单位职业卫生真实情况→限期治理＋处25万元（第75条第（二）项5万–30万区间）；安排禁忌者接触危害作业与①合并按第75条处理；造假检测评价结果→警告＋限期改正逾期5万–20万（本案8万元，第72条第（十）项）；对劳动者生命健康造成严重损害→责令停止产生职业病危害的作业＋并处30万元（第77条10万–50万区间）；本案行政罚款计63万元（示例）。
4. **结果**：车间停产整改；直接负责的主管人员涉嫌构成犯罪，依法追究刑事责任（第78条）；3名患者工伤待遇按工伤保险规定另行办理（见ch04；若未参加工伤保险全由公司承担，第59条）。

## Key Takeaways
- 未做职业健康检查和未提供防护用品是高发违法点
- 造成职业病危害事故可能追究刑事责任
- 罚款梯队：1万以内（第74条）→10万以下（第70条）→5万–10万（第71条）→5万–20万（第72、73条）→5万–30万（第75条）→10万–50万（第69、77条）
- 情节严重均伴停业／提请关闭；构成犯罪追刑事责任（第78、84条）
