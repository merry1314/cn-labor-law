# Chapter 4: 职业病诊断与职业病病人保障（第43–61条）

## Core Idea
规范职业病的诊断、鉴定程序和职业病病人的保障待遇，是劳动者权利救济的核心章节。记忆框架：**到哪诊**（第44条：单位所在地、户籍地、经常居住地三选）→ **依据什么**（第46条：三要素综合＋"必然联系"推定）→ **单位不给材料怎么办**（第47–48条：诊断机构依自述＋监管信息作出）→ **不服怎么告**（第52条：市级鉴定→省级再鉴最终）→ **诊出后怎么保障**（第56–59条：工伤保险＋民事赔偿＋未参保单位担）。

## Key Concepts
- **诊断机构**（第43条）：由省级以上卫生行政部门批准的医疗卫生机构承担
- **诊断机构条件**（第43条）：需《医疗机构执业许可证》＋人员设备质量制度，**不得拒绝**诊断要求
- **诊断地点选择**（第44条）：劳动者可在用人单位所在地、本人户籍所在地或者经常居住地的诊断机构进行诊断
- **诊断依据**（第46条）：①职业史、职业病危害接触史 ②临床表现及辅助检查 ③现场危害调查与评价
- **必然联系推定**（第46条第2款）：没有证据否定危害因素与临床表现必然联系的，**应当诊断为职业病**
- **单位供料义务**（第47条）：职业史、接触史、工作场所检测结果如实提供；可现场调查，卫生行政部门10日内组织
- **举证责任**（第49条）：用人单位不提供或不如实提供诊断所需资料的，诊断机构可根据劳动者自述、相关人员证明等作出诊断
- **缺料时的诊断结论**（第48条）：诊断机构结合临床表现、辅检、职业史、接触史、自述、监督检查信息作出；对资料有异议或单位解散破产的，卫生行政部门30日内判定
- **劳动关系等争议**（第49条）：劳动关系工种岗位在岗时间争议→30日裁决；证据在单位掌握的，限期提供否则担不利后果；单位程序结束后15日内可诉讼，期间治疗费走职业病待遇途径
- **鉴定程序**（第52条）：
  - 对诊断结论有异议的，30日内向**市级**卫生行政部门申请鉴定
  - 对鉴定不服的，15日内向**省级**卫生行政部门申请再鉴定
  - 省级鉴定为**最终鉴定**
- **诊断鉴定费用**（第53条）：**由用人单位承担**；鉴定专家省级专家库随机抽取
- **疑似病人保护**（第55条）：单位须安排诊断；诊断观察期间**不得解除或终止劳动合同**，费用由单位担
- **病人待遇**（第56条）：安排治疗康复定期检查；不适宜者调离妥善安置；给予适当**岗位津贴**
- **工伤保险待遇**（第57条）：职业病病人依法享受工伤保险待遇
- **民事赔偿权**（第58条）：除享有工伤保险外，尚有获得赔偿权利的，有权向用人单位提出民事赔偿
- **未参加工伤保险**（第59条）：用人单位没有依法参加工伤保险的，病人的医疗和生活保障由该用人单位承担
- **用人单位变更**（第60条）：用人单位发生分立、合并、解散、破产等情形时，应对从事接触职业病危害作业的劳动者进行健康检查，并按规定安置职业病病人
- **政府救助**（第61条）：用人单位不存在或无法确认劳动关系的，可向地方政府医疗保障、民政部门申请医疗和生活救助

## Anti-patterns
- **"公司不给检测数据，工人就诊断不了"**: 第48条——单位不提供检测结果的，诊断机构结合劳动者自述和日常监督检查信息作出结论；拒不提供造假→第72条第（十）项处罚
- **"公司破产了，职业病就没了"**: 第60条——分立合并解散破产须对接触者健康检查、妥善安置病人；单位不存在可向政府申请救助（第61条）
- **"先解聘再说诊断"**: 第55条——疑似职业病诊断观察期间**不得解除或终止劳动合同**，期间费用由单位承担
- **"工伤保险够了，没民事赔偿"**: 第58条——依民事法律尚有赔偿权利的，有权向单位提出赔偿——工伤保险与民事赔偿双轨并行
## Worked Example
老李，男，2014年入机床厂抛光岗（场地噪声92dB(A)，无防护），月薪8,200元，已参工伤保险。
1. **发生什么**：2026年1月社区医院纯音听力双侧高频平均45dB；2月向经常居住地诊断机构申请职业病诊断（第44条）。
2. **适用哪几条**：第44、46、47、48、52、53条。
3. **判定过程**：2026年3月诊断机构要求厂提供职业史接触史噪声检测结果（第47条）；厂只给2019年报告→老李对资料异议提请调查，卫生行政部门10日内现场调查（第47条第2款），认定厂2020年后未定期检测（第48条第2款）；5月诊断机构结合临床表现、辅检、职业史、接触史、自述、监督检查信息出具结论：**职业病（噪声性听力损伤）**（第46、48条）；6月厂申请鉴定，市级鉴定委员会（专家省级专家库随机抽取，第53条）维持；9月省级再鉴定再次维持，结论生效。
4. **结果**：全部诊断鉴定费用由厂承担（第53条）；厂未定期检测被令改正（第72条第（四）项，见ch06）；老李走工伤认定和劳动能力鉴定（见work-injury-regulations模块），厂安排治疗康复定期检，调离抛光岗（第56条）；若厂未参保则上述全由厂担（第59条）；老李可另依民法主张赔偿（第58条）。

## Key Takeaways
- 举证责任向劳动者倾斜：用人单位不提供资料时推定有利于劳动者
- 职业病病人可同时主张工伤保险和民事赔偿（第58条）
- 诊断地三选：单位所在地／户籍地／经常居住地（第44条）
- 诊断鉴定费用由单位承担（第53条）；疑似期间合同不得解除终止（第55条）
- 单位未参加工伤保险的，医疗和生活保障由单位承担（第59条）
