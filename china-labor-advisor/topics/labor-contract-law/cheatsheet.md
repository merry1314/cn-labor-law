## N/N+1/2N 速记

```
N    = 工作年限 × 月工资(前12个月平均)
       满1年=1个月；6个月以上不满1年=1个月；不满6个月=0.5个月
       社平3倍封顶 + 12年上限
N+1  = N + 代通知金1个月（仅40条无过错解除）
2N   = 违法解除/终止赔偿金（48条选择：继续履行 or 2N，不兼得）
```

**触发N的情形**：38条被迫解除；36条单位提出协商；40条解除；41条裁员；固定期限期满终止（单位未维持/提高条件）；单位破产/吊销/关闭/解散终止（第46条）
**无补偿情形**：39条过错解除；37条劳动者主动辞职；45条期满终止但单位维持/提高条件而劳动者拒续

## 劳动者高频请求清单（仲裁请求示例）

1. 支付未签书面劳动合同二倍工资差额（第82条）
2. 支付违法解除赔偿金 2N（第48、87条）或确认违法并要求继续履行
3. 支付拖欠工资/加班费/差额（第30、31条+劳动法44条）
4. 支付经济补偿 N（第46、47条）
5. 支付未休年假折算工资（※年休假条例+实施办法，300%含已发）
6. 补发试用期工资差额/违法试用期赔偿金（第20、83条）
7. 支付竞业限制经济补偿（※司法解释一第36条：30%标准）
8. 确认规章制度的"严重违纪"解除无效（第4、39条抗辩）
9. 出具离职证明+办理档案社保转移（第50条）
10. 派遣同工同酬差额（第63条）

## 解除合法性六问（速查卡）

1. 事由是哪条？39/40/41/协商？
2. 39条：单位举证+制度合法公示+确实"严重"？
3. 40条：医疗期满/先培训调岗/协商变更？30日或+1？
4. 41条：20人/10%+说明+听意见+报告？
5. 我在第42条六种人保护里吗？
6. 事先通知工会了吗？

**任一答"否"→ 违法解除 → 继续履行 或 2N（第48条，劳动者选）**
