# Chapter 3: 劳动合同的履行和变更 (Performance & Modification, 第29–35条)

## Core Idea
履行章确立"全面履行"原则（第29条），并给劳动者三件趁手工具：**支付令**（拖欠工资的法院快捷通道，第30条）、**拒绝违章指挥权**（第32条）、**变更须协商一致+书面形式**（第35条）。单位"换壳/合并/投资人变更"不影响合同履行（第33、34条）。

## Frameworks Introduced
- **全面履行原则（第二十九条）**：用人单位与劳动者应当按照劳动合同约定，全面履行各自义务
  - When to use: 一切履约争议的基准——单位降薪、调岗、缩短工时均须回到"合同约定"找依据
- **及时足额支付 + 支付令（第三十条）**：
  - 单位拖欠或未足额支付劳动报酬 → 劳动者可依法向当地人民法院申请**支付令**，法院应当依法发出
  - When to use: 欠薪事实清楚、金额明确时的最快路径（比仲裁快）
  - How: 向有管辖权基层法院申请 → 法院审查发出 → 单位15日内不提出书面异议又不履行的可申请强制执行（※《民事诉讼法》支付令程序）
  - 注意：单位提出书面异议且法院审查成立的，支付令失效，转入普通程序（可转仲裁）
- **加班强制规定（第三十一条）**：严格执行劳动定额标准；**不得强迫或变相强迫加班**；安排加班必须依法支付加班费
  - "变相强迫"高频形态：不批请假、以离职施压、以"自愿"名义强制、绩效考核绑架
- **拒绝违章指挥权（第三十二条）**：
  - 劳动者拒绝管理人员**违章指挥、强令冒险作业**的，**不视为违反劳动合同**
  - 对危害生命安全和身体健康的劳动条件，有权**批评、检举和控告**
  - When to use: 安全作业争议、工伤前纠纷；行使该权利不构成违纪，更不能据此解除
- **不影响履行的单位变更（第三十三条）**：变更名称、法定代表人、主要负责人或**投资人**等事项，不影响劳动合同履行
  - 常见"坑"：公司换老板/换注册名后以"新东家不认旧账"推脱工资——不成立
- **合并分立承继（第三十四条）**：单位合并或分立 → 原劳动合同**继续有效**，由承继权利义务的单位继续履行
- **变更规则（第三十五条）**：
  - 变更合同内容须**协商一致**
  - 变更必须采用**书面形式**
  - 变更后的文本双方各执一份
  - When to use: 单位单方降薪、调岗、变更工作地点的审查——未经协商一致的书面变更，劳动者可拒绝并要求按原合同履行
  - 例外：单位依第40条（医疗期满/不胜任/客观情况变化）协商变更不成而解除的，属解除而非变更

## Key Concepts
- **支付令**：法院督促单位支付欠薪的非诉快捷程序（第30条）
- **变相强迫加班**：以考核、请假审批等手段迫使加班的隐性形态（第31条）
- **承继**：合并、分立、投资人变更下的合同延续机制（第33、34条）
- **书面变更**：合同变更的形式要件（第35条）

## Mental Models
- "三件工具"模型：欠薪 → 支付令（最快）；危险作业 → 拒绝权（保命）；乱改合同 → 协商+书面原则（守住约定）
- 把第33/34条理解为"合同跟着岗位走，不跟着老板走"：公司主体形式变化不消灭既有权利义务，欠薪、年休假折算等继续算
- 变更审查两问：协商一致了吗？书面了吗？——两问任一为否，原合同条款继续有效

## Anti-patterns
- **单方调岗降薪**: 未协商一致书面变更，直接发调岗通知——劳动者可拒绝并按原合同主张；若被迫辞职，可走第38条（未按约定提供劳动条件/未足额付酬）+第46条（一）主张经济补偿
- **以"经营需要"变相强迫加班**: 第31条禁止；加班费照常计算（※加班费基数按约定工资）
- **换壳逃债**: 公司更名、换法定代表人、股权100%变更后拒付工资——第33条明确不影响履行
- **口头变更长期履行**: 口头降薪且劳动者继续工作较长时间的，※司法实践中可能视为已变更（《劳动争议司法解释一》第43条：变更且实际履行超过一个月，书面形式的除外，除非违反法律强制性规定）——建议对任何变更保留书面异议（微信/邮件明确"不同意降薪"）

## Worked Example
公司因业绩下滑，2025-05-01 全员邮件通知"工资下调15%，至另行通知"，未与员工协商。员工小王：(1) 该变更未经协商一致且非针对个人的书面协议 → 第35条变更无效，应恢复原工资；(2) 若公司坚持少发，属"未及时足额支付劳动报酬" → 小王可走第38条（二）被迫解除 + 第46条（一）经济补偿，或继续工作并主张工资差额；(3) 欠薪金额明确的，也可直接向法院申请支付令（第30条）——这是比仲裁更快的通道；(4) 全程保留：原合同工资条款、降薪邮件、每月工资流水对比、书面异议记录。

## Key Takeaways
1. 全面履行是原则，合同条款是标尺——任何降薪、调岗、改地点先查合同约定
2. 拖欠/未足额付酬 → 支付令（第30条）是最快的法院通道
3. 拒绝违章指挥不视为违约（第32条）——保命权利，单位不得报复
4. 名称/法定代表人/投资人/合并分立变更 → 合同继续有效（第33、34条）
5. 合同变更 = 协商一致 + 书面形式 + 双方各执一份（第35条）；单方通知不成立
6. 对变更的持续默认可能产生效力（※司法解释一第43条），务必保留书面异议
