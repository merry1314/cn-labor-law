# Chapter 4: 劳动合同的解除和终止 (Rescission & Termination, 第36–50条)

## Core Idea
解除章是全书争议最密集的部分：解除权按"协商/劳动者预告/劳动者即时/单位过错即时/单位无过错预告(N+1)/经济性裁员"六通道分配；**第42条六种人**不得无过错解除或裁员；**第46条**列举应付经济补偿的七种情形；**第47条**给出N的计算公式（含三倍社平封顶+12年上限）；**第48/87条**确立违法解除的"继续履行或2N"选择权；**第50条**规定离职证明与15日转移档案社保的法定义务。

## Frameworks Introduced
- **协商解除（第三十六条）**：协商一致可以解除
  - 补偿触发看"谁提出"：单位提出并协商一致的 → 应付补偿（第46条二）；劳动者提出的 → 无补偿
- **劳动者预告辞职（第三十七条）**：提前**30日书面**通知可解除；试用期内提前**3日**通知
  - 无需单位同意——到期自动生效；"辞职未批"不构成继续劳动关系
- **劳动者即时辞职（被迫解除，第三十八条）**：
  - 六种情形可解除（无30日等待）：未提供劳动保护/劳动条件；未**及时足额**支付报酬；未依法缴纳社保；规章制度违法损害权益；因第26条情形致合同无效；法律行政法规规定的其他情形
  - 两种情形可**立即解除、不需事先告知**：暴力、威胁或非法限制人身自由强迫劳动；违章指挥、强令冒险作业危及人身安全
  - **重大价值**：单位过错导致劳动者辞职的 → 劳动者可主张**经济补偿**（第46条一）——"被迫离职拿N"的法定通道
- **单位过错即时解除（第三十九条）**——无需预告、无补偿：
  1. 试用期被证明不符合录用条件
  2. **严重**违反规章制度（前提：制度合法+公示）
  3. **严重**失职、营私舞弊，造成**重大**损害
  4. 同时与其他单位建立劳动关系，对完成本单位工作造成**严重影响**，或经提出拒不改正
  5. 因欺诈等（第26条一款一）致合同无效
  6. 被依法**追究刑事责任**
  - 举证责任：单位对解除事由负举证责任
- **单位无过错预告解除（第四十条）——N+1 通道**：
  - 三种情形，提前**30日书面通知**或**额外支付一个月工资（代通知金）**后解除：
    1. 患病或非因工负伤，**医疗期满**不能从事原工作也不能从事另行安排的工作
    2. **不能胜任工作**，经**培训或调整岗位**仍不能胜任（培训/调岗是前置必经步骤）
    3. 订立时所依据的**客观情况发生重大变化**，合同无法履行，协商变更不成
  - 补偿：经济补偿（第46条三）
- **经济性裁员（第四十一条）**：
  - 裁减**20人以上**或不足20人但占职工总数**10%以上**
  - 程序：提前30日向工会或全体职工说明 + 听取意见 + 方案**报劳动行政部门**
  - 四种情形：破产重整；生产经营严重困难；转产/重大技术革新/经营方式调整变更合同后仍需裁减；其他客观经济情况重大变化
  - **优先留用三类**：较长固定期限合同；无固定期限合同；家庭无其他就业人员且有需要扶养的老人或未成年人
  - **六个月优先招用**：裁员后6个月内重新招用的，应通知被裁人员并同等条件优先招用
  - 补偿：经济补偿（第46条四）
- **第42条"六种人"保护（不得依40/41条解除）**：
  1. 接触职业病危害未做离岗前健康检查，或疑似职业病诊断/观察期
  2. 本单位患职业病或因工负伤并被确认**丧失或部分丧失劳动能力**
  3. 患病或非因工负伤，在规定的**医疗期内**
  4. 女职工**孕期、产期、哺乳期**
  5. 本单位**连续工作满15年且距退休不足5年**
  6. 法律法规规定的其他情形
  - 注意：第42条保护不阻却第39条过错解除（严重违纪等仍可解）；第44条合同期满时，有第42条情形的**续延至情形消失**（第45条）
- **工会程序（第四十三条）**：单位**单方解除**应事先将理由通知工会；工会认为违法有权要求纠正；单位应研究并将结果**书面通知工会**
  - 未事先通知工会 → ※司法解释一第47条：解除前补正（起诉前通知工会）的除外，构成程序违法
- **合同终止六情形（第四十四条）**：期满；享受基本养老保险待遇；死亡/宣告死亡失踪；单位破产；单位被吊销执照/责令关闭/撤销/提前解散；法律法规其他规定
  - 期满终止的补偿规则（第46条五）：除**单位维持或提高条件续订而劳动者不同意**外，固定期限合同期满终止**应付经济补偿**
  - 单位破产、被吊销/关闭/撤销/解散终止的 → 应付补偿（第46条六）
- **经济补偿 N 的计算（第四十七条）**：
  - 每满**1年**支付**1个月工资**；**6个月以上不满1年按1年**；**不满6个月支付半个月**
  - 月工资 = 解除或终止前**12个月平均工资**（应得工资，含奖金津贴）
  - **三倍封顶**：月工资高于当地上年度职工月平均工资**3倍**的，按3倍数额支付，且年限**最高不超过12年**
- **违法解除/终止（第四十八条、第八十七条）**：
  - 劳动者**选择权**：要求**继续履行** → 单位应当继续履行；不要求履行或已不能履行 → 单位支付**赔偿金**
  - 赔偿金 = **2×经济补偿**（第87条）
  - 拿到2N后不能再另要N（※司法解释一第87条：赔偿金与经济补偿不兼得）
- **离职后义务（第五十条）**：
  - 单位：解除/终止时**出具证明**；**15日内**办理档案和社保关系转移
  - 劳动者：按约定办理**工作交接**
  - 补偿支付时点：依本法应支付经济补偿的，**办结工作交接时支付**
  - 合同文本保存**至少2年**备查
  - 未出具证明造成损害（如影响再就业、失业金）→ 第89条责令改正+赔偿

## Key Concepts
- **代通知金（+1）**：第40条解除的替代通知方式，额外支付一个月工资
- **N / N+1 / 2N**：经济补偿（第47条）/ 无过错预告解除补偿+代通知金 / 违法解除赔偿金（第87条）
- **被迫解除**：第38条——单位过错致劳动者辞职并触发补偿
- **医疗期**：职工患病治疗期间不得解除的法定保护期（※《企业职工患病或非因工负伤医疗期规定》3–24个月）
- **离职证明**：单位法定义务，须写明合同期限、解除/终止日期、工作岗位、在本单位工作年限（※劳动合同法实施条例第24条）

## Mental Models
- "六通道"总图：协商（36）/ 劳动者30日预告（37）/ 劳动者即时-被迫（38）/ 单位过错即时（39）/ 单位无过错预告N+1（40）/ 裁员（41）——再叠加**第42条六种人**的"免疫区"（挡40/41，不挡39）
- 补偿判断口诀：38条被迫解→N；36条单位提出→N；40条→N+1；41条裁员→N；期满终止（单位未维持提高条件）→N；39条过错解→0；37条主动辞职→0；违法解/终→2N（或继续履行）
- 把"2N选择权"记牢：违法解除后，**劳动者**选继续履行还是拿钱——不要被动接受单位"给点钱让你走"的单一选项
- 裁员"20/10%"双触发 + 三程序（说明、听意见、报告）+ 优先留用三类 + 6个月优先招用

## Anti-patterns
- **用"严重违纪"口袋化解除**: 39条（二）要求规章制度合法+公示+行为确实"严重"——三者缺一即违法解除
- **"不胜任"直接开除**: 必须**先**培训或调岗，**仍**不胜任才能走40条（二）；跳过前置=违法
- **裁员不报劳动部门**: 41条程序缺"报告"环节即程序违法；未通知工会（43条）也是常见程序漏洞（※司法解释一第47条）
- **三期/医疗期员工被40/41条解除**: 第42条硬保护——命中即违法
- **不办离职证明**: 影响再就业或失业金领取 → 第89条责令改正+赔偿损失
- **"自愿离职"签字套取**: 单位诱导劳动者签"个人原因辞职"以规避N/2N——签字前看清措辞；已签的，若能证明受欺诈/胁迫，可主张撤销（举证难度高，尽量事前防范）
- **2N 与 N 混淆接受**: 单位报"补偿N"但实际是违法解除——先定性（有无39条事由/40条前置/42条保护），再谈金额

## Worked Example
员工赵某工作3年2个月，2025-04-10 公司以"业绩不佳"口头辞退，当日要求签"因个人原因辞职"的离职单。赵某未签，当日离岗。分析：
1. **定性**："业绩不佳"→ 若走40条（二）不胜任，须先培训/调岗（未做）→ 违法解除；口头辞退无书面理由、未通知工会 → 程序亦违法
2. **选择权**（第48条）：赵某可要求**继续履行**（恢复上班+补发离岗期间工资）；或放弃履行主张 **2N** = 3年2个月→按3.5年计N=3.5个月工资 → 2N=7个月工资
3. **反制套取**：拒签"个人原因辞职"（避免丧失补偿资格）；对口头辞退**录音**并要求公司出具**书面解除通知**（盖章）；当日离岗前保留考勤打卡
4. **离职手续**：若最终解除成立，单位须出具证明+15日内转移档案社保（第50条）；未出具的，影响失业金/再就业可另行索赔（第89条）
5. **程序**：劳动仲裁（※时效1年），主张违法解除赔偿金2N（或继续履行+工资损失）

## Key Takeaways
1. 解除六通道各有独立事由与程序：36协商/37预告30日(试用3日)/38被迫即时/39过错即时/40无过错预告(N+1)/41裁员(20人或10%)
2. 第42条"六种人"对40/41条解除免疫（职业病离检/工伤失能/医疗期/三期/满15年距退5年）
3. 补偿公式：N=年限×月工资（前12个月平均）；三倍社平封顶+12年上限（第47条）
4. 违法解除 → 劳动者二选一：继续履行 或 2N赔偿金（第48、87条）
5. 期满终止原则上应付N（单位维持/提高条件续订而劳动者不同意的除外，第46条五）
6. 离职三件事：书面证明 + 15日内档案社保转移 + 交接时付补偿（第50条）
7. 单方解除须事先通知工会（第43条），未通知是常见程序违法点
