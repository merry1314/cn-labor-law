# Chapter 7: 法律责任 (Legal Liability, 第80–95条)

## Core Idea
本章是劳动合同法的"罚则总表"，比《劳动法》第十二章更细、更重：**双倍工资**（未签合同/应签无固定，第82条）、**违法试用期赔偿金**（第83条）、**扣证罚款**（每人500–2000元，第84条）、**欠薪加付赔偿金**（应付金额50%–100%，第85条）、**2N赔偿金**（违法解除，第87条）、**派遣违法**（没收+1–5倍+每人5000–10000元+吊照，第92条）、**无资质用工**（出资人担责，第93条）、**个人承包**（发包组织连带，第94条）。

## Frameworks Introduced
- **规章制度违法（第八十条）**：违反法律法规 → 劳动行政部门**责令改正、警告**；造成损害 → **赔偿**
- **合同文本瑕疵（第八十一条）**：未载明必备条款或未将文本交付劳动者 → 责令改正；造成损害 → 赔偿
- **双倍工资（第八十二条）**：
  - 超1个月不满1年未签书面合同 → **每月二倍工资**
  - 违反规定不签无固定期限合同 → 自应订之日起**每月二倍工资**
  - ※计算口径（实施条例第6、7条）：二倍工资按应签之日次月起算；满一年视为订立无固定期限后不再支持
- **违法试用期（第八十三条）**：责令改正；已履行的 → 以**试用期满月工资**为标准，按**超过法定试用期期间**支付赔偿金
- **扣证/收财物（第八十四条）**：
  - 扣押身份证等证件 → 责令限期退还+依法处罚
  - 以担保或其他名义**收取财物** → 责令限期退还 + **每人500–2000元罚款** + 赔偿
  - 解除/终止时**扣押档案或其他物品** → 同上
- **欠薪四情形 + 加付赔偿金（第八十五条）**：
  - 未按约定/国家规定及时足额支付报酬；低于最低工资；安排加班不付加班费；解除终止未付经济补偿
  - 处理：劳动行政部门**责令限期支付**（差额、加班费、补偿）→ **逾期不支付** → 责令按**应付金额50%–100%加付赔偿金**
  - ※这是"加付"而非"替代"——原欠款项照常支付，赔偿金是附加
- **无效合同赔偿（第八十六条）**：第26条情形致合同无效，给对方造成损害 → **有过错方赔偿**
- **违法解除/终止（第八十七条）**：按第47条经济补偿标准的**二倍**支付赔偿金
  - ※与第48条选择权联动：继续履行 vs 2N；2N与N不兼得（※《劳动合同法实施条例》第25条）
- **强迫劳动与人身侵害（第八十八条）**：
  - 暴力、威胁、非法限制人身自由强迫劳动；违章指挥强令冒险作业危及人身安全；侮辱、体罚、殴打、非法搜查、拘禁；劳动条件恶劣环境污染严重致身心健康严重损害
  - 处理：依法**行政处罚**；构成犯罪 → **刑事责任**；造成损害 → **赔偿**
- **不出具离职证明（第八十九条）**：责令改正；造成损害（失业金、再就业损失）→ 赔偿
- **劳动者违约赔偿（第九十条）**：违法解除或违反保密/竞业限制约定，**给用人单位造成损失** → 赔偿
  - 注意：劳动者一方的金钱责任以"造成损失"为前提，且竞业限制补偿未付时责任受限（※司法解释一第38条：单位3个月未支付补偿的，劳动者可请求解除竞业限制约定）
- **招用未离职劳动者连带（第九十一条）**：给其他用人单位造成损失 → **连带赔偿**
- **派遣违法（第九十二条）**：
  - 未经许可经营 → 责令停止 + **没收违法所得** + 违法所得**1–5倍罚款**；无违法所得的 **5万元以下**罚款
  - 派遣单位/用工单位违反派遣规定 → 责令限期改正；逾期不改 → **每人5000–10000元罚款**；派遣单位**吊销**经营许可证
  - 用工单位给被派遣劳动者造成损害 → 与派遣单位**连带赔偿**
- **无资质用工（第九十三条）**：不具备合法经营资格的单位违法用工 → 追究违法犯罪责任；劳动者已付出劳动的 → 该单位**或出资人**支付报酬、经济补偿、赔偿金；造成损害 → 赔偿
  - ※个人独资、一人公司股东以财产逃避责任时的"刺破面纱"通道
- **个人承包连带（第九十四条）**：个人承包经营违法招用劳动者造成损害 → **发包组织与个人承包经营者连带赔偿**
- **监察渎职（第九十五条）**：劳动行政部门和其他主管部门及其工作人员玩忽职守、不履行法定职责或违法行使职权 → 赔偿；直接责任人行政处分；构成犯罪 → 刑责

## Key Concepts
- **双倍工资**：未签书面合同/应签无固定期限的惩罚性工资（第82条）
- **加付赔偿金**：逾期不支付欠薪的50%–100%附加（第85条）
- **2N**：违法解除赔偿金（第87条）
- **连带责任**：派遣损害（第92条）、招用未离职者（第91条）、个人承包（第94条）
- **出资人责任**：无资质用工时穿透到出资人（第93条）

## Mental Models
- "金钱责任阶梯"：工资报酬（本债）→ 经济补偿N（法定）→ 2N赔偿金（违法）→ 加付赔偿金50–100%（行政责令后逾期）→ 民事赔偿（实际损失）→ 没收+倍数罚款（行政对单位）→ 刑责（强迫劳动等）
- 劳动者索赔"打包"思路：同一事实常可多项请求并行——如违法解除=2N + 未签合同双倍工资 + 欠薪差额 + 未休年假折算 + 未缴社保损失
- 单位抗辩审查三问：事实（解除事由成立吗）？程序（通知工会/30日/报告）？主体（该赔的是派遣还是用工单位）？

## Anti-patterns
- **以"已发工资"抵充双倍工资**: 二倍工资中的"一倍"是惩罚，正常工资不能冲抵（※司法实践：二倍工资=已发工资+另付一倍差额）
- **把85条赔偿金当"谈判决价"**: 50–100%加付是**劳动行政部门责令**的行政措施，不是当事人自由约定——投诉是触发路径
- **无资质老板跑路**: 个体/小公司无资质或注销后欠薪——第93条出资人责任是重要追偿通道
- **发包单位甩锅个人承包**: 工程发包给无用工资格的个人，该个人招工人受伤/欠薪 → 第94条发包组织连带
- **竞业限制"只约束不付钱"**: 单位不付补偿金却主张违约金——劳动者可先催告支付，※3个月未付可请求解除约定（司法解释一第38条）

## Worked Example
某劳务公司（无派遣许可证）向某工厂"派遣"50名工人，其中与其中8人未签书面合同。工人发现后维权：
1. **非法经营**：劳动行政部门责令停止+没收违法所得+1–5倍罚款（第92条）
2. **未签合同8人**：每人自满1个月次日起每月双倍工资差额（第82条）——8人各可主张
3. **欠薪**：劳动部门责令限期支付，逾期不付→加付50–100%（第85条）
4. **连带关系**：若工厂（用工单位）造成损害 → 与劳务公司连带（第92条）；劳务公司无资质 → 其出资人对报酬、补偿、赔偿负责（第93条）
5. **组合策略**：集体投诉（监察处理非法派遣）+ 分别仲裁（各自双倍工资/欠薪）+ 必要时申请出资人承担（第93条）

## Key Takeaways
1. 未签合同/应签无固定 → 双倍工资（第82条）；违法试用期 → 超期赔偿金（第83条）
2. 扣证/收财物 → 退还+每人500–2000元罚款（第84条）
3. 欠薪四情形 → 责令限期支付，逾期加付50–100%（第85条）
4. 违法解除 → 2N（第87条）；不出离职证明 → 改正+赔偿（第89条）
5. 派遣违法 → 没收+倍数罚款+每人5000–10000元+吊照；用工损害连带（第92条）
6. 无资质用工 → 出资人担责（第93条）；个人承包 → 发包组织连带（第94条）
7. 强迫劳动、人身侵害 → 行政+刑事+赔偿三线并行（第88条）
