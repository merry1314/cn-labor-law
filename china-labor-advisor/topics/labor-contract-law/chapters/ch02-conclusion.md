# Chapter 2: 劳动合同的订立 (Conclusion of Labor Contracts, 第7–32条)

## Core Idea
订立章是劳动者保护最密集的章节：用工即建立劳动关系（第7条）、一个月内必须签书面合同否则双倍工资（第82条）、无固定期限合同强制触发情形（第14条）、试用期"四限"（第19条）、违约金只能出现在服务期与竞业限制两个口子（第25条）、无效合同三事由（第26条）。

## Frameworks Introduced
- **劳动关系建立时点（第七条）**：用人单位自**用工之日**起即与劳动者建立劳动关系——以实际用工为准，不以签合同为准
- **书面合同一个月规则 + 双倍工资（第十条、第八十二条）**：
  - 超过一个月不满一年未签书面合同 → 每月支付**二倍工资**
  - 满一年仍未签 → **视为已订立无固定期限劳动合同**（第14条第三款）
  - When to use: 未签合同劳动者的核心索赔依据；2N 基数之外的独立请求
- **无固定期限合同三种强制情形（第十四条）**：
  1. 连续工作满**10年**
  2. 初次实行合同制/国企改制重签时，连续工作满10年**且距退休不足10年**
  3. **连续订立二次固定期限合同**续订的（且劳动者无第39条、第40条一二项情形）
  - 劳动者提出或同意续订即应订立（除非劳动者自己要求固定期限）
  - 违反义务 → 自应当订立之日起每月支付**二倍工资**（第82条第二款）
- **试用期"四限"（第十九条）**：
  - 期限 3个月以上不满1年 → 试用≤**1个月**
  - 1年以上不满3年 → 试用≤**2个月**
  - 3年以上固定期限和无固定期限 → 试用≤**6个月**
  - **同一单位同一劳动者只能约定一次**；以完成一定工作任务为期限或期限不满3个月的**不得约定**
  - 试用期包含在合同期限内；只约定试用期的，试用期不成立，该期限视为合同期限
  - 违法约定已履行的 → 以试用期满月工资为标准，就超过法定期间支付**赔偿金**（第83条）
- **试用期工资底线（第二十条）**：≥本单位相同岗位最低档工资或约定工资的 **80%**，且 ≥ 当地最低工资标准
- **试用期解除限制（第二十一条）**：除第39条、第40条一二项情形外不得解除；解除须**说明理由**
- **九项必备条款（第十七条）**：单位信息、劳动者信息、合同期限、工作内容和工作地点、工作时间和休息休假、劳动报酬、社会保险、劳动保护/劳动条件和职业危害防护、其他法定事项
  - 缺条款/未交付文本 → 责令改正+赔偿（第81条）
- **报酬不明时的填充顺序（第十一条、第十八条）**：约定不明 → 按集体合同标准；无集体合同或集体合同未规定 → **同工同酬**
- **禁止扣押证件与收取财物（第九条、第八十四条）**：不得扣押身份证等证件、不得要求担保或收取财物；违者责令退还+按**每人500–2000元**罚款+赔偿
- **服务期与违约金（第二十二条）**：专项培训费用+专业技术培训 → 可约定服务期；违约金 ≤ 培训费用，且按服务期尚未履行部分**分摊**计算
- **保密与竞业限制（第二十三、二十四条）**：
  - 竞业限制人员限于**高管、高级技术人员和其他负有保密义务的人员**
  - 期限**不得超过2年**；期间单位须**按月支付经济补偿**
  - 劳动者违反 → 按约定支付违约金
- **违约金限定（第二十五条）**：除服务期（22条）和竞业限制（23条）外，**不得约定由劳动者承担违约金**——"提前离职赔X万"条款无效
- **无效合同三事由（第二十六条）**：欺诈/胁迫/乘人之危违背真实意思；单位免责排除劳动者权利；违反法律行政法规强制性规定
  - 无效由**仲裁机构或法院**确认；部分无效不影响其他部分（第27条）
  - 合同无效但已付出劳动的 → 参照相同/相近岗位支付报酬（第28条）
- **告知义务（第八条）**：单位招用时应如实告知工作内容、条件、地点、职业危害、安全生产状况、报酬等；单位有权了解与合同直接相关的基本情况
- **规章制度与合同冲突**：合同除必备条款外可约定试用期、培训、保密、补充保险、福利等（第17条第二款）

## Key Concepts
- **用工之日**：劳动关系建立的标志（第7条）
- **二倍工资**：未签书面合同/应签无固定期限而未签的惩罚性给付（第82条）
- **视为无固定期限**：满一年未签的拟制效果（第14条第三款）
- **同工同酬填充规则**：报酬不明的法定解决路径（第11、18条）
- **支付令**：拖欠/未足额支付报酬的快捷救济（第30条，见 ch03）

## Mental Models
- "签约时间轴"模型：第1天（用工=建立关系）→ 第1个月内（必须签合同）→ 第1个月–12个月（未签则双倍工资）→ 满1年（视为无固定期限）——每个节点都是独立请求权
- 试用期"四限一禁"：期限四档 + 只准约定一次 + 短合同/任务合同禁止——超档部分直接无效并按第83条赔偿
- 违约金"两口子"：劳动者违约金只可能出现在服务期与竞业限制，其余一律无效——看到其他违约金条款直接主张无效
- 竞业限制"三要件才有效"：适格人员 + 2年内 + 按月补偿——单位没付补偿金时，劳动者可主张解除竞业限制（※司法解释一第36条等）

## Anti-patterns
- **以"培训费"为名约定天价违约金**: 仅限**专项**培训费用（22条），普通入职培训费不算；违约金超培训费或未按未履行部分分摊的，超出部分无效
- **全员签竞业限制**: 竞业限制限于高管、高技、其他保密人员（24条）；普通员工无保密义务的竞业条款效力存疑
- **只约定试用期**: 试用期不成立，整个期限视为合同期限（19条）
- **扣押证件/收押金**: 入职收身份证原件、收服装押金/培训押金——直接违法（9条+84条），可向劳动监察投诉责令退还并处罚
- **格式合同"自愿放弃一切权利"**: 排除劳动者权利的条款无效（26条）

## Worked Example
李某 2024-03-01 入职某公司，公司一直未签书面劳动合同，2024-08-15 单方辞退。请求权梳理：
1. **双倍工资**（第82条）：自2024-04-01（满1个月次日）起至2024-08-15（实际用工不满一年），每月双倍工资差额——约4.5个月
2. 若李某已满足"连续订立二次固定期限合同"等情形且公司未签无固定期限 → 自应签之日起双倍（本案首份合同，不适用）
3. **违法解除赔偿金**：公司未说明解除理由/无第39条事由 → 第48条+第87条 → 2N（工作不满6个月→0.5个月工资×2=1个月工资）
4. 入职时被扣身份证 → 第84条：劳动监察责令退还
5. 程序：向劳动仲裁委申请（※时效1年），证据：工资流水、考勤、工牌、工作群记录（证明用工事实）

## Key Takeaways
1. 用工之日=劳动关系建立（第7条），书面合同只是一个月的"补签窗口"
2. 未签书面合同：1个月–1年 → 双倍工资；满1年 → 视为无固定期限
3. 无固定期限合同三种强制情形，满10年/两连签是最常见触发点
4. 试用期四档上限+只约定一次+短合同禁约；违法履行部分按第83条付赔偿金
5. 劳动者违约金只有服务期、竞业限制两个合法出口（第25条）
6. 扣押证件、收财物 → 行政责令退还+罚款（每人500–2000元）
7. 无效合同三事由 + 已付出劳动照样付酬（第28条）
