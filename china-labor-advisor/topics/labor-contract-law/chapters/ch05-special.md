# Chapter 5: 特别规定 (Special Provisions, 第51–72条)

## Core Idea
三个特别用工形态各有独立规则：**集体合同**（工会签约、15日生效、地板标准）、**劳务派遣**（三性岗位+比例控制+同工同酬+连带责任）、**非全日制用工**（小时计酬、口头协议、随时终止、15日结算周期）。

## Frameworks Introduced

### 第一节 集体合同（第五十一至五十六条）
- **订立主体与程序（第五十一条）**：
  - 企业职工一方与用人单位平等协商，就劳动报酬、工时、休息休假、安卫、保险福利等订立
  - 草案须提交**职代会或全体职工讨论通过**
  - 工会代表职工方签订；无工会的由**上级工会指导**劳动者推举代表签订
- **专项集体合同（第五十二条）**：劳动安全卫生、女职工权益保护、工资调整机制等可单独订立
- **行业性/区域性集体合同（第五十三条）**：县级以下区域内，建筑业、采矿业、餐饮服务业等行业可由工会与企业代表订立——对当地本行业本区域用人单位和劳动者有约束力
- **生效程序（第五十四条）**：报送劳动行政部门；**15日内未提出异议即生效**
- **地板标准（第五十五条）**：
  - 集体合同标准 ≥ 当地政府规定的最低标准
  - **个人劳动合同标准 ≥ 集体合同标准**
- **违约救济（第五十六条）**：单位违反集体合同侵犯职工权益 → 工会可依法要求承担责任；履行集体合同争议协商不成 → **工会可申请仲裁、提起诉讼**

### 第二节 劳务派遣（第五十七至六十七条）
- **经营许可（第五十七条）**：注册资本 ≥ **200万元**；固定经营场所设施；符合规定的管理制度；须向劳动行政部门申请**行政许可**
  - 未经许可经营 → 责令停止+没收违法所得+违法所得1–5倍罚款；无违法所得的5万元以下罚款（第92条）
- **派遣单位义务（第五十八条）**：
  - 是"用人单位"，履行用人单位义务
  - 合同载明用工单位、派遣期限、工作岗位
  - 必须订立**2年以上固定期限**合同，按月支付报酬
  - **无工作期间**按所在地**最低工资标准**按月支付
- **派遣协议（第五十九条）**：派遣单位与用工单位订立，约定岗位、人数、期限、报酬社保数额与支付方式、违约责任
  - 用工单位不得将连续用工期限**分割**订立数个短期派遣协议
- **费用禁令（第六十条）**：不得克扣用工单位支付的报酬；派遣单位和用工单位**不得向被派遣劳动者收取费用**
- **跨地区派遣标准（第六十一条）**：按**用工单位所在地**标准执行
- **用工单位义务（第六十二条）**：执行劳动标准、提供劳动条件保护；告知要求与报酬；支付加班费、绩效奖金、相关福利；在岗培训；连续用工实行正常工资调整机制；**不得再派遣**到其他单位
- **同工同酬（第六十三条）**：被派遣劳动者享有与用工单位劳动者**同工同酬**权利；相同岗位相同分配办法；无同类岗位的参照所在地相同/相近岗位
- **退回与解除（第六十五条）**：被派遣劳动者可依第36条、第38条与**派遣单位**解除合同；有第39条、第40条一二项情形的，用工单位可**退回**派遣单位，派遣单位依法可解除
- **"三性"岗位限制（第六十六条）**：
  - 劳务派遣只能在**临时性**（存续≤6个月）、**辅助性**（非主营业务）、**替代性**（劳动者脱产学习/休假等无法工作期间替代）岗位实施
  - 用工总量比例：不得超过**10%**（※《劳务派遣暂行规定》2014）
- **自派禁止（第六十七条）**：用人单位**不得设立**劳务派遣单位向本单位或所属单位派遣

### 第三节 非全日制用工（第六十八至七十二条）
- **定义（第六十八条）**：以小时计酬为主；同一单位平均**每日≤4小时**、**每周累计≤24小时**
- **口头协议可以（第六十九条）**：可不签书面合同；劳动者可与**一个以上**单位订立合同（后订的不得影响先订的履行）
- **不得约定试用期（第七十条）**
- **随时终止（第七十一条）**：任何一方**随时通知**即可终止；**不支付经济补偿**
- **报酬底线（第七十二条）**：小时计酬 ≥ 当地**最低小时工资标准**；结算支付周期**最长不超过15日**

## Key Concepts
- **集体合同地板**：个人合同不得低于集体合同标准（第55条）
- **行业性/区域性集体合同**：突破单一用人单位的集体协商形态（第53条）
- **三性岗位**：临时性/辅助性/替代性——派遣合法性的岗位限定（第66条）
- **10%比例**：派遣用工占用工总量的上限（※暂行规定第4条）
- **再派遣禁止**：用工单位不得将被派遣劳动者再派遣（第62条）
- **非全日制双工**：可同时为多个单位提供非全日制劳动（第69条）

## Mental Models
- 派遣关系"三方两合同"模型：派遣单位—被派遣劳动者（劳动合同，≥2年固定）+ 派遣单位—用工单位（派遣协议）→ 劳动者的"单位"是派遣公司，但工作地点、管理、加班费在用工单位——出险时责任分配是关键
- 同工同酬是派遣制度的核心保障：同岗同酬，跨地区按用工单位所在地标准（第61、63条）
- 非全日制 = "高灵活 + 低保障"：口头协议、随时终止、无补偿——但底线仍在（最低小时工资、15日结算、禁试用期）
- 集体合同三层地板：国家最低标准 ≤ 集体合同 ≤ 个人合同——自下而上逐层抬高

## Anti-patterns
- **"假外包真派遣"**: 以劳务外包名义规避派遣比例与三性限制——※司法实践按实质用工关系认定；外包人员被直接管理指挥的，可能被认定为派遣甚至劳动关系
- **自派**: 公司设立关联派遣公司给自己"派遣"员工 → 第67条禁止，且规避同工同酬/比例控制的目的落空
- **派遣岗位泛化**: 主营业务岗位长期派遣 → 违反"三性"限制（第66条）
- **无工作期间停发工资**: 派遣员工退回后无工作期间，派遣单位仍须按最低工资按月支付（第58条）
- **非全日制月结/拖欠**: 结算周期超15日 → 违反第72条
- **集体合同"走过场"**: 未经职代会讨论通过、未报送劳动行政部门 → 程序瑕疵影响效力与约束力

## Worked Example
小周被某科技公司"外包"至某银行前台，实际由银行直接考勤、排班、考核，连续工作3年，工资低于银行同岗正式员工30%。分析：
1. **定性**：由用工单位（银行）直接管理指挥 → 构成"假外包真派遣"（※按实质认定）
2. **岗位合法性**：银行前台属主营业务岗位 → 非"辅助性"，违反第66条"三性"限制
3. **同工同酬**（第63条）：工资低于同岗正式员工 → 可主张差额（以银行同岗分配办法为参照）
4. **合同期限**：若与派遣公司合同为1年 → 违反第58条"2年以上固定期限"
5. **比例**：银行派遣用工超10%的，超出部分不合规（※暂行规定）
6. **救济**：向劳动监察投诉（派遣违规由劳动行政部门责令改正，逾期按每人5000–10000元罚款，第92条）+ 仲裁主张同工同酬差额；若与派遣公司存在劳动关系，解除补偿向派遣单位主张，用工单位对损害承担**连带赔偿责任**（第92条）

## Key Takeaways
1. 集体合同：职代会通过 → 工会签约 → 报送15日无异议生效；个人合同标准不得低于它（第55条）
2. 派遣：200万注册资本+行政许可；2年以上固定期限；无工作期付最低工资；三性岗位+10%比例；同工同酬；不得再派遣、不得自派
3. 派遣损害：用工单位与派遣单位**连带赔偿**（第92条）
4. 非全日制：日4小时/周24小时；可口头、可多雇主；无试用期；随时终止无补偿；小时工资有底线、15日内结算
5. 违规派遣的行政责任：没收违法所得+1–5倍罚款；逾期不改按每人5000–10000元罚款+吊照（第92条）
