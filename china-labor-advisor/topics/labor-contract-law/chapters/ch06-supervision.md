# Chapter 6: 监督检查 (Supervision, 第73–79条)

## Core Idea
劳动合同制度实施由劳动行政部门**统一监督**（第73条），监察事项七类明确列举（第74条），监察员"出示证件+文明执法"（第75条），行业主管部门分责共管（第76条），劳动者救济与工会支持双通道（第77、78条），任何组织个人均可举报且有奖励（第79条）。

## Frameworks Introduced
- **监督体系分工（第七十三至七十六条）**：
  - 国务院劳动行政部门 → 全国劳动合同制度监督管理
  - 县级以上地方劳动行政部门 → 本行政区域
  - 建设、卫生、安全生产监督管理等有关主管部门 → 各自职责范围内监督管理
  - 监督工作中应当听取**工会、企业方面代表及有关行业主管部门**意见
- **七类监察事项（第七十四条）**：
  1. 直接涉及劳动者切身利益的**规章制度**制定与执行情况
  2. 劳动合同**订立和解除**情况
  3. **劳务派遣**单位和用工单位遵守派遣规定的情况
  4. 遵守**工作时间和休息休假**规定的情况
  5. 支付**劳动报酬**和执行**最低工资标准**的情况
  6. 参加**社会保险**和缴纳**社会保险费**的情况
  7. 法律法规规定的其他监察事项
  - When to use: 劳动者投诉时对照七类确定管辖与事由
- **监察权与程序（第七十五条）**：
  - 权力：查阅与劳动合同、集体合同有关的材料；对劳动场所**实地检查**
  - 义务：用人单位和劳动者都应**如实提供**情况和材料；监察员须**出示证件**、依法行使职权、**文明执法**
- **劳动者救济权（第七十七条）**：合法权益受侵害 → 有权要求有关部门**依法处理**，或依法**申请仲裁、提起诉讼**
- **工会监督与支持（第七十八条）**：
  - 工会对单位履行劳动合同、集体合同情况**监督**
  - 单位违反劳动法律法规和合同的 → 工会有权**提出意见或要求纠正**
  - 劳动者申请仲裁、提起诉讼的 → 工会依法给予**支持和帮助**
- **举报与奖励（第七十九条）**：任何组织或个人对违反本法的行为都有权**举报**；劳动行政部门应当**及时核实处理**；对**举报有功人员给予奖励**
  - When to use: 匿名/实名举报渠道；配合监察调查的激励依据

## Key Concepts
- **劳动合同监察**：以劳动合同制度实施为核心的行政监督（第73–76条）
- **如实提供义务**：用人单位和劳动者对监察检查的双向配合义务（第75条）
- **举报奖励**：举报有功人员的法定奖励（第79条）
- **工会支持**：工会对劳动者仲裁诉讼的法定帮助职责（第78条）

## Mental Models
- "一主多辅"监督格局：劳动行政部门为主监察（七类事项），行业部门分责（建设管建筑、卫生管职业卫生、应急管安全），工会与社会监督兜底
- 劳动者手里的三张牌：要求有关部门处理（行政）+ 仲裁/诉讼（准司法）+ 工会支持（组织）——三张牌可并行打出
- 举报有奖励：第79条的奖励条款是劳动者/公众参与的法定激励，举报后应及时跟进核实结果

## Anti-patterns
- **以"内部资料"对抗监察**: 第75条规定用人单位应当如实提供情况和材料——拒提供、伪造台账将承担相应责任（※《劳动保障监察条例》第25条：阻挠监察可处2000–20000元罚款，情节严重最高10万元）
- **监察员不出示证件**: 劳动者/单位有权要求核验——但不等于可以拒绝配合法定检查
- **忽视行业部门分责**: 建筑工程欠薪、职业卫生问题对口部门不同，投诉找错门会拖时间（※农民工工资问题还有《保障农民工工资支付条例》专门机制）
- **只仲裁不投诉**: 行政处罚（责令支付、罚款）与个人请求权并行，投诉能形成行政压力，仲裁解决个人损失——双管齐下

## Worked Example
某公司未签劳动合同、拖欠工资、超时加班。劳动者老陈的"组合拳"：
1. **劳动监察投诉**（第74条第2、4、5项：订立合同、工时休假、报酬与最低工资）→ 劳动行政部门查阅材料、实地检查（第75条）→ 责令改正/支付（第80、81、85条责任）
2. **仲裁**（个人请求权）：双倍工资（第82条）+ 工资差额 + 加班费
3. **工会支持**（第78条）：向公司工会或当地总工会反映，请求支持与帮助
4. **举报**（第79条）：对违法事实举报，配合调查，举报有功可获奖励
5. 监察中公司拒提供工资台账 → ※监察条例第25条可处罚——老陈如实提供自己所知情况与证据

## Key Takeaways
1. 七类监察事项（第74条）是劳动者投诉的"目录"：规章制度/合同订立解除/派遣/工时休假/报酬与最低工资/社保/其他
2. 监察员须出示证件（第75条）；单位与劳动者均应如实提供材料
3. 劳动者救济双轨：要求部门处理（行政）+ 仲裁/诉讼（第77条），可并行
4. 工会有权要求纠正违法，并支持劳动者仲裁诉讼（第78条）
5. 举报受保护且有奖励（第79条）——任何组织和个人均可
